## 1. 链路的精确定义与构造规则

### 1.1 用哪个图：三张图必须分开

人问"链路是否具有语义"，前提是**哪张图的链路**。本仓同时存在三种可被称为"链路"的东西（B：`kg-ontology-v0.md:31-56`；G3 §1.1）：

| 图 | 内容 | 能否当 L3 候选来源 | 依据 |
|---|---|---|---|
| **G_sem（语义边图）** | `edges[]`，`type ∈ {contain, extend, reference}`，清洗 8 条退化边后 54 条 | **是（唯一）** | G1 §2.3：`reference` 按定义无断言须从语义边集剔除或单列；告警：清洗后仍只有 contain/extend |
| **G_nav（导航锚点图）** | `links[]`：正文锚点，3 条 / 5 instances，**不承诺语义关系** | **否**，单列"导航链"（G1） | `kg-ontology-v0.md:48-56` |
| **G_derived（派生相似）** | co-citation / bibliographic coupling 查询时算 | **绝对否** | G3 规则③④：物化立即多 57 对伪边（≈ 现有边数 92%） |

> **规则 D-SRC**：L3 的候选链**只从 G_sem 枚举**。任何"从名字/共引/相似度拼出来的链"不得进入 L3 正例集；若要研究，按 §5.5 的替代方案 (b) 单列，且**不得称其为"图的链路语义"**。
> 依据：G1 §2.3 + G1 §5.3 + G3 规则③④（≥2 B 源）。

### 1.2 形式定义（预注册，改口径须整轮重来）

```
链路（chain）c = (v0, e1, v1, e2, …, ek, vk)

C1 有向      e_i 必须是 G_sem 中存在的边 v_{i-1} → v_i（方向不可省；对称谓词另标）
C2 跳数      k ∈ {2, 3}
C3 节点上限  |V(c)| = k+1 ≤ 4
C4 简单路径  所有 v_i 互不相同；所有 e_i 互不相同（同一对节点若有多条不同类型边，算不同链路）
C5 身份      节点身份 = kp_id（稳定 ID），**不是 name**（见 §1.3）
C6 谓词序列  σ(c) = (pred(e1), …, pred(ek))，pred ∈ {P1..P5, D}（G2 §1 定义；**当前 raw 枚举仅为占位**，见 §1.3）
C7 退化排除  链中任一边不得是 8 条退化 contain 边（7 同名 + 1 OCR）
C8 链路身份  id(c) = (有序 kp_id 序列, 有序谓词序列)；**反序是另一条链路**（对称谓词 P4/P5 除外，见 §3.2-N1）
```

**关键补充（必须写进任何实现）**：
- **k ≥ 2 的理由**：1 条边是 L2 的评价对象；k=1 会与 L2 重叠，失去"链路"这一评价单元（G1 §5.3）。
- **k ≤ 3 的理由**：① 组合语义每多一跳多一次组合失败机会，人判认知负荷与歧义上升；② 当前图 k=4 的候选为 0（§5.1）；③ L2 尚未给出 P1–P5，长链的组合表无法先验写全。**本项目假设**，触发条件：图扩充后若 k=3 的 α 与判别力不劣于 k=2，则保留；否则降为 k=2（见 §1.4 falsifier）。
- **"能否重复"**：同一节点/边不得在一条链内重复；同一链路不得重复计入样本（不同窗口重叠要在抽样时处理，见 §4.5）。

### 1.3 名字 vs 身份：一个必须更正的事实（B，本轮新增）

G1/G2 把 8 条退化 `contain` 边描述为"同名**自指**"。本轮逐条核对 `G2-edge-inventory-raw.json` 与冻结 sidecar 的 `range` 后发现：**7 条"同名"边其实不是 id 自环，而是两个不同 identity 同名、且 range 同起点嵌套**：

```
※线性相位理想低通滤波器  img-ch2-3-126 → img-ch2-3-125
    （id 不同、name 相同；两端 start line_hint 都是 3410，end 分别为 3429 / 3413 ⇒ 前者范围包含后者）
连续时间Fourier变换的性质  img-ch2-3-87 → img-ch2-3-85
    （id 不同、name 相同；两端 start line_hint 都是 2192，end 分别为 2305 / 2202 ⇒ 包含）
…共 7 对；第 8 条是 OCR 错名（目标 id 存在，名字多一个"传"字）
```

⇒ 三个后果，直接改 L3 设计：
1. **链路构造必须用 `kp_id`**：若按名字构造，这 7 对会生成"A→A"式的视觉自环，判据者会当成坏题而被 trivial 排除；按 id 构造它们是合法 2 节点序列，但**语义上仍是无信息的重复标题**（G2 判据判退化）。
2. **方向不是"按 id 顺序"**：实测边方向是 **126→125 / 87→85**（原文 `contain` 的 outer→inner），引用时不得写成 125→126 / 85→87。
3. **判据表呈现必须 id+name 同时给**，否则 36 组同名 / 114 个 KP（31.9%，G3）会让判据者无法区分"同名不同指"。
   > 这是对上游"同名自指 / 相邻"措辞的**事实性更正**（不影响 G2 的清洗结论，只影响链路构造与呈现口径）。已作为待登记项 §8-GUE-IDEA-010。

## 2. 「有语义」的可操作判据

### 2.1 为什么必须分级，不能压成一个比率

G1 §2.3 已证明边级"语义合格率"会被 `reference`（无断言）与 `contain`（结构派生）稀释；**链路层完全同构且更严重**：
- 一条 `contain` 祖先链**永远为真**（父子层级），但零新信息（G1 §5.3 明确"非冗余/有信息量"是必要条件）；
- 一条 `extend` 的"按节顺序"链（G2 的 D 标签）也**永远为真**（章节确实按此顺序），但不是语义关系；
- 一条只含 `reference` 的链连"真值"都没有（P5 无断言）。

⇒ 若把上述都算进"有语义"分子，会得到"链路语义率很高"的假阳性；若都算进分母又不区分，则数字不可解释。**做法：分级报告（G0–G4）+ 每条链路给"最低通过档"，不做单一比率。**

### 2.2 分级定义（预注册；每级给出**可由判据项机械推导**的规则）

| 级 | 名称 | 成立条件（所有级都要求：链中每跳在 L2×S 上有效，退化边排除） | 计不计入"有语义"分子 |
|---|---|---|---|
| **G0** | 无效/不可判 | 任一跳为假/无支撑；或链不可复述（C1=不能）；或判据者多数"不确定" | 否 |
| **G1** | 仅导航 | 含 ≥1 条 P5（无断言）或仅含 P4（对称对比），不能形成命题，只能"跳转/并列" | 否（单列） |
| **G2** | 仅结构/仅顺序 | 全为 P1（结构包含）或全为 D（仅章节顺序）：**陈述为真但无新增信息**（G1 §5.3-⑤不成立） | 否（单列，这正是"稀释源"） |
| **G3** | 有语义 | 每跳有效 + 组合文法合法（§2.4）+ 可复述为一句陈述（C1=能）+ 真值有文本支撑（C2=真）+ 非冗余（C3=有新增信息） | **是** |
| **G4** | 有用 | G3 + 能支撑一个真实提问/推理步骤（C4=有；需 CQ/gold 链） | 是（另一分子，需 G6） |

> **报告纪律**：任何"链路语义率"必须同时给 **G3/(G0..G3)** 与 **G3+G4 占比**，并单列 **G2 结构/顺序链比例**；禁止把 G2 并入分子（G1 §2.3 同一逻辑）。

### 2.3 五个候选判据（≥3 要求满足；各自失效条件写死）

#### K1 可复述陈述判据（主判据之一）

- **操作**：盲化呈现链路（节点 id+name+章节+首句 + 每跳谓词用词）；判据者先写"这句话"（一句陈述），再判该句真值（真/假/无支撑）与来源（能在给定原文片段找到支撑吗：能/不能）。
- **能证明什么**：链路在**人可读层面**是否有可表述语义；能抓"拼得出来但不真"。
- **失效条件（写死）**：① **编造**——判据者能写出通顺但与文本无关的句子（G1 §5.3-① 已警告）⇒ 必须配"来源支撑"与"全文核验子研究"（§4.3）；② **复合句变模糊**——长链靠"从而/因此"连词硬拗成立；③ 不覆盖"有用"（那是 K3/K5）。
- **现在能否用**：可试跑（仅当 L2 先给出每跳有效性）。

#### K2 组合文法判据（主判据之一）

- **操作**：用 §2.4 的**组合表**把谓词序列 `σ(c)` 机械分类为：可折叠为单谓词 / 可陈述复合命题 / 不可组合；不可组合直接判 G1 或 G0（视单跳有效性）。
- **能证明什么**：链路不是"边的堆叠"而是有**组合语义**；可把"每跳都真但组合是误导"的链路抓出来（这正是 N3 负例要考的）。
- **失效条件（写死）**：① **合法 ≠ 真**：P2∘P2 合法但某一跳可为假 ⇒ 必须与 K1/每跳真值合取；② **表本身错**：若人判对"表判合法"与"表判不可组合"两组的"有意义"比例差 <10pp，则表不 tracking 语义 ⇒ 回炉改表（falsifier）；③ 表依赖 L2 谓词，L2 未跑前只能用 raw 枚举占位。
- **现在能否用**：表可先写（A 源支撑），**校验必须等 L2**。

#### K3 独立 gold 链判据（最强，但当前不可用）

- **操作**：先建 CQ/真实问题集 + **独立于图**从原文标注 gold 推理链（节点序列+谓词）；再测候选链对 gold 链的 precision/recall。
- **能证明什么**：链路的**任务效用**（最贴近人的"有用"）。
- **失效条件**：**循环**——若 gold 链从图里抽，就是自证（G1 §5.3-②）。必须"从原文标、标注者不看图"。
- **现在能否用**：❌ 无 CQ 集、无 gold 链（G1 §7.1-2）。依赖 G2 §3 的最小任务集设计。

#### K4 匹配负例判别力（效度闸，不是主判据）

- **操作**：构造 §3 的 N1–N3 难度匹配负例，与 G3 正例混排盲判；算 balanced accuracy / AUROC。
- **能证明什么**：链路表示是否**携带可区分语义**（判别力）。
- **失效条件（写死）**：① **trivial separation**——负例可由"是否同文件/是否共词"等简单规则区分（§3.1 已量化：单规则 ≈0.87）⇒ 必须做 matched 设计 + 简单规则基线检查；② **只证"可区分"不证"为真"**——判别力通过 ≠ 语义成立；③ 负例合成偏差（合成负例的措辞指纹）⇒ 正负例呈现必须同模板。
- **现在能否用**：客观基线可算；人判判别力需样本与 L2。

#### K5 消融必要性（U 轴主判据，当前不可用）

- **操作**：任务集三条件：全图 / 去目标链的边 / 去随机等量边；Δ_targeted − Δ_random + 配对检验。
- **能证明什么**：该链路对任务**必要**（不是"存在且真"，而是"少了它就变差"）。
- **失效条件**：**按构造不可测**——agent 路径完全不读边（B：`kg-ontology-v0.md:20`）⇒ Δ 恒 0，不是效应小而是通路不存在（G2 §3.1 同结论）。
- **现在能否用**：❌ 等 G6 接线。且单链必要性统计功效不足，按 G2 §3.3 只做案例研究。

#### 判据组合规则（预注册）

```
链路"有语义"（G3）  ⇔  K2 合法  ∧  K1 可复述且真  ∧  C3 非冗余  ∧  每跳 L2 有效
链路"有用"（G4）    ⇔  上式  ∧  K3 gold 链命中（或 K5 消融为正，二者之一）
K4                 只用于：报告判别力 / 检验负例是否太易，**不进入单条链路判定**
```

### 2.4 谓词组合文法表（预注册草案，待 L2 回填谓词）

**方向约定**：`v0 —P→ v1` 表示"v0 与 v1 之间是 P"。组合指 `v0 —P→ v1 —Q→ v2`。

| 组合 | 语义 | 分类 | 说明 / 依据 |
|---|---|---|---|
| P1∘P1 | part-of 传递 | **可折叠为 P1，但降级 G2** | 折叠后仍是结构信息（G2 §1 P1）；且当前图 **无** P1∘P1 候选（§5.1） |
| P2∘P2 | prerequisite 传递 | **可折叠为 P2（G3 候选）** | 传递性见 G2 §1 P2；折叠出新知识（"要懂 C 必先 A"） |
| P3∘P3 | is-a 传递 | **可折叠为 P3（G3 候选）** | G2 §1 P3 标传递 |
| {P1,P2,P3} 混合 | 复合命题 | **可陈述（G3 候选）**，不得折叠为单谓词 | 如 P2 后接 P1："要理解 B 先 A，而 B 是 C 的一部分"——可读，但不能说成单条边 |
| 含 P5（任意） | 无断言 | **不可组合（G1 导航链）** | P5 不承诺真假（G2 §1 P5） |
| 含 P4（任意） | 对称对比 | **不可组合（G1）**；P4∘P4 也不传递 | G2 §1 P4：对称、不传递、不可与 P1/P2/P3 组合 |
| 含 D（任意） | 仅文档顺序 | **不可组合（G2/D 降级）** | D 不是语义谓词（G2 §1 D） |

**A 源锚点**：OWL 2 property chains（复合属性可定义传递/链式语义）https://www.w3.org/TR/owl2-syntax/#Property_Chains ；SPARQL 1.1 property paths（路径表达式的语义仅"可达"，**不等于命题真值**）https://www.w3.org/TR/sparql11-query/#propertypaths 。
**明确错配警告**：meta-path/PathSim 只把"类型化路径"当相似度输入，**不定义命题真值**（A：Sun et al. 2011），**不能**用来填这张表。

### 2.5 合格线（初值；G4 之后用 pilot 校准，不得当产品门禁）

| 指标 | 初值 | 依据 |
|---|---|---|
| K1 可复述且真 且 可溯源（G3 中"真+支撑"比例） | ≥70%（pilot 只报点估计+CI） | 沿用 G1 §5.3 初值 |
| K2 表与人工"有意义"判断的一致性 | 两组"有意义"比例差 <10pp 才算表可用 | 本项目假设（表 falsifier） |
| K4 balanced accuracy（hard 档） | ≥0.80 **且** 同时报平凡规则基线与人类上限 | G1 §5.3 合格线 + R6 |
| 一致性 α | **四档**：≥0.80 证据；0.667–0.80 暂定+扩样；0.50–0.667 marginal+扩样；<0.50 重来（不得压成单阈值） | G2 §2.4 预注册 + A（Krippendorff 2004） |
| G2 结构/顺序链占比 | 必须报告；>50% ⇒ 该图"链路语义"结论不成立 | G1 §5.3 放弃条件 |

## 3. 负例构造规范 + 难度校准

### 3.1 先证明"随机负例太容易"（可计算，B；**帧必须写明**）

`G4-path-census.json.trivial_separation_frames`。**同样叫"随机对"，帧不同数字差 1–2 个数量级 —— 引用必须带帧名**：

| 帧（universe / 边集） | 有序对 | 相邻 | 同弱分量 | 有向可达 | 同文件 | 平凡规则 BA：`同文件` | 平凡规则 BA：`3 节点同文件` | 平凡规则 BA：`同分量` |
|---|---|---|---|---|---|---|---|---|
| `all_357_over_raw_graph`（357 / 62 边 raw） | 127,092 | 0.049% | **0.634%** | **0.097%** | **27.98%** | **0.860** | 0.948 | 0.997 |
| `all_357_over_clean_graph`（357 / 54 边） | 127,092 | 0.043% | 0.618% | 0.0905% | 27.98% | **0.860** | 0.948 | 0.997 |
| `raw_79_62`（79 / 62 边 raw） | 6,162 | 1.01% | 13.1% | 2.00% | 26.2% | **0.869** | 0.962 | 0.935 |
| `clean_65_54`（65 / 54 边 clean） | 4,160 | **1.30%** | **18.9%** | 2.76% | **26.3%** | **0.869** | 0.958 | 0.906 |

**帧口径（复核 FAIL-1 修正后）**：357 帧的 universe = **全部 357 个 KP**（从 11 个 frozen sidecar 读 `KP.id → file`；**357/357 都有非空 file**，共 **9 个文件含 KP**，另有 2 个 sidecar 的 KP 数为 0）⇒ 同文件有序对 **35,558**、p=**27.98%**、BA=**0.860**（raw/clean 相同）。79/65 帧的 universe = 被边覆盖节点（79/65），同文件分子相应为 1,612 / 1,094。
> **v2 的 1.27%/0.86%/0.994* 是错的**：那两行把"边端点映射"（79/65 帧的数）当成了 357 帧的分子、分母却用 127,092 —— 分子/分母混帧；"孤立节点无 file"的前提也不成立（实测 357/357 有 file）。已在 census v3 修正（`G4-path-census.json.node_file_coverage`）。

**含义**：正例（23 条 2 跳链）**全部同文件、全部在最大块**。若负例取随机节点对：
- 规则"两端同文件 ⇒ 判正"：BA = (1 + P(不同文件))/2 = **0.860（357 帧）/ 0.869（79、65 帧）**；
- 规则"全部 3 节点同文件 ⇒ 判正"（链的完整形态）：**0.948（357 帧）/ 0.958–0.962（79/65 帧）**；
- 规则"同弱分量 ⇒ 判正"：**0.997（357 帧）/ 0.906–0.935（79/65 帧）**。

**全部 ≥ 0.86，已超过 G1 给 L3 定的 0.80 balanced-accuracy 合格线。** ⇒ **随机负例上得到的任何"区分度 0.86+"一律作废重造**（不是判据者强，是负例太弱）。
复核员独立复算的 `0.634% / 0.097%` 与本表 `all_357_over_raw_graph` 帧**完全一致**；其第二轮报的 357 帧同文件 **35,558 / 27.98% / BA 0.860** 与本文修正后**完全一致**；其第一轮报的 `0.8706` 与本文 79/65 帧 `0.869198 / 0.86851` 相差 ≤0.002，属 pair 级近似 vs 链形态的口径噪声（均 >0.80，结论不变）。

> 依据：R6（先构造必须失败用例）+ A：Jia & Liang 2017（可被平凡规则/系统解决的测试不能证明理解）+ B：本轮普查数字（`G4-path-census.json`）。

### 3.2 负例族 N0–N6（构造规范；写死"什么不能用"）

| 族 | 构造方法 | 难度档 | 现在可构造性 | 能否用于判别力指标 |
|---|---|---|---|---|
| **N0 trivial** | 随机节点对 / 跨章无关主题 | 最低 | 不限 | **否**——只作"指令理解 sanity floor"（判据者须 100% 判无效，否则说明题目/说明书坏了） |
| **N1 反向链** | 取一条真实链，**反序** + 保持每跳谓词用词 | 低–中 | 有（23 条 → 23 条） | 可，但**必须排除对称谓词**（P4/P5 反序不算错，见 §1.2-C8） |
| **N2 同类型邻居替换** | 取真实链，把某一跳的 target 换成同源同类型的另一个子节点（保持"每跳单独看都像真的"） | 中 | **受限于出度 ≥2 的 8 个节点，仅 10/23 条可行** | 可（样本少） |
| **N3 组合非法但每跳为真** | 取两条**各自为真**的边，组合成 §2.4 判"不可组合"的谓词序列（如 P2 后接 P4），陈述写得通顺 | **最高（最该考）** | 需 L2 谓词；文本层面可合成（不要求是图的子图） | 可，且是 head-line 判别力指标的唯一可信档 |
| **N4 不是负例！真但空**（P1 全链 / D 全链） | 结构/顺序链 | — | 当前 k=2 **无 P1 链**；D 链需 L2 判定 | **禁止当负例**（它们是 G2 档，标成负例会让任务自相矛盾）；必须作为"低信息量正例"单列，用于检验判据者是否把"真但空"误判为"有语义" |
| **N5 谓词错配** | 同一对节点，换一个错误谓词词（如把 part-of 说成 prereq） | 中 | 23 条基座均可 | 可（检验谓词敏感性） |
| **N6 退化边夹具** | 含 7 同名 / 1 OCR 边的链 | 极低 | 有（M2 夹具） | 仅作 M2 判别力夹具，**不进判别力估计**（太易） |

> **禁止项（写死）**：① 用"是否连通/是否相邻"构造负例（判据者看不到图时无意义；看到图时 trivial）；② 把 N4 真但空标为负例；③ 负例与正例用不同模板呈现（措辞指纹）；④ 负例全部来自不同章节而正例全部同章（可由"同章"规则区分）。

### 3.3 匹配设计（negative matching）：本轮最关键的一条

```
三条匹配轴，缺一即为 trivial（复核约束①）：
  M1 同文件/同章：负例的节点取自正例所在同一文件/章节，主题邻近度可比
  M2 同长度（同 hop 数与节点数）：2 跳正例只配 2 跳负例；3 跳只配 3 跳
  M3 同呈现模板：节点数、字段、字数、谓词用词格式一致；不带文件/图结构标签
⇒ "同文件/同章/同长度"规则对负例失效（by construction），负例不再是 trivial 的。
```

可用性：当前 23 条正例全在 `教材/03` ⇒ 同章负例可从同一章的其它小节对**在文本层面自由合成**（不要求是图的子图）——负例池不受图规模限制；**受限的是正例池**（§5.1）。**这是当前数据下唯一能防"trivial separation"的负例设计。**
依据：A：Gardner et al. 2020（contrast sets：用**最小编辑**构造近距离难负例，才能测到决策边界）+ A：Jia & Liang 2017 + B：G2 M2 known-bad 夹具做法 + B：§3.1 可计算基线。

### 3.4 难度校准五步（预注册，顺序不可换）

```
Step 1 平凡规则基线（机检，判据者看到之前做）
  规则 R1 "节点是否同文件"；R2 "节点是否同弱分量"；R3 "全部 3 节点是否同文件"；R4 "两跳谓词是否同型"
  在 (G3 正例 vs N1–N3) 平衡集上算 balanced accuracy
  门槛：任一规则 balanced accuracy ≥ 0.90 ⇒ 负例集作废重造（R6）；0.80–0.90 需记录并解释
  报告：每条规则的 TPR/TNR/BA + **所用帧名**（§3.1；帧不写清的 BA 不接受）
  参考上界（仅 23 条候选链这一批）：R1（同文件）0.860（357 帧）/0.869（79、65 帧）、R3（3 节点同文件）0.948–0.962、R2（同分量）0.906–0.997 ⇒ 若负例只做"随机对"，R3 直接过线

Step 2 判据者 floor
  N0 trivial 必须 100% 判"无效"；否则说明书/呈现坏了，重来（不得当判据者能力问题）

Step 3 阶梯单调性
  预期准确率：N0 > N1 ≈ N2 > N3
  若 N3 准确率 ≈ 0.5（机会水平）而 N1 ≈ 1.0 ⇒ N3 题目歧义或判据欠定义 ⇒ 裁决后重造
  若 N3 准确率 > N2 ⇒ 标注/构造有误（高难档不该更容易）

Step 4 人类上限
  取 L2 已判"明确真/明确假"的边构成的链作锚点，报上限（若上限 <0.9，说明题目本身模糊）

Step 5 只报 hard 档
  head-line 判别力 = N1–N3 合并的 balanced accuracy；N0/N6 只作 floor/fixture，不进指标
```

### 3.5 数量配比与功效（预注册）

- **配比**：正例 : N1+N2 : N3 = 1 : 1 : 1（每类 ≥8 条起；pilot）。
- **功效**：单类 n=20、p=0.8 ⇒ 二项 SE≈0.089、95% CI ≈ ±17.5pp；单类 n=32 ⇒ ±13.8pp。**⇒ "balanced accuracy ≥0.80"这条门槛，单类 n<32 时无法认证**（只能报点估计+CI 作 pilot）。
- **不做**：事后按结果调档、把 N0 混进 head-line、用同一批链既选阈值又报效果（预注册集/验证集分离：pilot 集只用于校准判定表，认证集须另取）。

## 4. 多人盲判协议

### 4.1 判定者（沿用 G2 §2.1，链路级更严）

| 方案 | 人数 | 一致性 | 许可 |
|---|---|---|---|
| A（优先） | **3 名真人**独立 | Krippendorff α（序数）+ Fleiss κ（分类），可两两报 | **主证据** |
| B（最低） | 2 名真人 | α + % agreement | 最低可接受 |
| C（降级） | 1 真人 + agent 代理 | α 仅内部参考；**必须标"agent 代判≠人判"** | 不独立支撑门禁 |
| D | 仅 1 人 | 无法算 α/κ | **不算证据（R2）** |

依据：A：Krippendorff 2004 + Fleiss 1971 + B：G2 §2.1/§2.4 既有协议。

### 4.2 盲化清单

| 呈现给判据者 | 隐藏 |
|---|---|
| 每节点：**kp_id + name + 文件/章节 + 该节点首句** | 边的 raw 类型（contain/extend/reference）、origin、derived、relevance |
| 每跳：**谓词用词**（P1–P5 的人话定义，如"组成/包含"） | 该链路是否是**图的真实子图** |
| 链级：k（2 或 3）与节点顺序 | 该条是正例/负例/夹具；难度档；别人的答案；L2 对该边的判定结果 |
| 说明：这是一条"待判的陈述" | 图的结构信息（度数、连通性、同名组） |

**要点**：盲化的是 **provenance/元标签**，不是**内容**——判据者必须看到"主张本身"才能判真值。这与 L2 的盲化口径一致（G2 §2.1）。
**呈现模板**（预注册）：统一模板，正负例同模板；节点名做必要保留原文（含 OCR 异常时照抄，不得"顺手修"——否则 N6 夹具失效）。

### 4.2b 不得复用现成判定表（复核约束③，写死）

现成 `JUDGE-SHEET-for-stranger.md` **不能**用于链路级正式盲判，三条硬理由（逐条核对过原文）：
1. **结构分组泄漏难度/来源**：它把 24 条按"同名 / 同章相邻小节 / 整体-部分 / 多指向同一目标"分成 4 组（L25-L78），分组本身就是 provenance 与难度标签，判据者看到组别即已知道一半答案。
2. **带引导性提示**：如"这一组大多可能是 D 仅顺序""请特别指出哪几条不只是顺序"（L57）、"L2-22/23/24 三条都指向同一个目标"（L78）——直接指向预期判定。
3. **§三给了 24 条示例答案**（L82-L90），等价于**答案键**：包含"第1组：全部 N 无关系，删""L2-03 是 P2 前置…留"等——任何看过该文件的人不能再作独立判据者。

⇒ 链路级判定表必须**全新构建**，并满足：
- **无结构分组**：全部条目单列，一次随机化（固定种子）后按序号排；
- **无提示/无示例答案**：谓词定义可以给（判真值所需），但**不得给任何条目的示范判定**；
- 训练集与正式集**物理分离**：训练用 3–5 条**不进入正式集**的样例（可为 N0/N6 难度），训练文件不得含正式条目；
- **污染检查**：若判据者此前看过 `JUDGE-SHEET-for-stranger.md` 或其答案，必须换人或整批条目更换（记忆污染不可通过"提醒别看"消除）；
- 建议 Lead 给该文件加"TRAINING/示例，不可用于正式盲判"的抬头，或重命名（本研究员不越权改）。

> 依据：B：`JUDGE-SHEET-for-stranger.md` 原文（分组 L25-78、提示 L57/L78、示例答案 L82-90）+ R2（独立盲判）+ G2 §2.1 盲化口径。

### 4.3 判据项（每链 ≈2.5 分钟；2 跳≈2 分钟，3 跳≈3 分钟）

**逐跳（每跳 5 问，沿用 G2 收窄版）**
- H1 可表述性：这一跳能否说成一句有意义的话？（能/不能/不确定）
- H2 谓词：属于哪个谓词？（P1/P2/P3/P4/P5/仅顺序/无关系/不确定）
- H3 真值：这句话在给定片段下为真吗？（真/假/无支撑）
- H4 方向：箭头方向对吗？（对/反了/不适用）
- H5 去留：这条边该保留吗？（保留/删除/不确定）

**链级（4 问）**
- C1 组合：整条链能否复述为**一句**陈述？（能/不能/不确定；能则写出该句）
- C2 真值：该陈述为真吗？（真/假/无支撑）
- C3 新增信息：相对节点间的标题/顺序关系，这条链是否**提供了新信息**？（有/无/不确定）
- C4 用途：这条链能否支撑一个真实提问/推理步骤？（有/无/不确定；写出可能的提问）
- + 置信度 1–5；+ 一句话理由。

**全文核验子研究（防 K1 编造，写死）**：随机抽 **5 条**链路，做第二个"给完整原文区间"的判定臂（同一判据者，间隔 ≥1 天），报告"片段判定 vs 全文判定"的一致率；一致率 <0.8 ⇒ 片段呈现不足以判真值，后续必须给全文（成本上升，需 Lead 决定样本量）。
依据：G1 §5.3-① 的"编造"失效条件 + B：G2 判据表的片段呈现先例。

### 4.4 一致性计算与门槛（预注册，先写死再看结果）

```
逐跳 H2/H3/H5  → 序数/分类：Krippendorff α（ordinal） + Fleiss κ（分类）
链级 C1/C2/C3  → 序数：Krippendorff α
推导级 G(g0..g4) → 序数 α（由 Q 项机械推导，见 §2.2）
bootstrap 2000 次给 CI；α 用点估计判门，CI 必报
agent 代判单独一组，不与人混算主 α
```

**门槛（必须沿用 G2 的【四档】，不得压成单阈值；链路级主门放在"推导级 α"上）**：

| 档 | α 区间 | 判定 | 动作 |
|---|---|---|---|
| **档 1** | **α ≥ 0.80** | 一致性好 | 可作证据；可进入多数表决/裁决 |
| **档 2** | **0.667 ≤ α < 0.80** | 暂定可用 | **必须扩样**（E1/E2）后才能当门禁；扩样后 α 仍 <0.80 则不得升级 |
| **档 3** | **0.50 ≤ α < 0.667** | marginal | 扩样 + 重写题目/呈现（E1/E3）；不得出结论 |
| **档 4** | **α < 0.50** | 不可靠 | **停止**：改谓词/改判定表/重训，只保留夹具结论（"<0.50 重来"） |

- **不得写成"α≥0.7 就算通过"或任何单阈值**；也不得把 Cohen κ 与 α 混用取平均。
- **组件门槛**：H3/C2（真值）的 α ≥ 0.667——核心项不得低于其它项；若只有核心项掉档，先改题目再扩样。
- **一致性达档前不得多数表决**；分歧裁决记录理由，裁决结果不计入 α 的分母（α 只算独立判定）。

**n=13/20 不能做阈值认证（写进预注册）**：Wilson 区间（p=0.5）半宽：**n=20 → ±20.07pp；n=13 → ±23.88pp；n=23 → ±18.9pp**（不是正态近似的 ±22/±27pp）。⇒ 只能报 pilot，不能宣称"达到/未达到 70%/80% 门槛"。认证需要 **n ≥ 32 条近似独立链**（Wilson n=32、p=.5 → **±16.37pp**；且每类负例 ≥32 才能认证判别力门槛）。
