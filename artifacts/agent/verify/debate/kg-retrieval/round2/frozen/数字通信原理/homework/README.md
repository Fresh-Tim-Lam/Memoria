# 作业题目集

本目录收录课内外作业 / 习题：记录**题面、来源、解法清单、答案与易错点**。

## 收录约定

- 命名：`hw-序号-内容摘要.md`（如 `hw-001-conv-exp-gate.md`）；一题一文件。
- 题面用公式原样抄录，不改编；解法按「大类 → 变体」编号。
- 每题末尾给**方法对照表**与**自检**（端点、极限、卷积起止点）。
- 本目录**不建知识点、不写 sidecar**（与 `notes/` 同口径）；引用库内既有知识点一律写 `[[kp-id]]`。
