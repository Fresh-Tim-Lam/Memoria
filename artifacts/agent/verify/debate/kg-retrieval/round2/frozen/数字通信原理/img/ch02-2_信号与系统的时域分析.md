### 一、在导数方面的意义

对于存在间断点的函数，引入冲激信号后，间断点处的导数可以用冲激信号表示，其强度等于该点的跳跃值。

### 二、信号关系构建方面

它有助于构建不同信号之间的关系，例如冲激信号、阶跃信号、斜坡信号和冲激偶信号之间存在微分关系。

可以用冲激信号来表示其他信号，在时域中将所有的连续时间信号表示为冲激信号的组合，这有助于对信号进行分析和处理。

### 三、系统分析方面

冲激响应是系统在冲激信号作用下的输出响应，通过冲激响应能够分析系统的特性，如系统的稳定性、因果性等。

求解连续时间线性非时变系统的零状态响应，需要先知道系统的冲激响应，因为零状态响应等于输入信号和系统冲激响应的卷积。

## 1. 基于求解线性常系数微分方程的方法

连续LTI系统可由线性常系数微分方程描述

$$
\begin{array}{l} y ^ {(n)} (t) + a _ {n - 1} y ^ {(n - 1)} (t) + \dots + a _ {1} y ^ {\prime} (t) + a _ {0} y (t) \\ = b _ {m} x ^ {(m)} (t) + b _ {m - 1} x ^ {(m - 1)} (t) + \dots + b _ {1} x ^ {\prime} (t) + b _ {0} x (t) \\ \end{array}
$$

微分方程的全解由齐次解 $y _ { \mathrm { h } } ( t )$ 和特解 $y _ { \mathrm { p } } ( t )$ 组成

$$
y (t) = y _ {\mathrm{h}} (t) + y _ {\mathrm{p}} (t)
$$

- 齐次解 $y _ { \mathrm { h } } ( t )$ 的形式由微分方程对应的特征根确定
- 特解 $y _ { \mathrm { p } } ( t )$ 的形式由方程右边激励信号的形式确定

### 一、求解零状态响应

在连续时间线性非时变系统中，为求解零状态响应，必须知道系统的冲激响应。因为零状态响应等于输入信号和系统冲激响应的卷积。

### 二、描述系统特性

冲激响应能反映系统的时域特性。不同的系统，其冲激响应不同，通过冲激响应可以区分不同的系统。

其只与系统本身特性有关，而与系统的输入和输出无足绝对可积的条件，可以判断系统是否稳定。

若描述连续LTI系统的线性常系数微分方程为

$$
\begin{array}{l} y ^ {(n)} (t) + a _ {n - 1} y ^ {(n - 1)} (t) + \dots + a _ {1} y ^ {\prime} (t) + a _ {0} y (t) \\ = b _ {m} x ^ {(m)} (t) + b _ {m - 1} x ^ {(m - 1)} (t) + \dots + b _ {1} x ^ {\prime} (t) + b _ {0} x (t) \\ \end{array}
$$

则连续LTI系统的冲激响应h(t)应满足

$$
\begin{array}{l} h ^ {(n)} (t) + a _ {n - 1} h ^ {(n - 1)} (t) + \dots + a _ {1} h ^ {\prime} (t) + a _ {0} h (t) \\ = b _ {m} \delta^ {(m)} (t) + b _ {m - 1} \delta^ {(m - 1)} (t) + \dots + b _ {1} \delta^ {\prime} (t) + b _ {0} \delta (t) \\ \end{array}
$$

当t> 0时， (t)及其导数的函数值均等于零。

【例】描述某连续LTI系统的微分方程为 $y ^ { \prime } ( t ) + 3 y ( t ) = 2 x ( t ) , \quad t > 0$ 试求该系统的冲激响应h(t)。

分析：当系统输入信号 $x ( t )$ 为(t)，输出信号y(t)则为 $h ( t )$ 描述系统的微分方程为

$$

$$
h ^ {\prime} (t) + 3 h (t) = 0
$$

故系统的冲激响应具有齐次解形式

【例】描述某连续LTI系统的微分方程为 $y ^ { \prime } ( t ) + 3 y ( t ) = 2 x ( t ) , \quad t > 0$ 试求系统的冲激响应。

$$

由此可见，连续LTI系统的零状态响应是输入信号与系统冲激响应的卷积积分，此揭示了信号与LTI系统在时域的内在作用机理。

## 信号卷积积分的计算

## 解析方法：

直接按照卷积积分的表达式进行计算

$$

$$
\begin{array}{l} x (t) * h (t) = \int_ {- \infty} ^ {\infty} x (\tau) \cdot h (t - \tau) \mathrm{d} \tau \\ = \int_ {- \infty} ^ {\infty} \mathrm{e} ^ {- \tau} \mathrm{u} (\tau) \cdot \mathrm{u} (t - \tau) \mathrm{d} \tau \\ \end{array}

由 $\mathrm { u } ( \tau ) \mathrm { u } ( t - \tau )$ 得到

$$

$$

由此可得 $x ( t ) ^ { * } h ( t ) = ( 1 - \mathrm { e } ^ { - t } ) \mathsf { u } ( t )$
