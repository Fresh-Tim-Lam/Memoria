一系列正弦信号的表示方法

$$
\mathrm{e} ^ {\mathrm{j} \omega t} = \cos (\omega t) + \mathrm{j} \sin (\omega t)
$$

$$
\cos (\omega t) = \frac {1}{2} (\mathrm{e} ^ {\mathrm{j} \omega t} + \mathrm{e} ^ {- \mathrm{j} \omega t})
$$

$$
\sin (\omega t) = \frac {1}{2 \mathrm{j}} (\mathrm{e} ^ {\mathrm{j} \omega t} - \mathrm{e} ^ {- \mathrm{j} \omega t})
$$

※ 连续周期信号的Fourier级数（CFS）

$$
\tilde {x} (t) = \sum_ {n = - \infty} ^ {\infty} C _ {n} \mathrm{e} ^ {\mathrm{j} n \omega_ {0} t}
$$

- u 周期信号x(t)可以表示为无数个虚指数信号的线性叠加
- $T _ { 0 }$ 为周期信号 $\tilde { { \boldsymbol { x } } } ( t )$ 的周期, $\omega _ { 0 }$ 为 $\tilde { { \boldsymbol { x } } } ( t )$ 的角频率
- $C _ { n }$ 是 $n \omega _ { 0 }$ 的函数 $C _ { n } = C _ { n } ( n \omega _ { 0 } )$ ,简写为 $C _ { n }$

信号展开为Fourier级数(Dirichlet)条件(充分条件):x(t)

(1) 在一个周期内绝对可积，即满足

$$
\int_ {- T _ {0} / 2} ^ {T _ {0} / 2} \left| \widetilde {x} (t) \right| \mathrm{d} t <   \infty
$$

- (2) 在一个周期内只有有限个不连续点；
- (3) 在一个周期内只有有限个极大值和极小值。

$$
\tilde {x} (t) = \sum_ {n = - \infty} ^ {\infty} C _ {n} \mathrm{e} ^ {\mathrm{j} n \omega_ {0} t}
$$

$$
\tilde {x} (t) = \ldots + C _ {- N} \mathbf {e} ^ {- \mathrm{j} N \omega_ {0} t} + \ldots + C _ {- 1} \mathbf {e} ^ {- \mathrm{j} \omega_ {0} t} + C _ {0} + C _ {1} \mathbf {e} ^ {\mathrm{j} \omega_ {0} t} + \ldots + C _ {N} \mathbf {e} ^ {\mathrm{j} N \omega_ {0} t} + \ldots
$$

$\ast \mathrm { e } ^ { \pm \mathrm { j } N \omega _ { 0 } t }$ 的周期为 $T _ { 0 } / N$ , 函数集在区间[0, $T _ { 0 } ]$ 上相互正交。

$$
\int_ {0} ^ {T _ {0}} \mathrm{e} ^ {\mathrm{j} N \omega_ {0} t} \mathrm{e} ^ {- \mathrm{j} M \omega_ {0} t} \mathrm{d} t = \left\{ \begin{array}{l l} T _ {0}, & N = M \\ 0, & N \neq M \end{array} \right.
$$

$$
C _ {n} = \frac {1}{T _ {0}} \int_ {0} ^ {T _ {0}} \tilde {x} (t) \mathrm{e} ^ {- \mathrm{j} n \omega_ {0} t} \mathrm{d} t = \frac {1}{T _ {0}} \int_ {<   T _ {0} >} \tilde {x} (t) \mathrm{e} ^ {- \mathrm{j} n \omega_ {0} t} \mathrm{d} t
$$

### 一、功率分布的直观呈现

**① 指数不是被「删掉」的，是筛选性质。** [[\h:#D6E4F0:#1B4F72|筛选性质]] $\int_{-\infty}^{+\infty}\delta(t)f(t)\mathrm{d}t=f(0)$ 表明：被积函数只在 $t=0$ 处取到函数值。故 $\int_{-T/2}^{T/2}\delta(t)\mathrm{e}^{-\mathrm{j}n\omega_0t}\mathrm{d}t=\mathrm{e}^{0}=1$，讲义省掉的是「代入 $t=0$」这一步（同样的省略见本文件 `:1293` 求 $\mathcal{F}[\delta(t)]=1$ 之处）。

**② 被积函数为什么是 $\delta(t)$ 而不是 $\delta_T(t)$。** 系数积分在一个周期上进行，而 $\delta_T(t)=\sum_{n}\delta(t-nT)$ 在 $(-T/2,\,T/2)$ 内只剩 $t=0$ 处的**一个**冲激，故 $\delta_T(t)\to\delta(t)$；$\pm T/2$ 本身不是冲激所在位置。若把周期取成 $[0,\,T]$，冲激会落在积分区间的端点上，端点如何取值需另作交代——讲义未说明。

**③ 真正该注意的是：$C_n$ 与 $n$ 无关 ⇒ 这条级数在普通意义下不收敛。** 把 $C_n\equiv 1/T$ 代回 $\delta_T(t)=\frac{1}{T}\sum_{n=-\infty}^{+\infty}\mathrm{e}^{\mathrm{j}n\omega_0t}$，通项模恒为 $1/T$、[[\h:#FADBD8:#922B21|不趋于 0]]，级数逐点发散（部分和为 Dirichlet 核）；$\delta_T(t)$ 自身也没有有限能量，狄里赫利条件无从谈起。因此该展开式与 $\mathcal{F}[\delta_T(t)]=\omega_0\sum_n\delta(\omega-n\omega_0)$（本文件 `:1475`）都只在[[\h:#FDEBD0:#A04000|广义函数（分布）意义]]下成立，属形式运算。工程上它对应[[\h:#D6E4F0:#1B4F72|理想冲激抽样]]这一理想化模型：理想冲激物理上不可实现（`教材/03_第3章_模拟信号的数字编码.md:57`），恢复端陡峭的理想低通亦然（`教材/03_第3章_模拟信号的数字编码.md:129`）；实际改用矩形脉冲串自然抽样时，$C_n$ 带 $\mathrm{Sa}$ 包络而衰减（`教材/03_第3章_模拟信号的数字编码.md:70`、`:82`）。

**④ 为什么是 $1/T$ 而不是 1。** 一个周期内冲激总面积为 1，$C_n$ 是[[\h:#FDEBD0:#A04000|每周期的平均]]，故为 $1/T$；这与末式 $2\pi\cdot\frac{1}{T}=\frac{2\pi}{T}=\omega_0$ 一致。

## 连续时间LTI系统的频率响应

对于稳定的连续LTI系统，虚指数信号 $\mathrm { e j } \omega$ t通过系统的零状态响应为

$$
y _ {\mathrm{zs}} (t) = \mathrm{e} ^ {\mathrm{j} \omega t} * h (t) = \int_ {- \infty} ^ {\infty} \mathrm{e} ^ {\mathrm{j} \omega (t - \tau)} h (\tau) \mathrm{d} \tau
$$

$$
= \mathrm{e} ^ {\mathrm{j} \omega t} \int_ {- \infty} ^ {\infty} \mathrm{e} ^ {- \mathrm{j} \omega \tau} h (\tau) \mathrm{d} \tau = \mathrm{e} ^ {\mathrm{j} \omega t} H (\mathrm{j} \omega)
$$

$$
H (\mathrm{j} \omega) = \int_ {- \infty} ^ {\infty} h (t) \mathrm{e} ^ {- \mathrm{j} \omega t} \mathrm{d} t
$$

$H ( \mathrm { j } \omega )$ 称为连续LTI系统的频率响应，其为h(t)的Fourier变换

系统频率响应 $H ( \mathrm { j } \omega )$ 的物理意义

![](.memoria/images/066378f05c7823d1d6412be771a34cf71ef93c2d71eb241833e64c83221e1edb.jpg)

频率为w的虚指数信号 $\mathbf { e } ^ { \mathbf { j } \omega t }$ 通过稳定的连续LTI系统的响应仍为同频率的虚指数信号。信号的改变由 $H ( \mathbf { j } \omega )$ 确定。

$H ( \mathbf { j } \omega )$ 反映了系统对不同频率信号的传输特性

## 幅度响应与相位响应

![](.memoria/images/6489c24230bc7c53913e379f75bf4bc2077949bd8198dec34e5f7c831501b696.jpg)

若h(t)是实信号时，则

幅度响应 $H ( \mathbf { j } \omega )$ 是w的偶函数，

相位响应 $\varphi ( \omega )$ 是w的奇函数。

## 连续时间LTI系统的频域响应

正弦信号 $\sin ( \omega _ { 0 } t { + } \theta )$ 通过连续LTI系统的响应

$$
\sin (\omega_ {0} t + \theta) = (\mathrm{e} ^ {\mathrm{j} (\omega_ {0} t + \theta)} - \mathrm{e} ^ {- \mathrm{j} (\omega_ {0} t + \theta)}) / 2 \mathrm{j}
$$

利用虚指数信号 $\bf { e j } \tilde { \omega } _ { 0 }$ t响应的特点及系统的线性特性，可得

$$
y _ {\mathrm{zs}} (t) = \left[ H (\mathrm{j} \omega_ {0}) \mathrm{e} ^ {\mathrm{j} (\omega_ {0} t + \theta)} - H (- \mathrm{j} \omega_ {0}) \mathrm{e} ^ {- \mathrm{j} (\omega_ {0} t + \theta)} \right] / 2 \mathrm{j}
$$

$$
| H (\mathrm{j} \omega_ {0}) | \mathrm{e} ^ {\mathrm{j} \varphi (\omega_ {0})} \quad | H (\mathrm{j} \omega_ {0}) | \mathrm{e} ^ {- \mathrm{j} \varphi (\omega_ {0})}
$$

$$
= \left| H (\mathrm{j} \omega_ {0}) \right| \sin (\omega_ {0} t + \varphi (\omega_ {0}) + \theta)
$$

正弦信号 $\sin ( \omega _ { 0 } t { + } \theta )$ 通过系统的响应

$$
\sin (\omega_ {0} t + \theta) \longrightarrow \left| H (\mathrm{j} \omega_ {0}) \right| \sin (\omega_ {0} t + \varphi (\omega_ {0}) + \theta)
$$

频率为 $\omega _ { 0 }$ 的正弦信号通过连续LTI系统的响应仍为同频率的正弦信号。

响应的幅度改变由 $H ( \mathbf { j } \omega _ { 0 } )$ 确定，

响应的相位改变由 $\varphi ( \omega _ { 0 } )$ 确定。

## 连续时间LTI系统的频率响应

对于连续LTI系统，输入x(t)、冲激响应h(t)、零状态响应 $\gamma _ { \mathrm { z s } } ( t )$ 的关系为

$$
y _ {\mathrm{zs}} (t) = x (t) * h (t)
$$

根据Fourier变换的时域卷积特性，可得

$$
Y _ {\mathrm{zs}} (\mathrm{j} \omega) = X (\mathrm{j} \omega) \cdot H (\mathrm{j} \omega)
$$

由此可见，系统频率响应 $H ( \mathrm { j } \omega )$ 也可表示为

$$
H (\mathrm{j} \omega) = \frac {Y _ {\mathrm{zs}} (\mathrm{j} \omega)}{X (\mathrm{j} \omega)}
$$

## 连续时间LTI系统的频域描述

若描述连续时间LTI系统的微分方程为

$$
a _ {n} y ^ {(n)} (t) + a _ {n - 1} y ^ {(n - 1)} (t) + \lambda + a _ {1} y ^ {\prime} (t) + a _ {0} y (t) =
$$

$$
b _ {m} x ^ {(m)} (t) + b _ {m - 1} x ^ {(m - 1)} (t) + \lambda + b _ {1} x ^ {\prime} (t) + b _ {0} x (t)
$$

利用Fourier变换的微分特性，可得该系统的频域描述方程

$$
\left[ a _ {n} (\mathrm{j} \omega) ^ {n} + a _ {n - 1} (\mathrm{j} \omega) ^ {n - 1} + \lambda + a _ {1} (\mathrm{j} \omega) + a _ {0} \right] Y _ {\mathrm{zs}} (\mathrm{j} \omega) =
$$

$$
[ b _ {m} (\mathrm{j} \omega) ^ {m} + b _ {m - 1} (\mathrm{j} \omega) ^ {m - 1} + \lambda + b _ {1} (\mathrm{j} \omega) + b _ {0} ] X (\mathrm{j} \omega)
$$

$$
\begin{array}{l} [ a _ {n} (\mathrm{j} \omega) ^ {n} + a _ {n - 1} (\mathrm{j} \omega) ^ {n - 1} + \dots + a _ {1} (\mathrm{j} \omega) + a _ {0} ] Y _ {\mathrm{zs}} (\mathrm{j} \omega) \\ = [ b _ {m} (\mathrm{j} \omega) ^ {m} + b _ {m - 1} (\mathrm{j} \omega) ^ {m - 1} + \dots + b _ {1} (\mathrm{j} \omega) + b _ {0} ] X (\mathrm{j} \omega) \\ \end{array}
$$

进一步化简连续LTI系统的频域描述方程，可得

$$
H (\mathrm{j} \omega) = \frac {Y _ {\mathrm{zs}} (\mathrm{j} \omega)}{X (\mathrm{j} \omega)} = \frac {b _ {m} (\mathrm{j} \omega) ^ {m} + b _ {m - 1} (\mathrm{j} \omega) ^ {m - 1} + \cdots + b _ {1} (\mathrm{j} \omega) + b _ {0}}{a _ {n} (\mathrm{j} \omega) ^ {n} + a _ {n - 1} (\mathrm{j} \omega) ^ {n - 1} + \cdots + a _ {1} (\mathrm{j} \omega) + a _ {0}}
$$

已知描述某稳定的连续时间LTI系统的微分方程为

$$
y ^ {\prime \prime} (t) + 7 y ^ {\prime} (t) + 1 2 y (t) = x ^ {\prime} (t) + 2 x (t)
$$

求解该系统的频率响应 $H ( \mathrm { j } \omega )$

解：该连续LTI系统为稳定系统，因而其存在频率响应 $H ( \mathrm { j } \omega )$ 根据微分方程和Fourier变换的微分特性，可得

$$
[ (\mathrm{j} \omega) ^ {2} + 7 (\mathrm{j} \omega) + 1 2 ] Y _ {\mathrm{zs}} (\mathrm{j} \omega) = [ (\mathrm{j} \omega) + 2 ] X (\mathrm{j} \omega)
$$

$$
H (\mathrm{j} \omega) = \frac {Y _ {\mathrm{zs}} (\mathrm{j} \omega)}{X (\mathrm{j} \omega)} = \frac {(\mathrm{j} \omega) + 2}{(\mathrm{j} \omega) ^ {2} + 7 (\mathrm{j} \omega) + 1 2}
$$

频率响应 $H ( \mathrm { j } \omega )$ 与冲激响应h(t) 的关系

![](.memoria/images/1d56505618eaba6b160fa8dd7ee78b53490069790a27589283ff84f6beac5d74.jpg)

$$
H (\mathrm{j} \omega) = \frac {Y _ {\mathrm{zs}} (\mathrm{j} \omega)}{X (\mathrm{j} \omega)} = \frac {\mathcal {F} [ h (t) ]}{\mathcal {F} [ \delta (t) ]} = \mathcal {F} [ h (t) ]
$$

$$
H (\mathrm{j} \omega) = \mathcal {F} [ h (t) ] = \int_ {- \infty} ^ {\infty} h (t) \mathrm{e} ^ {- \mathrm{j} \omega t} \mathrm{d} t
$$

1. 根据描述连续LTI系统的冲激响应h(t)，可得系统的频率响应 $H ( \mathrm { j } \omega )$

$$
H (\mathrm{j} \omega) = \int_ {- \infty} ^ {\infty} h (t) \mathrm{e} ^ {- \mathrm{j} \omega t} \mathrm{d} t
$$

稳定的连续LTI系统的冲激响应h(t)一定存在Fourier变换。

2. 根据描述连续LTI系统的微分方程，也可得系统的频率响应 $H ( \mathrm { j } \omega )$

$$
H (\mathrm{j} \omega) = \frac {Y _ {\mathrm{zs}} (\mathrm{j} \omega)}{X (\mathrm{j} \omega)} = \frac {b _ {m} (\mathrm{j} \omega) ^ {m} + b _ {m - 1} (\mathrm{j} \omega) ^ {m - 1} + \cdots + b _ {1} (\mathrm{j} \omega) + b _ {0}}{a _ {n} (\mathrm{j} \omega) ^ {n} + a _ {n - 1} (\mathrm{j} \omega) ^ {n - 1} + \cdots + a _ {1} (\mathrm{j} \omega) + a _ {0}}
$$

虽然连续时间LTI系统的频率响应H(jw)，可通过系统的输入与输出的频谱函数来求解，但H(jw)与系统的输入和输出无关。

【例】已知某稳定的连续LTI系统的冲激响应h(t)为

$$
h (t) = (3 \mathrm{e} ^ {- 2 t} + 2 \mathrm{e} ^ {- 4 t}) \mathrm{u} (t)
$$

求解该系统的频率响应 $H ( \mathrm { j } \omega )$ 。

$$
\begin{array}{l} H (\mathrm{j} \omega) = \mathcal {F} [ h (t) ] \\ = \frac {3}{\mathrm{j} \omega + 2} + \frac {2}{\mathrm{j} \omega + 4} = \frac {5 (\mathrm{j} \omega) + 1 6}{(\mathrm{j} \omega) ^ {2} + 6 (\mathrm{j} \omega) + 8} \\ \end{array}
$$

$$

## 连续LTI系统的频率响应计算

※ 根据连续LTI系统的输入输出信号，计算系统的频率响应

$$
H (\mathrm{j} \omega) = \frac {Y _ {\mathrm{zs}} (\mathrm{j} \omega)}{X (\mathrm{j} \omega)}
$$

输入信号x(t)存在Fourier变换

输出信号 $\gamma _ { \mathrm { z s } } ( t )$ 存在Fourier变换

【例】已知某连续LTI系统的输入信号 ${ \boldsymbol { x } } ( t ) { = } \mathrm { e } ^ { - t } \mathrm { u } ( t )$ ，系统的零状态响应为$y _ { \mathrm { z s } } ( t ) { = } \mathrm e ^ { - t } \mathrm u ( t ) { + } \mathrm e ^ { - 2 t } \mathrm u ( t )$ ，求该系统频率响应 $H ( \mathrm { j } \omega )$ 和单位冲激响应h(t)。

由于解： ${ \bf \dot { \boldsymbol { x } } } ( t )$ 和 $\gamma _ { \mathrm { z s } } ( t )$ 存在Fourier变换，分别进行Fourier变换，得

$$
X (\mathrm{j} \omega) = \mathcal {F} [ \mathrm{e} ^ {- t} \mathrm{u} (t) ] = \frac {1}{1 + \mathrm{j} \omega}
$$

$$
Y _ {\mathrm{zs}} (\mathrm{j} \omega) = \mathcal {F} [ \mathrm{e} ^ {- t} \mathrm{u} (t) + \mathrm{e} ^ {- 2 t} \mathrm{u} (t) ] = \frac {1}{1 + \mathrm{j} \omega} + \frac {1}{2 + \mathrm{j} \omega} = \frac {3 + 2 \mathrm{j} \omega}{(1 + \mathrm{j} \omega) (2 + \mathrm{j} \omega)}
$$

$$
H (\mathrm{j} \omega) = \frac {Y _ {\mathrm{zs}} (\mathrm{j} \omega)}{X (\mathrm{j} \omega)} = \frac {3 + 2 \mathrm{j} \omega}{2 + \mathrm{j} \omega} = 2 - \frac {1}{2 + \mathrm{j} \omega}
$$

$$
h (t) = \mathcal {F} ^ {- 1} [ H (\mathrm{j} \omega) ] = 2 \delta (t) - \mathrm{e} ^ {- 2 t} \mathrm{u} (t)
$$

## 连续LTI系统的频率响应计算

【例】图示RC电路，激励电压源为x(t)，输出y(t)为电容两端的电压 $\nu _ { \mathrm { { C } } } ( t )$ 电路的初始状态为零。求系统的频率响应 $H ( \mathrm { j } \omega )$ 和冲激响应h(t)。

![](.memoria/images/668ac72c2f2c340ab59adade253d72e42f35679e4edffcda1608a4a9bb851d8d.jpg)

解： RC电路的频域模型如图，由电路的基本原理有

$$
H (\mathrm{j} \omega) = \frac {Y (\mathrm{j} \omega)}{X (\mathrm{j} \omega)} = \frac {1 / \mathrm{j} \omega C}{R + 1 / \mathrm{j} \omega C} = \frac {1 / R C}{\mathrm{j} \omega + 1 / R C}
$$

【例】图示RC电路，激励电压源为x(t)，输出y(t)为电容两端的电压 $\nu _ { \mathrm { { C } } } ( t )$ 电路的初始状态为零。求系统的频率响应 $H ( \mathrm { j } \omega )$ 和冲激响应h(t)。

解：

$$
H (\mathrm{j} \omega) = \frac {1 / R C}{\mathrm{j} \omega + 1 / R C}
$$

由Fourier反变换，可得系统的冲激响应 $h ( t )$ 为

$$
h (t) = \frac {1}{R C} \mathrm{e} ^ {- (1 / R C) t} \mathrm{u} (t)
$$

$$

$$
\mathcal {F} [ x (t) \mathrm{e} ^ {- \sigma t} ] = \int_ {- \infty} ^ {\infty} x (t) \mathrm{e} ^ {- \sigma t} \mathrm{e} ^ {- \mathrm{j} \omega t} \mathrm{d} t
$$

$$
= \int_ {0} ^ {\infty} \mathrm{e} ^ {\alpha t} \mathrm{e} ^ {- (\sigma + \mathrm{j} \omega) t} \mathrm{d} t
$$

$$
\text {令} s = \sigma + \mathrm{j} \omega \quad = \int_ {0} ^ {\infty} \mathrm{e} ^ {- (s - \alpha) t} \mathrm{d} t = \frac {1}{s - \alpha}

若Re{s}=σ>α

推广到一般情况

$$
\mathcal {F} [ x (t) \mathrm{e} ^ {- \sigma t} ] = \int_ {- \infty} ^ {\infty} x (t) \mathrm{e} ^ {- \sigma t} \mathrm{e} ^ {- \mathrm{j} \omega t} \mathrm{d} t = \int_ {- \infty} ^ {\infty} x (t) \mathrm{e} ^ {- (\sigma + \mathrm{j} \omega) t} \mathrm{d} t
$$

$$
= \int_ {- \infty} ^ {\infty} x (t) \mathrm{e} ^ {- s t} \mathrm{d} t = X (s)
$$

令 s=+jw

## 3. 单边Laplace变换的收敛域

$$
X (s) = \int_ {0 ^ {-}} ^ {\infty} x (t) \mathrm{e} ^ {- s t} \mathrm{d} t
$$

若x(t)的单边拉普拉斯变换存在，上式积分需收敛。单边拉普拉斯变换存在的充要条件为：

$$
\int_ {0 ^ {-}} ^ {\infty} | x (t) \mathrm{e} ^ {- s t} | \mathrm{d} t = \int_ {0 ^ {-}} ^ {\infty} | x (t) \mathrm{e} ^ {- \sigma t} | \mathrm{d} t = C, \quad \sigma = \mathrm{Re} (s)
$$

对任意信号x(t) ，若满足上式，则x(t)应满足：

$$
\lim _ {t \to \infty} x (t) \mathrm{e} ^ {- \sigma t} = 0
$$

$$
X (s) = \int_ {0 ^ {-}} ^ {\infty} x (t) \mathrm{e} ^ {- s t} \mathrm{d} t
$$

$$
\lim _ {t \to \infty} x (t) \mathrm{e} ^ {- \sigma t} = 0
$$

上式成立的 $\sigma \mathrm { \cdot }$ 取值范围称为Laplace变换的收敛域，简称为ROC (Region Of Convergence)。

对于单边Laplace变换，ROC一般表示为：

$\Longrightarrow \sigma _ { 0 }$ ，或者R $. \mathrm { e } \{ s \} > \sigma _ { 0 } ( \sigma _ { 0 }$ 为实常数)。
