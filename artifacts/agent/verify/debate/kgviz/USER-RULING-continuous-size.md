# 人裁决记录②：节点尺寸**不设挡位，连续变化**

> **来源**：人直接裁决（2026-10-26，回答 Phase 4 的 V2 档数裁决）
> **原话**：「尺寸不设置挡位，而是连续变化」
> **效力**：**取代** D-KGV-01（3 档）与 D-KGV-02（tiePolicy）；**修正** D-KGV-03（映射契约）

## 1. 这条裁决消解了什么

Phase 3 最激烈的冲突 **V2（可辨档数）** 建在一个无法实测的问题上：
「人眼能清晰区分几档半径」——三方给的是 4 / 5 / 12–13，全是经验值，
`metrics-baseline` 承认「4 档也是经验值，当前不可判定」，并设计了一个 3 小时的人类判读实验。

**人选择不做挡位 ⇒ 这个问题整体消失**：
```
连续映射下不存在"档"这个概念
⇒ 不需要回答"相邻档差多少才可辨"
⇒ 不需要 tiePolicy（同 degree 同半径，天然连续）
⇒ 不需要 DS-1 判读实验（它唯一用途是定档数）
⇒ 不需要"3 档 vs 2 档"的降级路径
```

**这是比任何一方提案都简洁的解法**：把一个无法判定的离散化问题，改成不需要判定的连续问题。

## 2. 保留什么（人裁决 75%~165% 仍然有效）

```
范围：基准 × [75%, 165%]（线性尺寸）
基准 = 现状 nodeRadius 常量 6.0px
⇒ 半径 [4.50, 9.90] px，跨度 5.40px（直径 [9.00, 19.80] px）

面积比：最大/最小 = (9.90/4.50)² = 4.84×
直径比：9.90/4.50 = 2.20×
⇒ 两端差异显著可辨（远大于任何一方的"单档可辨阈值"）
```

## 3. 映射（连续，不设阈值数组）

```
radius(d) = R_MIN + (R_MAX - R_MIN) · t(d)
  R_MIN = 4.50, R_MAX = 9.90（由 基准×[0.75,1.65] 派生，随用户 nodeRadius 设置缩放 —— 见 U-KGV-2）
  t(d) ∈ [0,1]，单调不减
```

### t(d) 的选择（v0 默认 + 可切换）

| 方案 | 定义 | 优点 | 代价 |
|---|---|---|---|
| **A 连续分位（v0 默认）** | `t = percentile_rank(degree)`（连续，非分桶） | 人口在半径轴上均匀分布，结构性消除长尾；最厚节点仍可达 R_MAX | 半径依赖语料人口 ⇒ 同一 degree 跨库半径不同 |
| B 线性归一 | `t = (d - d_min)/(d_max - d_min)` | 半径直接反映绝对 degree 差 | 受长尾支配：少数超大 degree 把其余节点压到极小 |
| C 平方根归一 | `t = sqrt(t_B)` | 折中，压缩高值 | 仍受 d_max 异常值影响 |

**v0 取 A**，理由：
- Phase 3 已论证「分位在结构上消除长尾、自带上下界、不受 max 异常值影响」（`arch-contract` 因此撤回了「sizeScale 必须」）
- 连续分位与"分桶分位"的区别只在**没有档边界**，长尾优势保留
- 绝对值的语义由 **tooltip 显示 degree 原值** 兜住（D-KGV-03 附加约束不变）

**A 的代价如实记录**：同一 degree 在不同语料可能得到不同半径 ⇒
这是"相对量编码"的固有属性，不是缺陷；但**验收时必须用同一语料**（见 §5）。

## 4. tie（并列）处理：**不再需要策略**

```
连续映射下同 degree ⇒ 同半径，这是【正确行为】（相同数据应得到相同视觉结果）
⇒ 删除 D-KGV-02 的 tiePolicy 条款
⇒ 副作用：并列多的语料会出现大片同半径节点 —— 这是真实数据结构，不是缺陷
```

## 5. 验收（替代原 T-size 档数验收）

```
T-size-1  两端可辨：最大 degree 节点 vs 最小 degree 节点，用户判断"哪个更大" ≥90%
          （这是唯一需要真人的部分；比原来的"3 档挑最大"更弱、更容易通过）

T-size-2  单调性（机检）：radius 随 degree 单调不减，无反转
T-size-3  连续性（机检）：distinct 半径值个数 == distinct degree 个数（或差值 ≤ tie 数）
          且【无平台】：不存在"相邻 rank 半径差 < 0.01px"的连续段占比 >5%
          ⇒ 这条是"没有偷偷分桶"的直接证据
T-size-4  范围（机检）：min radius == 4.50±0.5，max radius == 9.90±0.5（含反锯齿 +1.0px 常量偏移）
          运行期 min/max 必须落在 [4.5, 9.9] + 反锯齿偏移内
T-census  语料身份三元组校验（134 节点 / 404 边 / manifest_sha256）
```

**T-size-3 是这次新增的关键机检**：它能直接证明"实现的是连续映射，不是掩人耳目的分桶"。

## 6. DS-1 判读实验的最终处置

```
【取消】不再需要 —— 它的唯一用途是定档数，而档数已不存在
【保留为 backlog 的唯一场景】若将来要做【3D 大小编码】（D-KGV-04 的 falsifier 之一），
  或要引入【第二视觉通道分档】时，才需要判读实验
```
