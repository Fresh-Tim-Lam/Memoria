# 人裁决记录：节点大小范围 75%–165%

> **来源**：人直接裁决（2026-10-26，回答 Lead 的 V2 提问）
> **原话**：「原来基础上75%~165」
> **效力**：**优先于 Phase 1–3 的一切档数主张**。V2 冲突（C 4 档 / A 5 档 / B 12–13 档）由本条裁定。

## 1. 字面含义与本文件采用的解释

```
「原来基础上的 75%~165%」
  · 基准 = 现状 nodeRadius 常量 6.0px（graph-layout-2d.js / graph-layout-3d.js）
  · 采用解释：**线性尺寸比例**（半径/直径等比缩放）
      min radius = 6.0 × 0.75 = 4.50 px
      max radius = 6.0 × 1.65 = 9.90 px
      跨度 = 5.40 px（半径）/ 10.80 px（直径）
```

⚠️ **一处待确认的歧义（不影响 v0 落地，但影响档数）**：
```
若人的原意是【面积】比例 75%~165%：
  半径比 = sqrt(0.75)=0.866 ~ sqrt(1.65)=1.284
  ⇒ radius 5.20 ~ 7.70 px，跨度 2.50 px（比线性解释更窄）
  ⇒ 3px 判据下只有 1 档、2px 判据下 2 档
```
本文件按**线性**解释推进（更保守档数、更接近"看起来大/小"的直觉）。
若人确认是面积比例，档数应下调，范围也应改为 5.2–7.7px。

## 2. 该范围在物理上能给出几档（Lead 计算，可复跑）

| 判据 | 阈值 | 最多档数 | 相邻半径差 |
|---|---|---|---|
| A 的绝对判据 | ≥2px | **3 档** | 2.70px |
| C 的绝对判据 | ≥3px | **2 档** | 5.40px |
| C 的相对判据 | ≥20%×r | 最多 5 档 | — |

**反锯齿 +1.0px 为常量偏移**（`metrics-baseline` 实测，所有半径一致）
⇒ 差分时抵消 ⇒ 不改变上述档数结论。

## 3. 与各方提案的对比：人给定范围比三方都窄

| 提案 | 半径范围 | 跨度 | 相对人给定 |
|---|---|---|---|
| A | 4–12px | 8.0px | 宽 1.5× |
| B | 5–18px | 13.0px | **宽 2.4×** |
| C | 6–15px | 9.0px | 宽 1.7× |
| **人给定** | **4.5–9.9px** | **5.4px** | — |

⇒ **三方各自的档数主张在其自身范围内自洽，但范围本身都超出人给定的约束**
⇒ 因此「12–13 档」「5 档」「4 档」在 v0 的合法范围内**都不可能**：
   - 12–13 档 ⇒ 相邻差 0.4px（远低于任何判据）
   - 5 档 ⇒ 相邻差 1.35px（低于 2px）
   - 4 档 ⇒ 相邻差 1.8px（低于 2px）
   - **3 档 ⇒ 相邻差 2.70px（唯一同时满足 2px 判据且在范围内）**

## 4. v0 承诺（拟）

> ⚠️ **判据归属必须先写清（防二次误读，metrics-baseline 2026-10-26 提醒）**：
> **本裁决的「3 档」采用的是 A 的 2px 判据，不是 C 的 3px 判据。**
> 在 [4.5, 9.9] 范围内：A 的 2px ⇒ **3 档**；C 的 3px ⇒ **2 档**。
> 若今后有人引用 C 的证据写成「C 支持 3 档」，那是第二次误读 ——
> C 的 3px 判据在 [6, 15] 范围下才给出 4 档，与本范围无关。

```
· 视觉尺寸范围：基准的 75% ~ 165%（人给定）
· 档数：3 档 —— 【依据 A 的 ≥2px 判据】相邻半径差 2.70px
· 映射：分位（quantile）驱动 —— 结构上消除长尾，A 已撤回「sizeScale 必须」
· 不承诺：4 / 5 / 12–13 档（超出人给定范围，物理上不成立）
· 反锯齿 +1.0px 常量偏移不影响差分判据，但须在验收脚本中记录
· 【保守性声明】3 档建立在 2px 判据上；若将来人类判读实测证明真实阈值是 3px，
  则应降为 2 档。DS-1 实验是这条降级路径的前提。
```

## 5. 连带效应

```
① metrics-baseline 提出的 人类判读实验 DS-1（5 被试 × 3 小时）
   ⇒ 【不再必要】：人已直接给出约束，比实验更快更准
   ⇒ 但仍登记为 backlog：若将来要更细档位（>3 档），必须先做 DS-1
② todo-owner 的 V6（布局稳定性）不受本条影响，仍按"v0 会话内稳定 / v1 跨会话持久化"裁
③ arch-contract 的 V3（分位映射）与之相容：分位映射在该范围内输出 3 档
④ 视觉验收可测：渲染 3 个不同 quintile 节点 ⇒ 实测直径差 ≥ 2×2.70+1 ≈ 6.4px（含反锯齿偏移）
```
