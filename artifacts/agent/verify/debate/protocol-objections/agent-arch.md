## 我对 CONFLICT-1..4 的立场

### CONFLICT-1（度量规则是否通用化）

- **立场**：**不通用化**（B1–B5 保持「仅度量证据」适用范围），但把 B3 的内核改写为
  「**首选解读权**（必须先被记录、不得被摘要掉）≠ **否决他人重解权**」。
- **理由**：
  1. 通用化的唯一收益是"保护测量者不被抢解读"，而这个收益在非度量场景下**已经被别处覆盖**：
     我的独有证据不被摊平 → E2 + J2；我的立场不被整体打包驳回 → J1；我的异议不被删 → J4。
     所以通用化没有新增保护，只新增副作用。
  2. 通用化的副作用是**解读垄断**：任何结论都能自称"只有我能解读"。这会给弱证据结论（B 级线索）一层不该有的冻结壳，
     与 M1「合法性来自证据而非权威」直接冲突——提出者对自己结论的"垄断解读权"，就是一种微型权威。
  3. 非度量结论的解读权归属**不需要新规则**：P1（要重解就给你的证据+替代解读）+ J1（逐条对照）+ J3（falsifier）已经够用。
- **证据**：`ev:file:artifacts/agent/verify/debate/protocol-v1.md#L68`（B3 原文）、`#L104-L106`（CONFLICT-1 原文）；
  我对该项的风险描述：`ev:file:artifacts/agent/verify/debate/protocol-proposals/agent-arch.md#§1.1`。
- **可机器校验**：B3 生效时，`interpretation.authority = primary-recorder` 字段只允许出现在 `evidence_kind = bench` 的证据上；
  非 bench 证据上出现该字段即 `misapplied-rule`。

### CONFLICT-2（unknowns 的中立边界）—— 针对我的一条真实反驳，正面回应

- **立场**：**接受「应知而未知」扣分。不接受"看情况"。** 光接受不够，我给出**可计算的判据**，让它不依赖任何人的主观判断：

  **判据（"应知"的唯一定义）**
  「应知」= 属于 **F1 冻结的问题陈述**（`frozen-questions[]` / 任务验收判据）所枚举的类目
  且 **未出现在** `coverage.checked[]` / `coverage.unchecked[]` / `coverage.out_of_scope[]` **任一清单**中的类目。
  → 换句话说：**范围由 F1 冻结，完整性由"三张表对同一枚举构成分割"机器判定**，评审者不需要"凭感觉说你应该知道"。
  → 收窄范围以规避责任这条路被 F1 堵死：任务陈述已定义范围，擅自收窄 = `baseline_mutation`（F1 原文已规定须重开 Phase）。

  **三种情况，三种处置（明确区分，不留缝）**
  | 情况 | 判定 | 处置 |
  |---|---|---|
  | 类目在冻结枚举内，且**不在任何表里** | `coverage_gap`（漏登记=应知而未知） | **扣分**：该方案 completeness 不得标 `full`；本条结论降级为 `有条件成立` |
  | 类目在 `unchecked[]` / `out_of_scope[]` 里，且写了"若为真则结论如何变" | 诚实盲区 | **不扣分**（P4 保障），且不被当作缺陷计票 |
  | 类目在 `checked[]` 里，但复核/重跑不成立 | `false_claim`（谎报） | **重罚**（不是扣分，是失效）：该方本轮**所有** `coverage.*` 声明降为 B 级线索；并且**取消其 P4/M3 豁免**（因为豁免的前提是诚实） |
- **为什么"堆 unknowns 逃避"这条路被结构性地堵死**（这是我对 CONFLICT-2 的核心回答）：
  每个 `unknowns[]` / `not_doing[]` 条目必须绑定 **`if_true_then`**：写明「若该未知为真，则结论变成什么」。
  于是堆条目**不降低**可攻击面，反而**逐条自曝**失败模式：质疑者可以直接引用提案者自己写的
  「若 Cordis 与 Memoria 能力插件真非同物，则我的"零改动移植"不成立」来一击命中，无需自己去证明。
  → 堆 unknowns 的边际收益 = 0，边际成本 = 每加一条多一个可被引用的 falsifier。激励从"藏"变成"算清楚"。
  → 若某条 unknowns **写不出** `if_true_then`（即"我也不知道它到底会不会改变结论"），则该条**不计入** P4 豁免（等价于没登记 → 触发 `coverage_gap`）。
- **保护谁**：诚实者拿到"写未知不扣分"的稳定预期；决策者拿到"每个未知都带着失效条件"的可审计台账。
- **伤害谁**：若不采纳（继续"看情况"），受伤的是**人**——他永远无法判断一份方案里的"不确定"是真盲区还是免责话术。
- **证据**：`ev:file:artifacts/agent/verify/debate/protocol-v1.md#L107-L109`（CONFLICT-2 原文）与 `#L59-L60`（F1 可作为枚举来源）；
  我 Phase 1 的原始立场：`ev:file:artifacts/agent/verify/debate/protocol-proposals/agent-arch.md#§1.3`、`#§2 R5`、`#§4.4`。

### CONFLICT-3（P2 的边界：覆盖面清单的最低充分性由谁判、按什么标准）

- **立场**：**不由任何个人主观判**。充分性由两条**可执行**判据确定，一条机器判、一条质疑者判；
  第三条纪律保住 P2 的不可退让内核。
  1. **机器判——分割完整性**：`checked[] ∪ unchecked[] ∪ out_of_scope[]` 必须等于 F1 冻结枚举全集，且两两不相交。
     缺、重、越界 = `coverage_gap`，可由脚本判（集合运算，不需要人）。
  2. **质疑者判——只认实例，不认"看起来不全"**：任何"你漏了 X"必须以「X 的具体身份 + X 属于冻结 scope 的证明（A1/A3）」提交；
     仅凭"清单看起来很单薄/不够全"的质疑 **不受理**（这正是 P2 不可退让的内核：它把"证明缺席"换成"举出一个存在"）。
  3. **抽查权（防假清单）**：审阅者可从 `checked[]` 随机抽 N 条（N 由轮次预算定）要求重跑或复核；
     任一抽查不复现 = `false_claim`（处置见 CONFLICT-2 表）。
- **判据的来源可复核性**：以上三条不需要新事实，只需要 `protocol-v1` 的 F1 枚举 + 提案者的三张表 ——
  第三方只凭磁盘产物即可重算（J6）。
- **保护谁**：交付强主张的人（我）不被要求证明缺席；同时保护评审者——他有"实例质疑"与"抽查"两个真实靶点，不是无牌可打。
- **伤害谁**：若把"充分性"交给单人主观判断，受伤的是**证据的可复核性**（M1 的合法性来源被一句"我觉得不够全"污染）。
- **证据**：`ev:file:artifacts/agent/verify/debate/protocol-v1.md#L39-L40`（P2 原文）、`#L110-L111`（CONFLICT-3 原文）。

### CONFLICT-4（裁决合法性 vs 人的最终决策权）

- **立场**：接受「人有最终决策权」这个组织事实（M1 的 note 已承认），但要求把人的推翻落成**独立事件类型 + 四项形式要件**，
  且最关键一条：**override 不得在后续被引用为"证据结论"**。
- **理由**：我在 §1.3 担心的正是"合法性与决策权被搅混"。若人的推翻被记成普通 `ruling`，三个月后它会被读成
  "证据表明该方案错误"，而它实际是组织决定。这会污染 J6 的可复算性：结论的来源类型必须可区分。
- **四项形式要件（可执行）**：
  1. 书面理由（替换 `理由: <一至三句>`）；
