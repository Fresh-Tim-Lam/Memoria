## 重点 ① J2：你把我放弃的权力换了个名字还给我 —— **我要求改写**

### 我接受这个后果吗？**不接受。**

**问题诊断**：J2 的条件是"被驳回立场持有 `unique_evidence`"。但协议**没有定义谁来判定 `unique_evidence` 成立**。若由异议方自报，则：

- 任何人只要声明"我有独有证据"，即触发「裁决只能 `open`，**禁止票决关闭**」；
- 而"独有"的定义（"其他立场没有的证据"）**几乎总能满足**——我随便找一条提案者没引用的代码行，就是"其他立场没有的证据"。

⇒ **J2 事实上给任何一方无限期阻塞权，且举证成本近零。** 这正是我 §3 主动放弃的"一票否决权"，被换个名字还了回来。

**更深的滑坡**：我 §2-R3 的原意是「**异议不得被静默**」（要求裁决方**逐条处理并记录**），J2 却写成「**不得关闭**」（禁止裁决方**得出结论**）。
- 「必须逐条处理」= 要求裁决方干活 → 合理，我支持。
- 「必须保持 open」= 禁止裁决方结论 → **这是把"程序义务"变成了"实体否决权"**。

### 替代方案（可收敛的阻塞权）

把 J2 改为**「有义务处理 + 有期限 + 举证责任在阻塞方」**：

```
J2' 少数派唯一证据强制处理（改写）
(a) 被驳回立场若声明持有 unique_evidence，裁决必须逐条写
    unique_evidence_handled: accepted|rejected|deferred + 理由。    ← 保留原文，这是"不得静默"
(b) unique_evidence 的成立由**裁决方核验**，不由异议方自报：
    异议方必须给出 ev: 身份 + 「为何其他立场未覆盖」的一句话论证；
    裁决方核验不成立 ⇒ 降为普通异议，可正常票决关闭。
(c) 核验成立 ⇒ 状态为 `deferred`（**不是 open**），且必须同时满足三件：
    ① 指派检验者（谁去验）；
    ② 给收敛期限（下一轮 / 明确时间点）；
    ③ 阻塞方承担举证义务：期限内未提交该证据的完整形态 ⇒ 自动降为 rejected 并记入 J4。
(d) 只有 deferred 且未过期限时，才禁止票决关闭。
```

**这套改写的取舍**：
- **保留** J2 的全部初衷：有唯一证据的人**不会被静默**，且裁决方**必须逐条回应**。
- **移除**：无限期阻塞（加期限）+ 自报即可触发（改裁决方核验）+ 零成本（加举证义务）。
- **谁受益**：持真证据的少数派（他们的异议**一定会被处理并留下记录**，不再依附于"能不能关闭"）；以及多数派（不会被零成本拖延）。
- **谁受损**：想用"我有独有证据"当拖延术的人。**这正好是应当受损的一方。**

**证据**：本仓 `task-39` 就是正面例子——我提交 L0=81.58% vs L1=100% 的反差，那是**可核验的 unique_evidence**，按 J2' 会走 `deferred`→指派检验→按期收敛；按 J2 原文则可以直接把整个 AST 决策无限期挂起，而实际上它当场就能裁决。

## 重点 ② CONFLICT-4：人的最终决策权 —— 我的形式要件提案

**前提承认**：人是最终决策者，这改不了，**也不该改**。我 §3-1 反对的从来不是"人有决策权"，而是"**用权威代替证据作为合法性来源**"。这两件事可以同时成立。

### 我的形式要件提案（保留决策权，防止橡皮图章）

人推翻一条**可复核**裁决时，协议要求三件事（不是请求，是**记录要件**）：

```
R-1 书面理由：必须写明「推翻的是哪条裁决 / 依据什么证据或考虑」。
R-2 可复核的 falsifier：必须写明「什么条件下这个推翻会被重新评估」
    —— 允许是人本位的条件（如"若用户量超过 X 再重议"），
       但不得为空，也不得写成"永远不重新评估"。
R-3 记录为 dissent 而非 overrule：
    原可复核裁决**保持有效状态**，人的决定作为 `human_override` 记录在案，
    两者并存于冻结产物（J4 的同族处理），**不删除原裁决**。
```

**R-3 是核心**：它让人保留**全部实际决策权**（想怎么定就怎么定，立即生效），但**不抹掉"曾经有一条基于证据的裁决"这个事实**。

- **为什么不叫 overrule 叫 dissent 并存**：因为"删除原裁决"会让未来的人失去"当初专家依据什么判断"这一信息。并存 = 决策权 100% 归人，**信息完整性 100% 保留**。
- **谁受益**：人（决策不被阻碍，且留下自己的理由）；未来复盘者（能看到当时的证据与人的理由并置）。
- **谁受损**：想"无声推翻且不留痕"的做法。这是**唯一应当受损的**。
- **这是否让裁决变橡皮图章**：不会。橡皮图章的定义是"裁决无实际约束力"。这里裁决**有实际约束力**——它约束 Lead/流程（J1-J6 照跑），只是**不能约束人**。而"不能约束人"是组织事实，不是我能在协议里改变的。

**一句话**：我不要求人"不该推翻"，我要求**推翻必须是"可追溯的推翻"**。

## 重点 ③ E1：反例要不要独立身份 —— **我要求新增 `ev:counterexample`**

### 结论：**要新增**，但不是替代 `ev:file`，而是**在其上叠加"证明义务"**

**理由（为什么 `ev:file:<path>#L<n>` 不够）**：

`ev:file:agent-panel.js#L3426` 表达的是「我引用了这个文件这一行」。
但我的核心证据形式是：「**这一行代码的存在，证伪了提案的某个前提**」——这是一个**论证**，不是一个**位置**。

两者强度不同：
| 引用 | 主张强度 | 可复核性 |
|---|---|---|
| `ev:file:X#L100` | "这里有段代码" | 只需打开文件确认存在 |
| 反例 | "这段代码**使得主张 Y 不成立**" | 需重放论证链：代码语义 → Y 的失败 |

若把反例塞进 `ev:file`，裁决方**无法区分**"我引了个文件"和"我给出了反例"——而我 §4.3 恰恰主张反例**权重最高**。**一个无法被识别为高权重的证据，就没有高权重。**

**建议的语法（最小增量，不破坏 E1 五类）**：

```
ev:counterexample:<id>                    ← 新 kind，注册表形式
  注册项（同 J6 日志内）:
    claim_ref:     被证伪的主张 id
    evidence:      支撑的 ev:file/commit/bench（可为多条）
    argument:      为什么它证伪 —— 一段可复核的推理，不得只写结论
    replay:        如何复核（command / 手工步骤）
    scope:         证伪的边界（在什么前提下成立）
```

**为什么用注册表而不是内联**：反例的价值在**论证链**，需要 `claim_ref`（对谁）和 `replay`（怎么查）。内联字符串装不下，也没有地方挂"复核方式"。

**保护谁**：评审者（我最强的证据终于能被识别）。**伤害谁**：想用"引个文件"冒充反例的人。**代价**：多一个注册表，但可由 J6 哈希链承载，**零新增机制**——这是"先条款后检查"的成本最低形态。

**替代方案（若 Lead 认为新增 kind 过重）**：退一步——**保留 `ev:file`，但要求反例必须同时给 `claim_ref` + `replay` 两个附加字段**，且「缺 `replay` 的反例按普通引用计权」。这等于在 E1 内加两个可选字段，不动 kind 枚举。**我接受这个退让**，因为核心是"论证链可复核"，不是 kind 的名字。

## 我对 CONFLICT-1..4 的立场

### CONFLICT-1｜B3「测量权与解读权同源」适用范围

**我的立场：仅适用于度量证据，不得通用化。**

- **理由**：若通用化（每个结论只能由提出者解读），则我做契约评审时**无权解读提案者的证据**——但对抗评审的**核心工作**就是解读他人证据找漏洞。通用化会**结构性取消我的角色**。
- **但对度量证据要保留强版本**：因为测量口径的细节（预热、抽样、环境）**只有测量者最清楚**，曲解成本最低、误导性最高。
- **非度量结论的解读权归属**：归**裁决方**，但受 J1（逐条对照）+ J3（falsifier）约束。
- **保护谁**：评审者（可解读非度量证据）。**伤害谁**：想垄断解读权的一方。

### CONFLICT-2｜unknowns 的中立边界

**我的立场：M3/P4 的"不确定不计缺陷"保留，但增加一条「应知门槛」——判"应知"的标准必须可复核，不能由裁决方感觉决定。**

- **可复核的"应知"判据（我建议用这三条之一即可）**：
  1. 该事项在**被冻结的问题陈述**（F1）中被明确列出；
  2. 该事项是**互斥方案选择所必需**的（不答就无法判优）；
  3. 该事项在**辩论过程中曾被任一方显式提出**（J5 已有类似的"不得加料"逻辑）。
- **反例（什么不算应知）**：实现细节、未来版本范围、未在冻结陈述内的问题。
- **为什么必须给判据**：否则"应知"变成裁决方的主观裁量，**正是我 M1 反对的"权威代替证据"的微缩版**。
- **保护谁**：诚实申报 unknowns 的一方。**伤害谁**：用 unknowns 逃避完整性的做法（有明确门槛卡住）。

### CONFLICT-3｜P2「不得要求缺席证明」的边界

**我的立场：P2 保留；「覆盖面清单的最低充分性」由裁决方按 F1 冻结的可接受判据判定，不由提案者自定，也不由评审者单方定义。**

- **具体**：充分性的锚点是 **F1 冻结的"可接受判据"**（Phase 0 已冻结）——即「满足这些判据即视为覆盖面充分」。若判据本身有缺口 ⇒ 走 F1 的 `baseline_mutation` 重开，而**不是**在 P2 里现场争论。
- **这样处理的好处**：把"够不够全"的争论**前移到 Phase 0**，避免在辩论中因"你漏了 X"打无限循环。
- **保护谁**：双方（都有客观锚点）。**伤害谁**：想在辩论中途临时提高完整性标准的一方（J5 也防这个）。

### CONFLICT-4｜裁决合法性 vs 人的最终决策权

**见重点 ②。我的形式要件提案：R-1 书面理由 / R-2 可复核 falsifier / R-3 记为 dissent 并存而非删除原裁决。**
