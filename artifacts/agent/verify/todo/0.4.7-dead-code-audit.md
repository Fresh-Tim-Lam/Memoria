## 四、错误约定注释的**历史来源**（Lead 加码 1：带历史锚）

**判定：属「约定腐化 + 腐化后无人复验」，不是"一开始就错"。**

| 时间 | commit | 事实 |

**修复后的注释（`agent-panel.js:7036` 起，含历史锚）**：
