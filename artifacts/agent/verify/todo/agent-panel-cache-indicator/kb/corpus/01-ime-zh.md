# 01 · 中文输入法与全角标点

这是一段连续中文段落，用来测输入法在纯中文语境下的落字与同步。这里的每一个标点都是全角：，。！？：；「」『』（）——……

中英混排的句子：这是 mixed 文本，Word 与 中文 交替出现，半角空格与全角逗号都要保持原样。

**加粗中文** 与普通中文之间的边界也要能打字：**这里是加粗**，这里不是加粗。

> 场景说明：把光标停在这一行末尾，**在此处切换到中文输入法**，输入「测试」两字的拼音 ceshi，观察候选框出现期间预览区不重渲；按空格落字后，真源应逐字出现「测试」。

拼音中途切换：先英文输入 abc，然后**在此处切换到中文输入法**继续输入「中文」，再切回英文输入 def，得到 abc中文def 的顺序应逐字正确。

「引号里的中文」和『单引号』以及（括号）内的标点，都不应被改写；破折号——与省略号……同样保持原样。
