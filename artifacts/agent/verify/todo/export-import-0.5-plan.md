## 4. 产出：范围 / 批次 / 验收（详见 `design/export-import-0.5.md`）

### 4.1 MVP（P0）
1. **入口与流程**：启用 `文件→导出`（当前 `index.html:77` disabled）；`export_scan` 预览（文件/图片/预估体积/形态）→ `export_execute` → 结果反馈。
2. **选择范围**：单文件 / 多选 / 全选。
3. **产物形态**：单 `.html`（自包含）或 网页文件夹（`index.html` + `assets/`）。
4. **渲染静态化（零外部依赖）**：导出时用现有 marked + MathJax `tex-svg` 预渲染 SVG 内联 + mermaid 预渲染 SVG；**导出页不加载 vendor**（MathJax/mermaid 只在导出时用）⇒ 断网可看。
5. **资产**：仅被引用图片；单文件 base64 / 文件夹相对路径；**绝不包含** `config/agent.json`、`agent/sessions`、API key。
6. **链接降级**：集内相对链接；集外保留文本+标记；外链保留。
7. **样式**：Q1 待拍板；先按推荐默认（Memoria 只读文档页，不含侧栏/图谱/搜索）。
8. **体积/性能**：预估 + 超限警告；全选 AAA_Vocab（182 md/2.0MB、21 图/1.9MB）为基线。
9. **隐私提示/i18n/文档**。

### 4.2 明确不做（0.5.x）
HTML 导入（I05）、bundle 导出（B7）、PDF（V04）、R14（V01）、图谱/搜索静态化、可达闭包、增量合并、自定义主题；理由与去向见文档 §7.2。

### 4.3 批次
- **Batch 1**：单文件导出（单 html）+ 默认样式 + 图片内联 + 链接降级 + 扫描预览/反馈。
- **Batch 2**：多选/全选 + 网页文件夹 + 资产目录 + 体积/性能 + 大库保护。
- **Batch 3**：Q1 拍板后的第二样式 + 边界/空态 + 文档/i18n/隐私 + Chrome/Edge 离线矩阵。
- **v1（之后）**：HTML 导入、可达闭包、搜索静态化、bundle 对。

### 4.4 验收（"浏览器打开后"可测）
断网 `file://` 打开：A1 外部请求 **0**；A2 console error **0**；A3 公式 SVG 数 == 源公式块数；A4 mermaid 块 == 内联 SVG；A5 所有 `<img>` naturalWidth>0；A6 集内链接可达/集外有标记不 404；A7 产物 grep 不到 api_key/session/agent.json；A8 体积记录且预估偏差 ≤30%；A9 单文档首屏 ≤2s；A10 可读性（16px/行宽 60–80/代码表格不溢出/打印不截断）。分批增量判据见文档 §9.2；禁止"看起来更好看"验收。
