# 02 · Inline 边界

这是加粗之前可以打字的一句。**这是加粗**这是加粗之后也可以打字的一句。

斜体前后同样留句子：这是斜体之前。*这是斜体*这是斜体之后。

嵌套：***又粗又斜*** 的左右各留一句可打字：左边这一句，右边这一句。

行内代码紧邻文字：普通文字`inline code`普通文字，交界处要能落字。

行内公式边缘：公式前 $x^2 + y^2 = z^2$ 公式后，在这两侧打字不应破坏公式。

Wikilink 中间可打字：前缀 [[目标-中]] 后缀——注意在 `[[` 与 `]]` 之间加字。

转义：这里有一个转义星号 \* 不应被当作斜体起始。

可在此处打字的句子 ①。**粗**可在此处打字的句子 ②。

可在此处打字的句子 ③。*斜*可在此处打字的句子 ④。
