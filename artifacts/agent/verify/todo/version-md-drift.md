## 2. L12 修正

**改前**：
```
| 说明 | 0.4.9 = 开发中（未发布）；最近已发布 = 0.4.8（0.5.0 已撤回，见 §2） |
```

**改后**：
```
| 说明 | 最近已发布 = **0.4.9**（2026-10-25，tag `v0.4.9` → `4cdcb3a1`；release commit `225110bb`）；下一个版本待定（0.5.0 曾发布后撤回，见 §2 0.x 约定） |
```

**改动要点**：
1. 「最近已发布」从 `0.4.8` → **`0.4.9`**（含日期 2026-10-25）；
2. 删掉「0.4.9 = 开发中（未发布）」这句话本身（它是错的）；
3. 补上 **tag → commit 证据锚**（`4cdcb3a1` / `225110bb`），让读者可自行核验，不必再猜；
4. 「下一个版本待定」—— 不臆断下一版号；
5. **0.5.0 撤回的信息保留**（那是真实历史，`v0.5.x` tag 实测不存在），只把指向改准（§2 0.x 约定）。

> **未改**：`§1 当前版本 = 0.4.9`（本来就对）；任何 `__version__.py` / `Package/VERSION`（人权限）；
> CHANGELOG 的 0.4.9 行（只修说明行，不动版本记录）。
