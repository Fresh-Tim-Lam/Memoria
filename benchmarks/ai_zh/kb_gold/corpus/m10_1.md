#### 知识点10-1：语言基础模型（大模型）的发展与建模（对应表格“语言大模型”）

**位置来源**：第289-295页（10.1.1-10.1.2节），第1-6页

**1. 自然语言处理范式的三次转变**
- **位置来源**：第289页，图10.1，第1页。

| 阶段 | 范式 | 特点 |
| :--- | :--- | :--- |
| **早期** | 浅层/深度学习模型 | 为每个任务分别设计和训练模型（碎片化，重复劳动） |
| **中期** | **预训练模型 + 微调** | 基于大规模语料训练预训练模型，再针对下游任务微调参数（BERT、GPT等） |
| **当前** | **预训练 + 提示学习 + 预测** | 不调整模型参数，通过设计提示（prompt）激活模型知识，完成下游任务 |

- **核心趋势**：“计算为大、语言式微”——从偏重语言学方法转向偏重计算学习。

**2. 语言大模型的建模：下一个词预测（NWP）**
- **位置来源**：第290-291页，第2-3页。
- 给定长度为 \(T\) 的单词序列 \(x = (w_1, w_2, \dots, w_T)\)，语言模型建模文本联合概率分布：

\[
P(w_1, w_2, \dots, w_T) = \prod_{i=1}^{T} P(w_i \mid w_1, w_2, \dots, w_{i-1})
\]

- **传统N-gram**：采用马尔可夫近似——下一个词仅与有限上文有关。
- **神经网络语言模型（NNLM）** ：用神经网络建模条件概率。
- **Transformer**：因高效并行计算和长程记忆能力，替代RNN成为主流架构。

**3. 三种预训练语言模型架构（图10.3）**
- **位置来源**：第291-292页，第3-4页。

| 类型 | 代表模型 | 预训练目标 | 适用任务 |
| :--- | :--- | :--- | :--- |
| **编码模型（Encoder-Only）** | BERT、RoBERTa | **掩码语言模型（MLM）** ：预测被掩码的单词（完型填空） | 文本分类、命名实体识别（自然语言理解） |
| **解码模型（Decoder-Only）** | GPT-2、GPT-3 | **自回归语言模型**：预测下一个单词 \(P(w_t \mid x_{<t})\) | 对话、摘要、故事生成（自然语言生成） |
| **编码-解码模型** | BART、T5 | 破坏输入文本，用序列到序列方式重建 | 同时支持理解和生成 |

- **MLM的缺点**：
  1. 预训练阶段使用[MASK]标记，微调阶段不存在 → 训练与推理不一致
  2. 不像自回归模型那样生成连贯文本

- **自回归模型的缺点**：生成时只考虑左侧上下文，无法利用双向信息。

**4. 教材示例：Transformer处理“项庄舞剑、意在沛公”（图10.5）**
- **位置来源**：第293-294页，第5-6页。
- **步骤**：
  1. 生成每个单词的内嵌向量 \(w_i\)（含位置编码）
  2. 计算查询向量 \(q_i = W_{\text{query}} \times w_i\)，键向量 \(k_i = W_{\text{key}} \times w_i\)，值向量 \(v_i = W_{\text{value}} \times w_i\)
  3. 计算关联度：\(\text{score}_{i,j} = w_i^T W_{\text{query}}^T W_{\text{key}} w_j\)
  4. 归一化：\([\alpha_1, \dots, \alpha_L] = \text{softmax}([\text{score}_1, \dots, \text{score}_L])\)
  5. 自注意力输出：\(\sum_{i=1}^{L} \alpha_i (W_{\text{value}} x_i)\)

- **GPT-3架构**（第294页）：50,275个单词词向量 → 96个堆叠Transformer → 前馈神经网络非线性映射 → 文字接龙式生成。

**5. 语言大模型的参数优化**
- **位置来源**：第295页，第6页。
- 给定前序 \(i-1\) 个单词，预测第 \(i\) 个单词的概率：
  \[
  P(w_i \mid w_{1:i-1}) = \text{softmax}(E \phi(w_{1:i-1})_{i-1})
  \]
- **最大似然估计**（负对数似然目标函数）：
  \[
  O(\theta) = \sum_{w_{1:L} \in D} \sum_{i=1}^{L} -\log P_\theta(w_i \mid w_{1:i-1})
  \]
- 用梯度下降算法优化，使模型完成“文字接龙”任务。


#### 知识点10-2：提示学习、指令微调与RLHF（对应表格“语言大模型”）

**位置来源**：第295-300页（10.1.3节后半部分及图10.6-10.9），第6-10页

**1. 提示学习（Prompt Learning）**
- **位置来源**：第295-296页，第6-7页，图10.6。
- **核心思想**：将各种NLP任务转化为语言模型预训练任务（完型填空或文字接龙）。
- **示例（情感分析）** ：“这部电影很精彩” → “这部电影很精彩，因为其剧情很[MASK1]” → 模型预测“引人入胜” → 映射到“正向情感”。
- **缺点**：
  1. 依赖设计高质量提示，需要多次迭代
  2. 难以完成零样本（zero-shot）学习任务

**2. 指令微调（Instruction Tuning）**
- **位置来源**：第296-297页，图10.6、图10.7，第7页。
- **核心思想**：将各种NLP任务转化为**生成式指令数据集**，基于指令数据集微调大模型。
- **目的**：让模型更好地理解人类意图，对齐人类指令，提升零样本性能。
- **与提示学习的区别**（图10.6）：
  - 提示学习：设计提示模板，不调整模型参数
  - 指令微调：基于指令数据集**微调模型参数**，减少构造提示模板的成本

**3. 人在回路微调——基于人类反馈的强化学习（RLHF）**
- **位置来源**：第298-300页，图10.8、图10.9，第8-10页。
- **目标**：使模型输出与人类价值对齐（保持诚实、不带偏见、无有害信息）。

**阶段一：训练奖励模型（Reward Model, RM）** （图10.8）
- 收集问题，使用SFT模型生成多个回答
- 人工对回答进行**排序**（而非打分，因为排序更客观）
- 损失函数（对回答两两组合）：
  \[
  \text{loss}(\theta) = -\frac{1}{C_K^2} \mathbb{E}_{(x, y_w, y_l) \sim D} \left[ \log(\sigma(r_\theta(x, y_w) - r_\theta(x, y_l))) \right]
  \]
  - \(y_w\)：更受人类偏好的回答
  - \(y_l\)：较不受偏好的回答
  - \(r_\theta(x, y)\)：奖励模型输出的奖励分

**阶段二：PPO算法优化SFT模型**（图10.9）
- 让SFT模型回答新问题，奖励模型打分
- 用**PPO（Proximal Policy Optimization，近端策略优化）** 算法微调
- 优化目标函数：
  \[
  \text{objective}(\phi) = \mathbb{E}_{(x,y) \sim D_{\text{RL}}} \left[ r_\theta(x,y) - \beta \log\left( \frac{\pi_\phi^{\text{RL}}(y|x)}{\pi^{\text{SFT}}(y|x)} \right) \right] + \gamma \mathbb{E}_{x \sim D_{\text{pretrain}}} [\log(\pi_\phi^{\text{RL}})]
  \]
  - 第一项：最大化奖励
  - 第二项：**KL散度约束**，防止策略偏离SFT基线太远（系数 \(\beta\)）
  - 第三项：防止过度优化，损失GPT-3原有核心性能（系数 \(\gamma\)，\(\gamma=0\) 时为PPO模型，否则为PPO-ptx模型）


#### 知识点10-3：自然语言中的机器翻译（对应表格“自然语言中的机器翻译”）

**位置来源**：第300-303页（10.2节全文），第11-13页

**1. 机器翻译的任务定义**
- **位置来源**：第300页，第11页。
- 给定一个**源语言句子**（如中文），自动翻译为**目标语言句子**（如英文）。
- 应用场景：跨国企业商务沟通、科学研究文献阅读、旅游和文化交流。

**2. 非深度学习方法**
- **位置来源**：第300-301页，第11-12页。
- **基于文法的机器翻译（Grammar-Based）** ：
  - 利用语言学规则实现单词替换
  - 两个步骤：**解析（Parsing）** → 生成语法结构树；**生成（Generation）** → 按目标语言文法生成句子
  - 优点：可控、规范、能处理复杂语法；缺点：形成大规模文法规则困难，难以处理语言变体和歧义
- **基于统计的机器翻译（SMT）** ：
  - 利用大规模双语语料库学习统计规律
  - 两个阶段：**训练**（学习源语言-目标语言对齐关系）→ **解码**（用隐马尔可夫模型等方法找最大概率匹配）

**3. 深度学习方法——编码器-解码器模型（NMT）**
- **位置来源**：第301-302页，图10.10，第12-13页。
- **编码器**：
  - 将源语言每个单词编码为词向量 + 上下文信息
  - 常用RNN/LSTM，逐一处理单词，最后时刻的隐藏状态作为源语言句子的整体表示
- **解码器**：
  - 将编码器的最终隐藏状态作为输入
  - 逐步生成目标语言单词：给定开始标记 \<SOS\>，逐词预测，直到生成结束标记 \<EOS\>
  - 每个时刻选择概率最大的单词作为输出
- **模型训练**：
  - 使用对齐的源语言-目标语言语料
  - 用**交叉熵损失函数**衡量生成译文与真实译文的差异
  - 用**误差反向传播**优化模型参数


#### 知识点10-4：图像分类与视觉对象定位（对应表格“视觉理解中的图像分类”）

**位置来源**：第303-305页（10.3节全文），第14-15页

**1. 任务定义**
- **位置来源**：第303页，第14页。
- **图像分类**：将一幅图像识别归属为 \(K\) 个类别中的某一个类别（如鸟类具体品种）。
- **视觉对象定位**：识别关键物体，同时确定其在图像中的**位置**（输出包围盒 bounding box）。
- 应用场景：自动驾驶、图像检索、监控安防。

**2. 基于CNN的解决方案（图10.11）**
- **位置来源**：第303-305页，第14-15页。
- 以卷积神经网络为主干，可采用多任务形式同时完成分类和定位。

| 操作 | 功能 |
| :--- | :--- |
| **卷积操作** | 提取图像特征（纹理、边缘、角点等），层层递进、逐层抽象 |
| **池化操作** | 最大池化或平均池化，对卷积结果进行约减 |
| **全连接层** | 将高度压缩的特征向量送入分类/定位头 |
| **分类任务** | softmax激活函数输出所有类别的概率分布 |
| **定位任务** | 参考**Faster R-CNN**（区域候选网络RPN + 感兴趣区域池化RoI Pooling），输出包围盒四维坐标 |


#### 知识点10-5：机器人中的行为控制（对应表格“机器人中的行为控制”）

**位置来源**：第313-316页（10.7节全文），第19-22页

**1. 机器人的基本构成**
- **位置来源**：第313页，图10.17，第19页。
- 机器人是融合**感知、决策、执行**于一体的自主智能体。
- 类型：操作机器人（机械臂）、移动机器人（无人机/自动驾驶）、类人机器人等。

**2. 机器人完成任务的基本流程（图10.18）**
- **位置来源**：第314-315页，第19-20页。

| 步骤 | 内容 |
| :--- | :--- |
| **感知（Perception）** | 多源传感器获取信息（相机、深度相机、激光雷达、毫米波雷达、IMU、GPS等） |
| **状态估计（State Estimation）** | 通过计算机视觉算法（检测、识别、定位、姿态估计）感知环境 |
| **规划（Planning）** | 生成路径（path）和轨迹（trajectory），常见方法：RRT快速扩展随机树、非线性最优控制 |
| **控制（Control）** | 低阶控制器控制机械臂/末端操作单元执行动作 |
| **循环迭代** | 直到完成任务 |

**3. 机器人操作任务（图10.19）**
- **位置来源**：第314页，第19页。
- 示例：机械臂物体抓取 → 感知图像 → 状态估计（6自由度姿态） → 坐标转换 → 抓取动作规划。

**4. 机器人导航任务（图10.20、图10.21）**
- **位置来源**：第315-316页，第20-21页。
- **传统方法**：感知 → 建图（Mapping）→ 路径规划（Path Planning）→ 轨迹执行
- **强化学习方法**：将建图到规划部分用神经网络替代，端到端学习策略。


#### 知识点10-6：科学计算——物理约束下的神经网络（PINN）（对应表格“科学计算”）

**位置来源**：第309-311页（10.5节全文），第17-19页

**1. 科学智能（AI4Science）**
- **位置来源**：第309页，图10.15，第17页。
- 将深度学习模型作为科学计算的模拟器，用数学物理方程约束训练结果。
- **两个显著特点**：
  1. 数据来源于采样与模拟，额外标注需求少（数据规模取决于模拟计算开销）
  2. 训练完成的模型在新数据上的计算速度相比传统数值方法**提升数个数量级**

**2. 物理约束下的神经网络（PINN）**
- **位置来源**：第310-311页，图10.16，第18-19页。
- **提出者**：Raissi等，2017。
- **核心思想**：用神经网络拟合微分方程的解函数 \(u(t, x; \theta)\)，以**数据与物理驱动**方式求解非线性偏微分方程。

**3. PINN的约束与损失函数**
- **位置来源**：第310-311页，第18页。
- 微分方程约束（PDE）：\(\mathcal{N}(t, x; \hat{u}(t, x; \theta)) = 0\)
- 初始条件（IC）：\(\mathcal{I}(x; \hat{u}(0, x; \theta)) = 0\)
- 边界条件（BC）：\(\mathcal{B}(t, x; \hat{u}(t, x; \theta)) = 0\)
- **总损失函数**（第311页）：
  \[
  \mathcal{L}(\theta) = w_{\text{PDE}} \mathcal{L}_{\text{PDE}} + w_{\text{IC}} \mathcal{L}_{\text{IC}} + w_{\text{BC}} \mathcal{L}_{\text{BC}} + w_{\text{Data}} \mathcal{L}_{\text{Data}}
  \]
  - \(\mathcal{L}_{\text{PDE}}\)：微分算子损失（在定义域内采样计算）
  - \(\mathcal{L}_{\text{IC}}\)：初始条件损失
  - \(\mathcal{L}_{\text{BC}}\)：边界条件损失
  - \(\mathcal{L}_{\text{Data}}\)：真实数据损失（可选，少量标注即可）

**4. 引入专业知识的其他方法**
- **位置来源**：第311页，第19页。
- **图神经网络（GNN）用于分子**：化学分子是天然图结构（原子→结点，化学键→边），用于分子性质预测、分子设计、化学反应预测。
- **自监督训练**：设计专业知识驱动的自监督任务（如AlphaFold中的多序列比对掩码恢复）。
- 科学计算已在物理仿真、化学合成、蛋白质结构预测（AlphaFold）、药物虚拟筛选、新材料合成、天气预测等领域发挥重要作用。
