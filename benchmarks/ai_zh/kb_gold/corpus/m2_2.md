#### 知识点2-4：知识图谱推理概述（对应表格“知识图谱推理”）

**位置来源**：第34-36页（2.4节前言及图2.1），第51-52页

**1. 知识图谱的定义与基本结构**
- **位置来源**：第34页，第51页。
- **知识图谱（knowledge graph）** 由**有向图（directed graph）** 构成，用于描述现实世界中**实体**及**实体之间的关系**。
- **结点**：表示客观世界中的一个实体。
- **边**：表示两个实体之间存在某一关系。
- **三元组表示**：形如 **<left_node, relation, right_node>** 的三元组形式。
- 这种三元组可表示为一阶逻辑（FOL）的形式，为基于知识图谱的推理创造了条件。

**2. 知识图谱推理的核心问题**
- **位置来源**：第34页，第51页。
- **关系推理**是统计关系学习研究的基本问题，也是知识图谱领域的研究热点。
- **目标**：对实体之间存在的关系进行推理，能够从现有知识中发现新的知识，在实体间建立新关联，从而扩充和丰富现有知识库。
- **示例**（教材原文）：从三元组 **<奥巴马，出生地，夏威夷>** 和 **<夏威夷，属于，美国>** ，可推理得到 **<奥巴马，国籍，美国>**。

**3. 教材示例：家庭关系知识图谱（图2.1）**
- **位置来源**：第34-35页，第51-52页，图2.1。
- 图2.1展示了一个简单的家庭关系知识图谱，包含结点（家庭成员）和边（关系）。
- 现有关系示例：**Couple(James, David)**、**Mother(James, Ann)**、**Mother(James, Mike)**、**Sibling(Ann, Mike)**。
- **推理目标**：从已有关系推知 **David 和 Ann 具有父女关系（Father(David, Ann)）**，但这一关系在初始图中并不存在。
- 为此可定义推理规则：  
  \[
  (\forall x)(\forall y)(\forall z)(Mother(z,y) \land Couple(x,z) \rightarrow Father(x,y))
  \]
- 应用该规则：已知 **Mother(James, Ann)** 和 **Couple(David, James)**，可推理得到 **Father(David, Ann)**，从而扩充知识图谱。

**4. 知识图谱推理的代表性方法（教材列举）**
- **位置来源**：第35页，第52页。
- 本节介绍两种具有代表性的方法：
  1. **FOIL（一阶归纳学习器）**——归纳逻辑程序设计（ILP）的代表性方法
  2. **路径排序算法（PRA）**


#### 知识点2-5：FOIL归纳推理算法（对应表格“知识图谱推理”）

**位置来源**：第35-40页（2.4.1节全文），第52-56页

**1. FOIL算法的背景与定位**
- **位置来源**：第35页，第52页。
- **ILP（归纳逻辑程序设计）** 是机器学习和逻辑程序设计交叉领域的研究内容。
- 普洛特金（Plotkin）和夏皮罗（Shapiro）为ILP奠定了理论基础。
- ILP使用**一阶谓词逻辑**进行知识表示，通过修改和扩充逻辑表达式对现有知识进行归纳，完成推理任务。
- **FOIL（First Order Inductive Learner）** 由昆兰（Quinlan）于1990年提出，通过**序贯覆盖**学习推理规则。

**2. FOIL算法的输入与样例构造**
- **位置来源**：第35-36页，第52-53页。
- **目标谓词 \(P\)**：是需要推断规则的结论，也称**规则头**。
- 以图2.1为例，目标谓词为 **Father(x, y)**。
- **正例集合 \(E^+\)**：目标谓词为真的实例。如 **Father(David, Mike)**（从图2.1中唯一可知的Father关系）。
- **反例集合 \(E^-\)**：从知识图谱中构造。如已知 **Couple(David, James)** 成立，则 **Father(David, James)** 可作为反例（记为 \(\lnot\)Father(David, James)）。
- **⚠️ 构造反例的约束**：只有在已知两个实体之间存在关系、且**确定这一关系与目标谓词相悖**时，才能用于构造反例。不能对未知关系（如Father(David, Ann)）构造反例——因为可能是正例。
- **背景知识**：目标谓词以外的其他谓词实例化结果，如 **Sibling(Ann, Mike)**、**Couple(David, James)**。

**3. FOIL算法的核心思想**
- **位置来源**：第35页，第53页。
- 从**一般到特殊**，逐步添加目标谓词的前提约束谓词，直到所构成的推理规则**不覆盖任何反例**。
- **“从一般到特殊”** 指对目标谓词或前提约束谓词中的变量赋予具体值。

**4. FOIL_Gain信息增益评估准则**
- **位置来源**：第36-37页，第53-55页，核心公式位于第54页。
- 添加前提约束谓词后所得推理规则的质量，由 **FOIL_Gain（信息增益值）** 判断。
- **公式**（教材第54页）：
  \[
  \text{FOIL\_Gain} = m_{+} \times \left( \log_2 \frac{m_{+}}{m_{+} + m_{-}} - \log_2 \frac{n_{+}}{n_{+} + n_{-}} \right)
  \]
  - \(n_{+}\)：旧推理规则覆盖的正例数
  - \(n_{-}\)：旧推理规则覆盖的反例数
  - \(m_{+}\)：加入新前提约束谓词后，新推理规则覆盖的正例数
  - \(m_{-}\)：加入新前提约束谓词后，新推理规则覆盖的反例数
- **⚠️ 特殊情况**：当 \(m_{+} = 0\) 时，\(\text{FOIL\_Gain}\) 记为 **NA（not available）**。

**5. FOIL算法在家庭关系图谱上的完整执行过程（教材例2.13）**
- **位置来源**：第36-40页，第53-56页，表2.6、表2.7、表2.8。

**第一轮迭代**（表2.7）：
- 当前推理规则：\(\text{Father}(x, y) \leftarrow\)（无前提条件，即空规则）
- 该空规则覆盖正例数 \(n_{+} = 1\)，反例数 \(n_{-} = 4\)（图2.1中共有1个正例Father(David, Mike)，4个反例）
- 逐一尝试将背景知识中的谓词作为前提约束加入，计算每个候选谓词的FOIL_Gain：
  - **Couple(x, z)**：加入后覆盖 \(m_{+}=1\)，\(m_{-}=1\)，FOIL_Gain最大 → **被选中**
- 得到新推理规则：\(\text{Father}(x, y) \leftarrow \text{Couple}(x, z)\)

**第二轮迭代**（表2.8）：
- 当前推理规则：\(\text{Father}(x, y) \leftarrow \text{Couple}(x, z)\)
- 当前覆盖正例数 \(n_{+}=1\)，反例数 \(n_{-}=1\)（仍覆盖反例Father(David, James)）
- 逐一尝试继续加入约束谓词：
  - **Mother(z, y)**：加入后覆盖 \(m_{+}=1\)，\(m_{-}=0\)，FOIL_Gain最大 → **被选中**
- 得到最终推理规则：
  \[
  \text{Father}(x, y) \leftarrow \text{Couple}(x, z) \land \text{Mother}(z, y)
  \]
- 当 \(x=\text{David}\)，\(y=\text{Mike}\)，\(z=\text{James}\) 时，该规则覆盖正例且不覆盖任何反例 → **算法学习结束**

**6. FOIL的“归纳+演绎”双重推理模式**
- **位置来源**：第40页，第56页，图2.2。
- **归纳学习**：从实例（正例、反例、背景知识样例）出发，学习得到一般性推理规则。
- **演绎推理**：学得推理规则后，将规则中的变量赋予具体实例，得到新知识。
- 教材强调：FOIL充分展示了“**归纳学习**”的能力，同时结合了“**演绎**”完成新知识的推理。


#### 知识点2-6：路径排序推理算法（PRA）（对应表格“知识图谱推理”）

**位置来源**：第40-41页（2.4.2节全文），第57-58页

**1. 路径排序算法的基本思想**
- **位置来源**：第40页，第57页。
- 将实体之间的**关联路径作为特征**，学习得到目标关系的**分类器**。
- 与FOIL不同，PRA不学习逻辑规则，而是学习一个分类器来判断两个实体之间是否存在目标关系。

**2. PRA算法的工作流程（三步）**
- **位置来源**：第40页，第57页。

| 步骤 | 名称 | 内容 |
| :--- | :--- | :--- |
| **1** | **特征抽取** | 生成并选择路径特征集合。生成路径的方式有：**随机游走（random walk）**、广度优先搜索、深度优先搜索等 |
| **2** | **特征计算** | 计算每个训练样例的特征值 \(P(s \to t; \pi_i)\)。特征值可表示为：从实体 \(s\) 经路径 \(\pi_i\) 到达实体 \(t\) 的**概率**、**布尔值**（是否存在路径）、**频次/频率**等 |
| **3** | **分类器训练** | 根据训练样例的特征值，为目标关系训练分类器。训练完成后，用于推理两个实体之间是否存在目标关系 |

**3. PRA算法在家庭关系图谱上的执行过程（教材例2.14）**
- **位置来源**：第40-41页，第57-58页。
- **目标关系**：Father
- **训练样例**：1个正例 + 3个负例
  - 正例：(David, Mike)
  - 负例：(David, James)、(James, Ann)、(James, Mike)
- **从知识图谱采样得到的4条路径**：
  - 路径1：Couple（对应(David, Mike)）
  - 路径2：Father \(\rightarrow\) Mother\(^{-1}\)（对应(David, James)）
  - 路径3：Mother \(\rightarrow\) Sibling（对应(James, Ann)）
  - 路径4：Couple \(\rightarrow\) Father（对应(James, Mike)）
- **特征向量构造**：对每个正例/负例，判断上述4条路径是否可链接该样例的两个实体（可链接记为1，不可链接记为0），得到4维特征向量：
  - (David, Mike)：[1, 0, 0, 0] → 标签+1
  - (David, James)：[0, 1, 0, 0] → 标签-1
  - (James, Ann)：[0, 0, 1, 0] → 标签-1
  - (James, Mike)：[0, 0, 1, 1] → 标签-1
- **分类器训练**：根据上述4个训练样本训练分类器 \(M\)。
- **预测**：对于 (David, Ann)，其特征向量为 [1, 0, 0, 0]，输入分类器 \(M\)，若输出为+1，则推理出 **Father(David, Ann)** 成立。


#### 知识点2-7：分布式表示下的知识推理（对应表格“知识图谱推理”）

**位置来源**：第41页（2.4.3节全文），第58页

**1. 基本思想**
- **位置来源**：第41页，第58页。
- 受**词向量（word2vec）** 的分布式表示方法启发，将知识图谱中的**结点（实体）** 和**关系**均映射到连续数值空间中，得到**分布式表示（distributed representation）**。
- 对映射过程施加约束，使得知识图谱中结点之间的拓扑结构得以保留，从而有效地对知识图谱进行表示和推理。

**2. 核心建模方法**
- **位置来源**：第41页，第58页。
- 给定三元组 **<left_node, relation, right_node>**（如 **Father(David, Mike)**）：
  - 首先学习 **David**、**Mike** 的分布式向量表示（记作 \(\text{David}\)、\(\text{Mike}\)）
  - 学习谓词 **Father** 的分布式向量表示（记作 \(\text{Father}\)）
  - 学习一个**度量函数 \(\psi\)**，使得：
    \[
    \text{David} + \text{Father} \approx \text{Mike}
    \]
  - 即 \(\psi(\text{David} + \text{Father}, \text{Mike})\) 取值最小
- **训练**：给定所有 **<left_node, relation, right_node>** 形式的样例知识，学习度量函数 \(\psi\)，使得 \(\psi(\text{left\_node}, \text{relation}, \text{right\_node})\) 取值最小。

**3. 推理应用**
- **位置来源**：第41页，第58页。
- 一旦学习得到度量函数 \(\psi\)，就可用其判断**任意两个结点之间是否具有某一关系**。
- 例如：计算 \(\psi(\text{David} + \text{Father}, \text{Ann})\)，若取值小于阈值，则可推理出 **Father(David, Ann)** 成立。


#### 知识点2-8：概率推理——贝叶斯网络（对应表格“因果推理基础”的前置知识）

**位置来源**：第41-43页（2.5节前言及2.5.1节），第58-60页

**1. 概率图模型的引入**
- **位置来源**：第41页，第58页。
- 大数据形成图式结构：两个结点之间存在连边，可视为具有**概率依赖关系**。
- **概率图（probabilistic graph）**：用概率描述两个相连结点之间的关联，而非假设影响一定会100%发生。
- **概率推理**：基于概率图进行的推理，反映推理过程中存在的**不确定性**。
- 概率图模型分为两大类：
  - **贝叶斯网络（Bayesian network）**：有向无环图（DAG），有向边表示结点之间的**单向概率依赖**
  - **马尔可夫网络（Markov network）**：无向图，无向边表示结点之间的**相互概率依赖**

**2. 贝叶斯网络的定义与结构**
- **位置来源**：第42页，图2.3，第59页。
- 图2.3给出一个贝叶斯网络示例，刻画了**多云（Cloudy）**、**洒水车（Sprinkler）**、**下雨（Rain）** 和**路湿（Wet Grass）** 四个因素之间的相互影响。
- 各因素之间的条件概率已在图中标出（如：多云情况下有10%的概率出动洒水车，80%的概率下雨）。

**3. 局部马尔可夫性（Local Markov Property）**
- **位置来源**：第42页，第59页。
- **核心性质**：在给定一个结点的**父结点**的情况下，该结点有条件地独立于它的**非后代结点（non-descendant）**。
- **示例**：\(P(\text{洒水车} \mid \text{多云}, \text{下雨}) = P(\text{洒水车} \mid \text{多云})\)，因为在给定多云的前提下，洒水车与其非子结点“下雨”无关。
- **联合分布的因子分解**：贝叶斯网络中所有因素的联合分布等于所有结点 \(P(\text{结点}|\text{父结点})\) 的乘积：
  \[
  P(C, S, R, W) = P(C) \times P(S|C) \times P(R|C) \times P(W|S, R)
  \]

**4. 贝叶斯网络中的概率推理计算（教材两个示例）**
- **位置来源**：第43页，第60页。
- **例1**：计算 \(P(\text{下雨}, \text{洒水车}, \text{路湿} \mid \text{多云})\)：
  \[
  P(\text{下雨}, \text{洒水车}, \text{路湿} \mid \text{多云}) = \frac{0.4 \times 0.1 \times 0.8 \times 0.99}{0.4} = 0.0792
  \]
- **例2**：计算 \(P(\text{路湿} \mid \text{非多云}, \text{下雨}) = 0.945\)
  - 计算过程使用了全概率公式，在“非多云且下雨”条件下，同时考虑“有洒水车”和“无洒水车”两种情况。


#### 知识点2-9：概率推理——马尔可夫逻辑网络（对应表格“因果推理基础”的前置知识）

**位置来源**：第43-45页（2.5.2节全文），第60-62页

**1. 马尔可夫逻辑网络（MLN）的定位**
- **位置来源**：第43页，第60页。
- 由多明戈斯（Domingos）和理查森（Richardson）首次提出。
- **MLN = 马尔可夫网络 + 一阶逻辑**，是一种**统计关系学习**模型。
- 在概率图模型中引入**谓词逻辑**，融入结构化知识；同时在一阶谓词逻辑中引入**不确定性**，对严格推理进行“松绑”，更好地反映客观世界的复杂性。

**2. MLN的基本建模方式**
- **位置来源**：第43-44页，第60-61页。
- 给定一个由若干**规则（公式）** 构成的集合，给集合中的**每条推理规则赋予一定的权重**。
- 某个断言 \(x\) 成立的概率为：
  \[
  P(x) = \frac{1}{Z} \exp \left( \sum_i w_i \times n_i(x) \right)
  \]
  - \(w_i\)：第 \(i\) 条规则的权重
  - \(n_i(x)\)：在断言 \(x\) 中第 \(i\) 条规则成立的次数
  - \(Z\)：归一化常数（配分函数）

**3. 教材中的具体计算示例**
- **位置来源**：第44-45页，第61-62页。
- 给定规则及权重：
  - \(w_1 = 1\)：\(\text{indoor} \lor \text{outdoor}\)
  - \(w_2 = 9\)：\(\lnot(\text{indoor} \land \text{outdoor})\)
  - \(w_3 = 5\)：\(\lnot \text{rain} \lor \text{indoor}\)
  - \(w_4 = 7\)：\(\lnot \text{lightshow} \lor \text{outdoor}\)
- 计算断言 **indoor \(\land\) \(\lnot\)outdoor** 的概率：
  - 检查四条规则在该断言下的成立情况：
    - 规则1（indoor∨outdoor）：indoor为真 → 成立，贡献 \(1 \times 1 = 1\)
    - 规则2（¬(indoor∧outdoor)）：indoor为真且outdoor为假 → 成立，贡献 \(9 \times 1 = 9\)
    - 规则3（¬rain∨indoor）：indoor为真 → 成立（无论rain），贡献 \(5 \times 1 = 5\)
    - 规则4（¬lightshow∨outdoor）：outdoor为假，且lightshow未知 → 不成立，贡献 \(7 \times 0 = 0\)
  - 总加权得分 \(= 1 + 9 + 5 + 0 = 15\)
  - \(P(\text{indoor} \land \lnot\text{outdoor}) = \frac{1}{Z} e^{15}\)

**4. MLN与贝叶斯网络的区别**
- **位置来源**：第45页，第62页。
- **MLN**：**无向图**，刻画谓词命题之间的**组合**关系。
- **贝叶斯网络**：**有向图（DAG）**，刻画变量之间的**依赖**关系。


#### 知识点2-10：因果推理基础（对应表格“因果推理基础”）

**位置来源**：第45-56页（2.6节全文），第62-73页

**1. 因果推理的哲学基础与辛普森悖论**
- **位置来源**：第45-47页，第62-64页。
- **因果关系**：哲学上把现象之间“**引起和被引起**”的关系叫作因果关系。引起某种现象产生的现象叫作**原因**，被某种现象引起的现象叫作**结果**。
- **辛普森悖论（Simpson's paradox）**：
  - 在总体样本上成立的某种关系，在分组样本中却不一定成立甚至相反。
  - 教材表2.9和表2.10给出用药与恢复率的例子：总体上看不用药恢复率（83%）高于用药恢复率（78%），但按性别分组后，用药患者恢复率（男性93%、女性73%）均高于不用药患者（男性87%、女性69%）——**结论完全相反**。
  - 另一个经典例子：1975年加州大学伯克利分校研究生院录取率——总体男性高于女性，按专业分组后女性高于男性。
  - **根本原因**：存在**第三个变量**（混淆变量）导致了虚假关联。

**2. 关联关系的三种来源（教材图2.5）**
- **位置来源**：第46-47页，第63-64页。
  - **因果关联**：一个变量是另一个变量的原因（如“下雨导致地面湿”）。
  - **混淆关联**：两个变量存在共同的原因变量（如 \(X\) 既是 \(T\) 的原因又是 \(Y\) 的原因，忽略 \(X\) 则 \(T\) 和 \(Y\) 出现虚假关联）。
  - **选择关联**：两个变量存在共同的结果变量（如选择偏差导致虚假关联）。

**3. 因果图（Causal Diagram）与联合分布分解**
- **位置来源**：第47-48页，第64-66页，图2.6。
- **因果图**：由朱迪亚·珀尔（Judea Pearl）于1995年提出，是一种**有向无环图（DAG）**，刻画了所有结点之间的依赖关系，可用于描述数据的生成机制。
- **联合分布分解公式**：
  \[
  P(x_1, x_2, \dots, x_d) = \prod_{j=1}^{d} P(x_j \mid x_{pa(j)})
  \]
  - \(x_{pa(j)}\)：结点 \(x_j\) 的父结点集合
- **例2.16**（第48页，第65-66页）：给出图2.6中8个变量的联合概率分解：
  \[
  P(X_1, \dots, X_8) = P(X_2)P(X_3)P(X_1|X_2,X_3,X_4)P(X_4|X_2)P(X_5|X_3)P(X_6|X_4)P(X_7|X_5)P(X_8|X_6)
  \]

**4. do算子与因果干预**
- **位置来源**：第49页，第66-67页。
- **do算子**（do-calculus）：由珀尔提出，计算当系统中一个变量取值发生变化、其他变量保持不变时，系统输出结果是否变化，从而判断该变量是否是“原因要素”。
- **干预（intervention）**：改变明确存在关联关系的某变量取值，研究其变化对结果变量的影响。
- **\(P(Y=y \mid X=x)\)**：发现 \(X=x\) 时 \(Y=y\) 的概率（**观测**）。
- **\(P(Y=y \mid do(X=x))\)**：对 \(X\) 进行**干预**，固定其值为 \(x\) 时 \(Y=y\) 的概率（**因果**）。

**5. 因果效应差（ACE）与调整公式**
- **位置来源**：第49-52页，第67-69页，图2.7、图2.8。
- **因果效应差（ACE）/平均因果效应**：
  \[
  \text{ACE} = P(Y=1 \mid do(X=1)) - P(Y=1 \mid do(X=0))
  \]
- **调整公式（Adjustment Formula）**：
  \[
  P(Y=y \mid do(X=x)) = \sum_z P(Y=y \mid X=x, Z=z) P(Z=z)
  \]
- 教材通过辛普森悖论数据完整计算了ACE：
  - \(P(Y=1 \mid do(X=1)) = 0.832\)
  - \(P(Y=1 \mid do(X=0)) = 0.7818\)
  - \(\text{ACE} = 0.832 - 0.7818 = 0.0502 > 0\) → **用药能帮助治愈患者**（推翻了总体样本的虚假结论）

**6. 反事实推理（Counterfactual Reasoning）**
- **位置来源**：第52-56页，第69-73页，表2.11、图2.9、图2.10、表2.12。
- **反事实**：如果某个结果已经出现，在假设导致结果出现的某个条件不具备的情况下，这个结果还会出现吗？（如“假如该男性不吸烟，是否还会患肺癌？”）
- **反事实计算的三步骤**（第54-55页，第72页）：
  1. **溯因（Abduction）**：利用现有证据 \(E\) 确定环境 \(U\)（外生变量）
  2. **动作（Action）**：修改模型，将 \(X\) 的等式替换为 \(X=x\)
  3. **预测（Prediction）**：利用修正模型和环境 \(U\) 计算反事实 \(Y_x(U)\) 的值
- **教材示例**（图2.9、图2.10，第53-55页）：已知张三的求知欲望 \(X=0.3\)、看书数量 \(Z=0.4\)、知识渊博程度 \(Y=0.5\)，模型参数 \(a=0.8, b=0.6, c=0.4\)。如果张三将看书数量**提高一倍（\(Z=0.8\)）**，反事实计算得 \(Y_{Z=0.8} = 0.74\)，即知识渊博程度从0.5提升到0.74。

**7. 因果推理的三个层次（珀尔，表2.12）**
- **位置来源**：第55页，第72页。

| 层次 | 问题类型 | 表达式 | 说明 |
| :--- | :--- | :--- | :--- |
| **层次1：关联** | What if we see A? | \(P(y \mid A)\) | 可直接从数据中计算得到的统计相关 |
| **层次2：干预** | What if we do A? | \(P(y \mid do(A))\) | 无法直接从观测数据得到，需干预实验 |
| **层次3：反事实** | What if we did things differently? | \(P(y' \mid A)\) | 对已发生结果进行否定性假设推理 |
