#### 知识点3-1：搜索基本概念与性能评价指标（对应表格“搜索算法的性能分析”）

**位置来源**：第61-64页（3.1节全文），第81-84页

**1. 搜索问题的一般性描述（以最短路径搜索为例）**
- **位置来源**：第61页，第81页，图3.1。
- 图3.1给出某地区城市交通网络图：结点表示城市，边上的数字表示两个城市之间的列车行驶时间。
- **任务**：寻找从城市A到城市K之间**行驶时间最短**的路线。

**2. 搜索的基本术语**
- **位置来源**：第61-62页，第81-82页。

| 术语 | 含义 | 示例（图3.1） |
| :--- | :--- | :--- |
| **状态（state）** | 搜索算法和搜索环境当前所处情形的描述，剔除无关细节 | 每个城市即为一个状态 |
| **初始状态** | 算法刚开始所在状态 | 城市A |
| **终止状态（目标状态）** | 完成任务时所在状态 | 城市K |
| **动作（action）** | 算法从一个状态转移到另一个状态所采取的行为 | 乘坐一趟列车从当前城市到下一城市 |
| **状态转移（state transition）** | 选择动作后，状态发生变化的过程 | 从状态A转移到状态D |
| **路径（path）** | 执行一系列动作后得到的状态序列 | A→E→G→K |
| **代价（cost）** | 一条路径对应的开销（如时间、距离等） | A→E→G→K的路径代价为各边数值之和 |
| **目标测试（goal test）** | 判断状态s是否为目标状态 | goal_test(K)=True |

**3. 搜索树的概念**
- **位置来源**：第62页，第82页，图3.2。
- **搜索树**：用一棵树来记录算法所探索的路径。每个结点用一个状态标记。
- **⚠️ 重要区别**：同一个状态标号可能在搜索树中出现多次，但它们属于**不同结点**，因为从根结点到达它们所经过的路径不同。例如图3.2第三层有三个标号均为A的结点，分别对应路径 A→B→A、A→D→A、A→E→A。

**4. 搜索算法的四大评价指标（对应表格“搜索算法的性能分析”）**
- **位置来源**：第63页，第83页。

| 评价指标 | 含义 |
| :--- | :--- |
| **完备性（Completeness）** | 当问题存在解时，算法是否能保证找到一个解（不要求最优） |
| **最优性（Optimality）** | 搜索算法是否能保证找到的第一个解是**最优解** |
| **时间复杂度（Time Complexity）** | 找到一条搜索路径所需的时间（通常用扩展的结点数量衡量） |
| **空间复杂度（Space Complexity）** | 算法运行时所需的内存空间（通常用同时记录的结点数量衡量） |

**5. 搜索算法复杂度分析的典型变量**
- **位置来源**：第63页，表3.1，第83页。

| 符号 | 含义 |
| :--- | :--- |
| $b$ | **分支因子**：搜索树中每个结点的最大分支数目 |
| $d$ | 根结点到**最浅目标结点**的路径长度 |
| $m$ | 搜索树中路径的**最大可能长度** |
| $n$ | 状态空间中的**状态数量** |

**6. 通用搜索算法框架（算法3.1）**
- **位置来源**：第63-64页，第83-84页。
- **边缘集合（Fringe / Open List）** $F$：保存搜索树中可用于下一步探索的所有候选结点。
- **核心函数**：
  - `pick_from(F)`：从边缘集合中选出一个结点
  - `successor_nodes(n)`：计算当前结点的后继结点（孩子结点）
- **扩展（Expand）**：从F中取出结点n → 将其从F中删除 → 将其后继结点加入F。
- **环路问题与剪枝**：
  - 如果不剪枝，算法可能陷入无限循环（如 A→B→A→B→…）。
  - **解决方法**：对可能产生环路的结点进行剪枝。排除环路对算法找到最优解不产生负面影响，因为任意包含环路的路径都可以用一条不含环路且代价更小或相等的路径代替。


#### 知识点3-2：贪婪最佳优先搜索（Greedy Best-First Search）（对应表格“贪婪最佳优先搜索”）

**位置来源**：第65-67页（3.2节全文），第85-87页

**1. 有信息搜索（启发式搜索）与无信息搜索的区别**
- **位置来源**：第65页，第85页。
- **无信息搜索（Uninformed Search）** ：不利用额外信息，如广度优先搜索、深度优先搜索。
- **有信息搜索（Informed Search）/ 启发式搜索（Heuristic Search）** ：利用能够辅助算法做出决策的额外信息（**启发信息**）。

**2. 启发函数与评价函数**
- **位置来源**：第65-66页，第85-86页。
- **启发函数 $h(n)$** ：估计从结点 $n$ 到目标结点还须付出多少代价。例如：从城市 $n$ 到目标城市K的**直线距离**。
- **评价函数 $f(n)$** ：决定搜索算法在边缘结点集合中下一步选择哪个结点。取值越小，优先级越高。
- **贪婪最佳优先搜索的定义**：将评价函数与启发函数视为同一个函数，即 **$f(n) = h(n)$** 。每次总是**“贪婪地”**选择离目标结点代价最小的结点进行扩展。

**3. 教材示例：城市间最短路径搜索（表3.2、图3.4）**
- **位置来源**：第66-67页，第86-87页，表3.2、图3.4。
- 表3.2给出了每个城市到目标城市K的直线距离（启发函数值）。
- 图3.4展示了贪婪最佳优先搜索的执行过程：
  - 从A出发，扩展得到B(10)、D(12)、E(7) → 选E（最小）
  - 扩展E，得到H(3)、G(5)、I(6) → 选H（最小）
  - 扩展H，得到J(3)、F(8) → 选J（最小，但注意J的路径代价A→E→H→J = 17）
  - 继续扩展J，得到K(0) → 到达目标
  - 找到路径：**A→E→H→J→K**
- **⚠️ 关键结论**：该路径**不是最短路径**。实际上最短路径为 **A→E→G→K**（代价14）。贪婪最佳优先搜索由于只关注到目标的估计距离，忽视了从起点到当前结点的实际代价。

**4. 贪婪最佳优先搜索的性能分析**
- **位置来源**：第67页，第87页。
- **完备性**：采用排除环路的剪枝方法时，是**完备的**（总能找到一个解）。
- **最优性**：**不是最优的**（如图3.4所示，找到的路径不是最短路径）。
- **时间复杂度**：最坏情况下为 **$O(b^m)$**（$b$：分支因子，$m$：最大深度）。
- **空间复杂度**：最坏情况下为 **$O(b^m)$**。
- **⚠️ 不排除环路时**：贪婪最佳优先搜索是**不完备的**。


#### 知识点3-3：A\*搜索算法（对应表格“启发式搜索A\*搜索”）

**位置来源**：第67-71页（3.3节全文），第87-91页

**1. A\*算法的核心思想**
- **位置来源**：第67页，第87页。
- **问题**：贪婪最佳优先搜索只关注到目标的估计代价，不关注从起点到当前结点的实际代价。
- **解决方案**：将**从起始结点到当前结点的路径代价**纳入评价函数。
- **评价函数定义**：$f(n) = g(n) + h(n)$
  - $g(n)$：从起始结点到结点 $n$ 的**实际路径代价**
  - $h(n)$：从结点 $n$ 到目标结点的**估计代价**（启发函数）
- 评价函数可理解为：**从起始结点经n到目标结点的估计最小代价**。

**2. A\*算法的教材示例（图3.5）**
- **位置来源**：第68-69页，第87-89页，图3.5。
- 使用表3.2的启发函数值，图3.5展示了A\*算法的搜索过程。
- 与贪婪最佳优先搜索的关键区别：
  - 贪婪最佳优先搜索选择扩展J（因为h(J)=3最小）
  - A\*算法选择扩展G（因为f(G)=g(E→G)+h(G)=4+5=9，小于f(J)=14+3=17）
  - **最终找到最短路径：A→E→G→K（代价14）**
- 教材强调：A\*算法扩展的结点不一定总是当前结点的相邻后继（如图3.5中扩展G时，G并不是先前扩展结点H的后继）。

**3. 可容性（Admissible）与一致性（Consistency）**
- **位置来源**：第69-70页，第89-90页，表3.3。

| 符号 | 含义 |
| :--- | :--- |
| $h(n)$ | 启发函数（估计代价） |
| $g(n)$ | 从起始结点到结点n的实际路径代价 |
| $f(n)$ | 评价函数 $g(n)+h(n)$ |
| $h^*(n)$ | 从n到目标结点的**实际最小代价**（真实代价） |

- **可容性（性质1）** ：对任意结点 $n$，有 **$h(n) \le h^*(n)$**。即启发函数**不会过高估计**从n到目标的代价。若n是目标结点，则 $h(n)=0$。
  - 含义：启发函数给出的估计代价总是**小于或等于**真实最小代价。
  - 如图3.1中，城市间的直线距离必然小于实际行驶距离，因此可作为可容启发函数。

- **一致性（性质2，也称单调性）** ：**$h(n) \le c(n, a, n') + h(n')$**，其中 $c(n, a, n')$ 是从n经动作a到达其后继结点n'的单步代价。
  - 即三角不等式：n到目标的估计代价 ≤ n到n'的实际代价 + n'到目标的估计代价。
  - **一致性 ⇒ 可容性**（定理：满足一致性的启发函数必然满足可容性）。
  - 教材在图3.6中给出了该证明的完整过程（利用最短路径上的逐项累加）。

**4. A\*算法的最优性证明**
- **位置来源**：第70-71页，第90-91页。
- **定理**：如果启发函数是**可容的**，则A\*算法满足**最优性**。
- **证明思路**（教材原文）：
  - 假设A\*算法找到的第一个终止结点为 $n_0$。
  - 对于边缘集合中的任意结点 $n'$，由于每次总是选择评价函数最小的结点扩展，有 $f(n_0) \le f(n')$。
  - 由于 $n_0$ 是目标结点，$h(n_0)=0$，故 $f(n_0)=g(n_0)$。
  - 而 $f(n')=g(n')+h(n') \le g(n')+h^*(n')$（可容性保证）。
  - 因此 $g(n_0) \le g(n')+h^*(n')$，即 $n_0$ 的路径代价不大于**任何经过边缘结点n'到达目标的路径**。
  - 故 $n_0$ 对应的路径是**最短路径**，算法满足最优性。

**5. A\*算法的完备性条件**
- **位置来源**：第70-71页，第90页。
- A\*算法是完备的，需要满足：
  1. 搜索树中分支数量有限（每个结点的后继结点数量有限）
  2. 单步代价的下界是一个**正数**（$\epsilon > 0$）
  3. 启发函数有下界
