#### 知识点5-4：循环神经网络（RNN）基础（对应表格“循环神经网络”）

**位置来源**：第160-164页（5.5.1节全文），第20-23页

**1. RNN的提出背景**
- **位置来源**：第160页，第20页。
- 前馈神经网络（MLP）和卷积神经网络（CNN）处理的输入数据是**一次性给定**的，无法处理存在**前后依赖关系**的序列数据（如文本句子、视频帧、语音信号）。
- **提出者**：杰弗里·埃尔曼（Jeffrey L. Elman）于1990年提出RNN的初始概念框架。
- **核心思想**：模拟人的**记忆能力**，在学习过程中记住部分已出现的信息，并利用这些信息影响后续结点的输出。

**2. RNN的核心公式**
- **位置来源**：第161页，第21页。
- 在时刻 \(t\)，RNN单元读取当前输入 \(x_t\) 和前一时刻的隐式编码 \(h_{t-1}\)，生成当前时刻的隐式编码 \(h_t\)：

\[
h_t = \Phi(W_x x_t + W_h h_{t-1} + b)
\]

- 展开形式（展示“记忆”的来源）：

\[
h_t = \Phi(W_x x_t + W_h \Phi(W_x x_{t-1} + W_h h_{t-2} + b) + b)
\]

- **关键特点**：\(h_t\) 包含了当前输入 \(x_t\) 和前面所有时刻的**历史信息**，体现了循环神经网络的“记忆”能力。

**3. RNN的三种模式**
- **位置来源**：第162页，图5.17，第22页。

| 模式 | 输入 | 输出 | 应用 |
| :--- | :--- | :--- | :--- |
| **多对多** | 多个单元 | 多个单元 | 机器翻译 |
| **多对一** | 多个单元 | 一个单元 | 情感分类 |
| **一对多** | 一个单元 | 多个单元 | 图像描述生成 |

**4. RNN的训练方法：BPTT**
- **位置来源**：第162页，第22页。
- **沿时间反向传播（Backpropagation Through Time, BPTT）** ：按照时间将RNN展开后，得到类似前馈神经网络的结构，再用反向传播和梯度下降训练模型参数。
- 损失函数需要对**所有时刻（或部分时刻）** 的损失进行累加。

**5. RNN的梯度问题**
- **位置来源**：第162-164页，第22-23页，图5.18。
- **梯度消失（Vanishing Gradient）** ：当序列较长时，反向传播的梯度逐时间步衰减，早期时刻的梯度趋近于0，导致无法学习长距离依赖。
- **梯度爆炸（Exploding Gradient）** ：当序列较长时，梯度逐时间步指数级增长，导致参数更新不稳定。
- **根本原因**：\(h_t = \Phi(W_x x_t + W_h h_{t-1} + b)\) 中，\(\frac{\partial h_t}{\partial h_{t-1}} = W_h \cdot \Phi'(h_{t-1})\)，如果 \(|W_h \cdot \Phi'| < 1\) 则梯度消失，如果 \(|W_h \cdot \Phi'| > 1\) 则梯度爆炸。
- **解决思路**：引入门控机制（LSTM、GRU）来缓解梯度消失问题。


#### 知识点5-5：长短时记忆网络（LSTM）（对应表格“循环神经网络”）

**位置来源**：第164-166页（5.5.2节全文），第24-26页

**1. LSTM的提出背景**
- **位置来源**：第164页，第24页。
- **提出者**：Hochreiter和Schmidhuber于1997年提出。
- **核心创新**：引入**门控机制（Gating Mechanism）** 和**内部记忆单元（Cell State）**，解决RNN的梯度消失问题。
- **关键思想**：通过门结构控制信息的“流入”“流出”和“遗忘”，使网络能有效捕捉长距离依赖。

**2. LSTM的三大门控结构**
- **位置来源**：第164-166页，第24-26页，图5.19、表5.4。

| 门控 | 函数 | 公式 | 作用 |
| :--- | :--- | :--- | :--- |
| **遗忘门（Forget Gate）** | sigmoid | \(f_t = \sigma(W_{xf} x_t + W_{hf} h_{t-1} + b_f)\) | 控制上一时刻记忆单元 \(c_{t-1}\) 中有多少信息被遗忘 |
| **输入门（Input Gate）** | sigmoid | \(i_t = \sigma(W_{xi} x_t + W_{hi} h_{t-1} + b_i)\) | 控制当前时刻有多少新信息流入内部记忆单元 \(c_t\) |
| **输出门（Output Gate）** | sigmoid | \(o_t = \sigma(W_{xo} x_t + W_{ho} h_{t-1} + b_o)\) | 控制内部记忆单元 \(c_t\) 有多少信息输出到隐式编码 \(h_t\) |

**3. LSTM的信息更新流程**
- **位置来源**：第165-166页，第24-25页。

| 步骤 | 公式 | 含义 |
| :--- | :--- | :--- |
| 候选记忆 | \(\tilde{c}_t = \tanh(W_{xc} x_t + W_{hc} h_{t-1} + b_c)\) | 当前时刻的新信息 |
| 记忆更新 | \(c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t\) | 遗忘旧信息 + 加入新信息 |
| 隐式编码 | \(h_t = o_t \odot \tanh(c_t)\) | 从内部记忆中提取输出 |

- \(\odot\)：按位相乘（element-wise product）
- **三个sigmoid门输出值域为(0,1)**，起到“调控开关”的作用：
  - 值接近0：**全闭**，禁止信息通过
  - 值接近1：**全开**，允许信息通过

**4. LSTM如何解决梯度消失**
- **位置来源**：第166页，第25页。
- 核心公式：\(c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t\)
- 求导：\(\frac{\partial c_t}{\partial c_{t-1}} = f_t + \frac{\partial f_t}{\partial c_{t-1}} \times c_{t-1} + \cdots\)
- 至少存在直接路径 \(\frac{\partial c_t}{\partial c_{t-1}} = f_t\)。如果遗忘门 \(f_t\) 接近1，则梯度可无衰减地沿时间反向传播，从而避免梯度消失。
- **形象比喻**：内部记忆单元 \(c_t\) 好比人脑的**长时记忆**，隐式编码 \(h_t\) 好比**短时记忆**。


#### 知识点5-6：门控循环单元（GRU）（对应表格“循环神经网络”）

**位置来源**：第167页（5.5.3节全文），第26页

**1. GRU的定位**
- **位置来源**：第167页，第26页。
- **提出者**：Cho等人于2014年提出。
- GRU是LSTM的**简化版本**，将LSTM的三个门（遗忘门、输入门、输出门）简化为**两个门**（更新门和重置门）。
- GRU不再使用独立的内部记忆单元 \(c_t\)，仅使用**隐式编码 \(h_t\)** 传递信息，因此计算速度更快。

**2. GRU的两个门控结构**
- **位置来源**：第167页，图5.20，第26页。

| 门控 | 函数 | 公式 | 作用 |
| :--- | :--- | :--- | :--- |
| **更新门（Update Gate）** | sigmoid | \(z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z)\) | 控制前一时刻状态信息被保留到当前状态的程度（值越大，保留越多） |
| **重置门（Reset Gate）** | sigmoid | \(r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r)\) | 控制忽略前一时刻状态信息的程度（值越小，忽略越多） |

**3. GRU的信息更新**
- **位置来源**：第167页，第26页。

| 步骤 | 公式 |
| :--- | :--- |
| 候选隐式编码 | \(\tilde{h}_t = \tanh(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)\) |
| 隐式编码更新 | \(h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t\) |

- **更新门的作用类比**：类似于LSTM中**遗忘门 + 输入门**的组合功能。
- **GRU vs LSTM**：GRU参数更少、计算更快，适用于数据集较小或对计算效率要求较高的场景；LSTM表达能力更强，适用于复杂长序列任务。


#### 知识点5-7：注意力机制与Transformer（对应表格“注意力机制”）

**位置来源**：第168-169页（5.6节全文），第27-28页

**1. 注意力机制的本质**
- **位置来源**：第168页，第27页。
- 注意力指意识对一定信息或对象有所指向与集中的过程，具有**选择性和集中性**。
- 在不同领域中注意力含义不同：
  - **自然语言**：句子中单词与单词因上下文共同出现的概率
  - **图像分析**：视觉子块之间的空间分布模式
  - **机器翻译**：源语言单词与目标语言单词之间的关联

**2. 自注意力（Self-Attention）的计算（Transformer模型，2017）**
- **位置来源**：第168-169页，第27-28页，图5.21。
- **提出者**：Vaswani等人（Google），2017年。
- 以句子“项庄舞剑、意在沛公”中的单词 \(w_3\)“意在”为例：

| 步骤 | 操作 | 公式 |
| :--- | :--- | :--- |
| **1** | 生成每个单词的**查询向量（Query）**、**键向量（Key）**、**值向量（Value）** | \(q_i = W^q w_i, \; k_i = W^k w_i, \; v_i = W^v w_i\) |
| **2** | 计算 \(w_3\) 与其他单词的**关联度**（点积） | \(\alpha_{3i} = q_3 \cdot k_i\) |
| **3** | **归一化**（softmax） | \(\alpha'_{3i} = \text{softmax}(\alpha_{3i})\) |
| **4** | 加权求和得到**自注意力值** | \(\sum_i \alpha'_{3i} \times v_i\) |

- **形象理解**（来自搜索引擎）：
  - Query = 搜索关键词
  - Key = 被搜索物品的描述信息（标题）
  - Value = 被搜索物品的语义内容

**3. 多头注意力（Multi-Head Attention）**
- **位置来源**：第169页，第28页。
- 使用多组不同的 \(W^q, W^k, W^v\) 映射矩阵，从**多个角度**挖掘单词之间的概率关联。
- 各头并行计算，最后将结果拼接。
- 多头注意力让模型能同时关注不同层面的语义关系。

**4. Transformer的架构组成**
- **位置来源**：第169页，第28页。
- 自注意力计算完成后，结果再经过**前馈神经网络（Feed-Forward Network）** 进行非线性映射。
- 非线性变换帮助模型捕捉更丰富的特征和语义信息，提高表达能力。
- **并行计算优势**：自注意力可以并行计算（不像RNN需要逐个时间步处理），极大提高了训练效率。


#### 知识点5-8：神经网络正则化技术（对应表格“网络优化与正则化”）

**位置来源**：第169-171页（5.7节全文），第29-30页

**1. Dropout**
- **位置来源**：第169-170页，第29页，图5.22。
- **核心思想**：在每次迭代训练中，以一定概率**随机屏蔽**每一层中的若干神经元（将其输出置为0），用余下神经元构成的网络继续训练。
- **作用**：降低神经网络复杂度，防止过拟合。
- **本质**：相当于在训练过程中训练了多个不同的子网络，最终结果是这些子网络的集成。

**2. 批归一化（Batch Normalization）**
- **位置来源**：第170页，第29页。
- **问题**：随着网络深度增加，输入数据经过非线性变换后，其分布逐渐向激活函数值域的两端偏移（如sigmoid函数在输入很大或很小时梯度接近于0），导致**梯度消失**，网络收敛缓慢。
- **核心操作**：将每层神经元的输入值分布改变为**均值为0、方差为1的标准正态分布**。
- **作用**：
  - 激活函数输入被映射到梯度较大的区域
  - 梯度变大，克服梯度消失
  - 加快收敛速度

**3. L1正则化与L2正则化**
- **位置来源**：第170-171页，第30页。
- 加入正则化项的损失函数：

\[
\min \frac{1}{n} \sum_{i=1}^{n} \text{Loss}(y_i, f(W, x_i)) + \lambda \times \Phi(W)
\]

| 范数 | 定义 | 特点 |
| :--- | :--- | :--- |
| **L0范数** | \(\|W\|_0 = \sum_i \mathbb{I}[w_i \neq 0]\) | 非零元素个数。NP难问题，难以求解 |
| **L1范数** | \(\|W\|_1 = \sum_i |w_i|\) | **稀疏规则算子（Lasso）** ，可产生稀疏解，用于特征选择 |
| **L2范数** | \(\|W\|_2 = \sqrt{\sum_i w_i^2}\) | 权重衰减（Weight Decay），使权重趋近于0但不会完全为0，防止过拟合 |
