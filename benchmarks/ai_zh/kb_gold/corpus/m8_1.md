#### 知识点8-1：人工智能伦理与可信人工智能（对应表格“可信人工智能”）

**位置来源**：第257-258页（8.1节全文），第1-2页

**1. 伦理的概念起源**
- **位置来源**：第257页，第1页。
- **伦理**（Ethics）来源于希腊语“道德”（character）和拉丁语“风俗”（customs）的组合，刻画人与人的言行道德与准则。
- 中文语境：“伦”表示各种人际关系，“理”说明人际关系有条有理。
- “伦理”最早见于《礼记·乐记》：“乐者，通伦理者也。”
- “伦”有三重含义：① 辈分次第关系（两人以上）；② 音乐与伦理、美与善的相通性（以愉悦和谐为要）；③ 类，强调对类的分辨。

**2. 科技的双重属性**
- **位置来源**：第257-258页，第1-2页。
- 科技具有**技术属性**和**社会属性**双重特点。
- **传统科技发展模式**：“技术先行或占先行动径路”（proactionary approach）——以发展技术为优先，追求效率最大化。
- 技术异化：单一维度的追求导致科技偏离“善”的方向，引发伦理风险。
- **科技伦理**：科技活动需要遵循的价值理念和行为规范。
- **科林格里奇困境（Collingridge's Dilemma, 1980）** ：
  - 技术的早期阶段无法预见其社会后果；
  - 当不良后果变得明显时，技术已成为社会结构的一部分，控制变得极端困难。
- **世界结构演变**：从“物理世界-人类社会”（PH）二元空间演变为**“信息空间-物理世界-人类社会”**（CPH）三元空间。
- **伦理学讨论的变化**：不再只是人与人、人与自然界的关系，而是人类与自己发明的一种产品在社会中所构成的关联。

**3. 可信人工智能的核心要求**
- **位置来源**：第258页，第2页。
- 人工智能创造和形成了人与机、机与机及人机共融的新的社会形态。
- 必须确保把**人类价值观、道德观和法律法规**贯穿于人工智能的产品和服务。
- 赋予人工智能**社会属性**，推动“普遍智能”更好地惠及社会大众。


#### 知识点8-2：人工智能可解释性（对应表格“人工智能可解释性”）

**位置来源**：第266-267页（8.3节全文），第10-11页

**1. 可解释人工智能（XAI）的定义**
- **位置来源**：第266页，第10页。
- 可解释人工智能（Interpretable AI 或 Explainable AI）指智能体如何**有效解释自己的行为过程机制和任务结果原因**，取得人类用户的信任，让人可以信任模型预测的结果。
- 与**黑盒式（Black Box）AI** 相反——后者无法给出过程和结果的合理性描述。

**2. 符号主义与联结主义在可解释性上的对比**
- **位置来源**：第266页，第10页。
- **符号主义**：以逻辑推理为基础，可给出清晰的推理过程。
  - 例：苏格拉底三段论——大前提“所有人都是要死的” + 小前提“苏格拉底是人” → 结论“苏格拉底是要死的”。结论如何得到，可由三段论推理过程解释。
- **联结主义（深度学习）** ：以概率输出为基础，难以在任务结果与推理计算过程之间建立清晰联系。
  - 例：APP为何将图像识别为人脸？黑棋落子为何战胜白棋落子？自动驾驶程序为何将交通灯识别为红灯？——难以给出明确解释。

**3. 神经网络可解释性的研究方向（教材列举）**
- **位置来源**：第266-267页，第10-11页。

| 研究方向 | 核心问题 |
| :--- | :--- |
| **中层特征语义可解释性** | 神经网络中层特征是否表达了明确语义？能否将混乱的中层特征拆分为语义清晰的基本概念？ |
| **决策逻辑可解释性** | 能否为神经网络的决策结果给予语义逻辑上的解释（因果决策逻辑、线性加和逻辑等）？ |
| **基于可解释性的中层对端学习** | 利用中层特征的语义信息，在语义层面迁移预训练特征、诊断错误表达，在弱监督条件下具有良好泛化能力 |

**4. 可解释性的哲学基础**
- **位置来源**：第267页，第11页。
- 亚里士多德《尼各马可伦理学》：“一切技术，一切规划以及一切实践和抉择，都以某种善为目标。”
- 现代科技发展若偏离“善”的方向，会导致科技异化（如大语言模型以概率关联产生非事实幻觉）。
- 教材引用马克思：“机器体系是'人类的手创造出来的人类头脑的器官'，既是一种异己的强大的机体，也受控于全社会所共同积累和分享的'普遍智能'。”
- **核心理念**：一方面推动AI技术发展赋能社会，另一方面**未雨绸缪**加强治理、保障安全，**成己成物**。


#### 知识点8-3：人工智能模型安全——对抗攻击（对应表格“算法攻击与防守”）

**位置来源**：第258-261页（8.2节及8.2.1节前半部分），第3-5页

**1. 模型安全的必要性**
- **位置来源**：第258页，第3页。
- 伦理约束AI不被恶意使用，但现实中模型应足够**稳健（robust）** 以应对恶意攻击。
- **对抗攻击**：在输入样本中人为添加人类无法察觉的细微干扰，导致模型以高置信度给出错误识别结果。
- **严重后果**：自动驾驶中将“禁止通行”标志识别为“加速通过”，造成安全危害。

**2. 对抗样本的概念（Christian Szegedy，2014）**
- **位置来源**：第258-259页，第3-4页。
- **两个重要发现**：
  1. 高层神经元随机线性组合所表达的语义信息与单个神经元表达的语义信息没有区别。
  2. 对抗样本**存在且可迁移（transferability）** ：输入图像添加肉眼不可感知的非随机扰动，可使神经网络输出错误预测。
     - 对任一网络模型生成的对抗样本，对其他网络模型仍具有攻击性。
- **三种攻击类型的阶段区别**（第259页）：
  - 对抗攻击：影响**推理阶段**
  - 数据投毒：影响**数据收集/准备阶段**
  - 后门攻击：可在**数据收集、模型训练、模型部署等任何阶段**进行

**3. 基于L-BFGS的对抗攻击（Szegedy，2014）**
- **位置来源**：第259-260页，第4-5页。
- **目标**：在图像 $x$ 上添加微小扰动 $\delta$，使模型 $f$ 错误分类为 $y'$。
- **优化问题**：
  - $\text{Minimize } \|\delta\|_2$
  - $s.t. f(x+\delta) = y'$，且 $x+\delta \in [0,1]^m$
- **等效转化**：Minimize $c\|\delta\| + L_{\text{CE}}(x+\delta, y')$，用L-BFGS求解。

**4. 快速梯度符号法（FGSM，Goodfellow，2014）**
- **位置来源**：第260页，第5页。
- **核心思想**：利用模型梯度信息一步生成对抗样本。
- **公式**：$x' = x + \eta \cdot \text{sign}(\nabla_x f(x))$
  - $\nabla_x f(x)$：损失函数的反向梯度
  - $\text{sign}(\cdot)$：符号函数（输入>0返回1，<0返回-1）
  - $\eta$：学习率/步长
- **与传统训练的区别**：
  1. 传统训练用**梯度下降最小化**损失函数；对抗攻击用**梯度上升最大化**损失函数
  2. 传统训练更新**模型参数**；对抗攻击更新**对抗噪声 $\delta$**

**5. 投影梯度法（PGD，Madry等，2017）**
- **位置来源**：第260页，第5页。
- 将FGSM扩展为迭代 $k$ 次的方法。
- **迭代式**：$x'_{k+1} = \text{Proj}\{x'_k + \alpha \cdot \text{sign}(\nabla_x f(x'_k))\}$
  - $\text{Proj}(\cdot)$：将对抗样本投影到不同范数空间（$L_0, L_2, L_\infty$）
  - PGD至今是对抗样本社区常用的评估基线

**6. 白盒攻击与黑盒攻击**
- **位置来源**：第261页，图8.2，第5页。

| 类型 | 特点 | 子类别 |
| :--- | :--- | :--- |
| **白盒攻击** | 攻击者知道模型参数和梯度信息，可访问模型梯度生成对抗样本 | — |
| **黑盒攻击** | 攻击者无法获得模型参数 | **基于迁移性**：训练替代网络生成对抗样本，利用对抗样本的迁移性攻击原模型 |
| | | **基于查询**：访问模型输入输出，用有限差分法估计梯度生成对抗样本 |


#### 知识点8-4：人工智能模型安全——数据投毒与后门攻击（对应表格“算法攻击与防守”）

**位置来源**：第261-263页（8.2.1节后半部分），第5-7页

**1. 数据投毒攻击（Data Poisoning Attack）**
- **位置来源**：第261-262页，第5-6页，图8.3。
- **攻击阶段**：数据收集阶段。
- **核心思想**：故意向训练数据中插入错误或有害样本（poisoned example），干扰模型训练。
- **示例**：垃圾邮件制造者大量提交垃圾邮件并标记为非垃圾邮件，破坏分类器准确率。
- **两类投毒攻击**（第261页）：

| 类型 | 说明 |
| :--- | :--- |
| **标签反转投毒攻击（Label-Flipping）** | 将训练样本标签更改为不同于真实标签的类别（如垃圾邮件→非垃圾邮件） |
| **干净样本投毒攻击（Clean-Label Poisoning）** | 不改变标签，仅修改输入样本本身，使攻击更隐蔽 |

- **形式化定义**（第262页）：
  - 干净数据集：$\mathbb{D}_{\text{clean}}^{\text{train}} = \{(x_i, y_i)\}_{i=1}^N$
  - 有毒样本构造：$x_i^* = f_{\text{poison}}(x_i)$，$y_i^* = l_{\text{poison}}(y_i)$
  - 目标：在混合后的数据集上训练的模型性能显著下降

**2. 后门攻击（Backdoor Attack）**
- **位置来源**：第262-263页，图8.4，第6-7页。
- **定义**：在机器学习模型中植入后门，输入正常样本时输出正常，添加后门触发器时产生恶意输出。
- **示例**（图8.4）：交通信号灯识别中，在“停车”标志上添加特定矩形触发器，模型错误识别为“限速80km/h”。
- **形式化定义**（第262-263页）：
  - 预定义目标类别 $y_t$，后门触发器 $\tau$
  - 有毒样本构造：$x^* = f_{\text{poison}}(x, \tau)$
  - 目标：混合数据集上训练的模型被植入后门，含触发器的样本被错误分类为目标类别

**3. 数据投毒与后门攻击的区别**
- **位置来源**：第263页，第7页。
- 后门攻击是数据投毒攻击的**特殊实现**。
- **关键区别**：
  - 数据投毒攻击的目标是**降低模型整体性能**
  - 后门攻击的目标是**植入特定行为**——正常输入正常输出，含触发器输入产生攻击者期望的输出


#### 知识点8-5：人工智能模型安全——防御方法与隐私保护（对应表格“算法攻击与防守”）

**位置来源**：第263-266页（8.2.2-8.2.3节），第7-10页

**1. 对抗攻击的防御方法**
- **位置来源**：第263-264页，第7-8页，图8.5。

| 防御阶段 | 核心思想 | 代表方法 |
| :--- | :--- | :--- |
| **测试阶段防御** | 引入随机性，缓解或消除对抗噪声的负面影响 | 输入前随机变化（Xie等，2017）；模型中间层添加随机噪声（Liu等，2018） |
| **训练阶段防御** | 将对抗样本以数据增强方式纳入训练 | **对抗训练（Adversarial Training，Madry等，2017）** |

- **对抗训练流程**（图8.5）：
  - **内层优化**：固定模型参数，生成对抗样本（最大化损失）
  - **外层优化**：基于对抗样本训练模型参数（最小化损失）
  - 损失函数：**最大-最小优化损失函数**
  - 对抗训练被证明是**至今最有效的对抗防御方法之一**（Athalye等，2018）

**2. 数据投毒攻击的防御方法**
- **位置来源**：第264页，第8页。

| 防御策略 | 核心思想 | 代表方法 |
| :--- | :--- | :--- |
| **投毒样本检测** | 在训练前检查数据集，筛除疑似投毒样本 | 特征空间k近邻检测（Peri等）；影响函数（Influence Function）检测（Seetharaman等） |
| **模型稳健性增强** | 增强模型自身稳健性 | SGD优化器（Wang等，2021）；差分隐私SGD（DP-SGD，Goldblum等，2022） |

**3. 后门攻击的防御方法**
- **位置来源**：第264-265页，第8-9页。

| 防御策略 | 核心思想 | 代表方法 |
| :--- | :--- | :--- |
| **输入样本触发器防御** | 在输入模型前引入预处理模块，去除触发器或过滤恶意样本 | ONION（Qi等，2021）：检测语言困惑度变化来识别并删除触发器 |
| **模型内嵌后门防御** | 直接修改可疑模型消除后门 | 使用本地干净样本重新训练（Liu等，2017），利用深度学习的**灾难性遗忘（Catastrophic Forgetting）** |

**4. 隐私保护**
- **位置来源**：第265-266页，第9-10页。
- **隐私的定义**：1890年《哈佛法律评论》《论隐私权》定义为“不受打扰的权利”。
- **三大隐私保护技术**：

| 技术 | 核心思想 | 特点 |
| :--- | :--- | :--- |
| **差分隐私（Differential Privacy, 2006）** | 对数据添加干扰噪声，保护用户隐私；攻击者即使知道模型输出也无法推断敏感信息 | 基于严格数学定义，可量化评估；2017年获哥德尔奖 |
| **同态加密（Homomorphic Encryption）** | 允许在密文条件下进行安全计算，实现对明文的操作 | 常用于分布式深度学习的参数加密 |
| **安全多方计算（Secure Multi-Party Computation）** | 无可信第三方条件下安全计算约定函数，保证各方私密输入独立 | 保证计算过程中不泄露任何本地数据 |

- **差分隐私的数学定义**（第265页）：
  - 算法 $M$ 对相邻数据集 $D$ 和 $D'$ 满足 $(\epsilon, \delta)$-差分隐私：
    $$
    \Pr[M(D) \in O] \le e^\epsilon \Pr[M(D') \in O] + \delta
    \]
  - $\epsilon$：隐私预算（越小保护越强）
  - $\delta$：可容忍的超出概率
- **实现方式**：对目标函数、梯度或输出结果添加随机噪声（Laplace、Gaussian、指数等）。
- **核心原则**：在保留统计学特征的前提下去除个体特征，保护用户隐私。
