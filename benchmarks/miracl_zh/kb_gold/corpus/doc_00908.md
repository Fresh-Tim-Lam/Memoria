# 周深音樂作品列表

華語流行歌手周深，截至2022年2月26日，正式发表137首个人录音室歌曲，此外有合作歌曲及現場歌曲一百余首，合计共两百多首正式在音乐平台发布的歌曲。其中《大魚》、《和光同尘》等十二首歌曲及演唱会《晚安 明天见》獲得頒獎典禮獎項，《茧》、《Rubia》等三十八首歌曲、一張專輯《深的深》獲得其它獎項，《梅香如故》等七首合唱歌曲獲得合唱獎項。根據中國中央電視台的記錄，《胡同少年誌》等九首獲得了全球中文音樂榜上榜周榜冠軍，《不再流浪》更是打破了榜上榜直播六年以來直播時段的得票記錄。《画绢》是QQ音乐首支评论破百万的空降歌曲。根據網易雲音樂截止到2020年7月1日所有曆史上架藝人，在網易雲音樂新歌榜、飙升榜、星雲人氣榜、熱搜榜的上榜總次數的統計，周深以飙升榜上榜221次獲得TOP1，新歌榜上榜534次獲得 TOP1，星雲人氣榜上榜276次的成績，被網易雲音樂稱爲“最近幾年華語歌手中出圈最成功的藝人之一”。2019年周深共有37首歌曲進入QQ音樂各種榜單共計815次，获得十大內地歌手称号。2020年周深共有45首歌曲進入QQ音樂各種榜單共計1052次，获得十大年度艺人称号。在腾讯音乐由你榜2022年1月的盘点中，周深是该榜上榜次数最多的歌手（427次），拥有最多冠军歌曲的歌手（10首），电影OST综合得分最高纪录保持者（《悬崖之上》96.26分），拥有最多90分以上高分歌曲的歌手（25首），五大维度推荐得分最高纪录保持者（《生活总该迎着光亮》95.39分），剧集OST综合得分最高纪录保持者（《My Only》97.98分）。
