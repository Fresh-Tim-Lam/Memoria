## 1. 一个新起的消解点（2026-10-19，与近期改动的联动）

- 渲染**已切 CHTML→SVG**（commit `4a3e5a7d`），MathJax 产物是**自包含矢量**、离线可内联、不依赖 woff 字体文件。
  ⇒ R12 的「MathJax 难点」从「带整套 MathJax+字体」变成「导出时把已排版的 SVG 内联进 HTML」，
  **体积与离线自包含同时受益**，且「绕开渲染开销」天然成立（导出时一次性物化，读者端零解析）。
- 与刚拍板的「**锚定 AST（内存运行时唯一坐标系）**」强耦合：导出可直接从 AST 生成 HTML，而非从渲染后的 DOM 抓取——
  这既复用「块身份/行号」锚点，又避免「DOM → 源码反推」的失真。

## 2. 决策点（人已拍板，2026-10-19）

### 决策 ① 导出范围 —— ✅ 可选「可达闭包」三档

- **单文件**：就导出这一篇（self-contained）。
- **某文件的「可达」文件**：从目标文件出发，沿 `[[wikilink]]` 边做**可达闭包**（图遍历：BFS/DFS 可达子图），导出整个可达子图。
- **全库**：全部文件。
- 实现依赖：**图谱边 + AST**（不是临时 DOM 扫描）；可达闭包 = 图遍历，复用图谱已有边数据。

### 决策 ② 样式 —— ✅ 复用 markdown-body

内联一套精简 CSS，复用 `markdown-body` 视觉语言（`ui-visual-language.md` 契约），保证导出观感与 App 内一致。

### 决策 ③ 公式/图离线策略 —— ✅ SVG 内联；且「公式渲染后端」必须是可插拔的

- math：SVG 内联（当前已切 `tex-svg.js`）；mermaid：导出时也内联 SVG。
- **重要澄清（人的洞察，2026-10-19）**：SVG **不是「公式变图片」**，是「同一 MathJax 引擎的另一种输出组件」（矢量文本，可缩放/可选/可复制 LaTeX 源）。
  CHTML 也不是该被遗弃的「旧线」——**真正的彻底重构 = 公式渲染后端做成可插拔**（CHTML/SVG 都是合法后端、可切换），
  而不是把 `index.html` 写死一个 `tex-svg.js`。当前写死是**临时**，重构目标是把「输出组件」留给配置。

### 决策 ④ 「html 资源文件夹」组织格式 —— ✅ 本阶段暂定 + 建 schema 版本

- 定义 `html_bundle` 布局契约，带 `schema_version`（可维护、可演进，将来「导入回库」靠它）。
- 本阶段先做「导出 + 双击看」，导入回库（R03 HTML 导入，最低优先级）留后续，但格式要先钉版避免将来返工。
