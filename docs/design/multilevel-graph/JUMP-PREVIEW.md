# 编辑器落点跳转：小窗优先

> 状态：已裁决（2026-11-06）；0.5 HOLD；未实现。
> 关联：I-06「链接点击统一小窗优先」（`df0479b6`，task-145）、I-07/I-08 小窗 v2/缩放、图谱节点双击跳转（task-387/task-389）。
> 本文只记录“跳转入口”的裁决，不改变小窗自身视觉/交互。

## 0. 人原话

> “我说的是关系到文本编辑器的跳转，不是图谱内节点导航行为”
>
> “所有跳转行为，都用之前设计好的‘小窗’先兜住，再确定拉到文本编辑器，还是说‘小窗’只兜住文本编辑器内跳转？”

## 1. 裁决

**所有“以文本编辑器为落点”的跳转，统一先经过小窗预览，再由用户确认是否真正跳到编辑器。**

不是只兜“编辑器内部”的跳转；跨界面（图谱→编辑器、文本→图谱→文本、搜索→编辑器）同样走小窗。

## 2. 适用范围

| 入口 | 是否进小窗 | 说明 |
|---|---|---|
| 文本内 `[[...]]` 链接 → 编辑器 | ✅ | 已按 I-06 落地 |
| 图谱双击叶子 KP → 编辑器 | ✅ | 小窗显示精确 quote/上下文 |
| 图谱双击章节/小节节点 → 编辑器 | ✅ | 小窗显示标题/范围，不承诺精确高亮 |
| 图谱 → 文本、文本 → 图谱 → 文本 | ✅ | 最终落点是编辑器的都算 |
| 搜索结果 / 候选知识点定位 | ✅ | 同一跳转入口 |
| 图谱内单击选中/高亮 | ❌ | 不落编辑器 |
| 图谱内 group 下钻 | ❌ | 图谱内导航 |
| 节点 A 返回 / Back / 面包屑 | ❌ | 视图栈导航 |
| 拖拽 / 平移 / 缩放 | ❌ | 非跳转 |

## 3. 统一跳转意图

新增/收敛到单一入口：

```text
requestJump({ kind: "editor", target, source })
```

流程：

```text
requestJump(editor)
  → 小窗预览（目标文件/范围/上下文/可钉住）
  → 用户点「打开编辑器」
  → jumpToTarget(...)
```

- 关闭小窗 = 不跳，保留当前图谱选中状态；
- 小窗不应自动跳转；
- 不另起图谱专用跳转窗；复用 I-06/I-07 的同一小窗组件与行为。

## 4. 预览内容

- **叶子 KP**：quote / 前后文 / 所属章节；
- **章节/小节节点**：标题 + 行范围，不把整节当成 evidence；
- **同名/歧义目标**：小窗内列出候选项，用户选一个再打开；
- 小窗中的「打开编辑器」是唯一真正的跳转动作。

## 5. 当前实现缺口

- 图谱双击目前直接 `nodeDblClick → jumpToTarget`，需要改为先发 `kind=editor` 跳转意图给小窗；
- 文本链接已走小窗；需要让图谱与文本复用同一个入口，避免两套；
- 图谱单击/下钻/返回保持不进小窗。

## 6. 验收

1. 图谱双击 KP 不直接跳，先出现小窗；点「打开编辑器」才定位；
2. 关闭小窗不改变编辑器位置；
3. 文本链接、图谱双击、搜索定位使用同一小窗入口；
4. 叶子 KP 小窗包含精确 quote；章节节点只给标题/范围；
5. 单击/下钻/返回/拖拽不弹小窗；
6. 可访问性：小窗可 Esc 关闭、按钮可键盘触发。

## 7. 边界

- 不改小窗既有视觉/交互（I-06/I-07/I-08）；
- 不改冻结图谱 S0–S10/C0；
- 0.5 HOLD，不发布、不写用户库。
