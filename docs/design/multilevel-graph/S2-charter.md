# S2 章程：簇与子图划分（语义内聚 + 桥 + 多归属 + 稳定身份）

> **依据（不可改写）**：`multilevel-graph-vision.md`（U-1..U-35，两轮原话）。
> **上游冻结**：`S0-terms-v1.md`（sha `241b1e1e…`）+ `S1-dimensions-v1.md`（sha `6676c71d…`），**不得违反**；
> 议程 V0.2；本场逐议项（U-34）。
> **状态**：S2 章程 V1（Lead 起草）。本场冻结前不写产品代码。
> **日期**：2026-11-03（Asia/Shanghai）。

## 1. 目的

把 S0 的「簇 = 语义内聚小群 + 零星桥，≠ 严格连通分量」落成**可机检的划分规则**：内聚度/桥的度量与阈值、
划分算法候选与可复算性、稳定性、多归属、稳定簇身份、簇与边/维度/持久化的接口、度量与验收。
S2 必须与 S1 的 `view_family`/`(level, view_family)` partition 作用域一致。

## 2. 不在范围

- 具体后端检索算法（S9）、渲染/视觉（S3/S4）、导航（S5）、数据契约细节（S6，但 S2 给出需求）；
- 自动改写用户正文/知识点（S10）；
- 词/句级节点（S0 已列 v1 范围外）。

## 3. 议项清单（逐项裁决；一项未裁决不得跳下一项）

每项产出：定义/规则、机检条件、反例、边界用例、U 映射、建议裁决、证据等级。

| 编号 | 议项 | 必须回答 |
|---|---|---|
| S2-1 | 簇定义与边界 | 簇是什么/不是什么；与严格连通分量（graph-groups）、S0-4、S1 `view_family` 的关系；单点簇/空簇/全库一簇的边界 |
| S2-2 | 语义内聚度 μ | 用什么量（边密度/语义权重/成员相似度/混合）；如何可复算；阈值 τ 的参数化与默认值 |
| S2-3 | 桥判定 β | 跨簇边比例/语义强度/单点桥；桥与「内聚高、外部零星」的关系（U-13）；阈值与边界 |
| S2-4 | 划分算法候选 | 社区发现/层次聚类/embedding 近邻/混合；确定性、可复算、复杂度；v1 选型与降级路径；禁止把 graph-groups 并查集当簇 |
| S2-5 | 稳定性 | 知识点增删/改边/改正文后簇是否漂移；重聚类触发条件；版本/run；稳定性度量（Jaccard/成员变化率） |
| S2-6 | 多归属 | 成员关系≠视图出现；层内/跨层/跨维/跨视图族的多归属规则；与 S0-7/S1 partition 的一致性；上限（S0 暂不设，S2 决定） |
| S2-7 | 簇身份 | `cluster_run_id+local_seq` 与 `cluster_key` 的落地方案；curation/审计引用；与 S0 D-2/S1 注册表版本的关系 |
| S2-8 | 嵌套与展开 | 子簇/嵌套簇；cluster 展开到 KP 的语义（S0 V6）；空/单点簇；簇成员与 KP 层的关系 |
| S2-9 | 簇与边 | 内部边/桥边/`data_edge_ids`；contain(structural) 内部边如何计；聚合边身份（S0 R-3）；簇边界边的呈现归 S4 |
| S2-10 | 簇与维度/层次 | H 的每层是否独立划分；A 维度是否影响簇（应不影响，需机检）；`view_family`/level 的接口；跨维多归属 |
| S2-11 | 持久化与缓存 | 簇是派生缓存还是事实；允许/禁止写产品 sidecar（S0 D-3）；版本/审计/回滚；S6 的需求清单 |
| S2-12 | 度量与验收 | 内聚/桥比例/簇数/稳定性/可复算指标；G6 快照口径；验收阈值与复跑脚本 |
| S2-13 | 与 agent | agent 能否触发重聚类/影响簇（只读？提议？）；审计；确定性服务边界（S0-10/S1-14） |

## 4. 预注册判据（会前写死）

1. μ/β/划分/稳定性必须可机检（给定图+参数→唯一结果或确定性分布）；
2. 每个阈值/参数有类型、默认、失败语义；参数非法 fail-closed；
3. 簇 ≠ 严格连通分量，必须有反例与机检区分；
4. 多归属与 S0-7/S1 partition 一致：同 `(level, view_family)` 内成员唯一、跨族/维可重叠；
5. 两份独立提案（A/B）差异逐条列出并裁决，不许静默合并；
6. 覆盖矩阵（U-6/13/14/15/17/21/22/31 及 S0/S1 相关）无缺失；
7. SE 工程校核确认簇/身份/缓存/多归属可落到 ER/DFD/状态图，且不违反 D-3/VM 纯度；
8. 不写产品代码、不改契约、不 commit。
