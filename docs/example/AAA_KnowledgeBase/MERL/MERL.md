## 1. 算法概述

### 1.1 一句话定位

**MERL** 是将 **ERL（进化强化学习）** 框架扩展到**多智能体（Multiagent）** 场景的算法。它通过**分离优化**的方式，让**进化算法（EA）优化稀疏的团队奖励**，同时让**策略梯度（RL）优化稠密的个体奖励**，两者通过**共享经验池**和**周期性迁移**实现信息交换，从而**无需奖励塑形（Reward Shaping）** 就能解决复杂的多智能体协调任务。

### 1.2 设计动机

在合作多智能体场景中，通常存在**两种奖励信号**：

| 奖励类型 | 特点 | 示例（足球） |
|----------|------|-------------|
| **团队奖励（全局）** | 稀疏、反映整体目标 | 赢球 / 输球 |
| **个体奖励（局部）** | 稠密、反映个人技能 | 带球、传球、跑动 |

**问题**：
- 只用团队奖励 → 稀疏，难以学习
- 只用个体奖励 → 稠密，但与团队目标不一致（可能学了错误技能）
- 奖励塑形（混合两者）→ 需要手工调参，且可能改变MDP本身

**MERL 的核心洞察**：**不需要混合奖励**，而是让两个优化器各管各的目标，再通过经验池和权重迁移实现信息交换。

### 1.3 与 ERL 的关系

| 维度 | ERL | MERL |
|------|-----|------|
| **场景** | 单智能体 | **多智能体（多智能体协调）** |
| **奖励类型** | 单一奖励 | **双重奖励**：团队奖励 + 个体奖励 |
| **策略结构** | 单一策略网络 | **多头策略网络**（共享trunk，每个agent一个head） |
| **经验池** | 全局共享 | **每个agent独立经验池**（保持多样性） |
| **EA目标** | 最大化总回报 | 最大化**团队奖励** |
| **RL目标** | 最大化总回报 | 最大化**个体奖励** |


## 2. 数学框架

### 2.1 符号系统

| 符号 | 含义 |
|------|------|
| $N$ | 智能体数量 |
| $M$ | 种群大小 |
| $\pi = \{\pi^1, \pi^2, \dots, \pi^N\}$ | 多头策略网络（每个头对应一个agent） |
| $\pi_{pg}$ | 策略梯度模块的策略网络 |
| $\mathcal{Q}$ | 共享的Critic网络 |
| $o_i$ | 第 $i$ 个agent的观测 |
| $a_i$ | 第 $i$ 个agent的动作 |
| $l_i$ | 第 $i$ 个agent的**个体奖励（局部奖励）** |
| $g$ | **团队奖励（全局奖励）** |
| $R^k$ | 第 $k$ 个agent的独立经验池 |
| $f(\pi)$ | 团队的适应度（=团队奖励 $g$） |
| $\xi$ | 每个rollout的episode数 |

### 2.2 MERL的双目标优化

MERL同时优化两个目标：

**EA部分（优化团队奖励）** ：

$$
\max_{\pi \in \text{pop}} f(\pi) = \max_{\pi} \mathbb{E}_{\pi}\left[ \sum_{t=0}^{T} g_t \right]
$$

**RL部分（优化个体奖励）** ：

$$
\max_{\theta^\pi} J(\theta^\pi) = \max_{\theta^\pi} \mathbb{E}_{\pi_\theta}\left[ \sum_{t=0}^{T} \gamma^t l_{i,t} \right], \quad \forall i \in \{1, \dots, N\}
$$

**关键点**：两个优化器优化的是**不同的奖励函数**——EA优化全局团队奖励 $g$，RL优化局部个体奖励 $l_i$。两者通过经验池共享和权重迁移间接耦合。

### 2.3 多头策略网络结构

MERL使用**多头神经网络**来表征团队策略：

```
                    ┌─────────────┐
                    │   观测 o_i   │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │  共享Trunk  │
                    │(特征提取层) │
                    └──────┬──────┘
                           │
          ┌────────────────┼────────────────┐
          │                │                │
          ▼                ▼                ▼
    ┌──────────┐    ┌──────────┐    ┌──────────┐
    │ Head 1   │    │ Head 2   │    │ Head N   │
    │ (Agent 1)│    │ (Agent 2)│    │ (Agent N)│
    └────┬─────┘    └────┬─────┘    └────┬─────┘
         │               │               │
         ▼               ▼               ▼
        a_1             a_2             a_N
```

**特点**：
- 所有agent共享低层特征提取网络（加速学习）
- 每个agent有自己的输出头
- 每个agent有独立的经验池（保持多样性）

### 2.4 RL部分的损失函数

**Critic更新（TD3风格，双Q网络）** ：

$$
y_i = l_i + \gamma \min_{j=1,2} \mathcal{Q}'_j(o_{i+1}, a')
$$

其中 $a' = \pi_{pg}^{\prime k}(o_{i+1}) + \epsilon$，$\epsilon \sim \text{clip}(\mathcal{N}(0, \sigma), -c, c)$（TD3的目标策略平滑）

$$
\mathcal{L}_{\mathcal{Q}} = \frac{1}{T} \sum_{i=1}^{T} \left( y_i - \mathcal{Q}(o_i, a_i) \right)^2
$$

**Actor更新（确定性策略梯度）** ：

$$
\nabla_{\theta_{pg}^\pi} J \approx \frac{1}{T} \sum_i \nabla_a \mathcal{Q}(o, a) \big|_{o=o_i, a=a_i} \nabla_{\theta_{pg}^\pi} \pi_{pg}^k(o_i)
$$

### 2.5 EA部分的适应度

$$
f(\pi) = \frac{1}{\xi} \sum_{j=1}^{\xi} g^{(j)}
$$

其中 $g^{(j)}$ 是第 $j$ 个episode的团队奖励总和。


## 3. 完整算法流程

```
Algorithm 1: MERL

 1:  初始化 M 个多头团队策略 pop_π，每个有 N 个agent头，权重 θ^π
 2:  初始化共享Critic网络 Q（双Q网络）和对应的目标网络
 3:  初始化 N 个独立的空循环经验池 R^1, R^2, ..., R^N
 4:  for generation = 1, 2, ... do
 5:      # ============ EA 阶段：评估种群 ============
 6:      for each team π in pop_π do
 7:          适应度 f, 经验池 R = Rollout(π, R, noise=None, ξ)       ▷ 无噪声评估
 8:          Rollout(π, R, noise=W_g, ξ=1)                            ▷ 有噪声探索（数据注入）
 9:      end for
10:      # ============ EA 阶段：选择与进化 ============
11:     按适应度降序排序种群
12:     选择前 e 个团队作为精英 Elites
13:     从剩余团队中用锦标赛选择选出 (M-e) 个团队，构成集合 S
14:     while |S| < (M-e) do
15:         从精英和S中各随机选一个，做单点交叉，加入S
16:     end while
17:     # ============ RL 阶段：优化个体奖励 ============
18:     for each agent k = 1 to N do
19:         从 R^k 中采样 T 个 transitions (o_i, a_i, l_i, o_{i+1})
20:         计算 TD目标：y_i = l_i + γ · min_{j=1,2} Q'_j(o_{i+1}, π_{pg}'^k(o_{i+1}) + ε)
21:         更新 Critic：最小化 L = 1/T Σ (y_i - Q(o_i, a_i))²
22:         更新 Actor：沿 ∇_a Q · ∇_θ π 方向更新 π_pg^k
23:         软更新目标网络：θ' ← τθ + (1-τ)θ'
24:     end for
25:     # ============ 信息迁移：RL → EA ============
26:     将 π_pg 拷贝到种群中适应度最差的个体：θ_{π_worst} ← θ_{π_pg}
27: end for
```

### Rollout子过程

```
Algorithm 2: Rollout

 1: function Rollout(π, R, noise, ξ)
 2:     fitness = 0
 3:     for j = 1 to ξ do
 4:         重置环境，获取初始联合观测 js
 5:         while env 未结束 do
 6:             对于每个agent k：a_k = π^k(s_k) + noise
 7:             执行联合动作，观察个体奖励 jl、团队奖励 g、下一状态 js'
 8:             对于每个agent k：(s_k, a_k, l_k, s_k') 存入 R^k
 9:             js = js'
10:         end while
11:         fitness = g  (每个episode的团队奖励)
12:     end for
13:     return fitness/ξ, R
14: end function
```


## 4. 与ERL的对比

| 维度 | ERL | MERL |
|------|-----|------|
| **场景** | 单智能体 | **多智能体（Marl）** |
| **策略结构** | 单一策略网络 | **多头策略网络**（共享trunk+N个head） |
| **经验池** | 单一全局经验池 | **每个agent独立经验池** |
| **奖励函数** | 单一奖励 | **团队奖励（EA）+ 个体奖励（RL）** |
| **RL优化目标** | 最大化总回报 | **最大化个体奖励**（不是团队奖励！） |
| **EA优化目标** | 最大化总回报 | **最大化团队奖励** |
| **迁移方向** | RL → EA（权重拷贝） | **RL → EA（权重拷贝）** |
| **信息复用** | EA经验 → RL | **EA经验 → RL（通过各agent独立经验池）** |


## 5. 关键创新

### 5.1 分离优化（Split-Level Optimization）

MERL最核心的创新是**不混合奖励**，而是让EA和RL各自优化不同的奖励函数：

- **EA** → 团队奖励（解决协调问题）
- **RL** → 个体奖励（解决感知/导航问题）

这样避免了奖励塑形所需的领域知识和手工调参。

### 5.2 独立经验池

每个agent有自己的经验池，不与其他agent共享。这保证了：

- 每个agent的经验分布保持独立
- 避免某个agent的失败经验污染其他agent
- 保持种群多样性

### 5.3 自适应信息迁移

迁移频率由条件选择率 $P(sel \mid mig)$ 自动调节：

- 如果迁移的个体被选为精英的概率高 → 迁移方向好，继续迁移
- 如果迁移的个体被选为精英的概率低 → 迁移方向差，自然被忽略

### 5.4 双Q网络（TD3风格）

MERL在Critic中使用双Q网络 + 目标策略平滑：

$$
y_i = l_i + \gamma \min_{j=1,2} \mathcal{Q}'_j(o_{i+1}, \pi_{pg}'^k(o_{i+1}) + \epsilon)
$$

减轻Q值过估计问题。


## 6. 实验环境

| 环境 | 说明 | 关键挑战 |
|------|------|----------|
| **Predator-Prey** | N个捕食者追赶1个更快的猎物 | 猎物自适应学习，动态对抗 |
| **Physical Deception** | 合作智能体需覆盖所有POI以欺骗对手 | 对手不知道目标POI |
| **Keep-Away** | 合作智能体需到达目标POI，对手阻止 | 对手必须从智能体移动中推断目标 |
| **Rover Domain** | N个智能体需同时到达POI（耦合要求1-7） | **耦合越高，协调越难**，状态空间不变 |


## 7. 实验结果

### 7.1 Rover Domain（耦合要求变化）

| 耦合要求 | EA | MATD3-Global | MATD3-Mixed | **MERL** |
|----------|-----|--------------|-------------|----------|
| Coupling=1 | ~0.4 | ~0.6 | ~0.7 | **~0.9** |
| Coupling=3 | ~0.2 | ~0.1 | ~0.1 | **~0.8** |
| Coupling=5 | ~0.05 | ~0 | ~0 | **~0.7** |
| Coupling=7 | ~0 | ~0 | ~0 | **~0.5** |

**关键观察**：
- 耦合要求 $n$ 越高，EA和MATD3性能急剧下降
- MERL在耦合=7时仍能学习，其他方法完全失败
- 因为耦合增加只增加**协调难度**，不增加状态空间复杂度，证明MERL解决了协调问题

### 7.2 条件选择率 $P(sel \mid mig)$

| 环境 | 条件选择率 | 含义 |
|------|-----------|------|
| Predator-Prey (简单) | **高** | RL个体 → EA种群，正迁移 |
| Predator-Prey (困难) | **高** | 即使猎物变快，迁移仍有益 |
| Physical Deception | 前期高，后期下降 | 初始受益，后期EA适应后不再需要RL |
| Keep-Away | **低** | 迁移有害，EA比RL强，自然被忽略 |
| Rover Domain | 前期高，后期下降 | 同Physical Deception |

**关键观察**：
- 期望选择率（随机）为 **0.47**
- 高于0.47 → 迁移对进化有益
- 低于0.47 → 迁移对进化有害，自然被忽略
- MERL的迁移是**自适应的**——好迁移自动保留，坏迁移自动丢弃


## 8. 总结

| 维度 | MERL |
|------|------|
| **核心思想** | 分离优化：EA优化团队奖励，RL优化个体奖励，无需奖励塑形 |
| **与ERL关系** | ERL在多智能体场景的扩展 |
| **关键创新** | 多头策略网络 + 独立经验池 + 自适应迁移 |
| **主要优势** | 解决稀疏团队奖励 + 稠密个体奖励的冲突，无需手工调参 |
| **性能** | 在耦合要求高达7的Rover Domain上远超MATD3 |
| **局限性** | 额外计算成本（EA种群）；遗传算法超参数较多 |
