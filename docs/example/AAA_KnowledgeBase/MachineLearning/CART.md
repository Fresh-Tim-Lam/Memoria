# CART 树详解

## 0. 一句话定位

**CART (Classification And Regression Tree)** 是一种**二叉树**决策树模型，由 Breiman 等人在 1984 年提出。它既可以用于分类任务（输出类别），也可以用于回归任务（输出连续值），是所有基于树的集成方法（Random Forest、GBDT、XGBoost、LightGBM 等）的**核心基础模型**。

---

## 1. CART 树的定义

### 1.1 决策树的通用形式

一棵决策树可以看作一个**分段常数函数**：它将特征空间递归地划分为一系列互不相交的区域（矩形），并在每个区域中预测一个常数值。

**数学表达**：

\[
f(x) = \sum_{j=1}^{T} w_j \cdot \mathbf{1}\{x \in R_j\}
\]

其中：
- $T$：叶子节点数量
- $R_j$：第 $j$ 个叶子节点对应的特征空间区域
- $w_j$：该叶子节点的预测值（回归问题为均值，分类问题为类别概率）
- $\mathbf{1}\{\cdot\}$：指示函数，当 $x$ 落在 $R_j$ 中时为 1，否则为 0

> **核心特点**：每个叶子节点的预测值是一个**常数**，整个函数是**分段常数**的。

### 1.2 决策树的非参数性

决策树本质上是一个**非参数模型**，因为它不对数据的分布做任何假设。而且决策树的复杂度会随着树的生长而增加，不受预先设定的参数限制——**只要继续分裂，树的复杂度就会继续增加**。

> 但也正因为它不是参数模型，传统的梯度下降方法无法直接优化决策树。这就是为什么 XGBoost 等算法需要使用**加法训练（Additive Training）** 和**贪心分裂**来逐步构建树，而不能一次性学习所有参数。

### 1.3 CART 的核心特征

| 特征 | 说明 |
|------|------|
| **二叉树** | 每个内部节点只有**两个子节点**（左、右），对应"是/否"判断 |
| **二元分裂** | 每次只在一个特征上进行分裂，且只分两叉 |
| **可分类/可回归** | 根据输出类型选择不同的分裂准则 |
| **递归分割** | 从根节点开始，递归地对每个子节点继续分割，直到满足停止条件 |

## 2. CART vs 其他决策树

| 对比维度 | ID3 | C4.5 | **CART** |
|----------|-----|------|----------|
| 输出类型 | 分类 | 分类 | **分类 + 回归** |
| 树结构 | 多叉树 | 多叉树 | **二叉树** |
| 分裂准则（分类） | 信息增益 | 信息增益比 | **基尼系数 (Gini Index)** |
| 分裂准则（回归） | — | — | **均方误差 (MSE)** |
| 处理连续特征 | 离散化 | 离散化 | **原生支持，二分切分** |
| 缺失值处理 | 不支持 | 支持 | 支持（XGBoost增强） |
| 剪枝方式 | — | 悲观剪枝 | **代价复杂度剪枝** |

> **为什么 CART 要限制为二叉树？** 多叉树的一个节点一旦分裂，后面的调整空间就很小了，容易导致树的结构不够灵活。二叉树每次只考虑一个特征的一个切分点，递归分裂后更容易捕捉数据的细微结构。

## 3. CART 的分裂准则

### 3.1 回归树：均方误差 (MSE)

对于回归问题，CART 使用**均方误差（Mean Squared Error）**作为分裂准则。

**单个节点的纯度（不纯度）**：

\[
\text{MSE}(R_j) = \frac{1}{|I_j|} \sum_{i \in I_j} (y_i - \bar{y}_j)^2
\]

其中 $\bar{y}_j = \frac{1}{|I_j|} \sum_{i \in I_j} y_i$ 是该叶子节点的预测值（样本均值）。

**选择分裂点**：

对于特征 $k$ 和分裂点 $s$，将样本分为左子集 $R_L$ 和右子集 $R_R$，目标是**最小化分裂后的加权 MSE 之和**：

\[
\min_{k, s} \left[ \frac{|I_L|}{n} \text{MSE}(R_L) + \frac{|I_R|}{n} \text{MSE}(R_R) \right]
\]

### 3.2 分类树：基尼系数 (Gini Index)

对于分类问题，CART 使用**基尼系数（Gini Index）**作为分裂准则。

**基尼系数的定义**：

\[
\text{Gini}(R_j) = 1 - \sum_{c=1}^{C} p_{jc}^2
\]

其中 $p_{jc}$ 是节点 $j$ 中第 $c$ 类样本的比例。

**直观理解**：基尼系数衡量一个节点的"不纯度"。
- 若所有样本都属于同一类，$p=1$，则 Gini = 0（最纯净）
- 若各类样本均匀分布，Gini 最大（最混杂）

**选择分裂点**：

\[
\min_{k, s} \left[ \frac{|I_L|}{n} \text{Gini}(R_L) + \frac{|I_R|}{n} \text{Gini}(R_R) \right]
\]

## 4. 过拟合与剪枝

决策树由于可以无限生长，非常容易**过拟合**。CART 使用**代价复杂度剪枝（Cost-Complexity Pruning）**来防止过拟合。

**代价复杂度函数**：

\[
\text{Cost}(T) = \text{Err}(T) + \alpha \cdot |T|
\]

其中：
- $\text{Err}(T)$：树 $T$ 的训练误差
- $|T|$：树的叶子节点数量
- $\alpha$：复杂度参数，平衡"误差"与"树的复杂度"

**剪枝过程**：

1. 先生成一棵**完全生长的树**（尽量长到最大深度）
2. 自底向上考察每个内部节点：如果剪掉该节点的子树后，代价复杂度函数的提升不超过 $\alpha$，则剪掉
3. $\alpha$ 越大，树越简单

**XGBoost 的改进**：XGBoost 在 CART 的基础上，直接在目标函数中内置了正则项（$\gamma T + \frac{1}{2}\lambda \|w\|^2$），把剪枝的成本和建树的目标统一成一个整体，因此不再需要单独的剪枝步骤。

## 5. CART 在集成学习中的角色

| 集成方法 | CART 的角色 |
|----------|------------|
| **随机森林** | 每棵树在不同数据子集和特征子集上独立生长，最终投票/平均 |
| **GBDT** | 每棵树拟合上一棵树的**负梯度**，串行生长 |
| **XGBoost** | 每棵树拟合上一棵树的**二阶梯度**，串行生长 + 内置正则化 |
| **LightGBM** | 基于 CART 的**叶子生长策略**（Leaf-wise），而非层生长 |
| **CatBoost** | 基于 CART 的**对称树**（Oblivious Tree）+ 排序提升 |

**核心原因**：CART 是**可解释性强、计算高效、处理混合类型特征（连续/离散）能力强**的二进制递归分割模型，天然适合作为集成学习的基模型。

---

## 6. 总结

| 维度 | CART |
|------|------|
| **全称** | Classification And Regression Tree |
| **输出类型** | 分类 + 回归 |
| **树结构** | 二叉树 |
| **分裂准则（分类）** | 基尼系数 (Gini) |
| **分裂准则（回归）** | 均方误差 (MSE) |
| **剪枝方式** | 代价复杂度剪枝 |
| **特征处理** | 原生支持连续和离散特征 |
| **在XGBoost中的角色** | 作为基学习器（基础树），被加法训练逐棵构建 |
| **本质** | 分段常数函数，非参数模型 |
