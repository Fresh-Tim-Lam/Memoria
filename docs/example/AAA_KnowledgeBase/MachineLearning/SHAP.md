# SHAP：模型预测的"归因说明书"

## 0. 核心思想：一句话定位

**SHAP (SHapley Additive exPlanations)** 是一种**基于博弈论**的模型解释方法。它把模型的**每一个预测**都拆解成"各个特征分别贡献了多少"，告诉你为什么模型对**当前这个样本**给出了这个结果。

**核心公式**（针对单个样本 $x$）：

$$
f(x) = \phi_0 + \sum_{j=1}^{M} \phi_j
$$

其中 $\phi_0$ 是模型的**基准预测**（比如所有样本的平均预测），$\phi_j$ 是特征 $j$ 的**SHAP值**。

**关键含义**：所有特征的SHAP值加和，正好等于该样本的预测值与基准值的差：

$$
\sum_{j=1}^{M} \phi_j = f(x) - \mathbb{E}[f(X)]
$$

所以你看——**SHAP不是给模型打一个"全局重要性分数"，而是为每一个样本的每一次预测，精确算出每个特征"贡献了多少"**。这就是"局部可解释性"的本质。

## 1. 数学原理：从博弈论到机器学习

SHAP的理论基础是**Shapley值**，来自合作博弈论。

### 1.1 博弈论的类比

| 博弈论 | 机器学习 |
|--------|----------|
| 游戏（Game） | 模型对一个样本做一次预测 |
| 玩家（Players） | 模型中的所有特征 |
| 联盟收益 | 用**部分特征**做预测的结果 |
| Shapley值 | 每个特征对本次预测的边际贡献 |

### 1.2 Shapley值的核心思想

要确定一个特征对本次预测的贡献，需要计算它在**所有可能的特征组合（幂集）**中的平均边际贡献。

**数学公式**（特征 $j$ 的SHAP值）：

$$
\phi_j = \sum_{S \subseteq F \setminus \{j\}} \frac{|S|!(|F|-|S|-1)!}{|F|!} \left[ f(S \cup \{j\}) - f(S) \right]
$$

- $F$：所有特征的集合
- $S$：**不包含**特征 $j$ 的特征子集
- $f(S)$：**只用 $S$ 中的特征**时模型的预测值
- 括号内的差：把特征 $j$ 加入 $S$ 带来的**边际贡献**
- 加权平均：对所有可能的 $S$ 取平均

### 1.3 SHAP的三个理想性质

SHAP之所以是"唯一"满足以下三个性质的解释方法，是因为它直接以Shapley值为基础：

| 性质 | 含义 |
|------|------|
| **局部准确性（Local Accuracy）** | 解释模型的输出等于原始模型的输出：$f(x) = \phi_0 + \sum \phi_j$ |
| **缺失性（Missingness）** | 如果某个特征在样本中缺失，它的SHAP值为0 |
| **一致性（Consistency）** | 如果模型变得更依赖某个特征，该特征的SHAP值不会减小 |

## 2. 关键洞察：SHAP如何绕过"重训练"？

你可能会问："计算 $f(S)$ 需要只用 $S$ 中的特征做预测，**难道要为每个子集重训练模型吗？**"

**不需要！**

SHAP的做法是：**用原始模型，把不在 $S$ 中的特征"遮掉"（设为缺失值），然后看模型输出如何变化**。

具体来说，对于不在 $S$ 中的特征，用它们在**背景数据集**上的分布来"填充"缺失值：

$$
f(S) = \mathbb{E}[f(x) \mid x_S]
$$

这相当于问：如果我只知道特征 $S$ 的取值，模型平均会预测什么？

## 3. 工程实现：TreeSHAP——树的专属加速算法

精确计算SHAP值需要遍历 $2^M$ 个特征子集，**指数级复杂度**，对高维数据不可行。

**TreeSHAP** 专门针对**树模型**（XGBoost、LightGBM、Random Forest等），把复杂度降到**多项式级**。

### 核心思想

树的预测过程就是**沿着路径分裂**。TreeSHAP通过遍历树的所有节点，计算每个特征在每棵树的每个分裂点上的边际贡献，然后累计求和。

**数学上**，随机森林的SHAP值是**所有决策树SHAP值的平均值**：

$$
\phi_{\text{Forest}} = \frac{1}{T} \sum_{t=1}^{T} \phi_{\text{Tree}_t}
$$

## 4. 使用与可视化

### 4.1 Python示例

```python
import xgboost
import shap

# 训练模型
X, y = shap.datasets.california()
model = xgboost.XGBRegressor().fit(X, y)

# 创建解释器
explainer = shap.TreeExplainer(model)  # 对树模型专用
shap_values = explainer(X)

# 可视化
shap.plots.waterfall(shap_values[0])   # 单个预测的分解
shap.plots.beeswarm(shap_values)       # 全局特征重要性
shap.plots.bar(shap_values)            # 特征重要性条形图
```

### 4.2 常用图表

| 图表类型 | 用途 |
|----------|------|
| **Waterfall图（瀑布图）** | 显示单次预测如何从基准值被各特征推高或拉低：红色推高，蓝色拉低 |
| **Beeswarm图（蜂群图）** | 展示所有样本中每个特征的SHAP值分布。横轴是SHAP值（影响方向和大小），颜色是特征值（红高蓝低） |
| **Bar图（条形图）** | 取每个特征SHAP值的平均绝对值，排序显示全局重要性 |
| **Force图（力图）** | 直观显示特征如何"推"预测离开或接近基准值 |

## 5. 全局 vs 局部解释

| 维度 | 局部解释（单个样本） | 全局解释（整个数据集） |
|------|---------------------|----------------------|
| 输出 | 每个特征对该样本的贡献值 | 每个特征的平均贡献值 |
| 用途 | 解释为什么这个客户被拒贷 | 理解模型整体依赖哪些特征 |
| 指标 | $\phi_j$ 本身的数值 | 平均绝对值 $\frac{1}{N}\sum |\phi_j|$ |
| 可视化 | 瀑布图、力图 | 蜂群图、条形图 |

---

## 6. 与XGBoost的关系

| 关系 | 说明 |
|------|------|
| **XGBoost是模型** | 训练一个树集成，输出预测值 |
| **SHAP是解释器** | 把XGBoost的预测拆解成"哪个特征贡献了多少" |
| **TreeSHAP是加速器** | 专门针对树模型的高效SHAP计算算法 |

**一句话**：XGBoost告诉你"是什么"（预测结果），SHAP告诉你"为什么"（谁的功劳/谁的责任）。

---

## 7. 关键局限性

| 局限 | 说明 |
|------|------|
| 计算成本 | 虽然TreeSHAP很快，但特征数极多时仍有压力 |
| 只是相关性 | SHAP反映模型内部逻辑，不代表真实因果关系 |
| 背景依赖 | 基准值和缺失值处理依赖用户提供的背景数据 |
