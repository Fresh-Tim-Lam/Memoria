## 1. 算法概述

### 1.1 一句话定位

**XGBoost (eXtreme Gradient Boosting)** 是一种基于**决策树集成**的监督学习算法。它将 **“梯度提升”（Gradient Boosting）** 框架与 **“二阶优化”、“正则化”、“并行计算”** 等技术深度融合，以**高精度、高速度、强泛化**著称，是 Kaggle 竞赛和工业界的首选模型之一。

### 1.2 XGBoost 名字的由来

| 组成部分 | 含义 | 解释 |
|----------|------|------|
| **Boosting** | 集成策略 | 串行生成多棵决策树，后一棵树**纠正前一棵树的错误** |
| **Gradient** | 梯度方向 | 每一棵新树拟合的目标是**损失函数在当前预测处的负梯度方向**，而不是原始标签 |
| **X (eXtreme)** | 极致优化 | 在GBDT基础上引入了**二阶导数信息、正则化、并行计算、缓存优化**等极致工程优化 |

> **一句话概括**：XGBoost 本质上是 GBDT 的“完全体升级版”——保留 Boosting 的串行纠错框架，将优化目标从“拟合残差”升级为“拟合负梯度”，再用二阶导数加速收敛，最后用系统级优化把速度推到极致。

### 1.3 设计动机

**传统 GBDT 的三个局限**：

| 局限 | 说明 | XGBoost 的解决方案 |
|------|------|-------------------|
| **一阶近似** | GBDT 只用一阶梯度（残差），收敛速度有限 | **二阶泰勒展开**：同时利用一阶和二阶梯度信息，收敛更快 |
| **无显式正则化** | 过拟合控制依赖外部剪枝和学习率 | **内置正则化**：目标函数直接包含叶子数惩罚 $\gamma T$ 和权重L2惩罚 $\frac{1}{2}\lambda\|w\|^2$ |
| **工程效率低** | 缺乏大规模数据下的并行和缓存优化 | **系统级优化**：特征预排序 + 列块并行 + 缓存感知访问 |


## 2. CART 树：XGBoost 的基础单元

### 2.1 CART 树的定义

**CART (Classification And Regression Tree)** 是 XGBoost 的基本组成单元。它是一棵**二叉树**，每个内部节点对应一个特征上的**二元分裂**（如“年龄 ≤ 30？”），每个叶子节点存储一个**数值权重** $w_j$。

CART 树的数学表达：

$$
f(x) = \sum_{j=1}^{T} w_j \cdot \mathbf{1}\{x \in R_j\}
$$

其中 $T$ 是叶子节点数量，$R_j$ 是第 $j$ 个叶子节点对应的特征空间区域，$w_j$ 是该叶子节点的输出值。

**结构相同，任务不同**：

| | 分类树 | 回归树 |
|--|--------|--------|
| 叶子输出 | 最多数的类别 | **所有样本的平均值**或**梯度加权值** |
| 分裂标准 | 基尼系数 / 信息增益 | **均方误差（MSE）** / **Gain** |
| 输出类型 | 离散（猫/狗） | **连续（房价/温度）** |


## 3. 数学原理

### 3.1 符号系统

| 符号 | 含义 |
|------|------|
| $n$ | 样本数量 |
| $m$ | 特征数量 |
| $K$ | 树的总数量 |
| $T$ | 单棵树的叶子节点数量 |
| $f_k(x)$ | 第 $k$ 棵树的预测函数 |
| $F_k(x) = \sum_{t=1}^{k} f_t(x)$ | 前 $k$ 棵树的集成预测 |
| $w_j$ | 第 $j$ 个叶子节点的权重（输出值） |
| $I_j = \{i \mid q(x_i) = j\}$ | 属于叶子节点 $j$ 的样本索引集合 |
| $\eta$ | 学习率（shrinkage） |
| $\gamma$ | 叶子节点数量的惩罚系数 |
| $\lambda$ | 叶子节点权重的L2正则化系数 |
| $g_i = \frac{\partial L(y_i, \hat{y}_i)}{\partial \hat{y}_i}$ | 一阶梯度 |
| $h_i = \frac{\partial^2 L(y_i, \hat{y}_i)}{\partial \hat{y}_i^2}$ | 二阶梯度 |
| $G_j = \sum_{i \in I_j} g_i$ | 叶子节点 $j$ 的一阶梯度累加和 |
| $H_j = \sum_{i \in I_j} h_i$ | 叶子节点 $j$ 的二阶梯度累加和 |

### 3.2 加法模型

XGBoost 使用加法模型进行预测：

$$
\hat{y}_i = \sum_{k=1}^{K} f_k(x_i), \quad f_k \in \mathcal{F}
$$

其中 $\mathcal{F}$ 是所有CART树的函数空间。

**最终预测**：新样本依次通过所有 $K$ 棵树，每棵树给出一个输出值，累加得到最终结果。

### 3.3 目标函数

XGBoost 的目标函数由两部分组成：**训练损失 + 正则化项**：

$$
\text{Obj} = \sum_{i=1}^{n} L(y_i, \hat{y}_i) + \sum_{k=1}^{K} \Omega(f_k)
$$

**树的复杂度定义**：

$$
\Omega(f) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^{T} w_j^2
$$

- $\gamma T$：对叶子节点数量的惩罚（预剪枝），值越大树越倾向于简单
- $\frac{1}{2}\lambda \sum w_j^2$：对叶子节点权重的L2惩罚，使权重平滑，防止过拟合

### 3.4 二阶泰勒展开：XGBoost 的核心改进

在第 $t$ 轮迭代中，我们需要优化新加入的树 $f_t$：

$$
\text{Obj}^{(t)} = \sum_{i=1}^{n} L(y_i, \hat{y}_i^{(t-1)} + f_t(x_i)) + \Omega(f_t)
$$

对损失函数在 $\hat{y}_i^{(t-1)}$ 处做**二阶泰勒展开**：

$$
L(y_i, \hat{y}_i^{(t-1)} + f_t(x_i)) \approx L(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i)
$$

去掉常数项 $L(y_i, \hat{y}_i^{(t-1)})$，第 $t$ 轮的目标函数简化为：

$$
\tilde{\text{Obj}}^{(t)} \approx \sum_{i=1}^{n} \left[ g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \Omega(f_t)
$$

**优势**：二阶信息使得损失函数的近似比GBDT的一阶近似更精确，收敛速度更快。

### 3.5 叶子节点最优权重

将 $f_t(x_i) = w_{q(x_i)}$ 代入，并按叶子节点归组：

$$
\tilde{\text{Obj}}^{(t)} = \sum_{j=1}^{T} \left[ G_j w_j + \frac{1}{2}(H_j + \lambda) w_j^2 \right] + \gamma T
$$

对每个叶子节点，这是一个关于 $w_j$ 的**一元二次函数**，其最优解为：

$$
\boxed{w_j^* = -\frac{G_j}{H_j + \lambda}}
$$

**解释**：叶子节点的最优权重等于**一阶梯度的加权平均值**除以**二阶梯度加正则化项**，负号表示朝着梯度下降方向移动。

**特殊情况下**，当损失函数为平方损失（MSE）时，$g_i = \hat{y}_i - y_i$（残差），$h_i = 1$，此时 $w_j^*$ 实际上就是该叶子节点内残差的平均值。

### 3.6 树结构打分函数

将最优权重 $w_j^*$ 代回目标函数，得到树结构 $q(x)$ 的最优目标值：

$$
\boxed{\text{Obj}^* = -\frac{1}{2} \sum_{j=1}^{T} \frac{G_j^2}{H_j + \lambda} + \gamma T}
$$

$\text{Obj}^*$ 越小，代表树的结构越好。它是衡量树结构好坏的直接标准。


## 4. 节点分裂规则

### 4.1 分裂增益公式

XGBoost 在节点分裂时，选择能使**目标函数下降最多**的分裂方案。

设当前节点为 $I = I_L \cup I_R$，分裂前的损失分数为 $-\frac{1}{2}\frac{G^2}{H+\lambda}$，分裂后为左右子节点分数之和 $-\frac{1}{2}\left(\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda}\right)$。

**分裂增益（Gain）**：

$$
\boxed{\text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{G^2}{H+\lambda} \right] - \gamma}
$$

### 4.2 Gain 公式的直观理解

| 部分 | 含义 |
|------|------|
| $\frac{G_L^2}{H_L+\lambda}$ | 左子节点的“分数”——分裂后左节点对降低损失的贡献 |
| $\frac{G_R^2}{H_R+\lambda}$ | 右子节点的“分数” |
| $-\frac{G^2}{H+\lambda}$ | 不分裂时父节点的分数（作为基准） |
| $-\gamma$ | 增加一个叶子节点的惩罚（分裂使叶子数增加1） |

**直观翻译**：Gain = 分裂后左右子节点的“分数”之和 - 不分裂时父节点的“分数” - 增加叶子的惩罚。

**分裂决策**：
- 如果 Gain > 0，分裂能降低目标函数，值得分裂
- 如果 Gain ≤ 0，分裂不划算，不分裂（**自带预剪枝**）

### 4.3 与标准 CART 回归树的对比

| 维度 | 标准 CART 回归树 | XGBoost |
|------|-----------------|---------|
| 分裂依据 | 最小化 MSE | **最大化 Gain** |
| 使用的信息 | 原始标签 $y_i$ | **一阶梯度 $g_i$ + 二阶梯度 $h_i$** |
| 损失函数支持 | 仅 MSE | **任意二阶可导损失函数** |
| 正则化 | 无内置正则，需外部剪枝 | **Gain 中自带 $\gamma$ 和 $\lambda$** |
| 分裂条件 | 直到 MSE 不再下降 | **Gain ≤ 0 时不分裂** |


## 5. 梯度计算

XGBoost 对损失函数 $L(y_i, \hat{y}_i)$ 关于当前预测值 $\hat{y}_i$ 求导。

### 5.1 回归任务（平方损失）

**损失函数**：

$$
L(y_i, \hat{y}_i) = \frac{1}{2}(y_i - \hat{y}_i)^2
$$

**一阶导数**：

$$
g_i = \frac{\partial L}{\partial \hat{y}_i} = \hat{y}_i - y_i
$$

**二阶导数**：

$$
h_i = \frac{\partial^2 L}{\partial \hat{y}_i^2} = 1
$$

**关键洞察**：在平方损失下，负梯度 $-g_i = y_i - \hat{y}_i$ 正好就是**残差**。所以 XGBoost 的每一棵树本质上是在拟合残差。

### 5.2 分类任务（逻辑损失 LogLoss）

**损失函数**（二分类，预测值 $\hat{y}_i$ 为 log-odds，概率 $\hat{p}_i = 1/(1+e^{-\hat{y}_i})$）：

$$
L(y_i, \hat{p}_i) = -y_i \log(\hat{p}_i) - (1 - y_i) \log(1 - \hat{p}_i)
$$

**一阶导数**：

$$
g_i = \frac{\partial L}{\partial \hat{y}_i} = \hat{p}_i - y_i
$$

**二阶导数**：

$$
h_i = \frac{\partial^2 L}{\partial \hat{y}_i^2} = \hat{p}_i(1 - \hat{p}_i)
$$

### 5.3 常见损失函数的梯度对比

| 任务类型 | 损失函数 | $g_i$ | $h_i$ |
|----------|----------|-------|-------|
| 回归（MSE） | $\frac{1}{2}(y - \hat{y})^2$ | $\hat{y} - y$ | 1 |
| 回归（MAE） | $\| y - \hat{y} \|$ | $\text{sign}(\hat{y} - y)$ | 0（不可导） |
| 二分类（LogLoss） | $-y\log p - (1-y)\log(1-p)$ | $\hat{p} - y$ | $\hat{p}(1-\hat{p})$ |
| 多分类 | 交叉熵 | 各类别概率 - 标签 | 各类别概率的协方差结构 |


## 6. 算法流程

### 6.1 宏观流程

```
Algorithm: XGBoost训练流程

1: 初始化模型：F_0(x) = argmin_γ Σ_i L(y_i, γ)        ▷ 通常为常数
2: for t = 1 to K do
3:     计算每个样本的一阶梯度 g_i 和二阶梯度 h_i
4:     构建一棵CART树 f_t(x)：
5:       从根节点开始
6:       对每个节点，遍历所有特征和阈值，计算 Gain
7:       选择 Gain 最大的分裂点
8:       分裂节点，递归直到达到停止条件
9:     计算叶子节点最优权重：w_j* = -G_j/(H_j+λ)
10:    F_t(x) = F_{t-1}(x) + η · f_t(x)                ▷ η为学习率
11: end for
12: return F_K(x)
```

### 6.2 一个完整的数值例子

假设我们要用 XGBoost 预测房价，有 5 个样本，特征是“面积”，目标是对平方损失做一轮训练。

| 样本 | 面积 | 真实房价 $y$ | 当前预测 $\hat{y}$ |
|------|------|-------------|-------------------|
| 1 | 23 | 110 | 100 |
| 2 | 25 | 105 | 100 |
| 3 | 28 | 95 | 100 |
| 4 | 35 | 90 | 100 |
| 5 | 40 | 98 | 100 |

**Step 1: 计算梯度和二阶梯度**

对于平方损失：$g_i = \hat{y}_i - y_i$，$h_i = 1$

| 样本 | $g_i$ | $h_i$ |
|------|-------|-------|
| 1 | -10 | 1 |
| 2 | -5 | 1 |
| 3 | 5 | 1 |
| 4 | 10 | 1 |
| 5 | 2 | 1 |

**Step 2: 寻找最佳分裂点**

设 $\lambda = 1$，$\gamma = 0$。

按面积排序后，依次尝试每个分裂点，计算 Gain。

**尝试在 面积 = 26 处分裂**：

左子节点（≤26）：样本1,2 → $G_L = -15$，$H_L = 2$
右子节点（>26）：样本3,4,5 → $G_R = 17$，$H_R = 3$

$$
\text{Gain} = \frac{1}{2} \left[ \frac{(-15)^2}{2+1} + \frac{17^2}{3+1} - \frac{2^2}{5+1} \right] = \frac{1}{2} \left[ 75 + 72.25 - 0.667 \right] \approx 73.29
$$

**尝试在 面积 = 30 处分裂**：

左子节点（≤30）：样本1,2,3 → $G_L = -10$，$H_L = 3$
右子节点（>30）：样本4,5 → $G_R = 12$，$H_R = 2$

$$
\text{Gain} = \frac{1}{2} \left[ \frac{(-10)^2}{3+1} + \frac{12^2}{2+1} - \frac{2^2}{5+1} \right] = \frac{1}{2} \left[ 25 + 48 - 0.667 \right] \approx 36.17
$$

**Step 3: 选择最佳分裂**

在面积=26处分裂的 Gain 更大（73.29 > 36.17），因此选择在面积=26处分裂。

**Step 4: 计算叶子权重**

左叶子：$w_L = -G_L/(H_L+\lambda) = -(-15)/(2+1) = 5$
右叶子：$w_R = -G_R/(H_R+\lambda) = -(17)/(3+1) = -4.25$

**Step 5: 更新预测**

假设学习率 $\eta = 0.3$：
- 样本1：100 + 0.3 × 5 = 101.5
- 样本2：100 + 0.3 × 5 = 101.5
- 样本3：100 + 0.3 × (-4.25) = 98.725
- 样本4：100 + 0.3 × (-4.25) = 98.725
- 样本5：100 + 0.3 × (-4.25) = 98.725

一次迭代完成，进入下一轮。


## 7. 系统级优化

XGBoost 的“eXtreme”体现在以下工程优化：

| 优化技术 | 说明 | 加速效果 |
|----------|------|----------|
| **特征预排序+Block结构** | 训练前对每个特征预排序，以Block格式存储，后续迭代复用 | 大幅减少排序时间 |
| **列块并行** | 各特征可并行计算最佳分裂点 | 充分利用多核CPU |
| **缓存感知访问** | 优化内存布局，提高CPU缓存命中率 | 减少内存访问延迟 |
| **近似分位数算法** | 对大规模数据使用加权分位数，仅采样少量候选分裂点 | 大幅减少计算量 |
| **稀疏感知分裂** | 自动处理缺失值和稀疏数据，学习默认分裂方向 | 无需预处理缺失值 |


## 8. XGBoost vs GBDT：核心区别

| 维度 | GBDT | XGBoost |
|------|------|---------|
| **目标函数近似** | 一阶泰勒展开（梯度） | **二阶泰勒展开**（梯度+曲率） |
| **正则化** | 无内置正则化，依赖外部剪枝 | **目标函数直接包含 $\gamma T + \frac{1}{2}\lambda\|w\|^2$** |
| **分裂准则** | 基尼系数/均方误差 | **基于梯度的Gain公式** |
| **树复杂度考虑** | 在剪枝步骤中考虑 | **建树时直接作为优化目标** |
| **并行能力** | 弱 | **特征级并行**（Block结构+多线程） |
| **缺失值处理** | 需预处理 | **内置稀疏感知算法，自动学习默认方向** |


## 9. 关键超参数

### 9.1 Booster参数

| 参数 | 含义 | 典型值 | 调参建议 |
|------|------|--------|----------|
| `eta` / `learning_rate` | 学习率 | 0.01-0.3 | 越小越需增加 `n_estimators` |
| `max_depth` | 树最大深度 | 3-10 | 越大模型越复杂，易过拟合 |
| `min_child_weight` | 叶子节点最小样本权重和 | 1-10 | 控制过拟合，值越大树越保守 |
| `gamma` | 分裂所需最小损失下降 | 0-0.5 | 值越大，越倾向于剪枝 |
| `subsample` | 每棵树使用的样本比例 | 0.6-1.0 | 行采样，防止过拟合 |
| `colsample_bytree` | 每棵树使用的特征比例 | 0.6-1.0 | 列采样，增加随机性 |
| `lambda` | L2正则化系数 | 0.1-10 | 权重衰减，值越大模型越保守 |
| `alpha` | L1正则化系数 | 0-10 | 特征选择，值越大越稀疏 |

### 9.2 调参策略

**推荐顺序**：

1. **学习率 + 迭代次数**：首先确定，两者需配合调整
2. **树深度 + 叶子节点权重**：控制模型复杂度
3. **gamma值**：控制剪枝力度
4. **行列采样 + 正则化**：最后微调泛化能力


## 10. 总结

| 维度 | XGBoost |
|------|---------|
| **模型本质** | 多棵CART树的加权和：$F(x) = \sum_{k=1}^K \eta f_k(x)$ |
| **训练方式** | 串行生成树，每棵树拟合当前预测的**负梯度方向** |
| **核心创新** | 二阶泰勒展开 + 内置正则化 + 系统级并行优化 |
| **与GBDT关系** | 算法框架相同，但精度、速度、泛化能力全面超越 |
| **数学本质** | 函数空间中的**牛顿法**（二阶收敛），而非简单的梯度下降 |
| **分裂规则** | 最大化 **Gain**：$\frac{1}{2}\left[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{G^2}{H+\lambda}\right] - \gamma$ |
| **叶子权重** | $w_j^* = -G_j/(H_j+\lambda)$ |
| **主要局限** | 对超高维数据（如图像、文本）不如深度学习；调参空间较大；数据分布依赖性强 |
