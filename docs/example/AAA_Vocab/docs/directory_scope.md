# Directory Scope Spec（目录收录范围规范 · 次生规范）

> **文档性质**：**次生规范（secondary spec）**。本文件不由 Memoria 分发，属本知识库自行约定的补充规则。
> **上游权威（冲突时以它们为准）**：`.memoria/agent/kb-spec.zh-CN.md`（主规范）、`vocab_format.md`（条目撰写格式）。
> **适用范围**：仅限本知识库 `AAA_Vocab`。
> **状态**：生效中，2026-10-10（v7：新增 `plan/`——**备考计划**目录，一次考试一份时间表，只写时间轴与任务、**不写知识内容、不建 KP**；v6 曾新增 `skills/`（**能力轴**目录，一条可反复演练的说话/写作能力一个文件），v5 曾新增 `theme/`（主题轴），v4 曾新增 `expressions/words/`（以基础词为单位的词组清单），v3 曾新增 `speaking/**` 收录说明与命名例外，v2 曾把 `expressions/` 拆为 `phrases/` 与 `patterns/`）。

## 1. 目的

主规范 [kb-spec.zh-CN.md §5](<../.memoria/agent/kb-spec.zh-CN.md>) 只规定"按主题规划目录树"，未规定**哪类内容进哪个目录**；`vocab_format.md` 的措辞是 `word/phrase`（[L2](<vocab_format.md>)、[L14](<vocab_format.md>)、[L18](<vocab_format.md>)），**同时允许单词与短语**。

本规范在此之上**按类型四分目录**：`vocab/` 只收单词；**以基础词为单位**、把同一个词撑起的多个词组收在一处的，入 `expressions/words/`；多词短语、习语、固定搭配入 `expressions/phrases/`；带可替换词槽、可整句套用的**句式 / 句型框架**入 `expressions/patterns/`。

此外另设 `theme/` 作**主题轴**（与上述**类型轴**交叉）：一个主题一文件，收「这个主题下该选哪个词」的**选词地图**，只做分轴与跳转；词条本身仍留在类型轴目录里，两边不重复收录内容。

另设 `skills/` 作**能力轴**（与类型轴、主题轴交叉）：一条**可反复演练的能力**一个文件，收「这类话该怎么说」的**做法与演练**（判别、阶梯、标记词、drills）。它解决的是「说的东西有没有骨架」，而不是「用哪个词」；一条能力若同时服务口语与写作，就放这里，不塞进 `speaking/`。

另设 `plan/` 作**操作性目录**（不参与上述三条轴）：一次考试（或一个备考阶段）一份**时间表**，只写日期、任务与打钩状态，**不写知识内容、不建 KP**；具体知识仍留在类型轴目录内，本目录需要指向它们时写反引号路径，不挂 `[[wikilink]]`。

> **分工说明**：`vocab_format.md` 定义**条目怎么写**（格式）；本规范定义**条目进哪个目录**（范围）。两者不冲突，各管一层，**不修改** `vocab_format.md` 任何内容。

## 2. 目录与收录范围

| 目录 | 收录内容 | 示例 |
|---|---|---|
| `vocab/` | **仅单词**：单一词形 | `blend`、`heritage`、`secluded`、`renovation` |
| `expressions/words/` | **以基础词为索引的词组清单**：一个词一个文件，收录该词撑起的不同日常意思（短语动词、惯用搭配） | `expressions/words/get.md`（`get through`／`get by`／`get around to`…） |
| `expressions/phrases/` | **多词短语、习语、固定搭配** | `hustle and bustle`、`flee the nest`、`step back in time` |
| `expressions/patterns/` | **句式 / 句型框架**：带可替换词槽、可整句套用的句法骨架 | `hard though ... may be`（让步倒装） |
| `speaking/**` | **口语素材笔记**：一篇对应一题（或一份可复用素材），**不是词汇条目**，不受 §2.1 判定标准约束 | `speaking/part2/experience_1.md`（经历题·好消息）、`experience_2.md`（经历题·漂流翻船）、`experience_3.md`（经历题·计划被打乱） |
| `theme/**` | **主题选词地图**：一个主题一文件，只做分轴、选词与跳转，**不重复写词条释义**；词条本身在 `vocab/`／`expressions/` 内，不受 §2.1 判定标准约束 | `theme/describing-heat.md`（描述「热」选词地图） |
| `skills/**` | **表达能力模块**：一条**可反复演练的能力**一个文件（怎么判别、怎么爬升、怎么练），不是词条、也不对应某一道题，不受 §2.1 判定标准约束 | `skills/point-vs-example.md`（point 与 example 的判别与升维） |
| `plan/**` | **备考计划 / 时间表**：一次考试（或一个备考阶段）一份，只写日期、每日任务与打钩进度；**不写知识内容，不建 KP**，不受 §2.1 判定标准约束 | `plan/exam-2026-11-07.md`（雅思 28 天备考计划） |

### 2.1 判定标准（先判句式，再判空格）

| 形态 | 归类 | 说明 |
|---|---|---|
| 含可替换词槽的**句式骨架**（整条是一个可整句套用的句法框架，写法上带 `...` 占位符） | `expressions/patterns/` | `hard though ... may be`（让步倒装）、`it is not X but Y that ...` |
| 标题**不含空格**（且非句式骨架） | `vocab/` | 含无空格合成词（`breathtaking`、`picturesque`） |
| 标题**含空格**（且非句式骨架） | `expressions/phrases/` | 短语、习语、固定搭配一律如此 |

- **判定顺序**：先看是不是句式骨架（是 → `patterns/`），再看标题含不含空格（不含 → `vocab/`，含 → `phrases/`）。
- 连字符不作为判定依据，只以**空格**为准（如 `large-scale` 不含空格，属单词，入 `vocab/`）。
- 同一句式只立一条，不同变体（`though` / `as` 等）写在**同一条目内**，不拆分。
- 一词多义、词形变化（复数/过去式）**不**拆分为多条。
- `expressions/words/` **不适用本节判定**：它按**基础词**归集词组（文件名就是那个词），一个文件里同时装着短语动词与惯用搭配。

## 3. 条目格式

`vocab/`、`expressions/phrases/`、`expressions/patterns/` 三类目录的条目**均沿用** `vocab_format.md` 的七段模板（其 `[WORD / PHRASE]` 写法对短语同样适用）；句式条目保持同一次序与同一载体（英释在前、中译括注、例句英中对照），段落标题可按句式需要微调为 Skeleton / Variation Ladder 等表述，**不另立格式**。

`expressions/words/` **例外**：它一个文件里装一批词组，七段模板套不进去，改用**轻量体例**——H1 为词本身，随后依次为体例说明块（`>` 引用）、`## 一句话地图`、`## 词组清单`（用 `### ` 按**意思簇**分组，每条给「英释＋中译括注＋英中例句＋易错提示」）、`## 易错与辨析`、`## 相关词条`。释义仍**英释在前、中译括注**，例句仍**英文＋中译**。

`skills/` **单独体例**：不套七段模板——H1 为能力名，随后依次为引言块（条目类型 / 为什么单独立条 / 来源）、`## 🎯 一句话定义`、`## 🔍 判别测试`、`## 🪜 阶梯`、`## 🔁 标记词`（如适用）、`## ⚔️ 反面症状`、`## 🧩 可套用骨架`、`## 🎯 Active Output Drills`、`## 📎 库内实作`、`## 📌 Revision Tags` 与 `**🔑 Answer Key**`。段落可按能力性质增删，但**必须**有判别、演练、库内实作三节。

## 4. 命名与 sidecar

| 项 | 规则 |
|---|---|
| 文件名 | 英文 kebab-case（短语用连字符连接：`flee the nest` → `flee-the-nest.md`；句式按**结构名**取 slug：`hard though ... may be` → `concessive-inversion.md`，占位符 `...` 不入文件名） |
| 正文标题 H1 | 词条原文，**含空格原样写**（`# flee the nest`）；句式写**骨架原文**并附中文类型括注（`# hard though ... may be（让步倒装）`） |
| KP `id` | 与文件名同名的 kebab-case slug，**全库唯一** |
| KP `name` | 与正文 H1 **完全一致** |
| sidecar 路径 | **镜像 md 路径**：`expressions/phrases/x.md` → `.memoria/sidecars/expressions/phrases/x.memoria.yaml`（句式同理，含 `patterns/` 层级） |
| `speaking/**` 文件名 | **例外**：不用 kebab-case，改用 `类型_序号`（**下划线**）。`类型` = 题型类英文 slug（`experience` ＝ 经历／事件题），`序号` = 同题型内的建立顺序，如 `speaking/part2/experience_1.md`；KP `id` 仍取内容 slug（如 `good-news-flight-transfer`），**与文件名不一定同名** |

- `expressions/words/**` 文件名：**基础词的小写原形**（`get` → `get.md`），H1 即该词（`# get`）；**一词一文件、一文件一 KP**（`id` = 该词，如 `get`）。该目录**不走 §2.1 的「不含空格 → `vocab/`」判定**——它装的是一批词组，只是按**词**归集。

- `theme/**` 文件名：**主题的 kebab-case 英文 slug**（`描述「热」选词地图` → `describing-heat.md`）；H1 用**中文主题名**（`# 描述「热」选词地图`），KP `name` 与 H1 完全一致、`id` 与文件名一致。该目录**不走 §2.1 判定**——它不是词条，是**主题地图**。

- `skills/**` 文件名：**能力的 kebab-case 英文 slug**，取**能力名**而非句式（`point vs example` → `point-vs-example.md`，与 `patterns/` 取「结构名」相对）；H1 为**能力名 + 中文括注**（`# point vs example（观点与例证）`），KP `name` 与 H1 完全一致、`id` 与文件名一致。该目录**不走 §2.1 判定**——它不是词条，是**能力模块**。

- `plan/**` 文件名：**计划类型 + 关键日期**（`exam-2026-11-07.md`）；H1 用中文「计划名 + 考试日期」（`# 雅思 28 天备考计划（2026-11-07）`）。该目录**不建 KP** —— 因此无 sidecar，也不受 `id` / `name` 一致性要求约束。

## 5. 移动条目时的约束

1. **移动只改路径，不改 `id`**：`[[kp-id]]` 是 id 寻址，跨目录移动后正文 wikilink **无需改动**。
2. **必须同步改 sidecar 的 `file:` 字段**，使其指向新路径。
3. 移动后 `kp_targets.json`、`pending.json` 等**产品生成文件**会由「构建」自动刷新，**禁止手写**。
4. 跨目录移动属主规范 [§7.3](<../.memoria/agent/kb-spec.zh-CN.md>) 所列「先问用户」的操作，**执行前必须列清单确认**。

## 6. 自检清单

1. `vocab/` 下所有条目标题**不含空格**。
2. `expressions/words/` 下文件名与 H1 均为**基础词的小写原形**（`get.md` / `# get`），**一词一文件**。
3. `expressions/phrases/` 下所有条目标题**含空格**。
4. `expressions/patterns/` 下所有条目均为可整句套用的句式骨架，且不与 `vocab/`、`phrases/`、`words/` 重复收录同一内容。
5. 已在 `phrases/` 单独立条的词组，`words/` 文件里只留 `[[跳转]]`，不重复写释义。
6. 每个 md 的对应 sidecar 的 `file:` 字段指向正确路径（含子目录层级）。
7. 所有 `[[id]]` 目标仍存在（移动不改 id，故应全部有效）。
8. `theme/**` 下每个文件都是**主题地图**：只做分轴、选词与跳转，**不重复写词条释义**；已立条的词一律挂成跳转指向对应词条（常见为 `vocab/` 内词条），未立条的写词形并标 ⚠。
9. 自检完成后提示用户在 Memoria 执行「构建」「检查」。
10. `skills/**` 下每个文件都是一条**能力模块**：给的是「怎么想 + 怎么练」（判别 / 阶梯 / 标记词 / drills），不是词条释义，也不与 `vocab/`、`expressions/`、`theme/` 重复收录同一内容。
11. `plan/**` 下每个文件都是**时间表**：只写日期、任务与打钩进度，**不写知识内容**、**不建 KP**、不新增 `[[wikilink]]`（本目录无 KP，挂链只会成悬空虚链），需要指向库内文件时写反引号路径。
