## 0. 术语、计分机制与处罚项

### 0.1 术语对齐（重要）

| 本库用法 | 官方用法 | 对应目录 |
|---|---|---|
| **Part 1** | **Task 1**（Academic 为图表报告） | `writing/part1/` |
| **Part 2** | **Task 2**（议论文） | `writing/part2/` |

> 本文件一律用 **Part 1 / Part 2**（与题源图内的 "Part 1 / Part 2" 及本库目录一致），括号内标注官方 Task 编号。

### 0.2 计分机制

- Part 1 与 Part 2 **各自独立评分**；各考四项（Part 1 第一项为 **Task Achievement**，Part 2 第一项为 **Task Response**；CC / LR / GRA 共用同一套描述语）。
- **四项等权，取算术平均**得该 Part 的分数，按 0.5 步进。
- **Part 2 的权重是 Part 1 的两倍**：Writing 总分 =（Part 1 + Part 2 × 2）÷ 3。
- Part 1 约 20 分钟 / ≥150 词；Part 2 约 40 分钟 / ≥250 词。

### 0.3 官方明示的处罚项

> Candidates should note that scripts may be penalised if they are **a) partly or wholly plagiarised**, **b) not written as full, connected text**（使用 bullet point 或 note form 均不合格）。

另据官方样卷评语：**直接抄写题干的部分不给分**（"no credit is given for copied rubric"）。

## 1. 四项标准各自在考什么（官方 Key Assessment Criteria 要点）

> 逐字全文见 `docs/ref/ielts/key-assessment-criteria.md`。

| 标准 | 官方在考什么 |
|---|---|
| **TA（Part 1）** | 用 ≥150 词对图表做**信息转换**：① 选取关键特征 ② 给足细节支撑 ③ **准确报数与报趋势** ④ 通过凸显趋势/主要变化/差异来做**比较对照**（而非机械描述）⑤ 格式得当。**只涉及给定数据的事实内容，不做数据以外的推测性解释** |
| **TR（Part 2）** | 用 ≥250 词**形成并展开一个立场**：① 回应是否充分 ② 主要观点是否被扩展与支撑 ③ 观点与题目是否相关 ④ **开篇、立场、结论是否清晰** ⑤ 格式是否得当。想法须有证据支撑，例子可来自个人经验 |
| **CC** | 整体组织与逻辑推进：信息的逻辑排序（coherence）＋ **多样且恰当**的衔接手段（连接词、连词、代词）以明确句内/句间关系（cohesion）；段落划分、段内与段间顺序、指代与替代的灵活使用 |
| **LR** | 词汇的**广度**与在该任务中的**准确性与得体性**：同义替换避免重复、话题词是否到位、选词精度、搭配/习语/复杂表达的掌控、拼写与构词错误的**密度与对交流的影响** |
| **GRA** | **句子层面**的语法资源：结构种类与得体性（简单句/并列句/复合句）、三类句子的准确性、语法错误的**密度与对交流的影响**、标点的准确得体 |

> ⚠️ **关键精度点**：**只有第一项（TA / TR）随题型变化**。CC / LR / GRA 的官方描述语与题型无关——地图题、流程图**不会**因为"是图"而在语法上被放宽（但各题型有其**高频语言要求**，见 §2.5 / §3.5，属"能不能拿高分"而非"标准放宽"）。

## 2. Part 1（官方 Task 1）

### 2.1 官方 Task Achievement 描述语（9→0，Academic）

| 档 | 官方描述 |
|---|---|
| **9** | All the requirements of the task are fully and appropriately satisfied. There may be extremely rare lapses in content. |
| **8** | The response covers all the requirements of the task appropriately, relevantly and sufficiently. **Key features are skilfully selected, and clearly presented, highlighted and illustrated.** There may be occasional omissions or lapses in content. |
| **7** | The response covers the requirements of the task. The content is relevant and accurate – there may be a few omissions or lapses. The format is appropriate. Key features which are selected are covered and clearly highlighted but could be more fully or more appropriately illustrated or extended. **It presents a clear overview, the data are appropriately categorised, and main trends or differences are identified.** |
| **6** | The response focuses on the requirements of the task and an appropriate format is used. Key features which are selected are covered and adequately highlighted. **A relevant overview is attempted. Information is appropriately selected and supported using figures/data.** Some irrelevant, inappropriate or inaccurate information may occur in areas of detail or when illustrating or extending the main points. Some details may be missing (or excessive) and further extension or illustration may be needed. |
| **5** | The response generally addresses the requirements of the task. The format may be inappropriate in places. **Key features which are selected are not adequately covered. The recounting of detail is mainly mechanical. There may be no data to support the description.** There may be a tendency to focus on details (without referring to the bigger picture). The inclusion of irrelevant, inappropriate or inaccurate material in key areas detracts from the task achievement. There is limited detail when extending and illustrating the main points. |
| **4** | The response is an attempt to address the task. **Few key features have been selected.** Key features which are presented may be irrelevant, repetitive, inaccurate or inappropriate. |
| **3** | The response does not address the requirements of the task (**possibly because of misunderstanding of the data/diagram**). Key features which are presented may be largely irrelevant. Limited information is presented, and this may be used repetitively. |
| **2** | The content barely relates to the task. |
| **1** | **Responses of 20 words or fewer** are rated at Band 1. The content is wholly unrelated to the task. Any copied rubric must be discounted. |
| **0** | 未出席/未作答；全篇非英语；有证据全篇背诵。 |

### 2.2 Part 1 图型分类与「必写要素」清单

> 官方 TA 描述语不区分图型。下表把每类图面拆成**逐项必达要素**——批改时逐项打勾，缺项即对应降档。

| 图型 | 官方题面措辞线索 | 必写要素（逐项核对） | 专属语言要求 |
|---|---|---|---|
| **① Line graph**（动态） | "The graph below shows … over time" | ① 总体趋势 ② 起点值 ③ 终点值 ④ 极值（峰/谷）⑤ 交叉或反超 ⑥ 变化速率（陡/缓） | 过去时（若年份已过）；趋势动词 + 副词（`rose sharply` / `declined steadily`） |
| **② Bar chart · 动态**（跨年份） | 年份 ≥2 个 | 同上 ①–⑥ | 同上 |
| **③ Bar chart · 静态**（单一年份） | 只有一个时间点 | ① 最高 ② 最低 ③ 排序/分组 ④ 显著差距（`almost twice as many as`）⑤ **不得出现趋势动词** | 一般现在时；比较级/最高级 |
| **④ Pie chart** | "the proportion of …" | ① 各部分占比 ② 最大/最小项 ③ 两项对比 ④（多饼图跨年）变化 | 占比动词：`account for` / `make up` / `comprise` / `constitute`＋`%` |
| **⑤ Table** | "the table below shows" | ① **筛选**出主要行/列 ② 分组归纳 ③ 关键对比 | 数据密度高：**禁止逐格抄** |
| **⑥ Combination**（≥2 图） | "The charts below show"（复数） | ① **每一图面都要写到** ② 各图自身的特征 ③ **图与图之间的关系/对照** | 需明确的过渡与关联表达 |
| **⑦ Map** | "The maps below show … in 1980 and today" | ① 时间点/时段 ② 方位（`to the north of` / `adjacent to` / `on the site of`）③ 每处**变化**（`demolished` / `constructed` / `extended` / `converted into` / `replaced by`）④ 最显著的整体改变（= overview） | **时态随年份定**（过去/现在/将来）；被动语态为主 |
| **⑧ Process diagram** | "The diagram below shows the process by which …" | ① 步骤/阶段**完整** ② 阶段数/起止点，且 overview 须**归纳关键阶段**（只报"共 N 步"不够——官方 8.5 档样卷仍被要求补足）③ 顺序衔接 ④ 循环图须点明 `cycle` ⑤ 副产品/回流支路 | **被动语态**为主；顺序词 `first` / `subsequently` / `at this stage` / `finally` |

### 2.3 Part 1 各档判定点（细化 × 图型）

> 同一档位的"通用行为"见每行左栏；右侧给出**该档位在图型上的具体表现**。

| 档 | 通用可观察行为 | 动态图（①②④） | 静态图（③⑤） | 组合图（⑥） | 地图（⑦） | 流程图（⑧） |
|---|---|---|---|---|---|---|
| **8** | 关键特征**筛选精准**；overview 凝练；数据准确；以归类对比代替罗列 | 趋势 + 关键数据点全部到位并**归类**（如"两组上升、一组持平"） | 按大小/类别分组比较，无多余数据 | 多图都写且**指出彼此关系** | 变化按类别归纳，方位表达精确 | 阶段完整且**分段合理**（按阶段性质而非机械切分） |
| **7** | **有独立、清晰的 overview**；数据分类合理；识别主要趋势或差异；细节可更充分 | 有明确 overview 句；主要趋势都点到，个别数据可再补 | overview 指出"整体格局"（最高/最低特征）；比较到位 | 两图均覆盖，关系点明但可更充分 | overview 指出最显著改变；方位与变化清晰 | overview 指出总阶段数或起止；步骤完整 |
| **6** | **overview 是"尝试"而非"清晰"**；关键特征覆盖；**用数字支撑**；细节处有少量不相关/不准确 | 有 overview 意图但表述含糊；数据基本准确 | 覆盖最高/最低与部分比较；可能有冗余列举 | 两图都提到但其中一图偏薄 | overview 有但未抓住核心变化；个别方位表述不准 | 步骤基本完整，个别步骤描述简略 |
| **5** | **机械罗列细节**；**可能完全没有数据支撑**；只盯细节不见全局；关键区域出现不相关材料 | 逐年/逐点罗列，无趋势归纳；**无 overview** | 逐格报数；**无 overview** | **漏写其中一图** | **方位词错乱或时态混乱**；无 overview | **漏步骤** |
| **≤4** | 选出的关键特征很少，或所写不相关/重复/不准；或**误解了图表** | 误解趋势方向 | 把静态数据读成趋势（事实错误） | 把组合图当单图写 | 方位彻底错乱 | 步骤大量缺失或顺序颠倒 |

### 2.4 Part 1 硬门限（先查）

| 硬门限 | 后果 |
|---|---|
| < 150 词 | **TA ≤ 5** |
| 全文 ≤ 20 词 | **Band 1** |
| 无 overview（未独立呈现总趋势） | **TA ≤ 6** |
| 动态图只描述点、不描述趋势 | **TA ≤ 6** |
| **完全没有数字/数据支撑描述** | **TA ≤ 5**（官方 5 档原话："There may be no data to support the description"） |
| 逐格照抄表格 | **TA ≤ 5** |
| 组合图漏写其中一图 | **TA ≤ 5** |
| 流程图漏步骤 | **TA ≤ 5** |
| 地图题方位词错乱或时态混乱 | **TA ≤ 5** |
| 静态图写了趋势 | 事实错误 → 降档 |
| **overview"写砸"**：试图写 overview 却只造成困惑 | **主动扣分**，比不写更糟（官方 1C-A，5 档："may have been an attempt at an overview but it simply causes confusion and detracts"） |
| **格式不当**：用书信体开头、加入个人评论等 | **限制 TA**，即使语言很强（官方 1C-B："uses an inappropriate format … limits the band for Task Achievement"） |
| overview 只报"有几个阶段/步骤"而不归纳关键阶段 | 冲 8+ 的瓶颈（官方 1C-C，8.5 档仍被要求"a fuller overview … to summarise those key stages"） |
| 加入数据以外的因果推测（"because…"、"this may be due to…"） | 计入不相关信息 → 降档 |
| 用 bullet point / note form | 官方可处罚 |

### 2.5 Part 1 的三项（CC / LR / GRA）在图型上的"高分语言要求"

> 标准本身不放宽，但**各图型有必用语言**；缺了会同时压低 LR 与 TA。

| 图型 | 组织（CC） | 词汇（LR） | 语法（GRA） |
|---|---|---|---|
| 动态图 | 按"整体→分组"组织；段内按趋势归类 | `rise / climb / surge / dip / plunge / plateau / level off`；`slightly / sharply / steadily` | 过去时；`having risen to X, it then …` |
| 静态图 | 按大小/类别分段 | `the highest / the lowest / almost double / a third of` | 比较级、最高级、`whereas` 对比句 |
| 饼图 | 按占比大小分段 | `account for / make up / comprise / constitute`＋`the largest share` | 主谓一致（`A accounts for`） |
| 表格 | 按归纳后的组分段（不按行） | `the vast majority of` / `a negligible proportion of` | 数字与主谓一致 |
| 组合图 | 段间用明确过渡（`Turning to the second chart`） | 图间关系词（`in contrast` / `similarly` / `corroborates`） | 指代清晰，避免图表指代混乱 |
| 地图 | 按"区域"或"变化类型"分段 | 方位词 + 变化动词（见 §2.2） | **时态一致**；被动与完成时（`has been converted into`） |
| 流程图 | 按阶段分段；顺序衔接词齐全 | 过程动词（`is filtered` / `is melted` / `is packaged`） | **被动语态**；`once / after which / at this stage` |

### 3.2 Part 2 题型分类与「必答要素」清单

| 题型 | 官方题面措辞线索 | 必答要素（逐项核对） | 常见致命误判 |
|---|---|---|---|
| **① Opinion / Agree‑disagree** | `do you agree or disagree?` | ① 明确立场 ②（若为题组句）**明确的同意程度** ③ 全文贯穿同一立场 ④ 反方至少被承认/驳斥 | 立场中立骑墙；只写不赞同理由而无条件性表述 |
| **② To what extent（程度式）** | `To what extent do you agree or disagree?` | ① **程度副词必须出现**（`completely / largely / partly / strongly`）② 程度与后文论证一致 ③ 界定同意的边界 | 通篇看不到"多大程度" |
| **③ Discussion** | `discuss both views and give your own opinion` | ① **观点 A 完整讨论** ② **观点 B 完整讨论** ③ **自己的意见明确** | 只写一边；两边都写但自己没表态 |
| **④ Advantages & Disadvantages** | `What are the advantages and disadvantages?` | ① 优势 ② 劣势 ③ 若问 `outweigh` → **必须给出裁决** | 问 outweigh 却不裁决；只写一面 |
| **⑤ Problem–Solution** | `What problems …? What solutions …?` | ① 问题 ② **与问题逐一对应**的方案 ③ 对应关系显性 | 方案与问题错配；只写问题 |
| **⑥ Two‑part question** | 两个直接问句（`Why …? Is this …?`） | ① 第一问明确回答 ② **第二问明确回答** ③ 两问在结构上都有独立段落 | 漏答一问；两问混在一段 |
| **⑦ Positive / Negative development** | `Is this a positive or negative development?` | ① **选边** ② 论证所选立场 ③（加分）承认另一面的合理成分 | 不选边，只罗列两面 |

### 3.3 Part 2 各档判定点（细化 × 题型）

| 档 | 通用可观察行为 | ① ② Opinion / Extent | ③ Discussion | ④ Adv. & Disadv. | ⑤ Problem–Solution | ⑥ Two‑part | ⑦ Pos./Neg. |
|---|---|---|---|---|---|---|---|
| **8** | 立场**清晰且有发展**；主要观点**充分扩展并有支撑**；偶有小遗漏 | 立场鲜明，条件界定清楚，例证有力 | 两观点都充分展开，自己的立场有理有据 | 两面充分；裁决明确且理由充足 | 问题与方案**一一对应**且各有例证 | 两问都充分回答且各有段落 | 立场鲜明，反方也被公允承认 |
| **7** | 立场**清晰且成形**；主要观点有扩展与支撑，但可能**过度概括**或**支撑材料缺焦** | 立场明确但支撑偏泛 | 两边都谈到，其中一边略薄 | 两面都有；裁决明确但论证偏泛 | 问题与方案齐备，对应清晰 | 两问都答，其中一问略简 | 选边明确但论证偏泛 |
| **6** | 立场**与题目直接相关**，但**结论可能不清/缺乏论证/重复**；部分主体观点发展不足 | 立场相关但结论模糊；有过度概括 | 两边都提到但一边明显偏薄 | 两面都写；**未给明确裁决** | 方案与问题**对应不够显性** | 两问都答，但一问只带过 | 选边但结论摇摆 |
| **5** | **表达了立场，但展开时清时不清**；观点有限、发展不充分；有不相关细节；有重复 | 立场要读一阵才看出；论证空泛 | **只写一边**（另一边仅一句带过） | **只写一面** | **只写问题**，方案缺失或错配 | **漏答一问** | **不选边**，只罗列 |
| **≤4** | **只是最低限度地碰触题目，或答案偏斜**；**立场要仔细读才找得到**；主要观点难辨 | 立场与题目错位 | 只复述题干未讨论 | 未回应权衡 | 未回应方案 | 未回应其中一问 | 未回应题目 |

| < 250 词 | **TR ≤ 5** |
| 全文 ≤ 20 词 | **Band 1** |
| `To what extent` 未给出同意程度 | **TR ≤ 6** |
| 立场中立、无明确倾向 | **TR ≤ 6** |
| 主体段**无任何具体例证** | **TR ≤ 6** |
| Discussion 只写一边 | **TR ≤ 6** |
| 双问题漏答一问 | **TR ≤ 6** |
| 问 `outweigh` 却不给裁决 | **TR ≤ 6** |
| 抄写题干 | 该部分**不给分**（官方评语原话） |
| 无结论段，或结论仅机械复述 | **CC 降一档** |
| 机械模板开场（`In today's society` / `With the development of…` / `Nowadays, more and more people…`） | **LR / CC 降档** |
| `Firstly / Secondly / Thirdly / In conclusion` 全套出现 | **6 分封顶** |
| 大量重复 `I think` / `I believe` | **CC 显性扣分** |
| 记忆语言搬运且与语境不符 | **LR 扣至 5** |
| **段落过短或分段不当** | **CC 降档**（官方 2B-A 的 5.5 即由"段落过短+词汇错误"直接限档） |
| bullet point / note form | 官方可处罚 |

> ⚠️ **一条防过度扣分的校正**（官方 2A-C 明示）：**Opinion / To what extent 类题不要求"两面都写"**。只论证支持面、不展开另一面，官方原话是 *"although this is not a requirement"*——**不得**据此扣 TR。反之 Discussion / A&D 类题少写一面才是硬伤（见 §3.2）。

### 3.5 Part 2 的三项（CC / LR / GRA）在各档的 do / don't

| 档 | CC | LR | GRA |
|---|---|---|---|
| **8** | 段落逻辑推进；句内衔接（`which` / `in other words` / `by contrast`）不抢戏 | 话题词广且准；**恰当**使用不常见/习语表达 | **大多数句子无错**；结构灵活 |
| **7** | 全文推进清晰；衔接手段有**误用/过度/不足** | 有能力用少量不常见表达；有语体意识 | 多种复杂结构，`error-free sentences are frequent` |

| **3** | **无明显逻辑组织**；次序词/衔接极少且不体现逻辑 | 词汇不足（**可能因篇幅明显不足**）；**过度依赖输入材料或背诵语言**；错误占多数，**可能严重妨碍意义** | **语法与标点错误占多数**，**大多数意义无法传达**；篇幅可能不足以体现句法掌控 |

## 5. 判定流程（三步法）

批改任何一篇时按此顺序，**顺序不可颠倒**：

1. **定题型 → 查必答要素**
   Part 1 查 §2.2（8 类图型）；Part 2 查 §3.2（7 类题型）。逐项打勾，**缺项 = 第一条降档理由**。
2. **查硬门限 → 先判第一项（TA / TR）**
   Part 1 查 §2.4；Part 2 查 §3.4。硬门限是**上限**（例如"无 overview → TA ≤ 6"），不能因为其他方面好而突破。
3. **对照官方描述语定档 → 再评 CC / LR / GRA**
   TA/TR 用 §2.1 / §3.1 的官方原文逐句比对（要求"a script must fully fit the positive features of the descriptor"）；CC/LR/GRA 用 §4 + §2.5 / §3.5 的 do/don't。
   最后四项**算术平均**，按 0.5 步进。

> 官方原文有一句关键限定，判定时必须遵守：**"A script must fully fit the positive features of the descriptor at a particular level."** ——不满足则**不得**给该档。
