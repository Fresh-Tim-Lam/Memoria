# 笔记范围与详略规范（Note Scope）

> 用途：规定**各类笔记的详略尺度**——哪些要写全，哪些只需一行。与 `vocab_format.md`（词条体例）、`directory_scope.md`（落点判定）配合使用。
> 生效：2026-10-16，依用户明确要求补充。

## 1. 两类笔记，两套尺度

| 类型 | 落点 | 尺度 |
|:---|:---|:---|
| 单词（不含空格） | `vocab/<word>.md` | **严苛**：按 `vocab_format.md` 全段体例 |
| 其他（短语／句式／固定说法／新义项） | `expressions/**` | **简记**：释义 ＋ 1–2 例句 ＋ 相关条目，约 20–40 行 |

## 2. 简记类只写三件事
1. **新表达／新义项本身**：是什么、什么场合用；
2. **1–2 个例句**：优先用用户实际听到／读到的原句，能补出处就补（篇目／题号）；
3. **一句要点**：来自听力的写清该抓的重音柱与音变；来自阅读的写清考点落在哪。

## 3. 禁止「跳太远」
- 不在一条笔记里引入**用户尚未学过的其他新表述**；必须点名时只一句带过，**不展开**、不附例句。
- **不做**近义辨析矩阵、搭配矩阵、语域三档这类扩写——除非用户当次问的正是单词、且要求按词条标准写。
- `## 🔗 相关条目` 最多 **2–3 条**，只挂真正同句出现、同型听力陷阱或上下游的条目。

## 4. 检索节制
- 检索只为两件事：①查重（该词／该表达是否已有条目）；②为新条目找 1–2 条可挂链的已有 KP。
- 不做多轮全库探查、不逐篇读样板；行号与原文只读**本批要改动的文件**。
- 不汇报检索与推理过程，只给结果。
