# Speaking Format（口语素材笔记规范 · 次生规范）

> **文档性质**：**次生规范（secondary spec）**。本文件不由 Memoria 分发，属本知识库自行约定的补充规则。
> **上游权威（冲突时以它们为准）**：`.memoria/agent/kb-spec.zh-CN.md`（KP / sidecar 与 §7 撰写整理）、`docs/format.md` 与 `.memoria/agent/preview-formats.md`（可用写法与渲染）、`docs/style_format.md`（样式语义与用量）、`docs/directory_scope.md`（目录归属）。
> **适用范围**：本知识库 `speaking/**` 的素材笔记（Part 1 / 2 / 3）。
> **状态**：生效中，2026-09-23。

---

## 1. 目的

让每份口语素材笔记**同时服务两件事**：

1. **升级版示范作答**——用库内词条（`vocab/` / `phrases/` / `patterns/`）把答案写得漂亮，拿评分里的加分点；
2. **只用常见词也能讲完的兜底版**——用户明确说过：很多专有词汇还不会，最后要靠自己已经会的词把故事讲出来。

所以：口语笔记**不能只给漂亮版本**，必须逐句给出平实版（§3）。这是本规范的核心条款。

## 2. 一篇素材笔记的骨架（顺序固定）

| 顺序 | 段落 | 要求 |
|---|---|---|
| 1 | `# <题干英文>` | H1 逐字对应 sidecar 里的 KP `name` |
| 2 | 元信息引言块 | `**来源**` / `**素材**` / `**题型**` / `**说明**` 四行 |
| 3 | `## 📋 题目 / Task` | 题干 + 4 条 `You should say` + 课件 Useful language 表 |
| 4 | `## 🧭 三/四槽位规划 / Planning Frame` | 课件框架（如 SETTING→CHANGE→FEELING、DANGER→ACTION→RESULT、SETTING→CHANGE→ACTION→RESULT）+ 关键英文词块 + 四问覆盖检查 |
| 5 | `## 🗣️ 固定开场模板 / Fixed Opening` | 老师给的模板原文（代码块）+ 本故事填空版 + 语法开关说明 + **≥ 2 个备用开场句式**（如 `if I had to pick one that stands out, it would be ...`、`the most ... one was ...`） |
| 6 | `## ✍️ 示范作答 / Model Answer` | 升级版，**约 230–260 词**、对应 1′40″–2′00″（按实考语速 120–130 wpm 反推：2 分钟能说的上限 ≈ 240–260 词，**固定开场模板独占 55–60 词**，正文四问只剩 175–190 词的额度，所以正文要精炼到「一个转折点＋一个收尾感想」）；**题干原词一律换成同义表达**（题干写 `good news`，答案里就不许再出现 `good news`——照抄题干**很扣分**，开场与收尾呼应同样适用） |
| 7 | `## 🔁 平实版对照 / Say It in Plain English` | **必须有**，见 §3 |
| 8 | `## 🔍 高分句` | 4 条，句子上高亮、后面讲它为什么好 |
| 9 | `## 🧰 词块与升级` | ① 课件关键词（音标 + 怎么用）② 库内词条升级表（平实说法 → 升级词条 → 例句） |
| 10 | `## ⚠️ 本题专属坑 / Traps` | 易错点、常见误用、时态与搭配 |
| 11 | `## 🎤 交付提示 / Delivery Notes` | 句重音 / 停顿 / 语速 / 填充词 / 降调收尾 |
| 12 | `## 🔁 追问演练 / Part 3 Follow-ups` | 3 问，每问给开场句 + 可用词块 |
| 13 | `## 📌 Revision Tags` + `**🔑 一句话结构速记**` | 标签行 + 结尾一行结构速记 |

## 3. 平实版对照（核心条款）

1. **位置**：紧接示范作答之后，单独成段（上面加 `---` 分隔）。
2. **逐句**：示范作答**每一句**都要有一行平实版，用 `**①**` `**②**` … 编号，与示范作答同序、不合并、不省略。
3. **写法**（固定形状）：
   - 上一行是**原句**（**纯文本**，把原句里的词条跳转标记去掉，便于对照）；
   - 中间空一行；
   - 下一行以 `↩︎ **平实版**：` 开头，给出**同义**的平实说法；
   - 行尾圆括号里标出「`难词` → `简单说法`」，多个替换用全角分号分隔。
4. **只降词汇、不降骨架**：`so … that …`、让步倒装、`as if …`、`not … until …` 这类**句型结构保留**，并在括号里点一句「这个架子要留着」——句型比难词更值钱，而它本来就不难。
5. **收尾两件套**（缺一不可）：
   - 一条引用提醒：平实版是**兜底**不是目标；升级词记得住就照用，平实版只保证想不起难词时不卡壳；
   - `### 2. 难词替换速查`：两列表 `| 示范作答里的说法 | 换不出来的话就说 |`，逐词给出常见说法，**覆盖 Traps 一节里出现的全部难词**。
6. **一节内不新增链接**：平实版段落按纯文本写，不挂知识点跳转，避免同一 KP 反复挂链、实例数虚增。
7. **不得改变语义与情节**：平实版与示范作答必须一一对应，不能借平实版加料、删情节或改口吻。

## 4. 来源与可信度

- 素材必须可溯：`**素材**：用户本人口述（YYYY-MM-DD）——…`，情节逐条保留，**不做通用化改写**。
- 英文是示范转写而非用户原文时，必须在 `**说明**` 里写明「英文为示范转写（非用户原文）」。
- 你自行补的情节 / 细节：在正文就近标 `<!-- ⚠ 来源待核实：… -->`；课件的疑误写法标 `<!-- ⚠ 待核实：… -->`。
- 保留专有细节（地名、人名、数字、时间），不改写成空泛说法。

## 5. 命名 / KP / 挂链

- 路径：`speaking/part<1|2|3>/<序号>.md`（同一题型内按建立顺序递增）。
- KP：全篇一个知识点；`id` = 内容 slug（如 `good-news-flight-transfer`、`rafting-whirlpool-rescue`）；`name` = H1 逐字；`range` = 整篇首行到末行。
- 挂链：示范作答里的升级词条**都要**挂知识点跳转（双方括号包住词条 id，语法见 `.memoria/agent/kb-spec.zh-CN.md` §4）；词条侧也补一条「📎 库内实作：`speaking/partN/M.md`」反向指引。
- 平实版一节里**不**挂链（见 §3.6）。

## 6. 样式

按 `docs/style_format.md`：高分句用黄色高亮；例句焦点用蓝字；字段标签与提示语用加粗；词条、命令、代码用行内代码；表格单元格不上色；每屏高亮 / 着色合计 ≤ 3 处。

## 7. 自检

1. 骨架 13 段齐全？示范作答之后**有**平实版对照？
2. 平实版对数 = 示范作答句数？有无漏句或合并？
3. 速查表是否覆盖了示范作答与 Traps 里的全部难词？
4. 平实版是否只用常见词，且未改变语义 / 情节？句型骨架是否保留？
5. H1 = sidecar `name`？KP id 全库唯一？升级词条都挂了跳转？词条侧有没有反向指引？
6. 样式用量是否合规（`docs/style_format.md` §4）？
7. 交付后提示用户在 Memoria 执行「构建」「检查」。
