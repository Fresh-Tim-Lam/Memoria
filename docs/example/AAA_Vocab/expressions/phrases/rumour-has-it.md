# rumour has it

## 🔉 Pronunciation & Listening Cue
- **英式音标 (British IPA)**: /ˈruːmə hæz ɪt/   (based on Oxford/Cambridge)
- **美式音标 (American IPA)**: /ˈruːmər hæz ɪt/   (based on Merriam‑Webster)
- **重音位置 (Stress)**: 主重音落在 **RU**mour；`has` 在语流里弱化成 /həz/ 甚至 /əz/，`it` 仍占一拍——三词一口气说完，别拆成三个重音
- **🗣️ 听力陷阱 (Listening trap)**: the /h/ of *has* frequently drops, so *rumour has it* can sound like “rumour-az-it”; and the **that** introducing the clause that follows is very often left out altogether (Rumour has it she's leaving).
  (中文说明：has 的 /h/ 常脱落，整块听起来像 rumour-az-it；后面那个 **that 还常被整个省掉**——听见一句完整的话却没有 that 开头，多半就是这个句式。同结构的 word has it / legend has it 同理。)

## 📖 Core Definitions (Dictionary‑Based)
> Source: Oxford Advanced Learner’s Dictionary / Cambridge Dictionary of English
> ⚠ 以下释义与例句的措辞由知识库助手撰写，尚未与原书逐条核对，核实后请摘除本注。
- **[idiom, informal] people are saying that … — used when the source of the information is unknown or unconfirmed**（据传；听人说……）
  - **Speaking example** – Rumour has it that the café on the corner is closing for good.
    （据传街角那家咖啡馆要永久关门了。）
  - **Writing example** – Rumour has it that the council plans to sell the old library, though nothing has been confirmed.
    （有传闻说市政会打算卖掉老图书馆，不过一切尚未证实。）
> 💡 用法提示：它是**固定句式**，三处常见落点：
> ① 句首引出（最典型）—— Rumour has it that …
> ② 口语里**省掉 that** —— Rumour has it she turned down the offer.
> ③ 后面想接名词短语就必须补 that —— Rumour has it that the merger is off.（✗ Rumour has it about the merger.）
> ⚠️ 句首的 `rumour` **用单数、不加冠词**；想说「有一条传闻」要换句式：There's a rumour that … ／ The rumour going round is that …
> ⚠️ 语域：informal–neutral——口语、杂志、新闻特稿很自然；学术与 Task 2 的立论句改用 `It is widely reported that …` ／ `It has been suggested that …`；若写的是「猜测」本身，用 [[speculation]] 的主场句式 *Amid speculation that …*。
> 🔗 按场景挂：媒体语境里它常与 [[mainstream]] 同框（mainstream media 正是传言的放大器）；「谁在传」与「谁在猜」的分工见 [[speculation]]。

## 🎯 Best Situation & Register Gate（何时该用 / 何时别用）
> **为何放在这个位置**：它决定「这个说法该不该用在这里」，必须在背搭配**之前**先过闸——它的失分点不在语法，而在**场合**：把「据传」写进本该自己下判断的句子，读者只会觉得你没证据。
- **✅ Best situation**: ① 口语 Part 2/3 转述一件**自己没核实**的消息（社区变化、朋友近况）② 半正式信函里提「听说」又不愿背书 ③ 新闻／特稿句式（Rumour has it that …）④ 闲聊开场，比 *I heard that* 更有味 ⑤ 想给「来源不明」留足余地
- **∇ Avoid**: ① Task 2 的**立论句**——那里要下判断，不要「据传」；改 *It is widely reported that …* / *It has been suggested that …* ② **Task 1 图表题**——图表之外的信息一律不能写：官方明言 Task 1 只处理图上事实，**“not to speculative explanations that lie outside the given data”**（`docs/ref/ielts/key-assessment-criteria.md:37`）③ 想让人相信你的**论据**时——用「据传」等于自认无实据，改 *evidence / figures / it is well documented that …* ④ 法律、公文、学术等要求可溯源出处的场合——那里用 *allegedly / reportedly* 并给出处
- **强度标记 Strength**: neutral，但**自带「来源不明、未经证实」的保留**；用在正式语境里能让整段显得道听途说
- **语域三档 Register ladder**: 日常 `I heard that …` / `Someone said …` → 通用 **`rumour has it (that) …`** ／ `word has it that …` → 正式 `It is widely reported that …` ／ `It has been suggested that …`

## 🧩 Word Family & Collocation Matrix
### Morphology / Root (memory aid)
- 词源：拉丁语 `rumor`（**喧闹、众人嘈杂的议论**）→ 古法语 `rumur` → 英语 rumour；本义是「四起的噪声」，后来专指「未经证实的消息」
- 句式 `X has it that …` 里的 **has 不是「拥有」**，而是古已有之的「主张、声称」义：`Legend has it that …`、`Tradition has it that …`、`Word has it that …` 都是同一个框
- 同族词形：`rumoured / rumored`（据说的）、`be rumoured to do / to be`、`the rumour mill`（传言加工厂）、`rumour-monger`（造谣者）
- **Memory hook**: Picture a crowd buzzing in a Roman square — the noise itself is *rumor*, and nobody owns it; that is why we say “rumour **has** it”, never “someone said it”.（想象古罗马广场上一片嗡嗡的议论声——那就是 rumor：没人说得清是谁在传，所以只能说「传言攥着这消息」。）

### ⚠️ 常见误用
- ✗ `A rumour has it that …` —— 固定说法里 rumour **用单数、不加冠词**；要说「有一条传闻」得换句式：**There's a rumour that …**
- ✗ `Rumour has it about the merger.` —— 后面必须接**完整从句**（that 可省）；接名词就改 There are rumours **about** the merger.
- ✗ `Rumours have it that …` —— 固定式用单数 Rumour has it；复数只出现在 rumours are circulating / rumours spread 这类说法里。
- ✗ 拼写 `rumor` 与 `rumour` 同篇混用 —— BrE 用 **rumour**、AmE 用 **rumor**，一篇里统一一种（库内 `vocab/speculation.md:80` 已注明双拼写）。
- ⚠️ 语域偏差：它是 informal–neutral；Task 2 立论句改用 `It is widely reported that …`，Task 1 里图表以外的传闻一句都不能写。
- ⚠️ 色彩偏差：`rumour` 自带「未证实」的暗示——用它描述自己的论据等于自认没实据，改 evidence / figures。

## ⚔️ Confusion Matrix (with Chinese explanations)
### 🔁 同义替换速查（「听人说」怎么说）

| 中文 | 英文 | 侧重与语域 |
|:---|:---|:---|
| 据传、听人说（最常用） | **rumour has it (that) …** | informal–neutral；来源不明，口语与特稿皆可 |
| 听人说（更低调） | **word has it that …** | 同结构，更含蓄，报章常见 |
| 据报、据报道 | **It is widely reported that …** | 正式；隐含「有出处」 |
| 据说（有依据的推断） | **It has been suggested that …** | 学术／评论常用 |
| 据说（传闻式甩锅） | **allegedly / reportedly** | 新闻体副词，常配被动 |
| 传闻、小道消息（法律） | **hearsay** | 正式；不可采信的证据 |
| 八卦 | **gossip** | 谈私事，多贬义 |
| 推测、猜测 | **speculation** | 重心在「谁在猜」，常被媒体渲染 |
| 传说 | **legend has it that …** | 讲历史、讲民间故事 |

### 近义辨析矩阵（rumour has it vs I heard that vs speculation）
| Dimension | This phrase: rumour has it (that) … | Synonym 1: I heard that … | Synonym 2: speculation |
|:---|:---|:---|:---|
| Core nuance (English + 中文) | 把消息**推给「传言」**，明说来源不明、自己不背书（Rumour has it that …） | 说**消息进到我耳朵里**了，重心在「我听说」，真假同样未定 | 依据不足时**做推测**，重心在「谁在猜」，常被媒体渲染（Amid speculation that …） |
| Formality (English + 中文) | informal–neutral（口语、杂志、特稿） | informal（口语最常用） | neutral‑formal（新闻、评论高频） |
| Typical collocates (English + 中文) | rumour has it that …；word has it that …（据传；听人说） | I heard (that) …；so I've heard（我听说；我也听说了） | fuel / dismiss speculation；amid speculation that …（引发、否认猜测；在……猜测声中） |
| IELTS example (English + 中文翻译) | Rumour has it that the scheme has been quietly dropped.（据传这个方案已被悄悄搁置。） | I heard that the council is cutting the bus service.（我听说市政会要削减公交服务。） | Amid speculation that tuition fees would rise, applications fell sharply.（在学费将上涨的猜测声中，申请人数骤降。） |
> 🔗 **关联**：本句式最常出现在**新闻与市场**两个场景：消息由主流媒体放大（[[mainstream]]），而「猜」的那一半交给 [[speculation]]——*Amid speculation that demand would [[plummet]], shares fell.* 想写「图表之外的推测」进 Task 1 则是官方点名的失分项（`docs/ref/ielts/key-assessment-criteria.md:37`）。

## 🎯 Active Output Drills
### 1. Gap‑fill
Rumour ________ it that the café on the corner is closing.
（中文提示：据传街角那家咖啡馆要关门了——填一个动词）
> 💡 提示：记的是 Rumour + 动词 + it + that 从句 这个框；句首用单数、不加冠词。
### 2. Speaking scenario
Pass on a piece of local news you have heard but cannot confirm.
（中文说明：口语 Part 2/3 转述一件你没核实的消息——先用 Rumour has it that … 开场，再补一句你是怎么听说的、真假你自己也不确定）
> 💡 Use rumour has it (that) … once, then say where you first heard it.
### 3. Writing scenario
Write one sentence for a semi-formal letter mentioning a plan you have only heard about.
（中文说明：半正式信件里提「听说」，别让读者以为你在下结论；正式大作文换 It is widely reported that …）
> 💡 一句就够——用多了整段就成了道听途说。
### 4. Word‑weaving (advanced)
Make one complex sentence using rumour has it (that) … , [[speculation]] and [[mainstream]].
（中文提示：用 rumour has it、speculation、mainstream 合成一句——写一件主流媒体跟着猜、却谁也没核实的事）
> 💡 各就各位：谁在传 → rumour has it；谁在猜 → speculation；谁把它放大 → mainstream media。
