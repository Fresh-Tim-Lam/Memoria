# op-ed skeleton（OP 与 ED 段落骨架）

> **条目类型**：**写作结构模板**（能力轴）——OP 段（开头）与 ED 段（结尾）的句子槽位表。
> **为什么单独立条**：写几段、OP 段放不放让步、ED 段怎么收，都取决于题型；这套判断不落在某一个词上，故单独立条。
> **来源**：用户 2026-10-17 提供的课件截图（L9 · Group9 · 第 37 页「Opening and Ending 的结构模板」）。母句为课件原文，中文说明与 drills 为整理者补注。

## 🎯 一句话定义

OP 段按「背景 → 让步 → 立场」三句搭；ED 段按「结论 → 总结 → 升华」收，[[\h:#fff3cd:#5c4a00|句数由题型定]]。

## 🔍 判别测试 / Diagnostic

| 看到题目 | 选哪套 | OP 段槽位 |
|:---|:---|:---|
| 单边（agree / disagree、to what extent） | 单边 | 1 背景 → 2 让步 → 3 立场 |
| 两边都能谈（discuss both views） | 双边·平衡 | 1 → 2（不放让步，最短） |
| 同上，但你要先承认对方有理 | 双边·让步 | 1 → 2 → 3（3 是让步句） |
| 同上，让步后还要拉回自己 | 双边·让步拉回 | 1 → 2 → 3 → 4（4 是拉回） |
| two-part（Causes / Effects / Solutions） | TWO-PART | 背景 → 成因 → 我主张的措施 |

## 🧩 可套用骨架 / Skeleton

**OP（单边 / 双边通用）**
- It is debated / discussed / witnessed that **background**.
- It cannot be denied that **concession**.
- As far as **1, 2, and 3** are concerned, **position**.

**OP（TWO-PART：成因与措施）**
- It is a common phenomenon that **background**, which is most likely caused by a combination of social factors.
- In my opinion, we ought to take measures to counter such a social trend.

**ED（收尾）**
- In conclusion, **summary**, and **extension / sublimation**.

> ⚠ 别整套照抄：`Firstly / Secondly / In conclusion` 全套出现会被判机械模板（`writing/part2/income-equality-impact.md` 改写示范段）；ED 段只做收束，**不引入新论点**（`writing/part2/income-equality-impact.md` 改写示范结论段）。

## 🎯 Active Output Drills

1. **填槽**：用单边三句给「图书馆该不该取消纸质书」写 OP 段（背景 / 让步 / 立场）。
2. **改档**：同一题改写成「双边·让步拉回」四句版，比较两版 OP 段的长度差。
3. **收尾**：把 `writing/part2/income-equality-impact.md` 的结论段重写一遍——只收束，不加新论点。

## 📎 库内实作 / Where it shows up

- `writing/part2/income-equality-impact.md` 改写示范结论段 —— 结论段正例：明确收束立场 ＋ 提出更优做法。
- `writing/part2/income-equality-impact.md` 批改部分结论段 —— 结论段反例：变成复述、末尾冒出新论点，CC 被扣。
