## 📖 Core Definitions (Dictionary-Based)
> Source: Oxford / Cambridge（库内 `docs/ref/**` 暂无该词条目）
- **[adj] intriguing** – interesting because it is unusual, mysterious or unexpected; it makes you want to find out more（引人好奇的；耐人寻味的）
  (中文释义：抓人的不是「好看」，而是**勾着你往下看**——中性偏褒，几乎不用于贬义。)
- **Speaking example** – The blurb was intriguing, so I bought the book without reading a single review.
  （简介太勾人，我连一条书评都没看就把书买了。）
- **Writing example** – The study raises an intriguing question about how memory works.
  （这项研究提出了一个关于记忆如何运作的耐人寻味的问题。）

- **[adj] intriguing + plot / story / idea / possibility** – the chunk worth memorising for story talk（用在情节、故事、想法、可能性前）
- **Speaking example** – It's an intriguing plot — you spend the first half trying to work out who's lying.
  （这情节很勾人——前半段你一直在猜谁在撒谎。）
- **Noun-sense warning** – the noun `intrigue` means 密谋／绯闻 (scheming, or a secret love affair), a different sense; keep it apart from `intriguing`.

## 🎯 Best Situation & Register Gate（何时该用 / 何时别用）
> **闸门作用**：`intriguing` 的门槛不在难易，而在**你要夸什么**——只有夸「让人好奇」才用它；夸「精彩、感人、震撼」都不是它。
- **✅ Best situation**: ① Part 2 书／电影题：`an intriguing plot` ② 评论悬念与谜题：`an intriguing question / mystery` ③ 谈研究、想法：`an intriguing possibility` ④ 描述耐人寻味的角色：`an intriguing character`
- **∇ Avoid**:
  - ✗ 想说「好看、精彩」→ 用 `gripping` / `engrossing`：`a gripping read`
  - ✗ 想说「普通的有意思」→ `interesting` 就够；`intriguing` 用错场合会显得用力
  - ✗ 想说「说服力强」→ 用 `compelling`：`a compelling argument`
- **强度标记 Strength**: **mild-positive** —— 强度落在「好奇」，不在「赞叹」
- **语域三档 Register ladder**: 日常 `interesting` → 中性偏雅 `intriguing` → 强 `gripping` / `compelling`

## 🧩 Word Family & Collocation Matrix
### Morphology / Root (memory aid)
- `intrigue` (verb) = to make somebody curious, especially by being mysterious；`intriguing` 是它的现在分词作形容词
- 同族词：`interesting` / `fascinating` / `captivating` —— 都是「-ing 形容词」，主语是**引起兴趣的事物**，不是人
- **Memory hook**: The plot **intrigues** you → it is **intriguing**; the person who feels it says *I'm intrigued*.（物用 -ing，人用 -ed）
  （记忆钩子：物用 -ing（intriguing），人用 -ed（I'm intrigued）——这一条能防掉一大类错。）
