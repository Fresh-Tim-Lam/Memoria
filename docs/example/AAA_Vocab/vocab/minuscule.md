# minuscule
## 🔉 Pronunciation & Listening Cue
- **英式音标 (British IPA)**: /ˈmɪnəskjuːl/   (based on Oxford Dictionary)
- **美式音标 (American IPA)**: /ˈmɪnəskjuːl/   (based on Merriam‑Webster)
- **重音位置 (Stress)**: **MIN**-us-cule → 重音在第一音节，中音 /ə/ 弱读，末音 `-scule` 的 /j/ 几乎消失
- **🗣️ 听力陷阱 (Listening trap)**: ① 很多人（包括母语者）读成 mi-**NUS**-cule，把重音后移——词典标准是首音节重音；② 与 **minus** /ˈmaɪnəs/（减号；负数）同源但**首元音不同**：minuscule 是 /ˈmɪn/，minus 是 /ˈmaɪn/；③ 与 **minute** /maɪˈnjuːt/（微小的，形容词）容易混——minute 重音在**第二**音节且读 /maɪ/，两者意思接近但重音完全相反。
  (中文说明：MIN-us-cule，重音在第一个音节；别读成 mi-NUS-cule；也和 minus（减号，/maɪn/）的元音不同。)

## 📖 Core Definitions (Dictionary‑Based)
> Source: Oxford Advanced Learner's Dictionary / Cambridge Dictionary

- **[adjective] Sense 1** – extremely small; much smaller than usual（极小的；微小的）
- **Speaking example** – The flat was minuscule — one room and a tiny kitchen.
  （那套公寓小得可怜——一间房加一个极小的厨房。）
- **Writing example** – Modern phones contain minuscule amounts of gold, which is why recycling them is worth the effort.
  （现代手机含有微量黄金，这正是回收它们值得费力的原因。）

- **[adjective] Sense 2** – very small in amount, degree or importance（（数量、程度）微乎其微的）
- **Writing example** – [[\h:#1e3a8a:#bfdbfe|The proportion of waste that is actually recycled]] remains minuscule compared with the volume that is simply buried.
  （与实际被填埋的数量相比，真正被回收的废物比例仍然微乎其微。）
- **Speaking example** – The chance of winning is minuscule, but people still buy tickets.
  （中奖概率微乎其微，人们照样买票。）

> 💡 语域提示：`minuscule` 是**书面偏正式**的形容词，在雅思写作里替代 `very small` 非常划算；但它**只讲尺寸或数量**，不陈述「不重要」的评价——要那层评价用 `negligible`。

## 🎯 Best Situation & Register Gate（何时该用 / 何时别用）
- **✅ Best situation**: `a minuscule amount / proportion / fraction / percentage`（极小的数量／比例）｜`minuscule compared with…`（与…相比微不足道）｜`a minuscule flat / room`（极小的住所）｜`minuscule levels of sth`（某物的极低水平）｜科技与政策文本里描述「占比很小」
- **∇ Avoid**: ① 想表达「不重要、可以忽略」→ 用 `negligible` / `marginal`；② 想表达「精致、细致」→ 用 `minute detail` / `meticulous`（minuscule 不带「精细」义）；③ 口语里夸小朋友可爱说「小小的」→ 用 `tiny`，用 minuscule 会显得在念稿。
- **强度标记 Strength**: **strong** —— 比 `small` / `little` 强得多，接近「小到要用放大镜看」
- **语域三档 Register ladder**: 日常 `tiny` → 中性书面 `small` → 正式书面 `minuscule` / `minute`
- **来源 Source**: Oxford 搭配语料（a minuscule amount、minuscule proportions）

## 🧩 Word Family & Collocation Matrix
### Morphology / Root (memory aid)
- 拉丁 `minusculus` ＝「稍小的」，是 `minus`（更少）的指小形式：`minus` ＋ `-culus`（指小后缀）
- 同一 `minus` 家族的 **minus**（减）、**minimum**（最小）、**minor**（较小的）、**diminish**（减少）都是同一条线索
- **Memory hook**: `minus`（少）＋ `-cule`（小小的）＝「少上加小」。**记住前缀 minus，就不会写成 miniscule。**
  （注意：英语里流传最广的错拼 `miniscule` 就是把中间的 `us` 换成了 `is`——听起来像 mini，但词根没有 mini。）

## ⚔️ Confusion Matrix (with Chinese explanations)
### 这组词真正的分界：**是「尺寸小」还是「重要性小」**
| Dimension | This word: minuscule | tiny | negligible |
|:---|:---|:---|:---|
| Core nuance (English + 中文) | **尺寸或数量极小**，描述客观大小（a minuscule fraction） | **口语里的小**，中性通用，可带亲昵语气（a tiny baby） | **小到可以不算数**，是**评价**而非描尺寸（a negligible effect） |
| Formality (English + 中文) | 正式书面（formal, written） | 中性口语（informal / neutral） | 正式（formal, academic） |
| Typical collocates (English + 中文) | a minuscule amount / proportion / fraction | a tiny bit / a tiny room / a tiny baby | a negligible effect / negligible risk / negligible difference |
| IELTS example (English + 中文翻译) | Only a minuscule proportion of plastic is recycled.（只有极小比例的塑料被回收。） | There's a tiny mark on the wall.（墙上有个小印子。） | The extra cost is negligible.（额外成本可忽略不计。） |
> 一句话判定：**能量出来的「小」→ minuscule；只是随口说的「小」→ tiny；想说「这不算事」→ negligible。**
