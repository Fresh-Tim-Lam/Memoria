# perilous
## 🔉 Pronunciation & Listening Cue
- **英式音标 (British IPA)**: /ˈperələs/   (based on Oxford Dictionary)
- **美式音标 (American IPA)**: /ˈperələs/   (based on Merriam‑Webster)
- **重音位置 (Stress)**: **PER**·il·ous → 重音在第一音节，中间音节为弱读 /ə/
- **🗣️ 听力陷阱 (Listening trap)**: 中间音节 /ə/ 几乎被吞掉，听上去约等于两个音节 "PER‑ləs"，而**不是** "per‑EE‑lous"；不要与 **previous** /ˈpriːviəs/（先前的）混淆——后者重音与首辅音都不同。
  (中文说明：中间的 -i- 是弱读 /ə/，几乎不发音；重音在首音节。别听成 per-EE-lous，也别与 previous 混。)

## 📖 Core Definitions (Dictionary‑Based)
> Source: Oxford Advanced Learner’s Dictionary / Cambridge Dictionary

- **[adjective] Sense 1** – very dangerous, especially because something bad could easily happen（危险的；凶险的；危机四伏的）
- **Speaking example** – The final stretch of the climb was perilous, so we turned back before the storm arrived.
  （攀登的最后一段极其凶险，所以在暴风雨来临前我们折返了。）
- **Writing example** – Deploying facial‑recognition technology without clear legal limits would be a perilous step for any government.
  （在没有明确法律边界的情况下部署人脸识别技术，对任何政府而言都是危险的一步。）

- **[noun] Sense 1** – serious danger（危险；险境）— 语域偏正式/文学
- **Speaking example** – Many coastal villages are now in peril because of rising sea levels.
  （由于海平面上升，许多沿海村庄如今身处险境。）
- **Writing example** – The report concludes that the perils of unregulated mass tourism outweigh its economic benefits.
  （报告结论是：不受管控的大众旅游之害，超过其经济收益。）

> 💡 语域提示：`perilous` / `peril` 都偏**正式与文学**，多见于新闻、报告、文学描写；雅思写作（尤其大作文）用得上，但**口语里描述日常小危险要用 `dangerous`**。
> ⭐ 最值钱的派生是动词 **imperil**（危及）——写作里替换 `endanger` / `threaten` 非常好用。
> 📚 **与课件互相印证**：你提供的 perilous 课件（`docs/ref/ppt/54e96fa342c79306197e56ef0430c197.png`，OCR 全文见 [`ocr.md`](docs/ref/ppt/ocr.md)）把同一条规则写作 **"Strong meaning: more serious than difficult"**，并给出同一条禁用清单（*a late bus / a difficult test / a minor inconvenience*）——本词条的语域判定与课件一致，课件另有 3 处补充见下方 §「何时该用它」与「语域三档对照」。

## 🧩 Word Family & Collocation Matrix
### Morphology / Root (memory aid)
- 源自拉丁语 `periculum`（危险，本义与"试验、冒险"相关）→ 古法语 `peril` → 英语 `peril`；形容词由 `peril` + `-ous` 构成
- 同源词：**experiment**（实验）、**expert**（行家）也来自 `periculum` 这一族——原始含义都带有"冒险去试"的意味
- 派生：`perilous`（形）、`perilously`（副）、`peril`（名）、`imperil`（动）、`parlous`（古语形容词，同义）
- **Memory hook**: `peril`（危险）＋ `-ous`（充满…的）=「充满危险的」。记住 `imperil` = **im‑**（使…进入）＋ **peril** = 使陷入危险 → **危及**。
  （想象登山者在悬崖边的窄路上：一步踏错就是 peril —— 那种感受就是 perilous。）

### ⚠️ 常见误用
- ✗ **perillous** —— 拼写多了一个 `l`；正确是 **perilous**（单 l）。
- ✗ `The road was perilous this morning.` —— 描述日常小危险用 `dangerous` 即可；**perilous 隐含严重、可能致命的危险**，用在小事上会显得夸张。
- ✗ `He is a perilous man.` —— perilous **不修饰人**，只修饰处境、行动、事物（journey / situation / path / state）。
- ⚠️ **peril 的可数性**：表示抽象的"危险"时**不可数**（`in peril`、`at your peril`）；表示"某种隐患/风险"时**可数**（`the perils of...`、`a grave peril`）。
- ⚠️ 语域错配：`in peril` 偏正式，口语中说 `in danger` 更自然。

## 🎯 Best Situation & Register Gate（何时该用 / 何时别用）

- **✅ Best situation**: **a storm**（暴风雨）｜**an accident**（事故）｜**getting lost**（迷路）｜**extreme weather**（极端天气）｜**a journey with genuine danger**（真正有危险的旅程）
- **∇ Avoid**: `a late bus`（公交晚点）｜`a difficult test`（考试难）｜`a minor inconvenience`（小麻烦）——配上 `perilous` 属**严重夸张**，应改用 `difficult` / `dangerous`
- **强度标记 Strength**: **strong**——课件原话 **"Strong meaning: more serious than difficult"**
- **语域三档 Register ladder**: 见下方「🎚️ 语域三档对照」（危险类词表较大，故展开为独立小节）
- **来源 Source**: 用户课件 `docs/ref/ppt/54e96fa342c79306197e56ef0430c197.png`

> 一句话判定：**"会不会出大事、甚至出人命？"** 会 → `perilous`；不会 → `dangerous` 或 `difficult`。

## 🎚️ 语域三档对照（日常 / 正式 / 文学）

**怎么用**：先看**危险的性质**（是物质危害？还是处境凶险？），再选语域档。**选高了一档就是"用词过头"**——这是中国考生最常见的失分方式。（同套课件的其它词卡：[[promising]] ｜ [[troubled]] ｜ [[favourable]]，四张卡共用同一套口语 Part 2 故事框架；另见 [[flail]]——危险处境中"乱扑腾"的动作词）

| 档 | 该档的词 | 强度 | 典型搭配 | 例句 | 使用提醒 |
|:---|:---|:---|:---|:---|:---|
| **① 日常（口语 / 中性）** | **dangerous** ⭐最常用 | 中 | a dangerous road / animal / situation；It's dangerous to… | It is dangerous to swim in this river. | **90% 的场合用它就够**，别为"高级"而升级 |
| | **risky** | 中 | a risky decision / investment / move | Putting all your savings into one stock is risky. | 强调"**冒险、可能失败**"，而非"当下凶险" |
| | difficult / tough | 弱 | a difficult test / a tough week | — | ⚠️ **不能**替代 `perilous`（课件 ∇ 明令） |
| **② 正式（报告 / 学术 / 新闻）** | **hazardous** | 较强 | hazardous waste / chemicals / materials / conditions | Workers handle hazardous materials every day. | 多指**物质、环境、职业**危害，**不用于"处境"** |
| | **precarious** | 较强 | a precarious position / existence / balance / housing | Millions still live in precarious housing. | 强调**不稳、随时可能崩塌**，不强调"致命" |
| | **hazard**（名词） | — | a health hazard / a fire hazard | Smoking is a serious health hazard. | 把"危险"转成"**危害源**"，写作很好用 |
| **③ 文学 / 强（戏剧性）** | **perilous** ⭐你学的词 | **最强** | a perilous journey / situation / **weather conditions** | We found ourselves in a perilous situation when the storm cut off the only path back. | **只用于确有危险的处境**；小事用它会夸张 |
| | **treacherous** | 最强 | treacherous roads / ice / currents | The mountain roads are treacherous in winter. | 强调**隐蔽、不可预料**的危险 |
| | **parlous**（古旧） | 最强 | a parlous state / situation | The industry is in a parlous state. | 现代几乎不用，仅文学语体 |
| | **imperil**（动词） | 最强 | imperil sth | Climate change imperils food security. | 动词档没有更高级的了，直接用 |

### 三步选词法

1. **小事、日常** → `dangerous`（或 `risky` / `difficult`）
2. **物质、环境、职业危害** → `hazardous`（名词用 `hazard`）
3. **处境／旅程本身凶险、且要戏剧性** → `perilous`（或 `treacherous`）

### 💬 口语 Part 2 故事框架（同一套课件）

课件把"危险经历"答成三个槽位，可直接套用：

| 槽位 | 课件原句 | 换成你自己的内容 |
|:---|:---|:---|
| **DANGER** | We found ourselves in a perilous situation when **visibility dropped suddenly**. | …when **the tide came in faster than we expected**. |
| **ACTION** | I tried to **remain calm, assess the risk, and contact someone for help**. | …**stay calm, retrace my steps, and call for help**. |

|:---|:---|:---|
| **危险的（处境/旅程）** | **dangerous** | 中性通用，日常最常用；严重度最低 |
| | **hazardous** | 多指**物质、环境、职业**危害（hazardous waste / chemicals） |

| | **treacherous** | 强调**隐蔽、不可预料**的危险（treacherous ice / roads） |
| | **risky** | 强调**冒险、可能失败**（a risky investment） |

### 近义辨析矩阵（perilous vs hazardous vs precarious）
| Dimension | This word | Synonym 1: hazardous | Synonym 2: precarious |
|:---|:---|:---|:---|
| Core nuance (English + 中文) | 处境或行动**本身凶险**，随时可能出事，常含戏剧性（a perilous climb） | 环境或物质**含有害因素**，技术性描述（hazardous chemicals） | **不稳定、随时可能翻盘或崩塌**，强调支撑不足（a precarious balance） |
| Formality (English + 中文) | formal / literary（正式、文学） | formal / technical（正式、技术） | formal（正式） |
| Typical collocates (English + 中文) | perilous journey / situation / path / state（凶险的旅程、处境、小路） | hazardous waste / materials / conditions / work（有害废物、材料、条件、作业） | precarious position / balance / existence / housing（不稳定的处境、平衡、生存、住所） |
| IELTS example (English + 中文翻译) | The last stage of the trek was perilous.（徒步的最后一段极其凶险。） | Workers are regularly exposed to hazardous substances.（工人经常接触有害物质。） | Millions still live in precarious housing.（数百万人仍住在不稳定的居所里。） |
