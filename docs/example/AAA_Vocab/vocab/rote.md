# rote
## 🔉 Pronunciation & Listening Cue
- **英式音标 (British IPA)**: /rəʊt/   (based on Oxford Dictionary)
- **美式音标 (American IPA)**: /roʊt/   (based on Merriam‑Webster)
- **重音位置 (Stress)**: 单音节词，整词重读 **ROTE**；英音 /rəʊt/ 是开口较大的双元音，美音 /roʊt/ 收得更圆
- **🗣️ 听力陷阱 (Listening trap)**: `rote` 与 `wrote` **完全同音** /rəʊt/ —— 只能靠句法位置区分：前面有 `by` 就是 rote（`learn it by rote`）；站在主语或动词位置就是 wrote（`he wrote it`）。
  (中文说明：听到 /rəʊt/ 先看它前面有没有 `by`——有 `by` 就是「死记」的 rote。)

## 📖 Core Definitions (Dictionary‑Based)
> Source: 库内实据 data/sources/vocab_writing100.js:483–486（中文原句 ＋ 两版英文译本 ＋ remark）＋ Oxford / Cambridge（库内暂无 rote 词典条目）

- **[noun, uncountable]** the practice of learning something by repeating it, without understanding it（死记硬背；机械记忆）
  (中文释义：rote 是**方法**的名字，不含「记住了」这个结果义——它只指「不靠理解、纯靠重复」这条路子，所以**自带贬义**。)
  - **Writing example** – Learning the times table by rote is not the best way to improve numeracy.
    （死记乘法表并不是提高算数能力的最好方式。）—— 书上译本原句（data/sources/vocab_writing100.js:484）
  - **Writing example** – Rote memorisation of the multiplication table is not the effective way to enhance arithmetic skills.
    （死记硬背乘法表并不是提高算数能力的有效方式。）—— 同题的另一译本（data/sources/vocab_writing100.js:485）
  - **Speaking example** – I learnt the whole speech by rote, so I froze the moment someone asked me a question.
    （我把整篇演讲都死记了下来，结果一有人提问我就卡住了。）⚠ 自撰示例，待核
  - 📎 同题 remark 另注明：**numeracy** n. 基本计算能力；识数（data/sources/vocab_writing100.js:486）

> 📌 **先记语法位置，再记意思**：rote 虽是名词，却**不作主语、不作宾语、不作表语**，只活在两个槽里——① `by rote`（介宾短语作状语）② `rote + 名词`（作定语）。它也**没有动词、形容词形态**：❌ `I rote it`、❌ `It is rote`。

## 🎯 Best Situation & Register Gate（何时该用 / 何时别用）
> **为何放在这个位置**：rote 的失分点不是「用错意思」，而是**立场**——它天生带批评口吻，放进中立描述就成了擅自贬损。
- **✅ Best situation**: ① 写作教育题：`rote learning` 是批应试教育的现成词块（`rote learning stifles creativity`）② 写作报告类：谈某地教学方式时，`learning by rote` 比 `memorising facts` 更利落 ③ 口语 Part 3 教育话题：`a lot of what we did at school was just learning by rote` ④ 批评式结论：`Rote learning rewards patience, not curiosity.` ⑤ 与 `cram` 分工合写：`cram` 讲「什么时候学」（考前突击），`by rote` 讲「怎么学」（机械重复）
- **∇ Avoid**:
  - ✗ 中立陈述事实时用它（❌ `Students learn vocabulary by rote.` 而你并无褒贬）→ 中性表述用 `memorise`；只有想表达「不理解」的批评意味时才用 `by rote`
  - ✗ 把它当动词或形容词（❌ `I rote the poem`、❌ `a rote student`）→ 动词用 `memorise`；要「死板的」用 `mechanical`
  - ✗ 宾语槽里塞可数名词裸单数（❌ `learn thing by rote`）→ ✓ `learn sth by rote` ／ `learn things by rote`
- **强度标记 Strength**: **strong**——是**负面评价**而非中性描述；一篇里用一次足够
- **语域三档 Register ladder**: 日常 `learning things off by heart` → 通用 **`learning by rote`** → 学术／教育评论 `rote learning / rote memorisation`
- **来源 Source**: 库内实据 data/sources/vocab_writing100.js:483–486（remark 原文：`learning sth. by rote 死记硬背地学。`／`rote learning 死记硬背`）＋ 用户 2026‑10‑13 提供的片段（`learn thing by rote`）；其余搭配为整理者补充 ⚠

## 🧩 Word Family & Collocation Matrix
### Morphology / Root (memory aid)
- ⚠ **词源存疑**：rote 的来源在通用词典中多标为不明（与拉丁 `rota`「轮」的关联并不可靠）——**本条目故不作词根拆解**，改以「槽位」当记忆锚点。
- 词形：rote 不可数、无复数、无比较级；**没有动词与形容词形态**——这是它最好记的一点。
- **Memory hook**: 把 rote 想成**一台唱机**——同一句唱词一圈一圈地转，只记「转了多少圈」，不问「你懂没懂」；所以它总是连在 `by rote` 这个介词框里。

## ⚔️ Confusion Matrix (with Chinese explanations)
<!-- ⚠ 来源待核实：下表区分按通用词典（Oxford / Cambridge）整理；库内 cram / recite 只有中文释义与各一个例句（data/sources/vocab_source1.txt:820、:1161；data/sources/vocab_source2.txt:820、:1161），语义对比为整理者归纳 -->
Compare with cram, recite
| Dimension | This word: rote | Synonym 1: cram | Synonym 2: recite |
|:---|:---|:---|:---|
| Core nuance (English + 中文) | 讲**怎么学**：不靠理解、纯靠重复（by rote） | 讲**什么时候学**：考前临时突击塞（cram for the finals） | 讲**学完之后做什么**：背出来给人听（输出端） |
| Formality (English + 中文) | neutral（说法本身中性，但语义**带贬**） | informal（口语化，学生腔） | neutral‑formal（朗诵、课堂场景偏正式） |
| Typical collocates (English + 中文) | learn / know sth by rote；rote learning | cram for an exam / the finals；cram school | recite a poem / a passage；recite in class |
| IELTS example (English + 中文翻译) | Learning the times table by rote is not the best way to improve numeracy.（死记乘法表并不是提高算数能力的最好方式。） | Lectures were all called off, so students can cram for the semester finals.（课全停了，学生可以突击备考期末。） | Each child had to recite a poem in class.（每个孩子都要在班上朗诵一首诗。） |
（中文说明：三者串成一条流水线——`cram` 是**考前**塞进去，`by rote` 是**塞的方式**，`recite` 是**事后**倒出来。）
> 🔗 **关联**：学习方式的反面对照是 [[assimilation]]——`rote` 求的是**记住**（靠重复，不问理解），`assimilation` 求的是**内化**（吸收进去、变成自己的）；写教育题时把两者并提，正好构成「怎么学」的两极。
> 🔗 **关联**：不想靠 `rote`，另一条路是 [[impart-instil-cultivate]]——`cultivate the habit of …`、`instil … in sb` 都是**靠时间养成**，而不是靠重复**塞进**记忆；对比题里正好一组：`by rote` vs `from an early age`。
> 🔗 **关联**：还有一条「搬出来」的路子正好相反 —— [[quote]] 是把别人的话**原封不动搬出去**（要一字不差、要标出处），`rote` 是**不靠理解地塞进去**；一个管「怎么记」，一个管「怎么用别人的原话」，写论文时这两件事一里一外。

### 1. Gap‑fill
Learning the times table __________ is not the best way to improve numeracy.
（中文提示：死记乘法表并不是提高算数能力的最好方式）
### 2. Speaking scenario
**Part 3: Is the way students are taught in your country too focused on memorising?**
（中文说明：先给立场，再用 `learning by rote` 点出其代价——不理解、不会迁移；最后给一个替代做法。）
> 💡 用一次 `learning by rote`、一次 `memorise`，把「学法」与「结果」分开说。
### 3. Writing scenario
Write one Task‑2 sentence on whether schools should rely less on rote learning.
（中文说明：大作文写一句话，论述学校是否该少依赖死记硬背）
> 💡 例：Rote learning rewards patience rather than curiosity, so schools that rely on it may end up training memory while leaving understanding untouched.（死记硬背奖励的是耐心而非好奇心，因此依赖它的学校可能只训练了记忆，理解力却原封未动。）

Make one complex sentence using "rote", [[rebel]] and [[rewarding]].
（中文提示：用 rote、rebel、rewarding 合成一句——写一个学生反抗死记硬背、改用自己的方式学，最后觉得收获很大）
