# troubled
## 🔉 Pronunciation & Listening Cue
- **英式音标 (British IPA)**: /ˈtrʌb.əld/   (based on Oxford Dictionary)
- **美式音标 (American IPA)**: /ˈtrʌb.əld/   (based on Merriam‑Webster)
- **重音位置 (Stress)**: **TROU**·bled → 重音在第一音节，第二音节弱读 /əld/
- **🗣️ 听力陷阱 (Listening trap)**: 词尾的 /əld/ 弱且快，几乎黏成一个音节 "TROU‑bld"；`troubled` /ˈtrʌbəld/ 与 `troubling` /ˈtrʌblɪŋ/ 在连读中极难区分，要靠**上下文与词性**判断（前者描述"有问题的对象"，后者描述"令人不安的事物"）。
  (中文说明：重音在首音节，尾巴弱读。听力里 troubled / troubling 容易混，靠搭配判断。)

## 📖 Core Definitions (Dictionary‑Based)
> Source: Oxford Advanced Learner’s Dictionary / Cambridge Dictionary；并与用户课件同套词卡（`docs/ref/ppt/827173d425464f8f8d047a965009054b.png`，OCR 见 [`ocr.md`](docs/ref/ppt/ocr.md)）对账

- **[adjective] Sense 1** – having serious problems, worries or difficulties（有严重问题的；陷入困境的；忧心忡忡的）
- **Speaking example** – It happened during a troubled period when I was under a lot of pressure at work.
  （那件事发生在我工作压力很大的那段艰难时期。）
- **Writing example** – The company has had a troubled few years, with three consecutive losses.
  （该公司这几年处境艰难，连续三年亏损。）

> 💡 **课件的核心规则**：**"For a temporary event, `difficult` or `stressful` often sounds more natural."**
> 中文：**一次性的事件**（一场考试、一个糟糕的周一）用 `difficult` / `stressful` 更自然。`troubled` 描述的是**持续存在严重问题**的时期、关系或人——用错就显夸张。

## 🎯 Best Situation & Register Gate（何时该用 / 何时别用）
- **✅ Best situation**: family conflict（家庭冲突）｜emotional stress（情绪压力）｜a difficult**period**（一段艰难的时期）｜someone who appears worried（看起来忧心忡忡的人）——**均来自课件 BEST SITUATION**
- **∇ Avoid**:
  - ✗ 描述**单次事件**（`a troubled exam` / `a troubled meeting`）→ 该用 `difficult` / `stressful`（课件 ∇ 明令）
  - ✗ 描述**短暂的坏心情**（今天有点烦）→ 该用 `upset` / `worried` / `stressed`
  - ✗ 把 `troubled` 用来指"坏透了/恶劣"→ 该用 `terrible` / `awful`
- **强度标记 Strength**: **strong（强）**——含"**严重且持续**"的判断，不是一时的困扰
- **语域三档 Register ladder**: 日常 `difficult` / `stressful` → 通用 `**troubled**` → 文学 `turbulent`（动荡不安的，多形容时代、局势）

## 🧩 Word Family & Collocation Matrix
### Morphology / Root (memory aid)
- `trouble`（麻烦；困扰）＋ `-ed`（过去分词作形容词）=「被麻烦缠住的」→ **陷入困境的**
- 同族：`trouble`（名/动）→ `troubled`（形，**自身有问题**）／`troubling`（形，**令人不安的**）／`troublesome`（形，**麻烦的、棘手的**）
- **Memory hook**: 一片**久旱的田地**——不是某一天坏了，而是**长期缺水**。持久的问题，才是 troubled。（对照 [[flail]]：troubled 说**状态**出了问题，flail 说**动作**在乱扑腾）
- ⭐ **`troubled` vs `troubling`（必须分清）**：`a troubled teenager` ＝ 有问题的少年（他自己在困境里）；`a troubling trend` ＝ 令人担忧的趋势（它让**我们**不安）。

### ⚠️ 常见误用
- ✗ `a troubled exam / a troubled Monday` —— 一次性事件用 `difficult` / `stressful`（课件 ∇ 明令）。
- ⚠️ 介词：`be troubled **by/about** sth`（为某事烦恼），**不是** `troubled of`。
- ✗ `I'm troubled today.`（今天有点烦）—— 语气过重；日常说 `I'm a bit stressed / fed up.`
- ⚠️ 不要与 `troubling` 互换：`a troubled result`（结果本身有问题）vs `a troubling result`（结果令人担忧）。

## ⚔️ Confusion Matrix (with Chinese explanations)
### 🔁 同义替换速查

| 义项 | 可替换表达 | 语域与差别 |
|:---|:---|:---|
| **长期有严重问题** | **difficult / stressful** | 一次性或短期的困难；**口语首选** |
| | **turbulent** | 文学/正式；多形容时代、局势、气流 |
| | **problematic** | 正式；强调"存在问题、需处理" |
| | **in crisis** | 强调**危机状态**，程度更急 |
| | **unstable** | 强调**不稳定**（多指局势、心理） |
| **令人不安（勿混）** | `troubling` / `worrying` / `concerning` | 描述"使人不安的事物"，**不是**"自身有问题的对象" |
| **反义** | `stable` / `settled` / `untroubled` | untroubled 偏文学 |

### 近义辨析矩阵（troubled vs difficult vs stressful）
| Dimension | This word | Synonym 1: difficult | Synonym 2: stressful |
|:---|:---|:---|:---|
| Core nuance (English + 中文) | **持续存在严重问题**，含情感、关系、制度层面的困扰（a troubled period） | **难度高、不易完成**，客观描述任务（a difficult test） | **给人造成压力**，强调主观感受（a stressful job） |
| Formality (English + 中文) | neutral，但语感偏重（中性偏重） | neutral（中性，最常用） | neutral（中性） |
| Typical collocates (English + 中文) | a troubled period / relationship / teenager / past（艰难的时期、有问题的关系、问题少年、动荡的过去） | a difficult question / decision / time（难题、难决定、难熬的时光） | a stressful job / situation / week（高压工作、情境、一周） |

## 🎯 Active Output Drills
### 1. Gap‑fill
It happened during a __________ period when I was under a lot of pressure at work.
（中文提示：那件事发生在我工作压力很大的那段艰难时期）
### 2. Speaking scenario
**Describe a difficult or dangerous situation you experienced.**（课件 Direction 2 原题）
- where you were ｜ what happened ｜ how you dealt with it ｜ what you learned from it
（中文说明：口语 Part 2，用 **DANGER → ACTION → RESULT** 三槽位；`troubled` 适合放在 **背景铺垫**（that was a troubled period in my life），危险本身仍用 [[perilous]]）
### 3. Writing scenario
Write one Task‑2 sentence about the pressure young people face today.
（中文说明：大作文写一句话，论述当代年轻人面临的压力）
> 💡 例：Many young adults enter the job market during a **troubled** economic period, which makes long-term planning unusually difficult.
### 4. Word‑weaving (advanced)
Make one complex sentence using "troubled", "troubling" and [[promising]].
（中文提示：用 troubled、troubling、promising 合成一句——注意 troubled 与 troubling 的方向相反）
