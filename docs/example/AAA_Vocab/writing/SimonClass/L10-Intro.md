# IELTS Training Course
1. Understand the task
2. Break the task into parts
3. Methods, techniques
4. Lots of practice
5. Feedback, measure progress

## Write an essay
- At least 250 words — a floor, not a target; no upper limit
- 40 minutes
- Universal topics
- 4 question types

## Four scoring criteria
1. Task response
2. Coherence and cohesion
3. Vocabulary
4. Grammar
