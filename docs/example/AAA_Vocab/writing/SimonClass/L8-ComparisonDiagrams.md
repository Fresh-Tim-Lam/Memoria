# Introduction

 [[\h:red:red|The diagrams below show]] [[\h:yellow:#b37b02|the existing ground floor plan of a house]] [[\h:red:red|and]] [[\h:blue:blue|a proposed plan for some building work]].

 [[\h:red:red|The two pictures compare]] [[\h:yellow:#b37b02|the current layout of the ground floor of a house]] [[\h:red:red|with]] [[\h:blue:blue|a plan to redesign the same living space]].
> `show` becomes `compare` once the two diagrams are two versions of the same house; `existing` -> `current`, `ground floor plan` -> `layout of the ground floor`, `proposed plan for some building work` -> `a plan to redesign the same living space`

## Overview 2 sentences 2 points
> 1. Hall is no longer on the new diagram (a main change)
> 2. entrances of the floor won't change ( a main thing that does't change)

We can see that the new design proposal [[\h:red:red|involves making]] **a number of changes** to the ground floor of the house, **mainly in the central hall area**. [[\h:red:red|There are no plans to change]] **external walls or entrances**.
> 2 sentences = 2 points: sentence 1 = **what** changes and **where**; sentence 2 = what stays the same.
> reusable frames: `involves making`, `There are no plans to change`. No room is named here - rooms go to the body.

## Paragraph 3: the hall disappears

The **most noticeable change** from the existing to the proposed floor plan is that **a separate hall area** [[\h:red:red|will no longer be]] when the building work has been done. [[\h:red:red|This will be achieved by]] **removing the internal wall and door** between the hall and living room, along with **the current staircase and under-stair storage cupboard**. With no separate hall area, the proposed living room will also contain **the staircase to the first floor**.
> order: biggest change first -> *how* it is done -> its knock-on effect. `will no longer be` is the old-vs-new negative; the last clause is a **consequence**, not a new feature.

## Paragraph 4: stairs, doors and furniture

[[\h:red:red|To replace]] **the current straight staircase**, **a new set of winding stairs** will be installed in **the corner of the living room**. The internal door between the hall and kitchen [[\h:red:red|will also be replaced with]] **double doors** connecting the kitchen with the new living room. Finally, the planned building work will also include **the installation of some kitchen furniture**.
> three changes, one sentence each; `also` / `Finally` chain them, so no Firstly/Secondly. `To replace` fronts the **reason** for moving the stairs - the change itself is what you name last.

## Vocabulary: paraphrasing, verbs, description of changes
**1. Paraphrasing (intro only)**
- `existing plan` → `current layout`
- `proposed plan` → `plan to redesign`
- `design proposal` = `planned building work`

**2. Naming the work before naming the change**
- `the design proposal involves` + -ing → `involves making a number of changes`
- `when the building work has been done`

**3. Verbs that carry the change**
- `there will no longer be` - the old-vs-new negative
- `this will be achieved by` + -ing - how it is done
- `will also contain` / `will also include` - what the new room is given
- `will be installed` / `will be replaced` - the object itself changes

**4. Nouns of place and object**
- `living space`, `central hall area`, `staircase`
- `under-stair storage cupboard`
- `a new set of winding stairs`
- `the installation of some kitchen furniture`
