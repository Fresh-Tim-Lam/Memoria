# 强化学习基础概念

强化学习（Reinforcement Learning, RL）是机器学习的三大范式之一，与监督学习和无监督学习并列。在强化学习中，智能体（agent）通过与环境（environment）交互来学习最优策略，目标是在长期累积奖励最大化。参见 [[mdp]] 了解其数学基础。

强化学习的独特之处在于：
- **延迟奖励**：动作的效果可能要很久之后才能体现
- **试错学习**：没有标注数据，智能体必须自己探索
- **序贯决策**：当前决策影响未来状态，不是[[独立]]的

强化学习的应用极其广泛：游戏 AI（AlphaGo、Dota 2）、机器人控制、自动驾驶、推荐系统、资源调度等。近年来，深度强化学习（Deep RL）将深度网络与 RL 结合，取得了令人瞩目的成果。两大主要范式是 [[q-learning]]（基于价值）和 [[policy-gradient]]（基于策略），它们各有优劣，也可以结合使用。

## 智能体与环境

强化学习的交互模型由智能体和环境构成，它们在离散时间步 $t = 0, 1, 2, \ldots$ 中持续交互：

1. **观察**：智能体观察当前状态 $s_t \in S$
2. **决策**：根据策略 $\pi(a|s)$ 选择动作 $a_t \in A$
3. **反馈**：环境返回奖励 $r_{t+1} \in R$ 并转移到新状态 $s_{t+1}$
4. **重复**：继续下一个时间步

这个循环形成了马尔可夫决策过程（MDP）的骨架。

智能体的核心要素：
- **策略（Policy）**：从状态到动作的映射，定义了智能体的行为方式
- **价值函数（Value Function）**：评估状态或状态-动作对的好坏程度
- **模型（Model）**：智能体对环境的内部表示（可选）

根据是否使用环境模型，RL 方法分为：
- **Model-based**：学习环境模型，可以规划（如 Dyna-Q）
- **Model-free**：直接从经验中学习，无需模型（如 Q-Learning、REINFORCE）

## 奖励函数

奖励函数 $R(s, a)$ 或 $R(s, a, s')$ 定义了智能体的目标，是强化学习中最核心的设计选择。

奖励函数的性质：
- **标量信号**：只有一个数值，简单明确
- **即时反馈**：每步都有奖励，但长期奖励可能更重要
- **人为设计**：通常需要领域知识来设计

奖励设计的常见陷阱：
- **奖励稀疏**：大多数步骤奖励为 0，只有终点有非零奖励，难以学习
- **奖励作弊**：智能体找到了获取高奖励但不符合意图的策略
- **奖励塑造**：添加辅助奖励引导学习，但可能改变最优策略

累积奖励（回报）的定义：

$$
G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}
$$

其中 $\gamma \in [0, 1)$ 是折扣因子，控制对未来奖励的重视程度。$\gamma \to 0$ 意味着目光短浅，$\gamma \to 1$ 意味着重视长远。
