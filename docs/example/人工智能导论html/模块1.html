知识点 1-1 可计算理论的起源与形式化纲领（希尔伯特、哥德尔） 对应表格“可计算理论”
📄 位置来源：第3-4页（1.2节前半部分），第19-20页

1. 从自然语言到形式化语言的转变

早期数学概念用自然语言描述（如《庄子·天下篇》“一尺之棰，日取其半，万世不竭”对极限的描述，亚里士多德三段论）。为解决自然语言不精确的问题，研究人员开始用形式化语言（符号系统）来刻画数学概念。例如，勾股定理可形式化表示为：
\(\forall \Delta \in\) 直角三角形，\(x\)、\(y\)和\(z\)分别是\(\Delta\)的两条直角边和斜边，则 \(x^{2}+y^{2}=z^{2}\)。

2. 形式化系统的三大核心性质

  • 完备性：所有能够从该形式化系统推导出来的知识，都可以从这个系统推导出来。
  • 一致性（自治性/非矛盾性）：所有可推导出来的知识，不会同时推导出它的否定（如不会同时推出 \(A \ge 0\) 和 \(A < 0\)）。
  • 可判定性：对于形式化系统推导得到的任何知识，存在算法可在有限步内判定其为真或为假。

3. 希尔伯特纲领（1900年）

德国数学家大卫·希尔伯特在1900年巴黎第二届国际数学会议上提出23个重要数学难题，其中第二个问题就是“证明算术公理的相容性”（即一致性）。希尔伯特希望构建起有效的形式化大厦，使得推理过程能够像算术运算一样“自动计算”。

4. 哥德尔不完全性定理（1931年）

哥德尔发表论文《论数学原理及有关系统中不可判定命题》，指出：任何表达力足够强的形式化系统（递归可枚举）都不可能同时具有一致性和完备性，且该系统本身的一致性无法在系统内被证明。
历史冲击：该定理说明有些数学问题是不可判定（不可计算）的（如费马大定理在当时的不可判定性）。它直接回应并部分驳斥了希尔伯特的乐观形式化计划，标志着“可计算理论”的哲学边界被划定。

知识点 1-2 可计算理论的机械实现——图灵机模型 对应表格“可计算理论”与“图灵机模型”
📄 位置来源：第4-6页（1.2节后半部分），第20-21页

1. 三种等价的可计算模型

哥德尔提出了原始递归函数；丘奇提出了 λ演算（λ-calculus）；图灵提出了图灵机模型。三者虽然在形式上完全不同，但在功能上完全等效：任何可计算函数均可通过这三种方式完成计算，任何不可计算函数均无法通过它们完成计算。

2. 图灵机的物理结构（机械化载体）

  • 无限长纸带：两端无限延伸，纸带上有连续排列的可擦写小方格，用于存放计算任务所需的数据、程序指令或置空。
  • 读写控制指针（读写头）：从左到右依次扫过纸带方格，读取信息或写入结果。
  • 程序控制器：事先存储若干指令集，根据读写头读入的信息触发对应指令。

3. 图灵机的运行机制（自动计算过程）

读写指针从纸带读入信息 → 触发程序控制器中的对应指令 → 执行操作并将计算结果写回纸带方格 → 指针移动到下一格 → 如此周而复始，直至计算结束（图灵停机）。一旦停机，纸带上最终记载的信息就是该计算任务的最终结果。

4. 教材中的具体计算示例：gcd(24, 16) × 10 + 17 = 97

图灵机先读入 gcd(24, 16) → 触发最大公因数指令，得到8 → 依次触发乘法指令（×10）和加法指令（+17）→ 最终在纸带方格中留下 97 这一计算结果，随后图灵机停机。该示例说明了：凡是能在有限步骤内停机的任务，即为可计算的任务。

5. 丘奇-图灵论题（Church-Turing Thesis）

核心论断：凡是可计算的函数都可以用图灵机计算；反之，任何不可计算的函数都无法通过图灵机完成计算。
历史贡献：图灵机模型成为了现代计算机（冯·诺依曼体系结构）的理论模型，为人工智能领域提供了最根本的“机器载体”。图灵因此被公认为“理论计算机之父”，计算机学界最高奖——图灵奖即以他的名字命名。

知识点 1-3 图灵测试——智能的哲学判断标准 对应表格“图灵测试”
📄 位置来源：第1页（绪论章首页引言后），第17页（AI定义段）

1. 图灵测试的核心思想

图灵测试由艾伦·图灵在1950年提出，是判断机器是否具备智能的一种哲学性、操作性标准。
测试方式：一名人类评判员通过文本终端同时与一台机器和一个人进行对话。评判员不知道哪一端是机器、哪一端是人。如果评判员在多次测试后无法可靠地区分机器和人，则称该机器通过了图灵测试，即被认为具有智能。

2. 图灵测试在教材中的定位

教材在绪论开头引用了大卫·希尔伯特的名言“我们必须知道，我们必将知道”，随后引入人工智能的定义，将图灵测试作为衡量机器是否达到人类智能水平的一种标杆性概念。虽然教材在正文中没有用大篇幅展开图灵测试的详细操作流程，但它作为人工智能的起源性思想实验，与图灵机模型共同构成了图灵在“可计算”与“可智能”两个层面上的奠基性贡献。

3. 图灵测试与图灵机的关系

  • 图灵机回答的是 “什么可以被计算”（机械自动化计算的理论边界）。
  • 图灵测试回答的是 “什么可以被认为是智能”（机器行为与人类行为不可区分的评判标准）。

二者共同构成了图灵对人工智能学科的双重奠基：计算载体（图灵机）+ 智能判据（图灵测试）。

4. 图灵测试的后续影响与争议

图灵测试为后来的人机交互、对话系统和大语言模型（如ChatGPT/GPT系列）的评估提供了思想源头。教材在绪论中提到，即使当前以GPT为代表的大模型在某些任务上通过了表面意义上的图灵测试，它们仍然无法通过自身思考达到更高层次的智能，与具有自我学习、直觉推理和自适应能力的通用人工智能（AGI）仍存在明显差距。

知识点 1-4 人工智能五大主流算法与方法（含符号主义、连接主义和行为主义） 对应表格“符号主义、连接主义和行为主义”
📄 位置来源：第6-8页（1.3节“智能计算方法”），第22-28页

🧠 逻辑推理（符号主义）

核心思想：将概念符号化，从若干判断（前提）出发推得新判断（结论），强调演绎、归纳与因果推理。
代表技术：专家系统、谓词逻辑、知识图谱推理、三段论。

🔍 搜索求解

核心思想：依据已有信息在解空间中寻找满足约束条件的答案。
代表技术：贪婪最佳优先搜索、A*搜索、Minimax搜索、蒙特卡洛树搜索。

📊 机器学习（连接主义）

核心思想：从数据出发，学习数据中所蕴含的模式，利用学习到的模式对未知数据进行识别/分类。
代表技术：监督学习、无监督学习、深度学习（CNN/RNN等）。

🎯 强化学习（行为主义）

核心思想：智能体与环境交互，根据环境反馈的奖惩不断调整行动策略，完成序贯决策任务。
代表技术：Q学习、深度Q网络（DQN）、Actor-Critic算法。

⚔️ 博弈对抗（决策智能）

核心思想：多个带有相互竞争性质的主体，以“求取均衡解”为核心进行对抗，推动机器学习从“最优解”向“均衡解”迈进。
代表技术：纳什均衡、虚拟遗憾最小化（CFR）、多智能体博弈。

各方法之间的互补关系（教材原文强调）

  • 逻辑推理解释性强，但难以拓展；
  • 搜索方法能在已有答案中进行查找，但容易陷入机械式匹配；
  • 数据驱动模型善于预测识别，但其过程难以理解；
  • 强化学习能探索未知空间，但依赖策略学习；
  • 博弈对抗在完全信息条件下表现优良，但难以找到非完全信息条件下的通用框架。

教材明确指出：解决现实问题时，一般需要综合使用多种机器学习算法，例如AlphaGo就是深度学习 + 强化学习 + 蒙特卡洛树搜索的综合体。

国际AI发展重要历史节点（教材提及）

  • 13世纪末：拉蒙·柳利提出 “知识树”（tree of knowledge）——最早对知识进行规范化描述的努力。
  • 17世纪：莱布尼茨提出 “人类思想字母表”——认为对规范化表达的知识按规则组合，就可构造思想机器。
  • 1937年：图灵发表《论数字计算在决断难题中的应用》——提出图灵机模型，为现代计算机理论模型奠基。
  • 1950年：图灵提出 “图灵测试”——提出衡量机器智能的操作性标准。
  • 1955年：麦卡锡等四人撰写达特茅斯项目建议书——首次使用“Artificial Intelligence”术语。
  • 1956年夏天：达特茅斯会议召开——AI正式登台。
  • 1969年：明斯基与佩珀特出版《感知机》——指出单层感知机无法解决XOR问题，神经网络陷入低谷。
  • 1986年：鲁梅尔哈特与欣顿完善误差反向传播算法——神经网络复兴。
  • 1997年：IBM深蓝战胜国际象棋冠军卡斯帕罗夫——搜索+剪枝在完全信息博弈中的重大胜利。
  • 2006年：欣顿提出深度信念网络——首次使用“深度学习”术语。
  • 2016年：AlphaGo 4:1战胜李世石——深度学习+强化学习+蒙特卡洛树搜索的组合。
  • 2017年：Transformer模型发表——引入自注意力机制，成为大模型核心架构基础。
  • 2019年起：GPT系列大模型（GPT-3等）——参数从1.17亿跃升至1750亿。

中国AI发展重要事件（教材提及）

  • 2015年12月：中国工程院批准启动 “中国人工智能2.0发展战略研究” 重大咨询研究项目。
  • 2016年5月：项目组上报《建议我国启动“中国人工智能2.0”重大科技计划》报告。
  • 2017年7月：国务院印发 《新一代人工智能发展规划》——中国首份AI系统性战略规划，提出五大技术形态（大数据智能、跨媒体智能、群体智能、混合增强智能、自主智能系统）。
  • 2021年底：教育部启动 “101计划”（计算机领域本科教育教学改革试点）——《人工智能引论》为其12门核心课程之一。
  • 2023年：浙江大学联合高等教育出版社发布面向AI教育的大模型 “智海-三乐”（“三乐”出自《孟子》“得天下英才而教育之，三乐也”）。

教材对AI发展的总体判断（新一代AI的三大驱动力）

  • 信息环境巨变：世界从“物理世界-人类社会”（PH）二元空间，演变为 “信息空间-物理世界-人类社会”（CPH）三元空间结构。
  • 社会需求扩大：AI研究从学术牵引迅速转化为需求牵引（智能城市、智能医疗、智能交通等）。
  • 目标理念转变：AI从“造人制脑”走向“赋能社会”，从“用计算机模拟人的智能”拓展为 “机器+人”、“机器+人+网络”、“机器+人+网络+物”的更复杂智能系统。
