知识点 10-1 语言基础模型（大模型）的发展与建模 对应表格“语言大模型”
📄 位置来源：第289-295页（10.1.1-10.1.2节），第1-6页

1. NLP范式的三次转变

  • 早期：为每个任务分别设计模型（碎片化，重复劳动）。
  • 中期：预训练模型 + 微调（BERT、GPT等）。
  • 当前：预训练 + 提示学习 + 预测（不调整参数，设计提示激活模型知识）。

2. 语言大模型的建模

\[ P(w_1, w_2, \dots, w_T) = \prod_{i=1}^{T} P(w_i \mid w_1, w_2, \dots, w_{i-1}) \]

3. 三种预训练语言模型架构

  • 编码模型（Encoder-Only）：BERT、RoBERTa —— 掩码语言模型（MLM）—— 自然语言理解
  • 解码模型（Decoder-Only）：GPT-2、GPT-3 —— 自回归语言模型 —— 自然语言生成
  • 编码-解码模型：BART、T5 —— 序列到序列 —— 同时支持理解和生成

4. Transformer处理示例（“项庄舞剑、意在沛公”）

  • 步骤：内嵌向量 → Query/Key/Value → 关联度 → softmax归一化 → 自注意力输出
  • GPT-3架构：50,275个单词词向量 + 96个堆叠Transformer + 前馈神经网络
知识点 10-2 提示学习、指令微调与人类反馈强化学习（RLHF） 对应表格“语言大模型”
📄 位置来源：第295-300页（10.1.3节后半部分），第6-10页

1. 提示学习

  • 将各种NLP任务转化为语言模型预训练任务（完型填空或文字接龙）。
  • 缺点：依赖设计高质量提示；难以完成零样本学习。

2. 指令微调

  • 将NLP任务转化为生成式指令数据集，基于指令数据集微调模型参数。
  • 目标：让模型理解人类意图，对齐人类指令。

3. RLHF（基于人类反馈的强化学习）

  • 阶段一：训练奖励模型——收集问题，生成多个回答，人工排序（而非打分）。

\[ \text{loss}(\theta) = -\frac{1}{C_K^2} \mathbb{E}_{(x, y_w, y_l) \sim D} \left[ \log(\sigma(r_\theta(x, y_w) - r_\theta(x, y_l))) \right] \]

  • 阶段二：PPO算法优化——让SFT模型回答新问题，奖励模型打分，用PPO微调。

\[ \text{objective}(\phi) = \mathbb{E}_{(x,y) \sim D_{\text{RL}}} \left[ r_\theta(x,y) - \beta \log\left( \frac{\pi_\phi^{\text{RL}}(y|x)}{\pi^{\text{SFT}}(y|x)} \right) \right] + \gamma \mathbb{E}_{x \sim D_{\text{pretrain}}} [\log(\pi_\phi^{\text{RL}})] \]

知识点 10-3 自然语言中的机器翻译 对应表格“自然语言中的机器翻译”
📄 位置来源：第300-303页（10.2节全文），第11-13页

1. 非深度学习方法

  • 基于文法的机器翻译：利用语言学规则，解析→生成。优点：可控、规范；缺点：形成大规模文法规则困难。
  • 基于统计的机器翻译（SMT）：利用大规模双语语料库学习统计规律。训练→解码。

2. 深度学习方法——编码器-解码器模型

  • 编码器：将源语言每个单词编码为词向量+上下文，最后时刻的隐藏状态作为整体表示。
  • 解码器：将编码器的最终隐藏状态作为输入，逐步生成目标语言单词（\ → 逐词预测 → \）。
  • 训练：使用对齐的语料，交叉熵损失函数 + 误差反向传播。
知识点 10-4 图像分类与视觉对象定位 对应表格“视觉理解中的图像分类”
📄 位置来源：第303-305页（10.3节全文），第14-15页

1. 任务定义

  • 图像分类：将一幅图像识别归属为 $K$ 个类别中的某一个。
  • 视觉对象定位：识别关键物体，同时确定其位置（输出包围盒 bounding box）。

2. 基于CNN的解决方案

  • 卷积操作：提取特征（纹理、边缘、角点等），层层递进、逐层抽象。
  • 池化操作：最大池化或平均池化，对特征图进行约减。
  • 分类任务：softmax激活函数输出所有类别的概率分布。
  • 定位任务：参考Faster R-CNN（区域候选网络RPN + 感兴趣区域池化RoI Pooling），输出包围盒四维坐标。
知识点 10-5 机器人中的行为控制 对应表格“机器人中的行为控制”
📄 位置来源：第313-316页（10.7节全文），第19-22页

1. 机器人完成任务的基本流程

  • 感知（Perception）：多源传感器获取信息（相机、激光雷达、IMU、GPS等）。
  • 状态估计（State Estimation）：计算机视觉算法感知环境。
  • 规划（Planning）：生成路径和轨迹（RRT、非线性最优控制等）。
  • 控制（Control）：低阶控制器执行动作。

2. 机器人操作任务

  • 示例：机械臂物体抓取 → 感知图像 → 状态估计（6自由度姿态） → 坐标转换 → 抓取动作规划。

3. 机器人导航任务

  • 传统方法：感知 → 建图 → 路径规划 → 轨迹执行。
  • 强化学习方法：将建图到规划部分用神经网络替代，端到端学习策略。
知识点 10-6 科学计算——物理约束下的神经网络（PINN） 对应表格“科学计算”
📄 位置来源：第309-311页（10.5节全文），第17-19页

1. 科学智能（AI4Science）

  • 将深度学习模型作为科学计算的模拟器，用数学物理方程约束训练结果。
  • 特点：数据来源于采样与模拟（额外标注需求少）；计算速度相比传统数值方法提升数个数量级。

2. PINN（物理约束下的神经网络）

  • 提出者：Raissi等，2017。
  • 用神经网络拟合微分方程的解函数 $u(t, x; \theta)$，以数据与物理驱动方式求解非线性偏微分方程。

3. PINN的约束与损失函数

  • 微分方程约束（PDE）：$\mathcal{N}(t, x; \hat{u}(t, x; \theta)) = 0$
  • 初始条件（IC）：$\mathcal{I}(x; \hat{u}(0, x; \theta)) = 0$
  • 边界条件（BC）：$\mathcal{B}(t, x; \hat{u}(t, x; \theta)) = 0$

\[ \mathcal{L}(\theta) = w_{\text{PDE}} \mathcal{L}_{\text{PDE}} + w_{\text{IC}} \mathcal{L}_{\text{IC}} + w_{\text{BC}} \mathcal{L}_{\text{BC}} + w_{\text{Data}} \mathcal{L}_{\text{Data}} \]

4. 引入专业知识的其他方法

  • 图神经网络（GNN）用于分子：原子→结点，化学键→边，用于分子性质预测、分子设计。
  • 自监督训练：如AlphaFold中的多序列比对掩码恢复。
  • 应用领域：物理仿真、化学合成、蛋白质结构预测（AlphaFold）、药物虚拟筛选、新材料合成、天气预测。
