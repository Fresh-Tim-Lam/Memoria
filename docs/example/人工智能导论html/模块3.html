知识点 3-1 搜索基本概念与性能评价指标 对应表格“搜索算法的性能分析”
📄 位置来源：第61-64页（3.1节全文），第81-84页

1. 搜索的基本术语

  • 状态（state）：对搜索算法和搜索环境当前所处情形的描述信息。
  • 初始状态：算法刚开始所在状态。
  • 终止状态（目标状态）：完成任务时所在状态。
  • 动作（action）：算法从一个状态转移到另一个状态所采取的行为。
  • 路径（path）：执行一系列动作后得到的状态序列。
  • 代价（cost）：一条路径对应的开销（如时间、距离等）。
  • 目标测试（goal test）：判断状态s是否为目标状态。

2. 搜索树的概念

搜索树：用一棵树来记录算法所探索的路径。每个结点用一个状态标记。
⚠️ 重要区别：同一个状态标号可能在搜索树中出现多次，但它们属于不同结点，因为从根结点到达它们所经过的路径不同。

3. 搜索算法的四大评价指标

  • 完备性（Completeness）：当问题存在解时，算法是否能保证找到一个解。
  • 最优性（Optimality）：搜索算法是否能保证找到的第一个解是最优解。
  • 时间复杂度（Time Complexity）：找到一条搜索路径所需的时间。
  • 空间复杂度（Space Complexity）：算法运行时所需的内存空间。

4. 复杂度分析的典型变量（表3.1）

  • \(b\)：分支因子，搜索树中每个结点的最大分支数目。
  • \(d\)：根结点到最浅目标结点的路径长度。
  • \(m\)：搜索树中路径的最大可能长度。
  • \(n\)：状态空间中的状态数量。

5. 环路问题与剪枝

如果不剪枝，算法可能陷入无限循环（如 A→B→A→B→…）。
解决方法：对可能产生环路的结点进行剪枝。排除环路对算法找到最优解不产生负面影响，因为任意包含环路的路径都可以用一条不含环路且代价更小或相等的路径代替。

知识点 3-2 贪婪最佳优先搜索（Greedy Best-First Search） 对应表格“贪婪最佳优先搜索”
📄 位置来源：第65-67页（3.2节全文），第85-87页

1. 启发式搜索与无信息搜索的区别

  • 无信息搜索：不利用额外信息（如BFS、DFS）。
  • 有信息搜索（启发式搜索）：利用能够辅助算法做出决策的额外信息（启发信息）。

2. 启发函数与评价函数

  • 启发函数 \(h(n)\)：估计从结点 \(n\) 到目标结点还须付出多少代价。
  • 评价函数 \(f(n)\)：决定搜索算法在边缘结点集合中下一步选择哪个结点。
  • 贪婪最佳优先搜索的定义：\(f(n) = h(n)\)，每次总是“贪婪地”选择离目标结点代价最小的结点进行扩展。

3. 教材示例（图3.4）

  • 从A出发，扩展得到B(10)、D(12)、E(7) → 选E
  • 扩展E，得到H(3)、G(5)、I(6) → 选H
  • 扩展H，得到J(3)、F(8) → 选J
  • 找到路径：A→E→H→J→K（代价为17）

4. 性能分析

  • 完备性：采用排除环路的剪枝方法时，是完备的。
  • 最优性：不是最优的（找到的路径不是最短路径）。
  • 时间复杂度：最坏 \(O(b^m)\)
  • 空间复杂度：最坏 \(O(b^m)\)
⚠️ 关键结论：该路径不是最短路径。实际上最短路径为 A→E→G→K（代价14）。贪婪最佳优先搜索由于只关注到目标的估计距离，忽视了从起点到当前结点的实际代价。
知识点 3-3 A*搜索算法 对应表格“启发式搜索A*搜索”
📄 位置来源：第67-71页（3.3节全文），第87-91页

1. A*算法的核心思想

  • 评价函数定义：\(f(n) = g(n) + h(n)\)
  • \(g(n)\)：从起始结点到结点 \(n\) 的实际路径代价
  • \(h(n)\)：从结点 \(n\) 到目标结点的估计代价（启发函数）

2. 教材示例（图3.5）

  • 贪婪最佳优先搜索选择扩展J（h(J)=3最小）
  • A*算法选择扩展G（f(G)=4+5=9，小于f(J)=14+3=17）
  • 找到最短路径：A→E→G→K（代价14）

3. 可容性（Admissible）

对任意结点 \(n\)，有 \(h(n) \le h^*(n)\)。即启发函数不会过高估计从n到目标的代价。

4. 一致性（Consistency，也称单调性）

\(h(n) \le c(n, a, n') + h(n')\)，即三角不等式。
重要结论：一致性 ⇒ 可容性。

5. A*算法的最优性

定理：如果启发函数是可容的，则A*算法满足最优性。
完备性条件：①分支数量有限；②单步代价有正下界；③启发函数有下界。

知识点 3-4 最小最大搜索（Minimax Search） 对应表格“Minimax搜索”
📄 位置来源：第71-74页（3.4节全文），第92-95页

1. 对抗搜索的适用场景

  • 信息确定、全局可观察、竞争对手轮流行动、零和（zero-sum）假设下的二人博弈。
  • 零和博弈：一方获得收益必然意味着另一方遭受损失。

2. 核心术语

  • 玩家MAX：以最大化得分为目标的玩家。
  • 玩家MIN：以最小化得分为目标的玩家。
  • 终局得分 \(utility(s)\)：终局状态s下MAX的得分。

3. Minimax递归定义

Minimax(s) =
  • utility(s)，若 terminal_test(s) 为真
  • max{Minimax(result(s,a))}，若 player(s)=MAX
  • min{Minimax(result(s,a))}，若 player(s)=MIN

4. 性能分析

  • 完备性：搜索树有限时，必然在有限时间内终止。
  • 最优性：对手理性时，得到的解是最优的。
  • 时间复杂度：\(O(b^m)\)
  • 空间复杂度：\(O(bm)\)
知识点 3-5 Alpha-Beta剪枝搜索 对应表格“Alpha-Beta剪枝搜索”
📄 位置来源：第75-80页（3.5节全文），第96-101页

1. 核心思想

在保证与Minimax得到同样搜索结果的前提下，剪去不影响最终结果的分支。

2. α值（Alpha）和β值（Beta）

  • α：MAX结点当前已知的最好下界（MAX至少能获得的分值）
  • β：MIN结点当前已知的最好上界（MIN至多能允许的分值）

3. 剪枝的两种情况

  • α剪枝：MIN结点值 ≤ 祖先MAX结点的α值 → 剪枝
  • β剪枝：MAX结点值 ≥ 祖先MIN结点的β值 → 剪枝

4. 性能分析

  • 最优情况：时间复杂度可降至 \(O(b^{m/2})\)
  • 最坏情况：剪枝效果为零，复杂度仍为 \(O(b^m)\)
知识点 3-6 蒙特卡洛树搜索（MCTS） 对应表格“蒙特卡洛树搜索”
📄 位置来源：第80-91页（3.6节全文），第102-113页

1. 探索与利用的困境（多臂赌博机问题）

  • 利用（Exploitation）：选择当前收益最高的摇臂
  • 探索（Exploration）：尝试其他摇臂以获得更准确的估计

2. UCB1算法

\[ l_t = \arg\max_i \left( \bar{x}_{i, T(i,t-1)} + C \sqrt{\frac{2\ln t}{T(i,t-1)}} \right) \]

3. MCTS的四步循环

  1. 选择（Selection）：从根结点开始，使用UCB1策略向下递归选择子结点。
  2. 扩展（Expansion）：如果当前结点不是终止结点，随机扩展一个未被扩展过的后继结点。
  3. 模拟（Simulation）：从新结点出发，使用简单策略（如随机策略）模拟后续博弈直到终局。
  4. 反向传播（Backpropagation）：用模拟结果更新路径上所有结点的统计信息（总奖励和访问次数）。

4. UCT公式

\[ \text{UCB}(v') = \frac{Q(v')}{N(v')} + C \sqrt{\frac{2\ln N(v)}{N(v')}} \]

5. MCTS的主要优势

  • 不依赖穷尽式枚举，基于采样决定搜索树的扩展方式。
  • 既能保证搜索效率，又能通过蒙特卡洛模拟准确评估每个分支的优劣。
  • 特别适用于搜索空间极大（如围棋）的场景。
⚠️ 反向传播特殊规则：在对抗搜索中，MIN层结点的总分要减去终局得分（因为MIN选择最小化得分的动作）；MAX层结点加上终局得分。
