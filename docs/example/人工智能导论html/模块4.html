知识点 4-1 机器学习基本概念与模型评估 对应表格“模型评估与参数估计”
📄 位置来源：第99-100页（4.1节全文），第6-7页

1. 机器学习的定义

  • 术语诞生：1959年，IBM工程师阿瑟·塞缪尔（Arthur Samuel）首次使用“机器学习”。
  • 塞缪尔定义：让机器具有不需要明确编程而具有的一种学习能力。
  • 米切尔定义：对于一项任务和一种对学习效果的评估方法，如果算法能通过从经验中学习来提升完成该任务的性能，则该算法被认为可以从经验中学习。

2. 监督学习、无监督学习与半监督学习

  • 监督学习：训练数据包含标注信息 \(\{(x_i, y_i)\}\)。代表方法：分类、回归。
  • 无监督学习：训练数据无标注 \(\{x_i\}\)。代表方法：聚类、降维。
  • 半监督学习：部分数据有标注，部分数据无标注。

3. 训练集、验证集与测试集

  • 训练集：用于训练模型参数（好比学生的练习册）。
  • 验证集：用于评估模型、调整超参数（好比模拟考）。
  • 测试集：用于最终评估模型性能（好比正式考试）。
  • ⚠️ 三者互不交叉，保证测试结果的客观性。

4. 没有免费午餐定理（No Free Lunch Theorem）

  • 提出者：戴维·沃尔珀特（David Wolpert）等，1995年。
  • 核心结论：任何一个机器学习模型如果在一些训练集以外的样本上误差小，那么必然在另外一些训练集以外的样本上表现欠佳。任何模型在平均意义上性能都是一样的。
  • 启示：离开具体场景和问题去讨论哪种算法更好是毫无意义的。应当在模型中引入先验假设（如在图像中使用卷积算子、在文本中使用n-gram文法）。
知识点 4-2 经验风险、期望风险与正则化 对应表格“模型评估与参数估计”
📄 位置来源：第100-101页（4.2.1节全文），第8-9页

1. 损失函数（表4.1）

  • 0-1损失函数：预测错误为1，正确为0
  • 平方损失函数：\((y_i - f(x_i))^2\)
  • 绝对损失函数：\(|y_i - f(x_i)|\)
  • 对数损失函数（对数似然）：\(-\log P(y_i|x_i)\)

2. 经验风险（Empirical Risk）

\[ \Re_{\text{emp}} = \frac{1}{n} \sum_{i=1}^{n} \text{Loss}(y_i, f(x_i)) \]

3. 期望风险（Expected Risk）

\[ \Re = \int_{x \times y} \text{Loss}(y, f(x)) \cdot P(x, y) \, dx \, dy \]

4. 过拟合与欠拟合

  • 过拟合（Overfitting）：模型过于复杂，经验风险很小但期望风险很大。
  • 欠拟合（Underfitting）：模型过于简单，经验风险和期望风险都大。

5. 结构风险最小化（SRM）与正则化

\[ \frac{1}{n} \sum_{i=1}^{n} \text{Loss}(y_i, f(x_i)) + \lambda J(f) \]

  • 哲学基础：奥卡姆剃刀定律（Occam's Razor）——“如无必要，勿增实体”。
知识点 4-3 模型性能度量方法 对应表格“模型评估与参数估计”
📄 位置来源：第101-102页（4.2.2节全文），第9-10页

1. 混淆矩阵（二分类）

  • TP（真正例）：预测为正例，实际为正例
  • FP（假正例）：预测为正例，实际为负例
  • FN（假反例）：预测为负例，实际为正例
  • TN（真反例）：预测为负例，实际为负例

2. 核心评价指标

  • 准确率（Accuracy）：\(\text{ACC} = \frac{TP + TN}{P + N}\)
  • 精确率（Precision）：\(\text{Precision} = \frac{TP}{TP + FP}\)（查准率）
  • 召回率（Recall）：\(\text{Recall} = \frac{TP}{TP + FN}\)（查全率）

3. F1-score

\[ \text{F1-score} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} \]

  • F1-score是精确率和召回率的调和平均数。
知识点 4-4 频率学派与贝叶斯学派参数估计 对应表格“模型评估与参数估计”
📄 位置来源：第102-104页（4.2.3节及知识卡片），第10-12页

1. 两大统计学派的核心区别

  • 频率学派（Frequentist）：概率是事件发生频率的极限值 → 最大似然估计（MLE）
  • 贝叶斯学派（Bayesian）：参数本身是随机变量 → 最大后验估计（MAP）

2. 最大似然估计（MLE）

\[ \hat{\Theta} = \arg\max_{\Theta} P(D|\Theta) \]

3. 最大后验估计（MAP）

\[ \hat{\Theta} = \arg\max_{\Theta} P(\Theta|D) = \arg\max_{\Theta} P(D|\Theta) \cdot P(\Theta) \]

  • \(P(\Theta)\)：先验概率
  • \(P(D|\Theta)\)：似然概率
  • \(P(\Theta|D)\)：后验概率

4. 形象比喻（教材原文）

  • 频率学派：“以史为鉴，可以知兴替”
  • 贝叶斯学派：“天行有常（先验概率），不为尧存，不为桀亡”
知识点 4-5 线性回归模型 对应表格“线性回归模型”
📄 位置来源：第104-108页（4.3节全文），第12-16页

1. 回归分析的起源

  • “回归”术语：由高尔顿（Galton）于1886年提出。
  • 最小二乘法：勒让德（Legendre，1806）和高斯（Gauss，1809）最早提出。

2. 一元线性回归

\[ L(a, b) = \sum_{i=1}^{n} (y_i - ax_i - b)^2 \]

  • \(a = \frac{\sum x_i y_i - n\bar{x}\bar{y}}{\sum x_i^2 - n\bar{x}^2}\)，\(b = \bar{y} - a\bar{x}\)

3. 多元线性回归

\[ f(x_i) = a_0 + \sum_{j=1}^{D} a_j x_{i,j} \]

闭式解：\(a = (XX^T)^{-1} X y\)

4. 逻辑斯谛回归

\[ y = \frac{1}{1 + e^{-(w^T x + b)}}, \quad y \in (0, 1) \]

  • 推广到多分类：softmax回归。
知识点 4-6 K均值（K-Means）聚类算法 对应表格“聚类”
📄 位置来源：第112-115页（4.5节全文），第19-23页

1. 目标函数

\[ \arg\min_{G} \sum_{i=1}^{K} \sum_{x \in G_i} \|x - c_i\|^2 \]

2. 算法流程

  1. 初始化聚类质心：随机选择 \(K\) 个数据点作为初始质心。
  2. 对数据进行聚类：将每个数据点分配到距离最近的质心所在的簇。
  3. 更新聚类质心：\(c_j = \frac{1}{|G_j|} \sum_{x \in G_j} x\)
  4. 迭代：重复步骤2和3，直到质心不再变化。

3. 局限性

  • 对离群点（outlier）敏感
  • 需要预先指定聚簇数目 \(K\)
  • 对数据坐标空间/尺度敏感
  • 属于硬聚类（hard clustering）
知识点 4-7 线性判别分析（LDA）——有监督降维 对应表格“有监督降维”
📄 位置来源：第115-119页（4.6节全文），第23-27页

1. 核心思想

  • 利用数据的类别标签（有监督），将高维数据线性投影到低维空间。
  • 投影原则：“类内汇聚、类间间隔”——同一类别的样本尽可能靠近，不同类别的样本尽可能远离。

2. Fisher准则（二分类）

\[ J(w) = \frac{w^T S_b w}{w^T S_w w} \]

  • 类间散度 \(S_b\)：\((m_2 - m_1)(m_2 - m_1)^T\)
  • 类内散度 \(S_w\)：\(\Sigma_1 + \Sigma_2\)

3. Fisher线性判别

\[ w = S_w^{-1} (m_2 - m_1) \]

4. 多分类LDA

  • 投影矩阵由 \(S_w^{-1} S_b\) 的前 \(r\) 个最大特征值对应的特征向量构成。
  • \(r \le \min(K-1, d)\)
知识点 4-8 主成分分析（PCA）——无监督降维 对应表格“无监督降维”
📄 位置来源：第119-123页（4.7.1-4.7.2节），第27-31页

1. 核心思想

  • 将 \(d\) 维特征数据映射到 \(l\) 维空间（\(d \gg l\)），最大限度保持原始高维数据的总体方差结构。
  • 哲学基础：奥卡姆剃刀原则——“如无必要，勿增实体”。

2. 协方差矩阵

\[ \Sigma = \frac{1}{n-1} X^T X \]

3. PCA的数学推导

\[ \Sigma w_i = \lambda_i w_i \]

  • \(w_i\) 是协方差矩阵的特征向量，\(\lambda_i\) 是对应特征值。

4. SVD实现PCA

  • 当特征维度 \(d\) 很大时，用奇异值分解（SVD） 高效实现。
  • 右奇异矩阵 \(V\) 的列向量即为协方差矩阵的特征向量。
知识点 4-9 特征人脸法（Eigenface） 对应表格“无监督降维”
📄 位置来源：第123-126页（4.7.3节全文），第31-34页

1. 核心思想

  • 将PCA应用于人脸图像数据集，用一组特征向量（特征人脸）的线性组合来表示原始人脸。
  • 提出者：Sirovich和Kirby（1987），Turk和Pentland（1991）用于人脸识别。

2. 构建步骤

  1. 计算均值人脸：\(\Psi = \frac{1}{n} \sum_{i=1}^{n} \Gamma_i\)
  2. 中心化：\(\phi_i = \Gamma_i - \Psi\)
  3. 构造矩阵 \(\Phi = [\phi_1, \phi_2, \dots, \phi_n]\)
  4. 用SVD加速求特征人脸：\(\Phi^T u_i\) 即为特征人脸

3. 投影与识别

  • 将人脸投影到特征人脸空间：\(\Omega_i = U^T \phi_i\)
  • 比较 \(\Omega_i\) 和 \(\Omega_j\) 的相似度完成识别。

4. 局限性

  • 特征人脸表达的是全局信息，无法凸显局部特征。
  • 非负矩阵分解（NMF） 可以提取局部信息（“部分组成整体”）。
