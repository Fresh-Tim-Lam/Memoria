知识点 5-1 从MCP到感知机 对应表格“感知器模型”
📄 位置来源：第139-143页（5.1节及5.2.1-5.2.2节），第1-3页

1. 神经网络的历史奠基

  • 赫布理论（Hebbian Theory, 1949）：心理学家唐纳德·赫布提出“Neurons that fire together, wire together”——神经元之间持续、重复的经验刺激可导致突触传递效能增加。
  • MCP模型（1943）：神经科学家麦卡洛克（McCulloch）和逻辑学家皮茨（Pitts）提出，是最早的神经网络雏形。
    缺点：连接权重和阈值需手工设置，无法从数据中学习。
  • 方向选择性细胞（1959）：胡贝尔（Hubel）和维泽尔（Wiesel）发现视觉系统信息分层处理机制，获1981年诺贝尔生理学或医学奖。

2. 感知机模型（Perceptron, 1957）

  • 提出者：弗朗克·罗森布拉特（Frank Rosenblatt）
  • 计算公式：\(y = \Phi(\sum_{i=1}^{n} w_i x_i + b)\)
  • 特点：输入\(x_i\)为实数值，权重\(w_i\)可从数据中学习。

3. XOR问题（1969）

  • 明斯基（Minsky）和佩珀特（Papert）出版《感知机：计算几何学》，指出单层感知机只能解决线性可分问题，无法解决XOR（异或）问题。
  • 这一论断导致神经网络研究陷入低谷。

4. 多层感知机（MLP）/ 前馈神经网络

  • 在输入层和输出层之间加入多个隐藏层，引入非线性激活函数（如sigmoid、tanh、ReLU），增强表达能力。
  • 关键：隐藏层中的非线性激活函数，使得MLP能够拟合任意复杂函数（包括XOR）。
知识点 5-2 神经网络参数优化——梯度下降与误差反向传播 对应表格“反向传播算法”
📄 位置来源：第147-154页（5.3节全文），第7-14页

1. 损失函数

  • 均方误差（MSE）：\(\text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2\)
  • 交叉熵损失（Cross Entropy）：\(H(y, \hat{y}) = -y \times \log \hat{y}\)

2. 梯度下降法

  • 核心思想：损失函数梯度的反方向是损失误差下降最快的方向。
  • 参数更新：\(\theta^{\text{new}} = \theta - \eta \times \nabla_\theta \mathcal{L}(\theta)\)
  • 三种变体：批量梯度下降（BGD）、随机梯度下降（SGD）、小批量梯度下降（Mini-batch GD）

3. 误差反向传播（链式法则）

\[ \frac{\partial \mathcal{L}}{\partial w_1} = \frac{\partial \mathcal{L}}{\partial O} \cdot \frac{\partial O}{\partial x} \cdot \frac{\partial x}{\partial w_1} \]

  • 提出者：Werbos（1974），由Rumelhart和Hinton（1986）完善。
知识点 5-3 卷积神经网络（CNN）基础 对应表格“卷积神经网络”
📄 位置来源：第154-160页（5.4节全文），第14-20页

1. 生物学基础

  • 视觉系统信息分层处理：胡贝尔和维泽尔（1959）。
  • Neocognitron（1980）：福岛邦彦提出，是CNN的前身。
  • LeNet-5：LeCun等人（1998）设计用于手写体识别，确立了CNN基本结构。

2. 卷积操作

  • 卷积核（Kernel）：一个二维权重矩阵，通过数据驱动学习得到。
  • 三个关键特点：局部感知、参数共享、下采样。
  • 输出分辨率公式：\(\frac{w - F + 2P}{S} + 1\)

3. 池化操作

  • 最大池化（Max Pooling）：从区域子块中取最大值。
  • 平均池化（Average Pooling）：从区域子块中取平均值。
  • 全局平均池化（GAP）：用于替代全连接层，大幅减少参数量。

4. 全连接层的作用

  • 卷积操作捕获局部特征（“不识庐山真面目，只缘身在此山中”）。
  • 全连接层组合局部特征，挖掘全局特征（“不畏浮云遮望眼，自缘身在最高层”）。
  • 全连接层参数约占整个网络参数的 \(80\% \sim 90\%\)。
知识点 5-4 循环神经网络（RNN）基础 对应表格“循环神经网络”
📄 位置来源：第160-164页（5.5.1节全文），第20-23页

1. RNN的核心公式

\[ h_t = \Phi(W_x x_t + W_h h_{t-1} + b) \]

  • 提出者：杰弗里·埃尔曼（Jeffrey L. Elman）于1990年提出。
  • 核心思想：模拟人的记忆能力，利用历史信息影响后续输出。

2. RNN的三种模式

  • 多对多：输入多个单元，输出多个单元（如机器翻译）
  • 多对一：输入多个单元，输出一个单元（如情感分类）
  • 一对多：输入一个单元，输出多个单元（如图像描述生成）

3. 梯度消失与梯度爆炸

  • 根本原因：\(\frac{\partial h_t}{\partial h_{t-1}} = W_h \cdot \Phi'(h_{t-1})\)
  • 解决方案：引入门控机制（LSTM、GRU）。
知识点 5-5 长短时记忆网络（LSTM） 对应表格“循环神经网络”
📄 位置来源：第164-166页（5.5.2节全文），第24-26页

1. LSTM的三大门控

  • 遗忘门 \(f_t\)：控制上一时刻记忆单元 \(c_{t-1}\) 中有多少信息被遗忘
  • 输入门 \(i_t\)：控制当前时刻有多少新信息流入内部记忆单元
  • 输出门 \(o_t\)：控制内部记忆单元有多少信息输出到隐式编码

2. LSTM的信息更新

  • 候选记忆：\(\tilde{c}_t = \tanh(W_{xc} x_t + W_{hc} h_{t-1} + b_c)\)
  • 记忆更新：\(c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t\)
  • 隐式编码：\(h_t = o_t \odot \tanh(c_t)\)

3. 如何解决梯度消失

  • \(\frac{\partial c_t}{\partial c_{t-1}} = f_t\)（至少存在直接路径）
  • 如果遗忘门 \(f_t\) 接近1，梯度可无衰减地沿时间反向传播。
  • 比喻：内部记忆单元 \(c_t\) 好比长时记忆，隐式编码 \(h_t\) 好比短时记忆。
知识点 5-6 门控循环单元（GRU） 对应表格“循环神经网络”
📄 位置来源：第167页（5.5.3节全文），第26页

1. GRU的简化

  • 提出者：Cho等人，2014年。
  • 将LSTM的三个门简化为两个门（更新门和重置门）。
  • 不再使用独立的内部记忆单元，仅用隐式编码传递信息，计算速度更快。

2. GRU的两个门控

  • 更新门 \(z_t\)：控制前一时刻状态信息被保留到当前状态的程度
  • 重置门 \(r_t\)：控制忽略前一时刻状态信息的程度

3. GRU的信息更新

  • 候选隐式编码：\(\tilde{h}_t = \tanh(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)\)
  • 隐式编码更新：\(h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t\)
知识点 5-7 注意力机制与Transformer 对应表格“注意力机制”
📄 位置来源：第168-169页（5.6节全文），第27-28页

1. 自注意力（Self-Attention）的计算

  • 提出者：Vaswani等人（Google），2017年。
  • \(q_i = W^q w_i\)，\(k_i = W^k w_i\)，\(v_i = W^v w_i\)
  • 关联度：\(\alpha_{ij} = q_i \cdot k_j\)
  • 归一化：\(\alpha'_{ij} = \text{softmax}(\alpha_{ij})\)
  • 自注意力输出：\(\sum_j \alpha'_{ij} \times v_j\)

2. 多头注意力（Multi-Head Attention）

  • 使用多组不同的 \(W^q, W^k, W^v\) 映射矩阵，从多个角度挖掘单词之间的概率关联。

3. Transformer的架构

  • 自注意力 + 前馈神经网络非线性映射
  • 并行计算优势：不像RNN需要逐个时间步处理，极大提高了训练效率。
知识点 5-8 神经网络正则化技术 对应表格“网络优化与正则化”
📄 位置来源：第169-171页（5.7节全文），第29-30页

1. Dropout

  • 在每次迭代中，以一定概率随机屏蔽部分神经元，防止过拟合。

2. 批归一化（Batch Normalization）

  • 将每层输入值分布改为均值为0、方差为1的标准正态分布。
  • 作用：克服梯度消失，加快收敛速度。

3. L1正则化与L2正则化

\[ \min \frac{1}{n} \sum_{i=1}^{n} \text{Loss}(y_i, f(W, x_i)) + \lambda \times \Phi(W) \]

  • L1范数：\(\|W\|_1 = \sum_i |w_i|\) —— 稀疏规则算子（Lasso）
  • L2范数：\(\|W\|_2 = \sqrt{\sum_i w_i^2}\) —— 权重衰减
知识点 5-9 网络结构搜索（NAS） 对应表格“网络结构搜索”
📄 位置来源：第140页、第171页、第176-177页（散见于5.1节、5.8节及延伸阅读）
📌 说明：教材正文中没有设置独立的“网络结构搜索（NAS）”专节。该知识点以散见形式分布于教材多处（第5章开篇、5.8节案例、延伸阅读）。本整理基于教材内容，将架构设计从手工到自动的演变脉络进行系统化梳理。

1. 手工设计架构的演进

  • LeNet-5（LeCun等，1998）：确立了CNN基本结构（卷积→池化→全连接）。
  • AlexNet（Krizhevsky等，2012）：5个卷积层+3个全连接层，6000万参数。
  • ResNet / GoogLeNet：使用全局平均池化（GAP）替代全连接层，大幅减少参数量。

2. NAS的核心问题

  • 搜索空间：定义可能的网络结构集合（层数、层类型、超参数等）。
  • 搜索策略：如何高效寻找最优结构（强化学习、演化算法、基于梯度的方法）。
  • 性能评估：快速评估候选结构的性能。

3. 教材对“大模型”的反思

  • 深度学习模型正变得越来越大、越来越复杂（GPT-3达1750亿参数）。
  • 教材引用《大模型的安魂曲》，列举大模型的“七宗罪”。
  • 感叹：复杂深度模型虽取得惊人效果，但对模型“知其所以然”的理解却举步维艰——“无他，但手熟尔”。
