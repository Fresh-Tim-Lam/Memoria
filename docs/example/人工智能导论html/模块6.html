知识点 6-1 强化学习基本概念与马尔可夫决策过程（MDP） 对应表格“马尔科夫决策过程”
📄 位置来源：第183-189页（6.1节全文），第1-6页

1. 强化学习的核心思想

  • 智能体通过“尝试与试错”和“探索与利用”，在与环境交互中学习。
  • 学习信号以奖励（reward）形式出现，追求最大化累积收益。
  • 形象比喻：tabularasa（拉丁语：白板）——“一张白纸绘蓝图”。

2. 强化学习的核心概念

  • 智能体（Agent）：强化学习算法的主体
  • 环境（Environment）：智能体以外的一切
  • 状态（State）：智能体对环境的一种理解和编码
  • 动作（Action）：智能体对环境产生影响的方式
  • 策略（Policy）：$\pi(s, a)$ 表示在状态 $s$ 下采取动作 $a$ 的概率
  • 奖励（Reward）：智能体从环境获得的收益（正值=奖励，负值=惩罚）

3. 马尔可夫决策过程（MDP）

  • 马尔可夫性：\(P(S_{t+1} \mid S_t, S_{t-1}, \dots) = P(S_{t+1} \mid S_t)\)
  • MDP的形式化定义：$\text{MDP} = (S, A, P, R, \gamma)$

4. 回报（Return）与折扣因子

\[ G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \]

  • $\gamma \in [0, 1]$：折扣因子，距离当前时刻越远的奖励贡献越小。
知识点 6-2 贝尔曼方程与策略评估 对应表格“贝尔曼方程”
📄 位置来源：第190-192页（6.1.4节），第7-9页

1. 价值函数与动作-价值函数

  • 价值函数：$V_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$
  • 动作-价值函数：$q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$

2. 价值函数的贝尔曼方程

\[ V_\pi(s) = \sum_{a \in A} \pi(s, a) \sum_{s' \in S} P(s' \mid s, a) \big( R(s, a, s') + \gamma V_\pi(s') \big) \]

3. 动作-价值函数的贝尔曼方程

\[ q_\pi(s, a) = \sum_{s' \in S} P(s' \mid s, a) \left[ R(s, a, s') + \gamma \sum_{a' \in A} \pi(s', a') q_\pi(s', a') \right] \]

4. 贝尔曼方程的意义

  • 描述了价值函数/动作-价值函数的递推关系
  • 将序贯决策问题转化为一系列互相联系的子问题
知识点 6-3 策略迭代与价值迭代 对应表格“基于表格求解法的策略学习”
📄 位置来源：第192-200页（6.2.1-6.2.4节前半部分），第10-18页

1. 通用策略迭代（GPI）框架

  • 策略评估：计算当前策略下的价值函数
  • 策略优化：$\pi'(s) = \arg\max_a q_\pi(s, a)$

2. 策略评估的三种方法

  • 动态规划（DP）：利用贝尔曼方程迭代求解，需知道状态转移概率
  • 蒙特卡洛（MC）：从采样轨迹中估计价值（样本均值→期望）
  • 时序差分（TD）：$V_\pi(s) \leftarrow V_\pi(s) + \alpha [R + \gamma V_\pi(s') - V_\pi(s)]$

3. 价值迭代

\[ V(s) \leftarrow \max_a \sum_{s'} P(s' \mid s, a) [R(s, a, s') + \gamma V(s')] \]

知识点 6-4 Q学习与表格求解 对应表格“基于表格求解法的策略学习”
📄 位置来源：第200-204页（6.2.4节后半部分），第18-20页

1. Q学习核心公式

\[ q_\pi(s, a) \leftarrow q_\pi(s, a) + \alpha [R + \gamma \max_{a'} q_\pi(s', a') - q_\pi(s, a)] \]

  • 核心思想：$q_\pi(s, a)$ 的估计值 = $R + \gamma \times \max_{a'} q_\pi(s', a')$
  • $Q$ 的命名：Watkins借用“质量”（Quality）的首字母。

2. Q学习算法流程

  • 初始化所有 $q_\pi(s, a)$
  • 选择动作 $a = \arg\max_{a'} q_\pi(s, a')$（当前最优）
  • 执行动作，观察奖励 $R$ 和下一状态 $s'$
  • 更新 $q_\pi(s, a)$，$s \leftarrow s'$
  • 最终策略：$\pi(s) = \arg\max_a q(s, a)$

知识点 6-5 探索与利用——ε-贪心策略 对应表格“探索与利用的平衡”
📄 位置来源：第204-206页（6.2.5节全文），第20-21页

1. ε-贪心策略

\[ \pi(s) = \begin{cases} \arg\max_a q(s, a), & \text{以概率 } 1-\epsilon \\ \text{随机选择 } a \in A, & \text{以概率 } \epsilon \end{cases} \]

2. 离策略（Off-Policy）与在策略（On-Policy）

  • 离策略：采样时策略和更新时策略不同。Q学习是离策略算法。
  • 在策略：采样时策略和更新时策略相同。Q学习对应的在策略版本是 Sarsa算法。
知识点 6-6 深度强化学习与DQN 对应表格“基于近似求解法的策略学习”
📄 位置来源：第206-210页（6.2.6节全文），第4-8页

1. 参数化Q学习

  • $q_\pi(s, a; \theta)$：用深度神经网络拟合动作-价值函数。
  • 损失函数：$L(\theta) = \frac{1}{2} [R + \gamma \max_{a'} q_\pi(s', a'; \theta) - q_\pi(s, a; \theta)]^2$

2. DQN的两个关键技术

  • 经验重现（Experience Replay）：将经验存入经验池，随机采样训练，减弱样本相关性。
  • 目标网络（Target Network）：用另一组参数 $\theta^-$ 计算目标值，保持稳定。
知识点 6-7 基于策略的强化学习——策略梯度法 对应表格“基于近似求解法的策略学习”
📄 位置来源：第210-212页（6.3.1-6.3.2节），第8-11页

1. 策略梯度定理

\[ \nabla_\theta J(\theta) \propto \sum_s \mu_{\pi_\theta}(s) \sum_a q_{\pi_\theta}(s, a) \nabla_\theta \pi_\theta(s, a) \]

2. REINFORCE算法

  • 用蒙特卡洛采样得到的实际回报 $G_t$ 来估计策略梯度。
  • 更新公式：$\theta \leftarrow \theta + \eta \gamma^t G_t \nabla_\theta \ln \pi_\theta(s_t, a_t)$
  • 特点：无偏但方差较大，要求问题是分段的。
知识点 6-8 Actor-Critic算法 对应表格“基于近似求解法的策略学习”
📄 位置来源：第212-213页（6.3.3节及算法6.10），第11页

1. Actor-Critic的双网络结构

  • Actor（执行者）：策略函数 $\pi_\theta(s, a)$，负责选择动作
  • Critic（评论家）：价值函数 $V_w(s)$，评价动作好坏

2. 更新公式

  • Critic更新：$w \leftarrow w + \eta_w \gamma^t [R + \gamma V_w(s') - V_w(s)] \nabla_w V_w(s)$
  • Actor更新：$\theta \leftarrow \theta + \eta_\theta \gamma^t [R + \gamma V_w(s')] \nabla_\theta \ln \pi_\theta(s, a)$
知识点 6-9 深度强化学习应用——AlphaGo 对应表格“典型深度强化学习方法”
📄 位置来源：第213-217页（6.4节全文），第11-14页

1. AlphaGo = 深度学习 + 强化学习 + MCTS

  • 监督学习策略网络：从人类棋谱中学习，用于MCTS扩展时赋予先验概率。
  • 强化学习策略网络：用策略梯度法微调，通过自我对弈提升。
  • 深度价值网络：评估当前局面的胜率。
  • MCTS：整合策略网络和价值网络，选择访问次数最多的落子。

2. AlphaGo Zero的改进

  • 不依赖人类数据：完全从随机初始值开始自我对弈。
  • 不依赖浅层神经网络进行模拟。
  • 学到了不同于人类已知策略但效果更好的策略。

3. 深度强化学习的挑战

  • 奖励稀疏：解决方案包括奖励塑造（Reward Shaping）和层次强化学习。
  • 样本效率低：解决方案包括经验重现和模仿学习。
  • 训练不稳定：改进手段包括预训练、课程学习、PPO/TRPO。
