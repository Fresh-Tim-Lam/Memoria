知识点 8-1 人工智能伦理与可信人工智能 对应表格“可信人工智能”
📄 位置来源：第257-258页（8.1节全文），第1-2页

1. 伦理的概念起源

  • 伦理：来源于希腊语“道德”和拉丁语“风俗”的组合，刻画人与人的言行道德与准则。
  • 中文“伦”有三重含义：①辈分次第关系；②音乐与伦理、美与善的相通性；③类。

2. 科技的双重属性

  • 科技具有技术属性和社会属性。
  • 科林格里奇困境：技术的早期阶段无法预见其社会后果；当不良后果变得明显时，控制已变得极端困难。
  • 世界结构演变：从“物理世界-人类社会”（PH）演变为 “信息空间-物理世界-人类社会”（CPH）三元空间。

3. 可信人工智能

  • 必须确保把人类价值观、道德观和法律法规贯穿于人工智能的产品和服务。
  • 赋予人工智能社会属性，推动“普遍智能”更好地惠及社会大众。
知识点 8-2 人工智能可解释性 对应表格“人工智能可解释性”
📄 位置来源：第266-267页（8.3节全文），第10-11页

1. 定义

  • 可解释人工智能（XAI）：智能体如何有效解释自己的行为过程机制和任务结果原因，取得人类用户的信任。
  • 与黑盒式AI相反——后者无法给出过程和结果的合理性描述。

2. 符号主义 vs 联结主义

  • 符号主义：以逻辑推理为基础，可给出清晰的推理过程（如苏格拉底三段论）。
  • 联结主义（深度学习）：以概率输出为基础，难以在任务结果与推理计算过程之间建立清晰联系。

3. 可解释性的研究方向

  • 中层特征语义可解释性：神经网络中层特征是否表达了明确语义？
  • 决策逻辑可解释性：能否为神经网络的决策结果给予语义逻辑上的解释？
  • 基于可解释性的中层对端学习：利用中层语义信息，在弱监督条件下迁移和诊断模型。
知识点 8-3 人工智能模型安全——对抗攻击 对应表格“算法攻击与防守”
📄 位置来源：第258-261页（8.2节及8.2.1节前半部分），第3-5页

1. 对抗攻击

  • 定义：在输入样本中添加人眼无法察觉的细微干扰，导致模型以高置信度给出错误识别结果。
  • 严重后果：自动驾驶中将“禁止通行”识别为“加速通过”。

2. FGSM（快速梯度符号法）

\[ x' = x + \eta \cdot \text{sign}(\nabla_x f(x)) \]

  • 利用模型梯度信息一步生成对抗样本。

3. PGD（投影梯度法）

\[ x'_{k+1} = \text{Proj}\{x'_k + \alpha \cdot \text{sign}(\nabla_x f(x'_k))\} \]

  • 将FGSM扩展为迭代 $k$ 次的方法。
  • 至今是对抗样本社区常用的评估基线。

4. 白盒攻击 vs 黑盒攻击

  • 白盒攻击：攻击者知道模型参数和梯度信息。
  • 黑盒攻击：攻击者无法获得模型参数（基于迁移性或基于查询）。
知识点 8-4 人工智能模型安全——数据投毒与后门攻击 对应表格“算法攻击与防守”
📄 位置来源：第261-263页（8.2.1节后半部分），第5-7页

1. 数据投毒攻击

  • 攻击阶段：数据收集阶段。
  • 类型：标签反转投毒攻击 vs 干净样本投毒攻击。
  • 目标：干扰模型训练，降低模型整体性能。

2. 后门攻击

  • 定义：在模型中植入后门，正常输入正常输出，添加后门触发器时产生恶意输出。
  • 示例：交通信号灯识别中，添加矩形触发器将“停车”识别为“限速80km/h”。
  • 可在数据收集、模型训练、模型部署任何阶段进行。

3. 数据投毒与后门攻击的区别

  • 后门攻击是数据投毒攻击的特殊实现。
  • 数据投毒目标：降低整体性能；后门攻击目标：植入特定行为。
知识点 8-5 人工智能模型安全——防御方法与隐私保护 对应表格“算法攻击与防守”
📄 位置来源：第263-266页（8.2.2-8.2.3节），第7-10页

1. 对抗攻击的防御

  • 测试阶段防御：引入随机性（输入随机变化、中间层添加随机噪声）。
  • 训练阶段防御：对抗训练（内层生成对抗样本，外层训练模型参数），被证明是至今最有效的防御方法之一。

2. 数据投毒攻击的防御

  • 投毒样本检测：特征空间k近邻检测、影响函数检测。
  • 模型稳健性增强：SGD优化器、差分隐私SGD（DP-SGD）。

3. 后门攻击的防御

  • 输入样本触发器防御：ONION（检测语言困惑度变化去除触发器）。
  • 模型内嵌后门防御：使用本地干净样本重新训练，利用深度学习的灾难性遗忘。

4. 隐私保护

  • 差分隐私：对数据添加干扰噪声，保护用户隐私。2017年获哥德尔奖。
  • 同态加密：允许在密文条件下进行安全计算。
  • 安全多方计算：无可信第三方条件下安全计算约定函数。

5. 差分隐私的数学定义

\[ \Pr[M(D) \in O] \le e^\epsilon \Pr[M(D') \in O] + \delta \]

  • $\epsilon$：隐私预算（越小保护越强）。
