知识点 9-1 人工智能基础软硬件框架 对应表格“人工智能算法支撑技术链”
📄 位置来源：第273-275页（9.1节全文），第1-3页

1. 智能计算框架的总体结构

  • 人工智能计算框架分为运行系统（部署和运行模型）和开发系统（开发和训练模型）两大部分。

2. 开发系统的四层结构（自底向上）

  • 人工智能芯片：提供物理上的计算支持。
  • 基础软件与计算系统：操作系统（文件系统、内核调度等）。
  • 训练框架：执行矩阵乘法、数据通信、计算图执行等AI计算任务。
  • 开发环境：封装训练框架，提供编程接口（如Python）。

3. 运行系统的四层结构（自底向上）

  • 芯片指令集标准：定义硬件设备可执行的指令集，确保软硬件兼容性。
  • AI编译框架：将高级模型描述转换为底层硬件可执行的指令。
  • 关键算法与模型：机器学习和深度学习算法。
  • AI垂直领域开放创新平台：提供特定领域解决方案和开发工具。

4. 智能计算结构与计算架构

  • 计算架构：从传统CPU到异构计算（CPU+GPU+TPU等）。
  • 算法优化：并行计算、分布式计算、量化、剪枝等。
知识点 9-2 人工智能芯片 对应表格“人工智能芯片（GPU、XPU和类脑芯片等）”
📄 位置来源：第275-276页（9.2节全文），第3-4页

1. 图形处理器（GPU）

  • 基本原理：因并行计算能力被用于AI计算。
  • 里程碑：2006年Chellapilla用GeForce7800实现CNN，比CPU快4倍；2012年AlexNet使用GPU完成训练。
  • 英伟达架构：以科学家命名（居里→特斯拉→费米→开普勒→麦克斯韦→帕斯卡→伏特→图灵→安培→霍珀→埃达）。

2. 张量处理器（TPU）

  • 提出者：谷歌公司。
  • 优势：在矩阵乘法和向量运算上性能显著，高内存带宽、低功耗、低延迟。

3. 可扩展处理器（XPU）

  • 一颗芯片集成多种类型处理器（CPU、GPU、DSP等），软硬件协同分配计算任务。

4. 类脑芯片（Neuromorphic Chip）

  • 受人脑神经元结构和功能启发，采用神经元模型和突触连接架构，事件驱动方式计算。

5. 特定领域芯片（Domain-Specific Chip）

  • 为特定应用场景设计（自动驾驶、机器人、物联网等），满足实时性、低功耗、高性能需求。
知识点 9-3 分布式神经网络训练算法 对应表格“分布式深度学习优化”
📄 位置来源：第277-279页（9.3.2节前半部分），第5-7页

1. 背景

  • 模型规模不断增大：GPT-1（1.17亿）→ GPT-2（15亿）→ GPT-3（1750亿参数）。
  • 单GPU V100训练GPT-3需约288年 → 必须使用分布式训练。

2. 数据并行（Data Parallelism）

  • 训练数据分配到不同计算节点，每个节点有一份完整模型。
  • 缺点：节点间高频通信传输梯度；节点数量增加影响收敛性能。

3. 张量并行（Tensor Parallelism）

  • 按神经元划分模型，每个节点存储一小块模型。
  • 通信要求：低延时、高带宽（一般在节点内部多加速器间实现）。

4. 流水线并行（Pipeline Parallelism）

  • 按网络层划分，每个阶段映射到一个GPU。
  • 关键要求：每个阶段计算负载均衡；相邻阶段需低延时、高带宽网络。
知识点 9-4 分布式训练系统与通信优化 对应表格“分布式深度学习优化”
📄 位置来源：第279-284页（9.3.2节后半部分及9.3.3-9.3.4节），第7-11页

1. 通信和同步机制

  • 参数服务器：维护集中参数存储，计算节点发送梯度更新后广播。优点：同步开销低；缺点：存储节点网络压力大。
  • Ring AllReduce：节点组织成环形拓扑，数据沿环传递，局部归约。优点：网络负载均衡。

2. 3D并行（Megatron-LM / DeepSpeed）

  • 机器间：用流水线并行（减少跨机通信）。
  • 机器内部：数据并行 + 张量并行混合。
  • ZeRO-Offload / ZeRO-Infinity：将参数、梯度、优化器状态卸载到CPU内存或SSD，支持在少量GPU上训练TB级大模型。

3. 网络通信的“剪刀差”问题

  • GPU计算能力：每2年增长3.1倍（20年增长约9万倍）。
  • DRAM带宽/网络互连带宽：每2年仅增长1.4倍（20年增长约30倍）。
  • 结论：分布式训练越来越成为网络瓶颈的负载。

4. 网内计算

  • SwitchML（Sapio等，2021）：用可编程交换机在网络传输时对梯度进行规约计算。
  • 结合了参数服务器和Ring AllReduce的优势。

5. GPU多租环境与资源调度

  • 资源分配：静态分配 vs 动态分配。
  • 资源调度：公平调度 vs 优先级调度。
  • 细粒度动态控制：对GPU内存和计算单元进行动态控制（Xiao等，2020）。
  • 未来方向：从云计算和端智能向端云协同进化计算模式跨越。
