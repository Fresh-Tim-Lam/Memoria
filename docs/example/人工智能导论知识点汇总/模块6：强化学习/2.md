#### 知识点6-6：深度强化学习与DQN（对应表格“基于近似求解法的策略学习”）

**位置来源**：第206-210页（6.2.6节全文），第4-8页（补充文件）

**1. 从表格求解到参数化求解**
- **位置来源**：第206页，第4页。
- **表格求解的局限**：
  - 状态数量非常多或无限时，无法用数组存储所有动作-价值函数值
  - 访问次数少的状态价值估计不可靠
- **参数化求解**：用回归模型（如深度神经网络）拟合 \(q_\pi\) 函数，只需记住一组参数：
  - 以深度神经网络拟合 \(q_\pi\) 的算法称为**深度强化学习（DRL）**
  - 参数化Q学习称为**深度Q网络（DQN）**

**2. 参数化Q学习的算法流程（算法6.8）**
- **位置来源**：第207页，算法6.8，第5页。
- **参数化动作-价值函数**：\(q_\pi(s, a; \theta)\)（用参数 \(\theta\) 表示）
- **损失函数**：

\[
L(\theta) = \frac{1}{2} \left[ R + \gamma \max_{a'} q_\pi(s', a'; \theta) - q_\pi(s, a; \theta) \right]^2
\]

- **参数更新**：\(\theta \leftarrow \theta - \eta \frac{\partial L(\theta)}{\partial \theta}\)（梯度下降）
- 采样策略仍用ε-贪心（探索）

**3. 参数化带来的两个新问题**
- **位置来源**：第207-208页，第5-6页。

| 问题 | 说明 |
| :--- | :--- |
| **样本相关性太强** | 相邻样本来自同一条轨迹，集中优化会导致模型对其他样本泛化差（教材图6.14示例：回归直线被A、B两点“拉偏”） |
| **目标不唯一** | 同一参数 \(\theta\) 同时用于计算目标值 \(R + \gamma \max_{a'} q_\pi(s', a'; \theta)\) 和当前值 \(q_\pi(s, a; \theta)\)，更新目标不明确 |

**4. DQN的解决方案**
- **位置来源**：第207-209页，第6-8页，图6.15、图6.16。
- **经验重现（Experience Replay）** （图6.15）：
  - 将探索的片段以 \((s, a, R, s')\) 四元组形式存入经验池
  - 更新参数时从经验池中**随机采样**一批样本
  - **两大好处**：① 减弱样本相关性；② 重复利用历史经验，提高信息效率
- **目标网络（Target Network）** ：
  - 用另一组参数 \(\theta^-\) 计算目标值（预测值）
  - 损失函数改为：

\[
L(\theta) = \frac{1}{2} \left[ R + \gamma \max_{a'} q_\pi(s', a'; \theta^-) - q_\pi(s, a; \theta) \right]^2
\]

  - \(\theta^-\) 保持相对稳定，以较低频率更新 \(\theta^- \leftarrow \theta\)
  - 目标值可看作常数，求解变为普通回归问题，训练更稳定

**5. DQN的应用场景**
- **位置来源**：第209页，图6.16，第7页。
- 输入：游戏画面（状态）
- 输出：每个动作对应的动作-价值函数值
- 动作：控制器的输入（如上下左右）
- 奖励：游戏得分
- DQN使用深度卷积神经网络拟合动作-价值函数，配合经验重现和目标网络，在雅达利（Atari）游戏中取得优异表现。


#### 知识点6-7：基于策略的强化学习——策略梯度法（对应表格“基于近似求解法的策略学习”）

**位置来源**：第210-212页（6.3.1-6.3.2节），第8-11页

**1. 从基于价值到基于策略**
- **位置来源**：第210页，第8页。
- **基于价值的方法**：以价值函数或动作-价值函数的建模为核心，通过策略优化定理求最优策略。
- **基于策略的方法**：**直接参数化策略函数** \(\pi_\theta(s, a)\)，用梯度上升优化策略参数。
- **参数化策略的优点**：选择动作的概率随参数**光滑变化**，对算法收敛有更好保证。

**2. 策略梯度定理（Policy Gradient Theorem）**
- **位置来源**：第210-211页，第8-9页。
- **优化目标**：\(J(\theta) \coloneqq V_{\pi_\theta}(s_0)\)（从初始状态出发的价值函数）
- **策略梯度定理**（Sutton等，1999）：

\[
\nabla_\theta J(\theta) \propto \sum_s \mu_{\pi_\theta}(s) \sum_a q_{\pi_\theta}(s, a) \nabla_\theta \pi_\theta(s, a)
\]

- 其中 \(\mu_{\pi_\theta}(s)\) 是策略 \(\pi_\theta\) 下的状态分布（折扣状态分布）。
- **直观理解**：\(\nabla_\theta \pi_\theta(s, a)\) 是策略参数的调整方向，\(q_{\pi_\theta}(s, a)\) 作为“权重”——高价值动作被促进，低价值动作被抑制。

**3. REINFORCE算法（算法6.9）**
- **位置来源**：第211-212页，算法6.9，第10页。
- **提出者**：Williams，1992。
- **核心思想**：用蒙特卡洛采样得到的实际回报 \(G_t\) 来估计策略梯度。
- **更新公式**（算法6.9第6行）：

\[
\theta \leftarrow \theta + \eta \gamma^t G_t \nabla_\theta \ln \pi_\theta(s_t, a_t)
\]

- **特点**：
  - 使用**完整片段的实际反馈**来更新策略（类似蒙特卡洛法）
  - 要求问题是**分段的（episodic）**
  - 只有在一个片段结束后才能进行更新
- **偏差与方差**：REINFORCE是无偏的（因为 \(G_t\) 是真实回报的估计），但**方差较大**。


#### 知识点6-8：Actor-Critic算法（对应表格“基于近似求解法的策略学习”）

**位置来源**：第212-213页（6.3.3节及算法6.10），第11页

**1. Actor-Critic的核心思想**
- **位置来源**：第212页，第11页。
- **提出者**：Witten（1977），Barto等（1983）。
- **核心思想**：用**时序差分（TD）** 方法替代蒙特卡洛采样来估计策略梯度。
  - 用 \(R + \gamma V_w(s')\) 代替 REINFORCE 中的 \(G_t\)
  - \(V_w(s)\) 是参数化的价值函数（参数为 \(w\)）

**2. Actor-Critic的双网络结构**
- **位置来源**：第212-213页，算法6.10，第11页。

| 组件 | 名称 | 功能 |
| :--- | :--- | :--- |
| **Actor（执行者）** | 策略函数 \(\pi_\theta(s, a)\) | 负责选择动作 |
| **Critic（评论家）** | 价值函数 \(V_w(s)\) | 评价Actor选出的动作好坏，指导Actor更新 |

**3. Actor-Critic算法流程（算法6.10）**
- **位置来源**：第212-213页，算法6.10，第11页。
- **Critic更新**（第8行）：

\[
w \leftarrow w + \eta_w \gamma^t [R + \gamma V_w(s') - V_w(s)] \nabla_w V_w(s)
\]

  - \(R + \gamma V_w(s') - V_w(s)\)：TD偏差
  - 假设 \(\nabla_w V_w(s') = 0\)（即目标值中的 \(V_w(s')\) 看作常数）——与DQN的目标网络思想一致

- **Actor更新**（第9行）：

\[
\theta \leftarrow \theta + \eta_\theta \gamma^t [R + \gamma V_w(s')] \nabla_\theta \ln \pi_\theta(s, a)
\]

  - 用 \(R + \gamma V_w(s')\) 作为 \(q_{\pi_\theta}(s, a)\) 的估计值
  - 相比REINFORCE，用TD估计替代蒙特卡洛回报，**方差更小**

**4. Actor-Critic的优点**
- 结合了基于价值方法（低方差）和基于策略方法（可处理连续动作空间）的优势
- 可进行**在线学习**（不需要完整片段），比REINFORCE更高效


#### 知识点6-9：深度强化学习应用——AlphaGo（对应表格“典型深度强化学习方法”）

**位置来源**：第213-217页（6.4节全文），第11-14页

**1. AlphaGo的基本框架**
- **位置来源**：第213-214页，第11-12页。
- AlphaGo将**深度学习、强化学习和蒙特卡洛树搜索**有机结合（图6.18）。
- **围棋的MDP描述**：
  - 状态：\(19 \times 19\) 棋盘盘面
  - 动作：落子位置
  - 奖励：终局胜负（胜+1，负-1）
  - 状态转移：确定性（每个动作只会导致一个固定后续状态）

**2. 深度学习的作用**
- **位置来源**：第214-215页，第12-13页。
- **监督学习策略网络**：从人类棋手16万局对弈棋谱中学习，拟合深度策略网络（用于MCTS扩展时赋予动作先验概率）和浅层策略网络（用于快速模拟）。
- **强化学习策略网络**：在监督学习策略网络基础上，用策略梯度法（REINFORCE）微调。
  - 为减少过拟合，训练时从旧版策略中随机选择对手进行自我对弈
- **深度价值网络**：用策略评估的蒙特卡洛法，通过自我对弈产生大量轨迹数据，拟合价值网络（评估当前局面的胜率）。

**3. 蒙特卡洛树搜索（MCTS）在AlphaGo中的整合**
- **位置来源**：第214-215页，第12-13页。
- **选择（Selection）** ：根据动作先验概率（监督学习策略网络）、访问次数、累积价值综合判断，选择UCB值最大的子结点。
- **扩展（Expansion）** ：使用监督学习策略网络赋予先验概率。
- **模拟（Simulation/Rollout）** ：使用浅层策略网络快速模拟到终局。
- **反向传播（Backpropagation）** ：根据价值网络更新路径上结点的累积价值和访问次数。
- **最终决策**：选择搜索树中**访问次数最多**的动作作为实际行棋。

**4. AlphaGo Zero的改进**
- **位置来源**：第215-216页，第13-14页。
- **不依赖人类数据**：完全通过**随机初始值**和自我对弈实现策略提升（从零开始，名“Zero”）。
- **不依赖浅层神经网络**：直接根据价值函数得到模拟结果，不再使用浅层策略网络进行模拟。
- 学到了不同于人类已知策略但效果更好的策略。

**5. 深度强化学习在实际应用中的挑战**
- **位置来源**：第216-217页，第14页。
- **奖励设置困难**：奖励滞后（稀疏奖励）时训练难以收敛；解决方案包括**奖励塑造（Reward Shaping）** 和**层次强化学习（HRL）**。
- **样本采集困难**：需要大量交互数据；解决方案包括**经验重现**、**模仿学习（Imitation Learning）**。
- **局部最优与探索**：ε-贪心探索有时仍会陷入局部最优；解决方案包括**优先探索访问次数少的状态**。
- **训练不稳定性与方差**：不同随机种子可能导致结果差异大；改进手段包括**预训练**、**课程学习（Curriculum Learning）**、**梯度截断**、**信赖域策略优化（TRPO/PPO）**。
- **泛化与迁移困难**：环境变化时策略失效；解决方案包括**多环境训练**、**微调（Fine-tuning）**。
