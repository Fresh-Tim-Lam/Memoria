#### 知识点7-1：博弈论基本概念与分类（对应表格“纳什均衡等博弈论概念”）

**位置来源**：第227-230页（7.1.1-7.1.3节），第1-5页

**1. 博弈论的起源**
- **位置来源**：第227页，第1页。
- **古代博弈思想**：《论语·阳货》记载“不有博弈者乎？为之，犹贤乎已”——博弈指六博和围棋两种棋艺。东汉马融《围棋赋》：“三尺之局兮，为战斗场。”
- **田忌赛马**（《史记·孙子吴起列传》）：以己之长，攻彼之短——用下等马对齐王上等马，上等马对中等马，中等马对下等马，以2:1获胜。
- **现代博弈论奠基**：1944年，冯·诺依曼（John von Neumann）与摩根斯特恩（Oskar Morgenstern）合著 **《博弈论与经济行为》** ，以数学形式阐述博弈论及其应用。

**2. 博弈论的核心术语**
- **位置来源**：第227-228页，第3-4页。

| 术语 | 含义 |
| :--- | :--- |
| **玩家/参与者（Player）** | 博弈的决策主体，通常假设是完全理性的 |
| **信息（Information）** | 参与者获得的与博弈相关的知识（如进展、对手策略） |
| **规则（Rule）** | 参与者行动的先后顺序及行动导致的后果 |
| **策略（Strategy）** | 参与者可以采取的行动方案（必须是事先准备好的完整方案） |
| **策略集（Strategy Set）** | 一个参与者所能采纳策略的全体组合 |
| **纯策略（Pure Strategy）** | 参与者确定地选择某一行为 |
| **混合策略（Mixed Strategy）** | 参与者按照一定概率随机选择若干不同行动 |
| **局势（Outcome）** | 参与者采取各自行动后形成的状态 |
| **收益（Payoff）** | 在不同局势下各个参与者得到的利益或回报 |
| **期望收益（Expected Payoff）** | 混合策略下对应的玩家收益 |

**3. 博弈的分类**
- **位置来源**：第228-229页，第4-5页。

| 分类维度 | 类型 | 说明 |
| :--- | :--- | :--- |
| **是否允许合作** | 合作博弈（Cooperative Game） | 部分参与者可组成联盟以获得更大收益 |
| | 非合作博弈（Non-Cooperative Game） | 参与者独立决策，不事先达成合作 |
| **决策时间** | 静态博弈（Static Game） | 所有参与者同时决策，或互相不知道对方决策 |
| | 动态博弈（Dynamic Game） | 参与者按规则先后行动，后行动者知道先行动者的行动 |
| **信息了解程度** | 完全信息博弈（Complete Information Game） | 所有参与者了解其他参与者的策略集、收益等信息 |
| | 不完全信息博弈（Incomplete Information Game） | 并非所有参与者掌握所有信息 |
| | 完美信息博弈（Perfect Information Game） | 参与者知道所有参与者之前采取的行动（是“完全信息”的子类） |
| **收益总和** | 零和博弈（Zero-Sum Game） | 终局时所有参与者收益总和为零 |
| | 非零和博弈（Non-Zero-Sum Game） | 终局时所有参与者收益总和不为零 |


#### 知识点7-2：纳什均衡与囚徒困境（对应表格“纳什均衡等博弈论概念”）

**位置来源**：第228-231页（7.1.2-7.1.4节），第4-8页

**1. 囚徒困境（Prisoner's Dilemma）**
- **位置来源**：第228-229页，表7.2、表7.3，第4-5页。
- **提出者**：梅里尔·弗勒德（Merrill Flood）和梅尔文·德雷舍（Melvin Dresher），1950年；塔克以“囚徒方式”阐述。
- **场景**：甲、乙两人被捕，分开审讯。若一人认罪并指证对方，另一方沉默，则认罪者释放，沉默者判10年；若两人都沉默，各判半年；若两人都认罪，各判5年。

| 局势 | 甲收益 | 乙收益 |
| :--- | :--- | :--- |
| 甲认罪，乙沉默 | 释放（0年） | 10年 |
| 甲认罪，乙认罪 | 5年 | 5年 |
| 甲沉默，乙认罪 | 10年 | 释放（0年） |
| 甲沉默，乙沉默（最优解） | 0.5年 | 0.5年 |

- **理性分析**：
  - 对甲：若乙沉默，甲认罪被释放（0年）优于沉默（0.5年）；若乙认罪，甲认罪判5年优于沉默判10年。**无论乙如何选择，甲都应认罪**。
  - 对乙同理。最终两人都选择认罪——这是**均衡解**，但不是**最优解**（最优解是两人都沉默）。
- **核心启示**：**个人最佳选择 ≠ 团体最佳选择**；总体最优局势不一定是均衡局势。

**2. 纳什均衡（Nash Equilibrium）**
- **位置来源**：第230页，第8页。
- **提出者**：约翰·纳什（John Forbes Nash Jr.），1950年博士论文《非合作博弈》（Non-Cooperative Games），1994年诺贝尔经济学奖。
- **定义**：参与者作出的一种策略组合，在该策略组合中，**任何参与者单独改变策略都不会得到好处**。
- **等价表述**：在给定所有其他参与者策略不变的前提下，没有任何参与者有动机改变自己的策略。
- **囚徒困境中的纳什均衡**：两人同时认罪，因为单独改变策略只会使收益更差。

**3. 纳什定理（Nash's Theorem）**
- **位置来源**：第231页，第9页。
- **内容**：任何有限策略下的博弈（参与者有限、策略集有限、收益函数为实值）都**必定存在一个混合策略纳什均衡**。
- **历史地位**：奠定了博弈论的数学基础，是**存在性定理**（不提供求解算法）。

**4. 策梅洛定理（Zermelo's Theorem）**
- **位置来源**：第231-232页，第9页。
- **内容**：对于任意一个**有限步的双人完全信息零和动态博弈**，一定存在**先手必胜策略、后手必胜策略或双方保平策略**。
- **证明**：用数学归纳法（从 $N=1$ 步到 $N=k+1$ 步的递推）。
- **意义**：为第3章的Minimax搜索提供了理论基础——在两人对抗博弈的有限搜索空间内，一定存在某种确定的结果。
- **局限**：仅对双人博弈有效（三人及以上不保证）。
- **与纳什定理的关系**：策梅洛定理（1913）比纳什均衡（1950）早二十多年，纳什定理可看作策梅洛定理对非零和博弈和多人博弈的推广。


#### 知识点7-3：混合策略与纳什均衡求解（对应表格“纳什均衡等博弈论概念”）

**位置来源**：第230-231页（7.1.4节），第8-9页

**1. 混合策略纳什均衡的定义**
- **位置来源**：第230页，第8页。
- 参与者以**概率形式随机选择**不同策略而达到的纳什均衡。
- **纯策略纳什均衡**：参与者确定地选择某一策略。
- 纳什定理指出：任何有限博弈**一定存在混合策略纳什均衡**（即使不存在纯策略纳什均衡）。

**2. 教材示例：雇主-雇员的监督博弈**
- **位置来源**：第230-231页，表7.4、表7.5，第8-9页。
- **场景**：雇主检查雇员是否偷懒。
- **符号定义**：
  - $H$：雇员不偷懒时的付出
  - $V$：雇员对公司的贡献
  - $W$：雇员工资
  - $C$：雇主检查成本
  - $F$：对偷懒雇员的罚金
  - 已知：$H < W < V$，$W > C$
- **混合策略参数**：
  - $\alpha$：雇主检查的概率
  - $\beta$：雇员偷懒的概率

**3. 期望收益计算（表7.5）**
- **位置来源**：第231页，表7.5，第9页。
- **雇主的期望收益**：
  - 检查：$T_1 = \beta(-C+F) + (1-\beta)(V-W-C)$
  - 不检查：$T_2 = -\beta W + (1-\beta)(V-W)$
- **雇员的期望收益**：
  - 偷懒：$T_3 = -\alpha F + (1-\alpha)W$
  - 不偷懒：$T_4 = W-H$

**4. 纳什均衡的求解**
- **位置来源**：第231页，第9页。
- **均衡条件**：
  1. 雇主检查与不检查的期望收益相等：$T_1 = T_2$
  2. 雇员偷懒与不偷懒的期望收益相等：$T_3 = T_4$
- **求解结果**：
  - 雇主检查概率：$\alpha = \frac{H}{F}$（由 $T_3 = T_4$ 推出）
  - 雇员偷懒概率：$\beta = \frac{C}{W+F}$（由 $T_1 = T_2$ 推出）
- **雇主最优工资**：$W = \sqrt{CV} - F$（对雇主期望收益求导得到）
  - 此时雇主最大期望收益：$T_{\max} = V - 2\sqrt{CV} + F$
- **实际意义**：博弈论可以帮助人们在科学决策中寻找最优策略。
