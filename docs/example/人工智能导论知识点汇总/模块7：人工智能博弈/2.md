#### 知识点7-4：遗憾最小化算法与虚拟遗憾最小化（CFR）（对应表格“博弈策略求解算法”）

**位置来源**：第233-239页（7.2.1-7.2.2节），第11-16页

**1. 策略求解的核心挑战**
- **位置来源**：第233页，第11页。
- 博弈论提供了数学模型和存在性保证（纳什定理），但求解均衡局势或最优策略需要高效的搜索算法。
- AI算法可帮助对大规模解空间进行近似求解（如围棋走子策略、非完全信息博弈如扑克）。

**2. 遗憾最小化算法（Regret Minimization）的核心思想**
- **位置来源**：第233-234页，第11-12页。
- **遗憾（Regret）** ：在给定其他玩家策略不变的前提下，当前玩家未选择某一策略所错失的潜在收益。
- **遗憾最小化**：重复博弈中，玩家逐步倾向于选择过去遗憾值小的策略，最终逼近最优反应策略。
- **公式**（第233页公式(7.2)-(7.3)）：
  - 策略组合：\(\sigma = \{\sigma_1, \sigma_2, \dots, \sigma_N\}\)
  - 玩家 \(i\) 在 \(T\) 轮中对策略 \(\sigma'_i\) 的累计遗憾值：

\[
\text{Regret}_i^T(\sigma'_i) = \sum_{t=1}^T \left( u_i(\sigma'_i, \sigma_{-i}^t) - u_i(\sigma^t) \right)
\]

  - \(\sigma_{-i}\)：除玩家 \(i\) 外其他玩家的策略组合
- **遗憾匹配（Regret Matching）** ：下一轮选择策略的概率与**正遗憾值**成正比（若有正遗憾，则下轮倾向选择该策略；若均为负，则随机选择）。

**3. 教材示例：石头-布-剪刀（RPS）**
- **位置来源**：第234-235页，表7.6、表7.7，第12-13页。
- 第一局：玩家A出石头（R），玩家B出布（P）。A收益 -1，B收益 +1。
  - A未选“布”的遗憾值：\(\text{Regret}_A^1(P) = u_A(P,P) - u_A(R,P) = 0 - (-1) = 1\)
  - A未选“剪刀”的遗憾值：\(\text{Regret}_A^1(S) = u_A(S,P) - u_A(R,P) = 1 - (-1) = 2\)
  - 第二局A选策略概率：石头0/3，剪刀1/3，布2/3
- 表7.7展示玩家A经过两轮后的累计遗憾值：石头2，剪刀3，布3（选择概率：石头1/6，剪刀2/6，布3/6）

**4. 虚拟遗憾最小化（Counterfactual Regret Minimization, CFR）**
- **位置来源**：第235-239页，第13-16页。
- **提出者**：Zinkevich等，2007。
- 将遗憾最小化推广到**序贯决策（多步博弈）**，每个结点（信息集）分别计算遗憾值。
- **博弈树表示**：每个中间结点为一个**信息集（Information Set）I**，包含该结点的状态及到达该结点的所有历史行动。

**5. CFR的关键概念**
- **位置来源**：第235-236页，第13-14页。
- **信息集 \(I\)** 下可采取的动作集合：\(A(I)\)
- **行动序列 \(h\)**：从根结点到当前结点的路径
- **策略组合 \(\sigma\) 下行动序列 \(h\) 的出现概率**：\(\pi^\sigma(h)\)
- **信息集出现概率**：\(\pi^\sigma(I) = \sum_{h \in I} \pi^\sigma(h)\)
- **虚拟价值（Counterfactual Value）** （公式(7.4)）：

\[
v_i(\sigma, h) = \sum_{z \in Z} \pi_{-i}^\sigma(h) \cdot \pi^\sigma(h, z) \cdot u_i(z)
\]

  - 含义：不考虑玩家 \(i\) 策略（即 \(\pi_i^\sigma(h)=1\)），其他玩家按策略 \(\sigma_{-i}\) 行动，从 \(h\) 出发到达终局 \(z\) 的期望收益
- **信息集 \(I\) 下动作 \(a\) 的遗憾值**（公式(7.6)）：

\[
r_i(I, a) = v_i(\sigma_{I \to a}, h) - v_i(\sigma, h)
\]

**6. 教材示例：库恩扑克（Kuhn's Poker）**
- **位置来源**：第236-239页，表7.8、图7.1、表7.9，第14-16页。
- **游戏简介**：双人有限注扑克，牌值1、2、3各一张，每位玩家各持一张，可“过牌（P）”或“加注（B）”，最后比牌大小。
- 表7.8给出了完整规则和收益定义。
- 图7.1展示了先手玩家A的博弈树（12个信息集：{1, 1P, 1B, 1PB, 2, 2P, 2B, 2PB, 3, 3P, 3B, 3PB}）。
- **虚拟遗憾值计算示例**（信息集{1PB}，选择“过牌”P）：
  1. 初始策略为随机选择（P和B各50%概率）
  2. 路径概率：\(\pi_A^\sigma(h) = 1 \times 0.5 = 0.5\)（不考虑A策略，B以50%概率加注）
  3. 当前策略下的虚拟价值：\(v_A(\sigma, h) = 0.5 \times u_A(z_1) + 0.5 \times u_A(z_2) = 0.5 \times (-1) + 0.5 \times (-2) = -0.75\)
  4. 若在{1PB}选择“过牌”：\(v_A(\sigma_{I \to P}, h) = -0.5\)
  5. 遗憾值：\(r_A(\{1PB\}, P) = -0.5 - (-0.75) = 0.25\)
- 表7.9给出CFR迭代后12个信息集应采取行动的概率（最终策略）。

**7. CFR算法步骤**
- **位置来源**：第237页，第15页。
  1. 初始化遗憾值和累加策略表为0
  2. 采用随机选择的方法决定策略
  3. 利用当前策略与对手进行博弈
  4. 计算每个玩家采取每次行动后的遗憾值
  5. 根据博弈结果计算累加遗憾值以更新策略
  6. 重复步骤3~5若干次，不断优化策略
  7. 根据重复博弈最终的策略，完成最终动作选择


#### 知识点7-5：安全子博弈（对应表格“博弈策略求解算法”）

**位置来源**：第241-243页（7.2.3节全文），第17-19页

**1. 子博弈求解的基本思路**
- **位置来源**：第241页，第17页，图7.3。
- 在实时博弈中，将当前已完成的博弈部分视为已完成，从当前状态出发，将后续博弈过程视为一个**单独子博弈**，缩小搜索空间。
- **完全信息博弈**：这种方法适用（如棋类残局）。
- **非完全信息博弈**：直接搜索子博弈空间**不适用**——即使是博弈树中不能到达的分支，对当前子博弈也有影响。

**2. 抛硬币示例（图7.4）**
- **位置来源**：第241-242页，第17-18页。
- 玩家A抛硬币（正面概率0.5，反面概率0.5）：
  - 正面：A卖掉硬币收益0.5，或让B猜（B猜错则A得1，猜对则A失1）
  - 反面：A卖掉硬币收益-0.5，或让B猜（B猜错则A得1，猜对则A失1）
- **关键结论**：B在“猜硬币”这个子博弈中的最优策略，**依赖于A卖掉硬币的期望收益**（T₁和T₂）。若单独考虑猜硬币而不考虑卖硬币，B会以0.5概率猜正反面；但考虑卖硬币后，B应以0.25概率猜正面、0.75概率猜反面（使A两种选择收益相等）。

**3. 安全子博弈（Safe Subgame）的定义**
- **位置来源**：第242-243页，第18-19页。
- **安全子博弈**：在子博弈求解中得到的结果，一定**不差于**全局近似解法。
- 在抛硬币示例中，B的行动若基于A卖掉硬币的收益来决定，猜硬币这个子博弈就是**安全的**；若仅考虑猜硬币过程而不考虑卖硬币收益，则是**不安全的**。
- **实现方法**：通过虚拟价值的估计找到安全子博弈。比较采取动作 \(a'\) 和信息集 \(I_1\) 之间的价值差距，若差距足够小，则对应的子博弈就是安全的（Brown等，2018）。


#### 知识点7-6：双边匹配——Gale-Shapley算法（对应表格“博弈规则设计”）

**位置来源**：第243-245页（7.3.1-7.3.2节），第19-21页

**1. 博弈规则设计的研究问题**
- **位置来源**：第243页，第19页。
- 如果所有博弈者追求各自利益最大化，可能导致整体利益受损，需要设计合理的博弈规则使最终局势达到**整体利益最大**。
- **应用场景**：车牌发放（竞价+摇号）、拍卖竞价、供需匹配、名额分配等。

**2. 稳定婚姻问题（Stable Marriage Problem）**
- **位置来源**：第243-244页，第19-20页。
- **问题描述**：给定 \(n\) 名男性集合 \(M = \{m_1, \dots, m_n\}\) 和 \(n\) 名女性集合 \(F = \{f_1, \dots, f_n\}\)，每人对对方有严格偏好顺序，寻找稳定的匹配。
- **稳定匹配**：不存在未达成匹配的两人，彼此都更倾向于对方而不是当前的匹配对象。
- **不稳定匹配**：存在不是伴侣的一男一女，彼此可接受对方，且对目前伴侣的好感度没有对方高。

**3. Gale-Shapley算法（G-S算法，1962）**
- **位置来源**：第244-245页，第20-21页。
- **提出者**：美国数学家大卫·盖尔（David Gale）和博弈论学家沙普利（Lloyd Shapley），2012年沙普利因该贡献获诺贝尔经济学奖。

| 步骤 | 操作 |
| :--- | :--- |
| **1** | 单身男性向**最喜欢**的女性表白 |
| **2** | 收到表白的女性从所有表白者中选择最喜欢的男性，**暂时匹配** |
| **3** | 未匹配的男性继续向**没有拒绝过他的**女性表白 |
| **4** | 若女性已匹配但更喜欢新表白者，则**替换**之前匹配的男性 |
| **5** | 循环迭代，直到所有人都成功匹配 |

**4. 教材示例**
- **位置来源**：第244-245页，表7.10、表7.12，第20-21页。
- 表7.10展示4男4女的偏好序列；表7.12展示G-S算法的执行过程。
- 第一轮：4男分别向最喜欢的女性表白 → A收到3人表白选了3，B选了4
- 第二轮：未匹配的1和2继续表白 → B选择了更喜欢的2，放弃4
- 继续三轮，所有人匹配完成，且结果稳定。
- **G-S算法特点**：
  - **总是能找到稳定匹配**
  - 对**主动方（男性）** 有利——男性得到的是所有稳定匹配中最好的结果之一（主动方最优）
  - 结果**唯一性**不保证（不同执行顺序可能得到不同稳定匹配）


#### 知识点7-7：单边匹配——Top Trading Cycle（TTC）算法（对应表格“博弈规则设计”）

**位置来源**：第246-247页（7.3.3节），第21-22页

**1. 单边匹配问题的特点**
- **位置来源**：第246页，第21页。
- 与双边匹配不同，单边匹配类似于**以物易物**的交换匹配问题（如室友匹配、座位分配）。
- 分配对象是不可分的标的物，它们只能属于一个所有者，且可以属于任何一个所有者。

**2. Top Trading Cycle（TTC）算法（1974）**
- **位置来源**：第246页，第21页。
- **提出者**：沙普利（Shapley）和斯卡夫（Scarf），1974年。

| 步骤 | 操作 |
| :--- | :--- |
| **1** | 记录每个标的物的初始占有者（或随机分配） |
| **2** | 每个交易者连接一条指向他**最喜欢**的标的物的边；从每个标的物连接到其**占有者**或具有**高优先权**的交易者 |
| **3** | 此时形成一张有向图，必存在环（称为**交易圈**）。交易圈中的交易者获得各自指向的标的物，放弃原先占有的标的物，占有者和匹配成功的标的物离开匹配市场 |
| **4** | 从剩余交易者和标的物中重复交易圈匹配，直到无法形成交易圈 |

**3. 教材示例：室友床位匹配**
- **位置来源**：第246-247页，表7.13、图7.5、图7.6，第21-22页。
- 四位同学A、B、C、D对床位1、2、3、4的偏好如表7.13所示（当前分配：A→4，B→3，C→2，D→1）。
- **第一轮**（图7.5）：
  - A指向1，B指向2，C指向1，D指向4
  - 标的物1→占有者D（因为D占有1），标的物2→占有者C，标的物3→占有者B，标的物4→占有者A
  - 形成交易圈：A→1→D→4→A（A得到1，D得到4），A和D离开市场
- **第二轮**（图7.6）：
  - B指向2，C指向2；标的物2→占有者C
  - B→2→C→2形成环：C得到2，B得到3
- **最终结果**：A→1，B→3，C→2，D→4
