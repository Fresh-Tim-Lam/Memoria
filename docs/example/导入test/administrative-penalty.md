## 行政处罚

行政处罚指行政机关依法对违反行政管理秩序的公民、法人或其他组织，以减损权益或增加义务的方式予以惩戒的行为。

制裁性；法定性；处分性；不利性；惩戒性

### 行政处罚种类

警告；通报批评；罚款；没收非法财物和非法所得；吊销许可证；暂扣许可证件；降低资质等级；限制开展经营活动；责令停产停业；责令关闭；限制从业；人身罚；其他种类（13种）

### 行政处罚的设定

（从无到有）

- 法律可以 $13 + N$ ，可以创制《行政处罚法》中没有的
- 行政法规可以 $12 + N$ ，即除了限制人身自由的除外，也可以创设处罚
- 地方性法规不能设定限制人身自由处罚，不能吊销营业执照（可以设定暂扣）；无权创设其他种类处罚
- 规章：只有警告，通报批评和一定数额的罚款，不能创设处罚
- 除法律法规规章外，其他规范性文件都不得设定行政处罚

行政处罚具体规定（从粗到细）

- 不能改变行政处罚的适用对象
- 不能违反上位法的处罚种类和处罚幅度

补充设定（从有到全）（非创设处罚，而是在没有行政处罚的规定下补充设定）

- 法律对未作出的行政规定，行政法规为实施法律，可以补充设定，听证会，论证会
- 地方性法规对法律和行政法规的补充设定
- 补充设定，听证、论证会

### 行政处罚的实施

主体：

- 行政机关；综合执法机关（只有国务院和省政府决定综合执法机关，限制人身自由的只有公安机关和法律规定的其他机关）；授权的；委托的（以委托者的名义，且不能二次委托）

管辖：

- 级别管辖：（只有省、自治区、直辖市有权决定）县级以上地方人民政府具有行政处罚全的行政机关管辖；管辖权下放：将县级政府部门的行政处罚全交由乡镇政府、街道办事处行使
- 地域管辖
- 管辖争议：最先立案的行政机关管辖
- 协助协助

实施程序：

- 普通程序：立案；调查；接受询问；保存证据（证据登记保存属于行政强制措施）；审核；决定（90日内）；送达（当场，即当面或7日内送达；）
- 简易程序：适用情形：一清二百三千警告：违法事实确凿的；对公民处以200以下罚款；对法人或其他组织3000以下的打款或警告；当场处罚当场送达
- 听证程序：
  - 法定听证：必须申请，没有依职权。告知+申请+听证；行政机关，降级吊证件，责令关停业的，当事人申请，应当听证；公安机关：停吊四（责令停产停业，吊销许可证，罚款四千以上）；未成年
  - 约定听证：官名双方自愿情况下，可以听证。
  - 治安管理处罚的申请听证（要求+同意=听证）行为人要求听证，公安机关认为必要的，应当及时依法听证
  - 听证期限：5日内提起申请。7日前通知

### 行政处罚实施规则

- 不处罚：无责任能力；情节轻微主观无过错；超过处罚时效：2年内没有发现的；涉及公民生命健康安全，等，5年。治安处罚6个月（公安管就6个月，其他行政机关就是2年或5年）
- 不再罚：一个行为不得两次处罚
- 不重罚
