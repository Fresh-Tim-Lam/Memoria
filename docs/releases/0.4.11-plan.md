## 4. 回滚

- 未 push：`git tag -d v0.4.11`；`git reset --hard <pre-release-commit>`（**仅限本地、且先确认无用户改动**）。
- 已 push/发 Release：删除远端 tag/Release（`git push origin :refs/tags/v0.4.11`），恢复版本号并重新构建上一个 Package；在 GitHub Release 说明中标注撤回。
- 用户数据（`docs/example/AAA_Vocab` 等 dirty 文件）**不得**被 release commit 吞入；发布前用 `git add -p`/显式路径。
