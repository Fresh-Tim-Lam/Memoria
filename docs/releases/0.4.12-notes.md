# Memoria v0.4.12

> 0.4.11 → 0.4.12：DSH 对话交互移植（轮次导航 / 待发送队列 / 气泡输入框 / 会话底栏 / 结构化上下文）、模型端点断网重试、语义引用与标注工具改进；另含 0.5 图谱探索的前置渲染/导航工作。多层级图谱与 0.5 检索优化**尚未完成**，不在本版承诺范围内。

## English

### Why upgrade

Three user-facing reasons to install this PATCH release:

1. **The agent conversation panel now behaves like a modern chat surface.** A fixed-pitch turn rail on the right marks every user turn, previews the prompt/answer on hover, highlights the current turn while scrolling, and jumps on click. Typing while an answer is running now **queues the draft** instead of dropping it: rows can be edited, removed, or used to interrupt the current answer; the next row drains automatically when the turn ends. The composer is a DSH-style rounded card with arrow Send and pause Stop controls, and the session footer keeps model/network/balance/token/context/cache facts inside the conversation panel rather than in Memoria's global status bar.
2. **Context usage is now inspectable as structured data.** Clicking the context ring opens a structured panel with the character budget, compaction threshold, compaction count, this-turn and session token totals, cache hit/miss, and the backend split of the request into **system prompt / tool schemas / message history** (real character counts; tokens are explicitly labelled `chars/4` estimates). The new read-only RPC is `agent_context_breakdown`.
3. **A network blip is retried instead of immediately becoming a failed answer.** The model loop now uses a patient bounded policy for transport failures: 6 retries, 0.8s initial backoff, 15s cap, 240s total budget. It still never replays a stream after the first token has been delivered, and deterministic failures (DNS, TLS certificate, connection refused) are not retried.

### New and changed

- **Turn rail / conversation queue / DSH composer.** See `ui-chat/TurnNavigator` and `ui-conversation/queue/QueueDock` behaviour; no React dependency was added to Memoria.
- **In-panel session footer.** Model, network, balance, turn tokens, context ring, cache hit rate, and the context breakdown panel live in `#agent-session-footer`; the global footer no longer shows the cached-hit text.
- **Composer resize handle moved above the input**, so the bottom action row stays uncluttered.
- **Annotation board is draggable** (dev tool): drag the title bar to move it, position is persisted, double-click resets to the bottom-right. Buttons in the bar do not start a drag.
- **Network retry policy.** `Remote end closed`/connection reset/429/5xx are retried before any stream chunk is delivered; retry exhaustion still surfaces a readable error with the retry count.
- **Agent context breakdown RPC** for the structured context panel. It reads the same system prompt, tool schemas, and history builder as the real request.
- **Graph groundwork from the 0.5 line** (background/child station visuals, `RenderScene` refactor, jump preview, parent/child navigation) is present, but this release is **not** the 0.5 multilevel-graph deliverable.

### Fixes and disclosures

- E36 split-view precise line/offset anchoring is closed; E35 (literal dollar/math pairing) is only partially closed; E37 (caret/selection loss) remains open. These are recorded in the todo ledger rather than hidden behind a green release note.
- The vendored DSH reference checkout (`dsh-src/`) was refreshed from `0.1.6-alpha.1` to `0.2.1-alpha.2` (commit `9fb030ad35`). It is a read-only reference and is not part of the application build.
- No data migration and no `schema_version` bump.

### Upgrade notes

- Settings/api key location is unchanged (`%LOCALAPPDATA%\Memoria\config`).
- Replacing the application folder is safe; existing knowledge bases are not rewritten.
- The pending conversation queue is in-memory: it survives turn completion, but not an application restart. Attachments are not queued; they stay with the current draft.
- Context breakdown tokens are estimates (`chars/4`) and are visibly labelled as such; they are not provider billing tokens.

### Known debts

- E35 main-preview MathJax proof remains partial; E37 caret/selection loss remains open (🔴 K1).
- Multilevel graph 0.5 scope is not complete; only groundwork is present.
- Context breakdown does not yet use a provider tokenizer, so its token numbers are order-of-magnitude estimates.

## 中文

### 为什么要升级

本次 PATCH 版本值得安装的三件事：

1. **对话面板现在有现代聊天界面应有的交互。** 右侧固定刻度栏逐轮标记用户消息，悬停预览问题/回答，滚动时高亮当前轮，点击跳转；回答生成中继续输入会**进入待发送队列**而不是被丢弃，队列行可编辑、删除、打断当前回答，本轮结束后自动发下一条。输入框改为 DSH 风格圆角气泡，发送/暂停改为圆形图标按钮；会话底栏把模型、网络、余额、token、上下文圆环、缓存命中率收进对话面板内部，不再占用 Memoria 全局底栏。
2. **上下文占用可以按结构化数据检查。** 点击上下文圆环会打开面板，显示字符预算、压缩阈值、已压缩次数、本轮/本会话 token、缓存命中/未命中，以及后端拆分的 **系统提示 / 工具定义 / 消息历史** 三段（字符数是真实值；token 明确标注为 `chars/4` 估算）。新增只读 RPC：`agent_context_breakdown`。
3. **网络瞬断会重试，而不是立刻变成失败回答。** 模型循环对传输类失败使用有界耐心策略：最多 6 次重试、0.8s 起步、15s 上限、240s 总预算；**一旦已经向界面投递分片，就不再重放**；DNS 失败、TLS 证书失败、连接被拒等确定性失败不重试。

### 新增与变更

- **轮次导航 / 待发送队列 / DSH 气泡输入框**：行为对齐 DSH，未引入 React 依赖。
- **会话栏内底栏**：模型、网络、余额、本轮 token、上下文圆环、缓存命中率、结构化上下文面板均在 `#agent-session-footer` 内；全局底栏不再显示缓存命中文字。
- **输入框高度把手移到上方**，底部操作行不再被把手挤占。
- **批注板可拖动**（开发工具）：拖标题栏移动，位置持久化，双击复位右下角；标题栏按钮不会误触发拖动。
- **断网重试策略**：`Remote end closed`、连接重置、429、5xx 在尚未投递分片时重试；重试耗尽后的错误仍带可读的重试次数。
- **上下文拆分 RPC**：与真实请求使用同一份 system prompt、工具 schema、history builder。
- **0.5 图谱前置工作**（背景/子节点视觉、`RenderScene` 重构、跳转预览、父子导航）已在代码中，但本版**不是** 0.5 多层级图谱交付。

### 修复与披露

- E36 分屏精确行列锚点已收口；E35（字面美元符/公式配对）只完成部分修复；E37（光标/选区丢失）仍未关闭。这些在 todo 台账中如实记录，不用绿色发布说明掩盖。
- 仓库内 DSH 参考检出 `dsh-src/` 已从 `0.1.6-alpha.1` 同步到 `0.2.1-alpha.2`（commit `9fb030ad35`）；它只是只读参考，不进入应用构建。
- 无数据迁移，`schema_version` 不变。

### 升级注意

- 设置与 API key 位置不变（`%LOCALAPPDATA%\Memoria\config`）。
- 直接替换应用目录是安全的；已有知识库不会被改写。
- 待发送队列是内存队列：跨本轮保存，但**应用重启后不保留**；附件不参与排队，仍属于当前草稿。
- 上下文拆分的 token 是 `chars/4` 估算，已在界面明确标注，不是 provider 计费 token。

### 已知债务

- E35 主预览 MathJax 证明仍不完整；E37 光标/选区丢失仍开放（🔴 K1）。
- 多层级图谱 0.5 范围尚未完成，本版只有前置工作。
- 上下文拆分尚未接入 provider tokenizer，token 数字只是量级估算。
