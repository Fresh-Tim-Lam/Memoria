# Memoria v0.4.14

> 0.4.13 → 0.4.14：**两项 PATCH 修复**——更新页 Release notes 的 Markdown 渲染（不再显示原始 `#`/`##` 文本），以及 C10 弹窗层级（模态框不再被搜索面板/右键菜单/取色器/闪报遮挡）。无数据迁移、无 `schema_version` 变化。P08 使用频次统计与 0.5 多层级图谱仍未完成。

## English

### Why upgrade

Four reasons to install this small PATCH:

1. **The update page now renders Release notes as readable Markdown.** Headings, blockquotes, bold/emphasis, lists and inline code appear as formatted content instead of raw `# Memoria v0.4.13` / `## English` lines.
2. **Rendering is sanitized.** `update-settings.js` renders `#update-notes` through `marked` plus an explicit tag/attribute allowlist, so the release body cannot inject raw HTML, event handlers or unsafe markup into the update dialog.
3. **This build is required to receive the fix.** Users still on v0.4.13 keep seeing the raw Markdown until they install v0.4.14; the fix ships in this release and does not change update check/download behavior.
4. **Modal dialogs now sit above background overlays (C10).** A settings modal used to be at `z-index: 1000` while the search panel (9000), context menu (10050), flash host (12000) and color picker (20000) were above it. The modal now uses a single layer token at 21000, so it stays visible and clickable; the image lightbox remains above it.

### New and changed

- `src/memoria/ui/static/app/js/update-settings.js`: render the fetched Release body with `marked` and a sanitizer/allowlist for tags and attributes; the update notes container is `#update-notes`.
- `src/memoria/ui/static/app/css/app.css`: C10 layer tokens (`--z-search-panel:9000`, `--z-context-menu:10050`, `--z-flash:12000`, `--z-color-picker:20000`, `--z-modal:21000`, `--z-lightbox:99999`) replace the raw z-index declarations for those overlays.
- Verified with the existing update tests: `pytest tests/test_update_ui_contract.py tests/test_update_mechanism.py` → **18 passed**; `node --check` on `update-settings.js` → **PASS**; `node scripts/i18n_selftest.js` → **PASS**.
- Lead/dev CDP verification injected a real 0.4.13 release result and confirmed the dialog rendered `h1` / `blockquote` / `strong` / `h2` / `ul` / `li` / `code` elements. Fix commit: **`f44adf82`**.

### Fixes and disclosures

- **Fix:** the update dialog showed the Release notes as raw Markdown; it now renders sanitized Markdown.
- **Fix (C10):** Dev CDP reproduced `#settings-modal` at z-index 1000 and a `MemoriaApp.showTreeContextMenu()` menu at 10050 painting over it; after the fix modal=21000 and the menu center hit-tests inside the modal. Commit **`63278126`**, tests `tests/test_z_index_layers.py` **3 passed**. Probe images: `artifacts/agent/verify/c10/before-contextmenu-over-modal.png` / `after-contextmenu-under-modal.png`.
- **Scope:** update-note rendering and the C10 layer ordering changed; update check/download/apply behavior and data formats are unchanged.
- **Disclosure:** older clients (including v0.4.13) cannot retroactively render the notes; they need this build. The sanitizer is an allowlist, not a promise that arbitrary HTML is supported.
- **No data migration and no `schema_version` change.**

- Settings and API key remain in `%LOCALAPPDATA%\Memoria\config`; update check/download behavior is unchanged.
- After installing v0.4.14, the update dialog renders Release notes as formatted Markdown; before that, the same notes remain raw text.
