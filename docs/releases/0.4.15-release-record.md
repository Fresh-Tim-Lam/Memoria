## 4. 功能与回滚路径

- 更新页下载完成后新增「自动更新并重启」：用户确认后写 job JSON，启动独立 PowerShell helper，Memoria 退出。
- helper：等待父进程退出 → 复核 sha256 → 解压同盘 staging → 校验 `VERSION` / `Memoria.exe` → 保留 `config/` → 旧应用目录改名带时间戳 backup → staging 激活 → lite 保留 `hf/` → 启动新版本 → 写 `update-result.json`。
- 失败：未交换前不碰旧目录；交换后失败恢复 backup；结果在下一次启动显示。
- 真机 E2E：0.4.15 lite + mock 0.4.16 → 点击自动更新 → 约 5s 替换 → `VERSION=0.4.16`，`hf/`+`config/` 保留，backup 生成，result=success。证据 `artifacts/agent/verify/auto-update/`。
- 兼容边界：0.4.14 及更早没有此按钮，必须先手动升级到 0.4.15 才能使用一键更新。
