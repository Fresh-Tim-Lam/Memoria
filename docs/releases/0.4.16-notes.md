# Memoria v0.4.16

> 0.4.15 → 0.4.16：**轮次定位条短历史间距修复**。历史很短时，横条簇不再按比例拉满整条 rail；相邻横条最大间隔限制为 36px，簇不足 rail 高度时垂直居中。无数据迁移、无 `schema_version` 变化。0.4.15 的一键自动更新已可用于本版（0.4.15 → 0.4.16 是第一次可用一键更新的正式升级路径）。

## English

### Why upgrade

1. **Short chats get an aesthetic turn rail again.** With only a few turns, the rail used to stretch its ticks across the full 420 px height (dev CDP: 6 turns at tops `0,25,82,168,277,410`; max gap **133 px**). Ticks are now clamped to at most **36 px** apart and the whole cluster is vertically centered (`121,145,181,217,253,289`).
2. **Long histories keep the old behavior.** If the clamped cluster would exceed the rail height, the existing fill-the-height + minimum 10 px hit-gap fallback is used, so dense sessions do not overlap and remain navigable.
3. **This release exercises the 0.4.15 auto updater.** A v0.4.15 installation can now use **Update and restart automatically** to reach v0.4.16; older clients still need one manual upgrade to v0.4.15 first.

### New and changed

- `src/memoria/ui/static/app/js/agent-panel.js`: `RAIL_MAX_GAP_PX = 36`; each adjacent raw gap is clamped to `[10, 36]`; when the cluster fits, it is centered in the usable rail height; the old fill/min-gap path remains for dense histories.
- `tests/test_agent_panel_turn_rail_queue.py`: new pin for max gap, centering and dense-history fallback.
- Dev-only: annotation outline is now appended inside the shadow root, so hovering during pick mode no longer grows the page / causes a black screen (`eb237de7`; not shipped in the product bundle).

### Fixes and disclosures

- **Fix:** short-history rail ticks no longer fill the whole height.
- **Fix (dev-only):** dev annotation outline no longer shifts the page.
- **No data migration and no `schema_version` change.** Replacing the application folder is safe; knowledge bases are not rewritten.
- **Known debt:** full pytest is not rerun for this PATCH; targeted rail/annotator/update checks are the release-candidate verification. P08 and 0.5 multilevel graph remain undelivered.

### Verification (release-candidate targeted run)

- `pytest -q tests/test_agent_panel_turn_rail_queue.py tests/test_dev_annotator.py` → **9 passed**
- Dev CDP (Lead): 6-turn rail before `[0,25,82,168,277,410]` / max gap 133; after `[121,145,181,217,253,289]` / max gap 36, rail height 420 unchanged.
- `node --check agent-panel.js` and `node --check tools/dev-annotator/annotator.js` → PASS.
- Package format gates and `release_preflight` are run by the Lead on the release candidate. Full pytest is not claimed green.

## 中文

### 为什么要升级

1. **短对话的轮次定位条恢复正常观感。** 只有少数几轮时，旧实现会把横条按比例拉开到整条 420px rail（dev CDP：6 轮 tops `0,25,82,168,277,410`，最大间隔 **133px**）。现在相邻间隔最多 **36px**，整簇垂直居中（`121,145,181,217,253,289`）。
2. **长历史保持原行为。** 如果限制后的簇总高超过 rail，仍使用原来的“铺满高度 + 最小 10px 点击间距”回退，密集会话不会重叠、仍可导航。
3. **本版可以验证 0.4.15 的自动更新。** v0.4.15 用户现在可以用「自动更新并重启」升级到 v0.4.16；更早版本仍需先手动升级到 0.4.15。

### 新增与变更

- `src/memoria/ui/static/app/js/agent-panel.js`：新增 `RAIL_MAX_GAP_PX = 36`；每个原始相邻间隔限制在 `[10, 36]`；簇不足 rail 高度时垂直居中；密集历史仍走原来的铺满 + 最小间距路径。
- `tests/test_agent_panel_turn_rail_queue.py`：新增最大间隔/居中/密集回退的回归钉子。
- dev-only：批注 outline 改为挂进 shadow root，点选 hover 不再撑高页面/黑屏（`eb237de7`；不进入产品包）。

### 修复与披露

- **修复**：短历史 rail 横条不再拉满整条高度。
- **修复（dev-only）**：dev 批注板 outline 不再让页面位移。
- **无数据迁移、`schema_version` 不变。** 替换应用目录安全，知识库不会被改写。
- **已知债务**：本次 PATCH 未重跑全量 pytest；以上 rail/annotator/update 定向测试是发布候选验证。P08 与 0.5 多层级图谱仍未交付。
