# Memoria v0.4.17

> 0.4.16 → 0.4.17：**轮次定位条最大间隔再收紧**。`RAIL_MAX_GAP_PX` 从 36 降到 24；6 轮历史的横条簇更紧凑，仍垂直居中。无数据迁移、无 `schema_version` 变化。0.4.16 客户端可直接用一键自动更新升级到本版。

## English

### Why upgrade

1. **The short-history turn rail is tighter.** With only a few turns, 0.4.16 still left up to 36 px between ticks (6 turns: `121,145,181,217,253,289`). The cap is now **24 px**, so 6 turns sit at `145,169,193,217,241,265` — the same centered cluster, but visually denser.
2. **Long and dense histories are unchanged.** The 10 px minimum hit gap and the fill-the-height fallback for dense sessions still apply; the 28-turn window and wheel paging are untouched.
3. **This is a one-click target for 0.4.16.** Install/keep v0.4.16, check for updates, download, then use **Update and restart automatically** to reach v0.4.17.

### New and changed

- `src/memoria/ui/static/app/js/agent-panel.js`: `RAIL_MAX_GAP_PX 36 → 24`; cluster centering and dense-history fallback unchanged.
- `tests/test_agent_panel_turn_rail_queue.py`: updated pin to the 24 px layout.

### Fixes and disclosures

- **Fix:** short-history rail gaps are now capped at 24 px instead of 36 px.
- **No data migration and no `schema_version` change.**
- **Known debt:** full pytest is not rerun for this PATCH; targeted rail tests are the release-candidate verification. P08 and 0.5 multilevel graph remain undelivered.

### Verification (release-candidate targeted run)

- `pytest -q tests/test_agent_panel_turn_rail_queue.py` → **7 passed**
- Dev CDP (Lead), 6 turns, rail height 420: before (0.4.16) `[121,145,181,217,253,289]`, max gap 36; after `[145,169,193,217,241,265]`, all gaps 24; rail height unchanged.
- `node --check agent-panel.js` → PASS.
- Package format gates and `release_preflight` are run by the Lead on the release candidate. Full pytest is not claimed green.
