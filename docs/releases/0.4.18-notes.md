# Memoria v0.4.18

> 0.4.17 → 0.4.18：**冷启动蒙层与“最小化再打开”蒙层统一**。冷启动不再显示第二套星穹/标题/使用痕迹布局；splash 根层透明，视觉统一由 `#memoria-loading`（logo + Memoria + 状态 + Astral Veil 星场）承担。无数据迁移、无 `schema_version` 变化。0.4.17 客户端可直接一键更新到本版。

## English

### Why upgrade

1. **One mask instead of two.** Cold start used `#memoria-splash` (its own star field, brand, hint and usage-traces line), while minimize/restore used `#memoria-loading` (logo + Memoria word + status label). They looked inconsistent. Now the splash root is transparent and its own sky/inner/meteor are hidden, so the visible cold-start mask is exactly the restore mask.
2. **Splash behavior is preserved.** `splash.js` still owns the cold-start audio, settings and fade timing; only its visual layers are delegated to the loading overlay. No JS behavior change, no data migration, no `schema_version` change.
3. **0.4.17 can one-click to this version.** Check → Download → **Update and restart automatically**.

### New and changed

- `src/memoria/ui/static/app/css/app.css`: splash root transparent; `::-before`/`__sky`/`__inner`/`__meteor` hidden so `#memoria-loading` is the only visible mask.
- `tests/test_splash_animation.py`: new pin for the single-visible-mask contract.

### Fixes and disclosures

- **Fix:** cold-start and minimize/restore now share the same visible mask.
- **No data migration and no `schema_version` change.**
- **Known debt:** full pytest is not rerun for this PATCH; splash tests and dev CDP are the release-candidate verification. P08 and 0.5 multilevel graph remain undelivered.

### Verification (release-candidate targeted run)

- `pytest -q tests/test_splash_animation.py` → **18 passed**
- Dev CDP (Lead): cold start has `#memoria-splash` with `inner/sky display:none` and `#memoria-loading` visible (`logo`, `Memoria`, `Starting…`); blur+focus shows the same loading overlay (`Restoring window…`, detail `25 files`). Screenshots `artifacts/agent/verify/mask-sync/`.
- Package format gates and `release_preflight` are run by the Lead on the release candidate. Full pytest is not claimed green.
