### 未决设计 / 风险（逐条待裁决；todo-owner 不替人决定）

1. **Token 安全（最高风险）**：把可写 GitHub PAT 嵌入客户端=可被提取，任何人都能伪造计数/写仓库。待裁决：是否接受该风险，或改用**无客户端的计数后端**（如 Cloudflare Worker / 轻量 API）、GitHub Actions / issue 等替代方案。**本条目在裁决前禁止实现，且禁止写入任何真实 token。**
2. **页面与数据结构**：具体是 `site/index.html` 内写死静态数字，还是新增 `site/stats.json` 由页面读取；当日/总量字段名、时区（Asia/Shanghai）、并发写冲突（GitHub Contents API 409/sha）如何避免/重试，待设计。
3. **计数语义**：每次启动 +1，还是每日每设备一次；「当日」指启动次数还是去重用户数，需人确认。
4. **本地屏蔽判据**：开发模式 / `sys.frozen` / 环境变量 / 本地标记文件 / `Package-test/`（见 I-32）等；发布包与本地测试副本必须区分。
5. **后台任务约束**：不阻塞启动；超时/失败静默但**可诊断**；不重试风暴；离线不报错。
6. **隐私/披露**：是否告知用户会发送匿名启动计数；是否需要 opt-out。
