## 7. 建议顺序（0.4.13）

1. **M1+M3（0.5 天）**：targeted tests（已过 16）+ 全量 pytest 记录 + `node --check` / `i18n_selftest`；failed 项逐条归因（环境/既有/本版）。**若发现本版回归 ⇒ 转修，不发布**。
2. **M2（0.5–1 天）**：4 条真机/CDP 行为探针；结果落 `artifacts/agent/verify/release/0.4.13/`。
3. **（可选）S1/S2**：仅当 Owner 有余量且修复可独立验证；否则写入 notes known debts。
4. **发版准备（0.5 天，Lead/release-manager）**：版本号三处 bump（Lead 权限）→ `docs/releases/0.4.13-notes.md` 双语+造价+known debts → `release_preflight --phase pre`。
5. **构建/门禁（Lead）**：打包 → manifest/format gate → 冒烟 → `--phase post` → tag/Release/资产 → `--verify-published`。
6. **收尾**：release record + 0.4.13 台账收口（todo-owner）。
