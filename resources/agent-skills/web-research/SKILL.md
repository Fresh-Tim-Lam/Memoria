# 联网查资料（web-research）

> 本技能**随应用分发**（在知识库目录之外），它**没有**需要你另外读取的资源文件——照着下面做即可，
> 不要去读技能的资源目录（库外路径会被读取工具拒绝）。

## 1 先决定「该不该查」

联网是**有代价**的动作（一次检索 = 一次完整的模型调用，额外花 token），所以按顺序过三问：

1. 库内真的没有吗？——**先**用 `search_kb` / `grep` / `read_document` 之类的手段在库里找一遍；
   库里有的，一律以库内为准。
2. 用户是不是明确要了外部信息？——「查一下」「最新的」「官网上怎么说」这类才是授权。
   用户只是问一个你本来就能答的问题，**不要**顺手联网（他不会为此付钱的）。
3. 需要的是**外部事实**还是**你的判断**？——外部事实（版本号、发布日期、官方口径、某个网页里的原话）
   才需要联网；你自己的解释、总结、写法建议不需要。

三问都过不去 ⇒ 直接回答，并说明"库内没有相关内容"。**不要**为了显得勤奋而检索。

## 2 两把工具的代价与顺序

| 工具 | 给你什么 | 代价 |
|---|---|---|
| `web_search` | 标题 + URL + **摘要**，**不给正文** | 一次完整模型调用（贵） |
| `fetch_url` | 正文 → **落进待确认清单**，只回「路径 + 摘要 + 长度」 | 一次抓取（正文**不进你的上下文**） |

固定顺序：

1. **一次** `web_search`，关键词写**具体**（「Memoria 知识图谱 行号锚点」好过「Memoria」）；
2. 从结果里挑 **1–2 条**最相关的再 `fetch_url`；**不要**把 5 条全抓一遍；
3. 摘要就够回答的，**到此为止**，不必抓正文。

几条硬规矩：

- 结果里带 ⚠ 的条目是**域不在可抓取名单**里 —— 抓了必被拒（`WEB_BLOCKED_DOMAIN`），别白试；
  要抓请让用户在「设置 → Agent」里放行那个域。
- 同一个问题**不要**反复换关键词扫；两次没结果就如实说"没查到"，并给出你已经试过的关键词。
- 你写的 URL 必须**来自检索结果或用户原话**，不许凭印象拼一个。

## 3 抓完的内容放哪里

`fetch_url` 的正文落在**待确认清单**（`.memoria/pending.json`，草案态），**不会**进你的上下文 ——
这是省 token 的设计，不是故障。据此：

- 要用抓来的内容回答，先在**已有摘要**的基础上答；需要引用原文时，**请用户在面板上确认那条草案**，
  确认后它才成为库内容、才能按 `路径:行号` 引用；
- **不要**把长正文复制粘贴回对话里（那等于把刚省下的 token 又花掉）；
- 多页比对、抽表格这类**中间产物**写到**脚本工作区** `.memoria/agent/scratch/`：
  用 `scratch_write` 落文件（如 `web/notes.md`、`parse.py`），需要时 `scratch_read` 读回；
- 工作区里的脚本**你自己跑不了**：`scratch_*` 只有读 / 写 / 删 / 列，**没有运行工具**。
  写好之后**请用户点面板上的「运行」**，你看结果再继续。这是有意留给人手上的那道闸，别绕。

## 4 这四种情况必须停下来说清楚，不要硬凑

| 症状 | 错误码 | 你该说什么 |
|---|---|---|
| 出网总开关关着 | `WEB_DISABLED` | 让用户去「设置 → Agent」打开出网开关 |
| 本库没启用这项能力 | `capability_disabled` | 说"这个库没启用联网（检索 / 抓取）"，让用户去「能力插件」逐库启 |
| 目标域被名单挡了 | `WEB_BLOCKED_DOMAIN` | 说"这个域被禁止抓取"，让用户决定是否放行 |
| 抓下来的是草案 | —— | 说"已抓取，正文在待确认清单里，确认后才能引用" |

一律**如实转述**错误码与提示里那句话；**不要**换一条路偷偷绕过去（换域名、改设置、编造内容都算绕）。

## 5 引用口径

- 库内内容：`文件相对路径:行号`（例如 `neural-network.md:17`），行号取工具给的真实锚点；
- 联网内容：给出**标题 + URL**，并**明确标注这是外部来源**、不是知识库内容；
- 两者混在一段时分开写（"库内是 A；网上 B 的说法是……”），别让读者分不清哪句有库内依据。

## 6 不许做的事

- 不改用户的设置、不改域名名单、不改知识库正文（写库一律走 `propose_write` 的计划与确认）；
- 不抓私网 / 本机 / 内网地址（会被拒，且本就不该试）；
- 不把"没查到"写成"大概是这样"——**没查到就说没查到**，并说明下一步可以怎么查。
