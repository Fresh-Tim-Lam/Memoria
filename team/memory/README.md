# 记忆卡（Memory Cards）

> **用途**：把成员「学到的东西」压缩成**可注入的卡片**，招募新成员时随 prompt 注入 1–2 张，
> 省去重新学习 —— 但**不复制会话**（会话 42MB，卡 ≤8KB）。
>
> **为什么不是复制记忆**（2026-10-24 人的提议，经论证后调整为记忆卡）：
> | | 复制会话 | 记忆卡 |
> |---|---|---|
> | 体量 | 数十 MB | ≤8 KB |
> | 内容 | 全量（含已推翻的假设、已废弃的修法） | 裁决过的 |
> | 可审计 | 不能（黑盒） | 能（git 可 diff） |
> | 污染判断 | 会（继承错误框架） | 不会（明确标注"前人结论，需自验"） |
>
> **纪律**：卡里写的是「**前人认为**」，不是「事实」。使用前必须自验。
> 其中「**我试过但失败的路**」通常比「成功经验」更省时间。

## 目录约定

```
team/memory/<member-id>.md      ← 一个成员一张卡，**append 累积**（多任务不覆盖）
```

## 卡的结构（四段，缺一不可）

```markdown
## <member-id> · <任务/日期>

### 我确认的事实
- <结论> —— 证据：<file:line / commit sha / 命令输出>

### 我试过但失败的路
- <尝试> —— 失败原因：<...>  ← 这一段最有价值

### 我留下的坑 / 下一个人从哪开始
- <未完成/半成品/已知限制> —— 建议起点：<...>

### 我推翻过的假设
- 原以为 <...>，实测 <...> ⇒ 不要重走
```

## 注入方式

招募成员时在 prompt 里附上相关卡（**不是全量**），并前置免责句：

```
以下是前人（<id>）的裁决结论，不是客观事实。使用前必须自己验证；
其中"失败的路"通常比"成功经验"更有价值。
```

**配套**：`docs/guides/agent-team-lessons.md`（跨成员的通用判据，27 条）与
`docs/guides/lead-dispatch-rules.md`（Lead 的派发规范）。
**插件侧**：DSH `spawn_teammate` 的 `memoryCards` 参数（task-87，team-plugin-creator 实现中）。
